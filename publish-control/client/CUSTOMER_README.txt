漫剧发布助手 · 安装使用说明（Windows）
【第一步 · 必看】右键压缩包 → 全部解压缩 → 打开解压文件夹 → 双击 bootstrap.bat
前提（只有三条）
1. Windows 10 / 11 的电脑，能上网
2. 你的账号是这台电脑的管理员
3. 已装 Google Chrome。没装就双击包内 chrome-offline\ChromeStandaloneSetup64.exe（官方原版）
三步装好
1. 装：右键压缩包 → 全部解压缩 → 打开解压文件夹 → 双击 bootstrap.bat，通常约 1–3 分钟（以实际电脑为准）。装完自动完成授权，桌面只有一个快捷方式：「漫剧发布助手」，另有一个「发布素材」文件夹
2. 登录：双击桌面「漫剧发布助手」，在面板里给每个平台各扫一次码，每个平台一个灯；登录状态只保存在这台电脑上，下次打开不用再扫
3. 用：把要发的视频（mp4）直接复制进桌面「发布素材」文件夹，不要改名、不要再套一层文件夹；然后在飞书跟发布机器人发「发布」即可
加账号
面板顶部显示「已用 X / 4 个账号」；点「添加抖音账号」填名称 → 勾选平台（抖音/星图）→ 创建 → 开始登录扫码。停用保留历史数据，删除会二次确认并移入回收站。面板「发布节奏」区可设每天每个号发几条，并自由添加/修改/删除/启停发布时段，保存后重排未来草稿；已入队任务需服务商单独调整，草稿不会自动提交发布
| 能力 | 本版 |
|---|---|
| 抖音 | 登录、上传、填表、在飞书点「确认发布」后发布、抓后台数据：均须在你的真实账号上验收 |
| 星图 | 数据能力待现场验收 |
| 微信（视频号 / 公众号） | 本版未开通 |
| 小红书 | 本版未开通 |
遇到弹窗这样点
| 弹窗 | 怎么点 |
|---|---|
| Windows 已保护你的电脑 | 先联系服务商核对包的校验值，确认来源后再处理 |
| 杀毒软件提示 | 发提示内容给服务商核查 |
| 权限提示 | 是 |
| 电脑自动黑屏 / 自动睡眠 | 双击包内 fix-blackscreen.bat，关闭息屏、睡眠和屏保后重开面板 |
装完没授权 / 换了新电脑
正常情况下装完自动授权，不用填任何东西。若面板提示「未授权」，先确认电脑能上网，再点面板里的「重试自动授权」；仍不行就把桌面上的 install-log.txt 发我们，我们在后台处理，不需要你导入文件
有问题
把桌面上的 install-log.txt 发我们（完整日志在 %LOCALAPPDATA%\HuolongAgent\publish-worker\logs\install.log）；也可双击 selftest.bat 做自检（授权、浏览器、后台常驻、媒体工具、出错记录、存储、运行环境共 7 项），把结果一起发我们；解压就报错的话，换到 D:\ 再解压一次，并把截图发我们。
