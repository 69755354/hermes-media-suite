漫剧发布助手 · 安装使用说明（Windows）
【第一步 · 必看】右键压缩包 → 全部解压缩 → 打开解压文件夹 → 双击 bootstrap.bat
装之前不用卸载旧版：安装程序会自动停掉还在运行的旧版进程，并删掉电脑上的旧版本目录（放在桌面、下载里的旧包也一起清理），你的账号登录、发布素材和已排好的任务都不会动。
以后升级不用重装
新版本发布后，程序会自己更新，你不用再找安装包、也不用重新登录。看到面板顶部版本号变了就是升好了；如果提示更新失败，把桌面上的 install-log.txt 发我们。
前提（只有三条）
1. Windows 10 / 11 的电脑，能上网
2. 你的账号是这台电脑的管理员
3. 已装 Google Chrome。没装就双击包内 chrome-offline\ChromeStandaloneSetup64.exe（官方原版）
三步装好
1. 装：右键压缩包 → 全部解压缩 → 打开解压文件夹 → 双击 bootstrap.bat，通常约 1–3 分钟（以实际电脑为准）。装完会自动进入 14 天试用，不需要做任何授权操作；桌面只有一个快捷方式：「漫剧发布助手」，另有一个「发布素材」文件夹
2. 登录：双击桌面「漫剧发布助手」，在面板里给每个平台各扫一次码，每个平台一个灯；登录状态只保存在这台电脑上，下次打开不用再扫
3. 用：把要发的视频（mp4）直接复制进桌面「发布素材」文件夹，不要改名、不要再套一层文件夹；然后在飞书跟发布机器人发「发布」即可
加账号
面板顶部显示「已用 X / 4 个账号」；点「添加抖音账号」填名称 → 勾选平台（抖音/星图）→ 创建 → 开始登录扫码。停用保留历史数据，删除会二次确认并移入回收站。面板「发布节奏」区可设每天每个号发几条，并自由添加/修改/删除/启停发布时段，保存后重排未来草稿；已入队任务需服务商单独调整，草稿不会自动提交发布。
取数据 / 出表
在飞书跟机器人发「抓取数据」或「出表」：机器人会把这台电脑上登录的每个抖音号各取一遍，出一张 Excel，一个号一个工作表（页签就是账号昵称），另有「汇总」页看每个号的行数、播放量、星图有效播放和分成。某一轮某个号没取到（浏览器没开或登录失效），表里会沿用该号最近一次取到的数据，并在回复里注明，不会把那个号漏掉。
| 能力 | 本版 |
|---|---|
| 抖音 | 登录、上传、填表、在飞书点「确认发布」后发布、抓后台数据：均须在你的真实账号上验收 |
| 星图 | 登陆、任务匹配、有效播放/分成数据：须在你的真实账号上验收 |
| 微信（视频号 / 公众号） | 本版未开通 |
| 小红书 | 本版未开通 |

开通授权 / 试用到期 / 换了新电脑
这个新客户包不带预置的自动激活信息。装完会自动进入 14 天试用，不需要做任何授权操作；试用期内可以正常登录、抓数和发布。
试用到期、面板提示「未授权」，或换了新电脑时，按下面任一方式开通（优先用 8 位激活码）：
方式一：8 位激活码（推荐）
1. 双击桌面「漫剧发布助手」打开面板。
2. 点面板顶部的「查看机器码」，把显示的机器码发给我们。机器码也保存在 %LOCALAPPDATA%\HuolongAgent\publish-worker\logs\机器码.txt，可以直接把这个文件发给我们。
3. 我们收到机器码后会回复一串 8 位激活码。
4. 把激活码填进面板的「激活码」输入框，点「用激活码激活」。面板显示正式授权即完成。
方式二：导入 license.json（备用）
1. 先按方式一第 2 步取得机器码并发给我们，我们会签发 license.json 后发回。
2. 任选一种导入：a) 面板「授权维护 → 导入授权」选择 license.json；b) 把 license.json 拖到包内 import-license.bat 上（也可以先放进包内 license\ 文件夹再双击 import-license.bat）。
3. 面板显示正式授权即完成。
如果自检或安装日志提示「试用未创建」或「未激活且试用不可用」：把机器码和桌面上的 install-log.txt 发给我们，由我们人工恢复试用或签发 license.json。不要自己删除或修改授权文件，也不要反复重装。
换新电脑：在新电脑上重新装好，按方式一取机器码发给我们，重新开通授权。
有问题
把桌面上的 install-log.txt 发我们（完整日志在 %LOCALAPPDATA%\HuolongAgent\publish-worker\logs\install.log）；也可双击 selftest.bat 做自检（授权、浏览器、后台常驻、媒体工具、出错记录、存储、运行环境共 7 项，结果里包含机器码），把结果一起发我们；解压就报错的话，换到 D:\ 再解压一次，并把截图发我们。
