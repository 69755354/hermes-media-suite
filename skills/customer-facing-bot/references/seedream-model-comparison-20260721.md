# Seedream 模型选型对比（2026-07-21 实测）

## 核心结论

**Seedream 4.5 在写实人像上优于 5.0 Lite。** 5.0 Lite 虽然更清晰，但皮肤过于光滑、五官过于对称，一眼睛 AI 感，缺乏真人实拍的质感。

| 维度 | Seedream 4.5 | Seedream 5.0 Lite |
|:-----|:------------:|:-----------------:|
| 皮肤质感 | 有毛孔/细纹/自然纹理 | 过于光滑，塑料感 |
| 五官自然度 | 有不对称/瑕疵，更像真人 | 过于对称，AI 感重 |
| 写实人像 | ✅ 首选 | ❌ 太假 |
| 风景/物品 | 可用 | ✅ 更清晰 |
| 成本 | 0.22元/张 | 0.22元/张 |

## 踩坑记录

### 1. Prompt 中避免使用"小鹿"二字

`小鹿` 在中文里同时是人名和动物名。Seedream 图生图模式下，prompt 中出现「小鹿」会被理解成「一只小鹿/鹿科动物」，生成鹿的照片而不是人物。

**Fix:** 用「同一人物」「参考图人物」「保留参考图五官」替代。

### 2. 图生图比文生图更稳定

Seedream 4.5 的跨图一致性能力很强（百度百科验证），图生图模式下能较好地保留参考图的五官特征。如果要保持角色一致性，优先走图生图通道。

### 3. ARK file ID 可直接传 image_list

参考图在服务器本地无法上传到公网时，先调 ARK 文件上传 API 拿到 `file-xxx` ID，直接填入 `image_list` 数组即可。不需要公网 URL。

### 4. 尺寸最小 1440x2560

API 要求总像素 ≥3,686,400。9:16 竖屏最小可用尺寸 1440×2560。720×1280 会被拒绝。
