# WeChat DM Delivery Troubleshooting Guide

来源：用户自编排查指南（2026-07-12），结合 iLink Bot + Hermes 网关实测。

## 六大常见原因

### 一、白名单限制（最常见）

绝大多数微信 Bot（Wechaty、iLink、第三方云端机器人）默认开启好友白名单过滤：

- 只允许绑定的微信号发消息触发
- 其他好友不在白名单，消息直接被代码拦截，完全不进 AI 处理逻辑
- 部分工具默认只响应机器人自身账号消息，外部好友全部屏蔽

**解决：**
- 打开配置文件/机器人后台，找到「好友白名单」，把测试号的微信备注/昵称完整添加进去
- 关闭白名单模式，切换为「全部好友可触发」（生产环境不推荐）

**Hermes iLink 特定排查：**
- iLink Bot 基于腾讯云即时通信 IM + LightVela 微信通道
- 登录 IM 控制台 → 功能配置 → 好友与关系链 → 关闭「单聊消息检查」
- LightVela 管理台 → 通道 → 确认已接入通道列表

### 二、触发规则拦截（关键词 / 前缀 / @唤醒）

- 私聊设置了前缀触发：必须带 `!`、`#` 才调用 Bot
- 群聊仅 @触发：普通私聊不受影响，但群内不 @机器人完全无响应
- 仅自身账号免前缀，外部好友强制要求关键词

**解决：** 关闭「仅关键词/前缀触发」，或告知测试号带上指定前缀发送消息测试。

### 三、好友关系未建立（微信底层限制）

- 测试号没加机器人微信好友，或只是单向好友（只有机器人加对方）
- 很多协议不推送单向好友的私聊消息
- 对方把机器人拉黑/删除，消息发送成功但机器人收不到回调

**解决：** 互相添加好友，确认双向好友关系，重启机器人进程。

### 四、机器人账号掉线 / 实例冲突

- 绑定 Bot 的微信登录失效、协议掉线，只能收到本机自己发的消息，外部消息断流
- 多台设备同时运行同一个 Bot，进程抢占消息通道，外部消息丢失

**排查：** 打印消息日志，看有没有打印出外部小号发来的消息。日志无记录 = 账号掉线 / 协议失效。

**Hermes 特定排查：**
```bash
# 查网关日志
grep -i "inbound\|from=\|message" /home/ubuntu/.hermes/profiles/<profile>/logs/gateway.log

# 确认 session 未过期
grep "Session expired" /home/ubuntu/.hermes/profiles/<profile>/logs/gateway.log

# 检查 sync 轮询心跳
cat /home/ubuntu/.hermes/profiles/<profile>/weixin/accounts/*.sync.json
# 等10秒再看，buffer 应变化
```

### 五、Webhook / 后端超时丢消息（云端机器人）

- 第三方平台 Bot 依赖回调接口，AI 调用耗时过长（超过 5 秒），平台判定超时丢弃消息
- 服务器防火墙拦截微信回调域名，外部消息根本推不到 Bot

**排查：** 查看平台调用日志，确认是否收到外部好友的消息请求。

### 六、微信风控拦截（个人微信 Bot 高频踩坑）

- 微信对第三方协议机器人有消息过滤
- 陌生好友、新添加好友的消息，风控延迟推送甚至直接屏蔽
- 短时间大量陌生号发消息，触发限流，消息静默丢弃

**建议：** 新绑定的 iLink Bot 账号建议观察 24 小时，让账号稳定后再测试。

## 快速自测流程（5 分钟定位问题）

1. **用机器人自己的微信号发消息** → 能正常回复 → 代码、API、Bot 本身没问题，问题在好友过滤 / 触发规则
2. **查看机器人日志**，是否捕获到外部小号的消息：
   - 日志无消息 → 账号掉线、非双向好友、微信风控
   - 日志有消息但不回复 → 白名单、前缀关键词过滤
3. **临时关闭白名单、取消前缀触发**，重新用小号发消息测试

## 最简修复方案

1. 确认测试号与机器人双向好友
2. 后台移除好友白名单限制，或把小号备注加入白名单
3. 关闭「关键词/前缀触发」，允许全量私聊响应
4. 重启机器人服务，重新登录绑定微信号

## LightVela / 腾讯云 IM 对照

| iLink 问题 | 排查位置 | 期望配置 |
|:-----------|:---------|:---------|
| 好友消息检查 | IM 控制台 → 功能配置 → 好友与关系链 | 关闭「单聊消息检查」 |
| 回调配置 | IM 控制台 → 回调配置 | 正确设置回调 URL，勾选「发单聊消息」事件 |
| 通道授权 | LightVela 管理台 → 通道 | 确认已接入通道包含测试号 |
| 消息不转发 | getupdates 接口 | 检查 msgs 数组是否为空 |
