# Seedream 4.5 API 完整参数（2026-07-21 天行者验证版）

## 核心结论

Seedream 4.5（doubao-seedream-4.5 静态图模型）**完整支持参考图生图（图生图）**。

1. 支持模式：文生图、图生图、多参考图融合
2. 参考图上限：最多同时传入 **14张** 公网图片URL
3. 入参字段：**`image_list`** / `ref_img_url` 数组，仅接受 HTTP/HTTPS 公网图片链接
4. ❌ 参数名 `image` 无效 — 正确参数名是 `image_list`
5. ❌ Data URI 不支持 — 必须是公网可访问的 HTTP/HTTPS URL

## 定位区分

| 模型 | 用途 | 参考图参数 |
|:-----|:-----|:-----------|
| **Seedream 4.5** | 生成**静态图片** | `image_list`（公网URL数组） |
| **Seedance 2.0 Mini** | 生成**视频片段** | `reference_image`（驱动视频人物样貌） |

## 端点

```
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Authorization: Bearer <ARK_API_KEY>
```

## 合法入参白名单

| 参数 | 类型 | 说明 |
|:-----|:-----|:------|
| `prompt` | string | 正向提示词 |
| `negative_prompt` | string | 负向提示词 |
| `image_list` | string[] | 公网图片URL数组，最多14张 |
| `size` | string | 分辨率（见下方规则） |
| `n` | int | 每次生成1张（多张可能被拒） |
| `watermark` | bool | **必须传 `false`** |

## 分辨率规则（API实际强制要求）

**API硬性要求：总像素 ≥ 3,686,400。**

天行者规定的规范写「默认720×1280」，但实测720×1280（921,600px）会被API拒绝。实际可用的最小9:16尺寸：

| 场景 | 尺寸 | 像素 | 状态 |
|:-----|:-----|:----:|:----:|
| 默认竖屏9:16 | **1440×2560** | 3,686,400 ✅ | API最小达标值 |
| 默认正方形 | **1920×1920** | 3,686,400 ✅ | 通用 |
| 强制高清 | 2160×3840 | 8,294,400 ✅ | 强制要求时用 |
| ❌ 720×1280 | 921,600 | ❌ | API拒绝（像素不够） |

**注意：** 生成成功后的输出图片包含 `size` 字段，实际尺寸 = 传入的 `size` 参数。

## 脚本用法

文件：`scripts/seedream_gen.sh`（支持文生图/图生图两种模式）

```bash
# 文生图：自动拼小鹿特征+质感描述
bash seedream_gen.sh                    # 默认小鹿形象照
bash seedream_gen.sh "穿红色连衣裙"     # 小鹿穿红色连衣裙

# 图生图：带参考图URL
bash seedream_gen.sh --ref_url "https://图URL" "自定义prompt"
```

脚本自动处理：
- 文生图：小鹿人物特征 + 用户描述 + 质感描述 + 负向提示词
- 图生图：用户prompt + 负向提示词 + image_list
- 默认尺寸1440×2560（满足API最小像素要求）
- 负向提示词统一加载（杜绝AI假人）

## 参考图注意事项

- 参考图需要是**公网可访问的HTTP/HTTPS链接**，不支持data URI
- 国内服务器可能无法上传到外网图床 — 替代方案：用 `vision_analyze` 分析参考图特征 → 写详细prompt → 走文生图
- 图生图的prompt应根据参考图**实际内容**来写（门店场景写门店、人像写人像），不要用固定模板
