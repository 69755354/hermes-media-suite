# 工作流工具升级 + 审批门禁模式（2026-07-20）

## 背景

飞书小鹿（customer profile bot）的工作流有大量步骤根本执行不了——因为她是纯对话AI，没有 `read_file`、`write_file`、`web_search`、`vision_analyze`、API调用等工具。流程写了「读行业策略文档」「写复盘报告」「搜爆款验证」但她永远做不到，只能假装完成或卡住。

## 修复方案：三步走

### Step 1: 开通工具权限（工作流豁免）

在 SOUL.md 的「禁止自作主张」下加工具白名单：

```markdown
**🟢 工作流豁免（以下工具调用不算「自作主张」）：**
- `read_file` → 读行业知识库/接力文件/用户配置
- `write_file` → 写接力文档/复盘报告
- `web_search` → 搜爆款/搜数据验证
- `vision_analyze` → 看客户发的图片
- `create_video` / 文生图API → 出片/出图（需客户确认后）
- 以上工具只能在执行工作流指定步骤时调用，不准私自乱调
```

### Step 2: 安全规则加豁免

不改安全规则的话，即使开了工具白名单，安全规则也会拦截。需要修改的规则：

| 规则 | 加什么豁免 |
|:----|:----------|
| 路径/文件结构零容忍 | 「内部工作流 `read_file` 读知识库/接力文件属于内部操作」 |
| 禁止读服务器文件（含路径的） | 「工作流 `read_file` 调用例外，只限于行业知识库和接力文件」 |
| 禁止调API | 「工作流中明确要求的工具调用除外」 |

### Step 3: 重写工作流步骤

把「读文档」「写文件」「搜数据」这些模糊描述改成具体的工具调用指令：

| ❌ 旧写法 | ✅ 新写法 |
|:----------|:----------|
| 读对应行业策略文档（wiki/concepts/...） | `` `read_file` 读行业策略速查表 `` |
| 搜近期爆款验证方向 | `` `web_search` 搜近期爆款验证方向 `` |
| 写复盘报告到 wiki/cases/ | `` `write_file` 写复盘报告 `` |
| 用文生图生成配图 | 调用文生图API生成配图 |

### Step 4（新增）：天行者审批门禁

开通工具权限后，客户一句话就能触发 `create_video` 产生费用。必须有审批拦截：

```
客户说不用改
  ↓
`write_file` 写审批请求到 /tmp/projects/<项目名>/审批.md
  ↓
告诉客户：「文案定了，提交老大审批中，批了就出片～」
  ↓
**【等待天行者审批】**（不往下走）
  ↓
天行者批了 → create_video 出片
```

**审批文件格式：**
```yaml
项目: <项目名>
行业: <行业>
客户: <客户ID>
文案: <文案全文>
状态: 待审批
```

## 常见坑

1. **只做 Step 1 不做 Step 2** — 安全规则拦截，工具白名单无效。三个步骤缺一不可。
2. **只做 Step 1-3 不做 Step 4** — 客户可无审批触发付费API。Step 4 是费用安全门。
3. **行业知识库速查表代替文件读取** — 纯对话AI（无 read_file）时，把知识库核心策略浓缩后直接注入 SOUL.md 的速查表，比让 bot 读文件更可靠。
