# 飞书开发者后台权限配置清单

## 症状：机器人拉进群但@不理你

飞书机器人能正常连接（gateway_state 显示 connected），也能收到消息（网关日志有 influx 记录），但发出的回复在群里看不到 → 通常是飞书开发者后台权限没开齐。

## 必开权限列表

登录飞书开发者后台（https://open.feishu.cn/app）→ 找到你的应用 → 左侧菜单：

### 1️⃣ 权限管理 → 需审核权限

| 权限 KEY | 用途 | 必开 |
|:---------|:-----|:----:|
| `im:message` | 接收和发送消息 | ✅ |
| `im:message:send_as_bot` | 以机器人身份发送消息 | ✅ |
| `im:chat:readonly` | 读取群组信息（群聊场景需要） | ✅ |
| `contact:user.employee_id:readonly` | 读取用户信息 | ⚠️ 按需 |

**操作：**
- 在「需审核权限」标签页搜索框搜以上权限
- 点「开通」→ 弹窗确认
- **需要飞书管理员审核**（如果应用是企业自建）

### 2️⃣ 事件订阅

| 事件 KEY | 用途 | 必开 |
|:---------|:-----|:----:|
| `im.message.receive_v1` | 接收所有消息（私聊+群聊） | ✅ |

**操作：**
- 左侧菜单 → 事件与回调 → 添加事件
- 搜索 `im.message.receive_v1`
- 确认后保存

### 3️⃣ 应用功能配置

- 左侧菜单 → 应用能力 → 机器人
- 确保「机器人」已开启 ✅
- 不需要额外群聊开关（`im.message.receive_v1` 自动覆盖群聊）

## 添加权限后

```bash
# 1. 重新发布应用（开发者后台右上角「发布」）
# 2. 重启网关
```

**注意：** 飞书开放平台**不强制重启**，但建议等 1-2 分钟让权限缓存刷新后再试。

## 常见排查

| 现象 | 原因 | 解决 |
|:----|:-----|:-----|
| 网关日志显示 `response ready` 但群看不到回复 | 没开 `im:message:send_as_bot` | 开权限后重新发布 |
| 网关日志收不到群消息 | 没加 `im.message.receive_v1` 事件 | 加事件后重新发布 |
| 权限开通但依然不行 | 应用没重新发布 | 点右上角「发布」 |
| 发布后在群里@bot还是不回 | 群策略是 `allowlist` | 配 `FEISHU_GROUP_POLICY=open` |
