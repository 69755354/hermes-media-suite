# Bot角色形象照生成

> 给聊天机器人/数字助手设定视觉形象。用户说「给小X设计个形象」时调用。

## 场景

- 用户问「小天是不是得给自己设置个形象？」
- 用户说「比如自拍图片之类的」「头像图」
- 需要一张静态自拍头像，不是视频角色的彩铅三视图

## 工作流

### 第一步：定风格

直接问用户，或从上下文推断：

| 维度 | 示例 |
|:----|:-----|
| 性别风格 | 治愈系小姐姐 / 清爽小哥哥 / 国风 |
| 参考人物 | 「用小鹿的照片」→ 找已有参考图 |
| 背景氛围 | 温暖居家 / 茶室 / 户外阳光 / 工作室 |
| 画风 | 写实 / 卡通 / 文艺 |

### 第二步：找参考图

1. 如果用户给了参考人物照片 — 从照片提取外貌特征（脸型/五官/发型/穿搭）
2. 如果用户只说风格 — 自行设计外貌方案，写入prompt
3. 检查 `/home/ubuntu/assets/characters/` 是否有现成参考图

### 第三步：调用Helper API生成

**端点：** `POST localhost:1888/seedream`
**模型：** doubao-seedream-4-5（helper API已封装，无需直接选模型）

**请求：**
```bash
curl -s -X POST http://localhost:1888/seedream \
  -H "Content-Type: application/json" \
  -d '{"prompt": "详细的画面描述"}'
```

### 第四步：Prompt写作模板

**标准结构：**
```
[风格]自拍头像，[人物外貌描述]，[背景场景描述，含色调/光线/氛围]，
[表情]看镜头，自然光自拍视角，高清写实，皮肤质感真实
```

**成功案例（小天·基于小鹿形象）：**
```
治愈系小姐姐自拍头像，白色方领吊带，碎花短裙，茶棕微卷锁骨发，
金色项链和耳钉，温暖居家氛围，暖光落地窗边，木质地板上洒满午后阳光，
绿植盆栽，米白色棉麻沙发，原木茶几上一杯热茶冒着白气，
画面整体暖黄色调柔和温馨，浅笑看镜头，自然光自拍视角，
高清写实，皮肤质感真实
```

### 第五步：图片下载 & 保存

```bash
curl -s -o /home/ubuntu/assets/characters/<bot名>_<风格>.jpg "<image_url>"
```

### 第六步：用户确认

- 用户满意 → 标记为正式头像，记录文件路径
- 用户要改 → **保持人物特征不变，只改背景/穿搭/表情/色调**
  - 改背景温馨 → 改背景段，不改人物段
  - 改穿搭 → 穿搭段改，五官脸型不改

### ⚠️ 常见陷阱

#### 🚨 坑1：用真实人物照片生成bot头像 = 暴露身份

**症状：** 用户说"太宝路了，暴露"。

**原因：** 用真实人物（如小鹿本人照）做参考图生成bot头像 → 头像太像真人 → 客户一眼看出"这是那个小鹿"，bot角色的独立人格感被破坏。

**正确做法：**
- 用真实人物照做**灵感参考**（描述prompt时借鉴风格/氛围），**不要做reference image**
- prompt中描述"像小鹿一样干净"等气质类词汇，但不锁定五官
- 让Seedream自由发挥，生成一个"有这个feel但不是同一个人"的新形象

#### 🚨 坑2：多版本迭代保持人物一致

用户可能会要多个版本（全身/大头/不同背景），每次重新生成时：

1. **不要换脸** — 保存上一版prompt的人物描述段，新版本只改背景/构图/视角段
2. **换背景不改穿搭** — 除非用户明确说换衣服
3. **每一版都保存** — 命名规则：`<bot名>_<版本名>.jpg`

示例命名：`xiaolu_portrait.jpg`（第一版全身）、`xiaolu_warm.jpg`（改背景暖调）、`xiaolu_closeup.jpg`（大头特写）

### 🎨 Prompt迭代技巧

| 需求 | 做法 |
|:----|:-----|
| 用户说"背景温馨点" | 保留人物段，替换背景段：暖光窗边、绿植、毛毯、热茶、暖黄色调 |
| 用户说"来个大头照" | 保留人物段，构图改为"胸部以上特写"、"背景虚化奶油感" |
| 用户说"换个穿搭" | 保留五官/发型段，替换穿搭描述 |
| 用户说"太像本人了" | 重新设计人物（换发型/换穿搭/微调气质关键词），不锁参考图 |

## 关键原则

| 原则 | 说明 |
|:----|:-----|
| 人物一致性 | 一旦用户确认了长相，后续迭代**只改背景/穿搭/色调**，不换脸 |
| 参考图复用 | 已有assets参考图的角色，复用时保持特征一致 |
| Prompt分段 | 人物段/背景段/画质段分开写，方便单段替换不改他段 |
| 暴露防护 | 真实人物照只做灵感，不做reference image锁脸 |
