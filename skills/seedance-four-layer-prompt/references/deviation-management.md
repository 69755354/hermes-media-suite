# 四层Prompt生产法（Seedance偏差管理范式）

## 核心思想

prompt的本质是**偏差管理**，不是画面描述。用「全局固定前缀+正向补充+专属负面」三段式取代纯九模块描述。

## 四层结构

```
第一层：导演意图（1-2句人话）
  这镜的情绪核心？观众看到什么感受？
  → 不写机器指令，纯人类语言

第二层：全局锁定（复制粘贴，整片共用）
  锁站位/锁机位/锁光影/锁人物/锁衣服
  量化参数：位移≤2mm、动态强度X%、焦距50mm
  → 每段prompt开头，权重最高

第三层：正向补充（本镜专属动作指令）
  这段要发生什么？多久完成？
  写行为不写情绪——不是「开心」是「笑肌2秒匀速抬升」
  → 用参数控制：「X秒内完成」「匀速XX」

第四层：专属负面（堵死本镜跑偏路）
  这段AI最可能怎么崩？
  → 不是通用词，是本镜专属的崩法
```

## 动态强度分层参考表

| 动作类型 | 动态强度 | 说明 |
|:--------|:--------:|:-----|
| 抬头/低头/转头 | 38%~40% | 头部角度有明显变化 |
| 收笑/表情切换 | 35%~38% | 面部有变化但幅度不大 |
| 静态情绪（得意/放空） | 30%~32% | 只有呼吸级微动 |
| 强忍泪/高潮情绪 | 30%~32% | 情绪饱满但动作极少 |

## 接力锁脸SOP

1. 第1段用初始master_ref或彩绘四视图
2. 生成完成 → 截取最后1帧最清晰人脸画面
3. 尾帧base64编码 → 作为第2段参考图
4. 重复，每段接力

## 专属负面高频词库（按场景分类）

| 场景 | 常见崩法 | 负面词 |
|:----|:---------|:-------|
| 抬头 | 幅度过大、晃动 | 抬头幅度过大、头部晃动 |
| 微笑 | 咧嘴、假笑、突然爆笑 | 咧嘴大笑、表情僵硬、歪头 |
| 收笑 | 收笑慢、嘴角抽 | 咧嘴、挑眉、面部大幅度形变 |
| 委屈 | 眼眶红肿、撇嘴 | 眼眶红肿、皱眉、撇嘴 |
| 放空 | 频繁眨眼、眼神乱动 | 频繁眨眼、眼神乱动 |
| 忍泪 | 眼泪滑落、泪痕 | 眼泪滑落、泪痕、表情狰狞 |

## 通用负面词（每段必加）

侧身、转体、肩膀偏移、身体歪斜、五官变形、人脸漂移、镜头晃动、变焦、碎发、手部出镜、肢体动作、流泪、泪痕、大面积眼周红肿

## 抽卡策略

- 高风险段（表情切换/忍泪）：每段多跑2-3次，选最优
- 侧身/歪肩 → 负面词里标注(侧身:1.8)重跑
- 表情完全无变化 → 动态强度提高2%~3%

## 后期拼接

1. 每段首尾衔接处各剪掉1帧
2. 统一调色预设抹平段间光影差异
3. 整体0.9x慢放让微表情过渡丝滑
