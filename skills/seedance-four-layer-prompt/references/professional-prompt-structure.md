# 专业级Seedance Prompt结构（麦芽菜法）

> 来源：抖音@麦芽菜「AIGC情绪表演提示词」合集
> 实测级别：已验证可生成15秒专业级微表情短片

## 一、核心思想

普通prompt写「发生了什么」（文学描述）
专业prompt写「肌肉执行了什么指令」（机器指令）

```
普通：她很开心地笑了
专业：笑肌0.1秒瞬间卸力，把笑容完全收回到口腔内，只在嘴角留下1mm的浅括弧

普通：她委屈得想哭
专业：下眼睑泪腺附近1mm范围突然泛出薄红，虹膜对焦突然虚掉0.3秒

普通：她强忍着不让眼泪掉下来
专业：眼泪已经在眼眶里打转却强忍着没掉下来，鼻孔微扩张0.2mm，上唇掀开1mm缝隙维持0.5s
```

## 二、完整结构模板

```
一、基础设定
[模型版本/风格声明]
[全程禁止项]
[镜头参数：固定机位+焦段+景别，零位移零变焦]
[光线设定：冷/暖调+方向+精度]
[背景设定：虚化程度+内容]
[肌肉约束：全局最大位移量]
[动作约束：禁止动作清单]
[视线落点：精确到画外位置+角度]
[人物锚点：发型/服饰/配饰精确对齐]
[全程禁止：眼泪/泪痕/挤眼/皱眉等]

二、分镜动作设定

[时间1]-[时间2]s [情绪标签]：
[起始姿势]
[动作序列：每0.X秒完成什么]
[微表情：精确到哪块肌肉]
[生理细节：皮肤颜色/瞳孔变化/肌肉跳动]
[视线变化：精确落点]
[排除项]

[时间2]-[时间3]s [情绪标签]：
...同上...

三、负面提示词
[全局负面：大颗泪珠、全范围泛红、大幅动作等]

四、画质要求
[帧率+顺滑度+禁止瑕疵]
```

## 三、关键技巧

### 3.1 肌肉级描述法

| 要表达的情绪 | 普通写法（不要用） | 专业写法（用这个） |
|:-----------|:-----------------|:-----------------|
| 开心 | 开怀大笑 | 笑肌2秒极慢抬升，最后半帧才抬出全部6颗下齿露笑 |
| 得意 | 暗自开心 | 笑肌0.1秒瞬间卸力，笑容收回口腔，嘴角留1mm括弧，瞳孔收缩半格 |
| 委屈 | 委屈想哭 | 下眼睑泪腺附近1mm范围泛薄红，虹膜虚掉0.3秒，上唇不受控跳0.2秒 |
| 沉思 | 陷入沉思 | 上眼睑匀速下移盖虹膜35%，睫毛1次/秒轻颤3次 |
| 释怀 | 释然了 | 鼻孔扩张0.2mm，上唇掀1mm，锁骨隆起0.5mm |
| 意难平 | 忍不住要哭 | 泪光积满不落，眼角鼻梁耳尖全部生理泛红，嘴角硬扯微笑 |

### 3.2 时间分段法

```
15秒标准结构：
0-2s   情绪A（起始态）
2-5s   情绪B（第一次切换）
5-7s   情绪C（快速切换）
7-11.5s 情绪D（稳定态，有细节变化）
11.5-13s 情绪E（第二次切换）
13-15s  情绪F（收尾定格）
```

每段的切换点精确到0.1秒级瞬变，没有慢过渡缓冲。

### 3.3 生理细节三件套

每段情绪变化时，加入以下三个生理维度中的至少两个：
1. **皮肤颜色变化**：泛薄红/淡粉潮红/耳朵尖红
2. **微肌肉跳动**：上唇不受控跳/睫毛轻颤/鼻孔翕动
3. **体液/光学变化**：泪光积满/瞳孔收缩/虹膜虚焦

### 3.4 视线控制

情绪表演的核心在于视线落点。每个时间段的视线必须精确指定：
- 画外左方（肩膀水平位置，因对方身高需要微抬）
- 围巾中心点/胸口
- 镜头偏下5cm
- 画外下方

全程禁止"眼神乱动"——视线只在这几个落点间切换。

### 3.5 反向约束（写什么不要比写什么要更重要）

每段必须标注：
- 禁止眼泪流下（要含泪不流）
- 禁止挤眼/皱眉
- 禁止大幅度转头
- 禁止多余手部动作
- 禁止B级片式夸张演技

## 四、与四层Prompt法的关系

专业prompt结构 = 四层法的超集

| 四层法 | 专业结构中的对应 |
|:-------|:----------------|
| 第一层 导演意图 | 情绪标签（如「幸福态」「藏得意」） |
| 第二层 全局锁定 | 一、基础设定（更精确，含mm级肌肉约束） |
| 第三层 正向补充 | 二、分镜动作设定（时间精确到0.1秒） |
| 第四层 专属负面 | 三、负面提示词 + 每段末的「眼睛无泪」 |

## 五、常见错误

1. ❌ 用情绪词代替肌肉指令（「开心」→ 应写「笑肌2秒抬升」）
2. ❌ 情绪切换有过渡缓冲（应0.1秒瞬变，无过渡）
3. ❌ 视线落点模糊（应精确到「画外左方肩膀水平」）
4. ❌ 缺少全局约束（「面部最大位移≤2mm」必须有）
5. ❌ 眼泪控制不精确（「含泪不流」和「眼泪流下」是两回事）
