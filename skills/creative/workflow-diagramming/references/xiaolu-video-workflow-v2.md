## 完整链路（唯一入口，SOUL 265 行「做视频流程」）

```
客户说"做个视频"（触发：做视频/探店/口播/剧情）
↓
① 搜集客户信息：店名/地址/实景照/内容类型——只问客户独有的，平台不问
↓
② 用户画像分析：受众是谁——机器人内部做，白话版同步客户
↓
③ 平台选择（不问客户，禁止问「你准备发哪个平台」）：
   实体店同城→抖音｜干货→B站/公众号｜种草→小红书｜私域→视频号｜老铁→快手
   客户主动指定→按其指定
↓
④ 平台打法分析：内容形式/爆款逻辑/合规/账号打法
↓
⑤ 爆款拆解：按选定平台搜（小红书拆小红书、抖音拆抖音）→ 3点法
↓
⑥ 选题（按平台选）
↓
⑦ 写文案（按平台适配）→ 只问「需要修改不？」
↓
🔴 人工确认点 node4_copy（confirm_gate.py 拦截，未确认 exit 非0）
↓
权限检查（permissions.json level 字段）：
├─ basic → 「视频/图片生成不支持，文案类正常，升级请联系管理员」→ 结束
└─ normal → 今日配额（/tmp/projects/quota_日期.json）
   ├─ 已用≥1条 → 「今日视频配额已用完，明天再来」→ 结束
   └─ 未超 → 扣配额（视频+1）→ 出片
      ├─ 探店 → Seedance 多场景逐镜（8s人物/12s特写；需门头+店内照片）
      ├─ 剧情 → Seedance（单人1场景/双人2场景；转场≤1；禁性别对立/阶层对立）
      └─ 口播 → 婵镜 create_video 数字人（emotion_oral/view_oral/knowledge_oral；必须穿插Broll）
      ↓
      🔴 node8_image 生图确认（走生图时）
      🔴 node12_render 出片确认（confirm_gate）
      ↓
      成功 → 发下载链接（只发链接不说技术细节；优先直接发视频本体）
      失败 → write_file 调度请求.md + 告知天行者手动处理
↓
交付后 → 复盘报告 wiki/cases/<项目名>_复盘.md（不写不准接下一单）
```

## 3 个人工确认点（confirm_gate.py）

- node4_copy 文案 / node8_image 生图 / node12_render 出片
- 未确认 exit 非0 拦截；客户说「跳过/直接出片/不用给我看」→ 全放行（合法跳过路径）

| ⑥ 选题 | codex + 外部校准（搜了啥/对比了啥） |
| ⑦ 写文案 | codex（创作类）+ 合规红线 + 知识库引用 |
| 确认点 | confirm_gate.py（人工门） |
| 权限/配额 | permissions.json + 配额文件 |
| 出片 | huoshan 三通道 + Seedance/婵镜 API + 节点执行铁律 |
| 交付 | 原生发送优先（文件太大再发链接） |

## 陪跑服务机制

- 新客户：每个节点出活后转白话版发客户（「这一步我们做了XX」），只有人工选择点才停等输入
- 老客户：说「跳过确认/直接出片」→ 一次直达出片，只发关键节点

## 配套机制

- 接力文档：`/tmp/projects/<项目名>/` 节点0_项目简报 → 节点1_用户画像 → 节点2_爆款分析 → 节点3_选题定稿+外部校准 → 节点4_剧本定稿…；节点N 开工前必读节点N-1，排雷项不准违背
- 知识库物理闸：knowledge_gate.py check/mark/verify，未查知识库 BLOCK
- 内容创作类必须先调 codex（codex_remote.sh），禁 DS 直出；拿不准按「错得起/错不起」判
- 对客户禁提工具名/路径/平台（只大白话）
