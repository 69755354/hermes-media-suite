# Seedance 2.0 官方提示词公式

> 来源：ByteDance Seed 官方博客（seed.bytedance.com）+ 即梦官方操作手册 + 火山引擎方舟文档。本会话2026-07-11交叉验证。

## 万能公式（8维度，严格按此顺序）

```
①主体 → ②动作 → ③场景 → ④光影 → ⑤镜头语言 → ⑥风格 → ⑦画质 → ⑧约束
```

### 各维度写法规则

| 维度 | 要求 | ✅ 正确示例 | ❌ 错误示例 |
|:----|:----|:-----------|:-----------|
| **①主体** | 用@引用参考图，写具体特征 | `@图1 年轻女生白色亚麻连衣裙` | 「一个女生」「漂亮女生」 |
| **②动作** | 写慢写连续，优先用「缓慢」「轻柔」「自然」 | 从远处走向门头，脚步自然，走到入口前停步 | 跳舞、剧烈跑动、快速跳跃 |
| **③场景** | 具体空间+1-2个环境细节 | 熹园门头小青瓦木廊，绿植藤蔓环绕 | 好看的地方、环境幽静 |
| **④光影** | 具体光源+方向+色温 | 午后暖光从门头侧上方打亮侧脸 | 光线好看、氛围感 |
| **⑤镜头语言** | 选1个景别+1个运镜，越简单越稳 | 远景横向跟摇，人物占画面四分之一 | 多运镜混用 |
| **⑥风格** | 明确风格方向 | 照片级写实，无CG感，有胶片感 | 高端、大气、高级感 |
| **⑦画质** | 具体清晰度参数 | 面部稳定不变形，画面清晰稳定，色彩自然 | 高清好看 |
| **⑧约束** | 防变形防崩脸，**必写** | 面部稳定不变形，五官清晰，人体结构正常 | 缺约束 |

## 官方五条铁律

1. **不用抽象形容词** — 「好看」「很美」AI听不懂，换成具体描述
2. **动作不写笼统词** — 不写「跳舞」「走路」，写「缓慢转身」「轻轻抬手」
3. **镜头选一个** — 近景/中景/全景/特写选1个，运镜选1个
4. **约束词必写** — 防变脸变形，每个prompt都带「面部稳定不变形，五官清晰，人体结构正常」
5. **@引用要精确** — 谁是谁要写清楚，禁止混用@图编号

## 官方示例

```
一位年轻女生在林间缓慢行走，微风轻拂头发，自然微笑，
暖色阳光透过树叶洒下斑驳光影，
中景，缓慢推镜，画面流畅稳定无抖动，
4K高清，电影感，面部清晰不变形，人体结构正常，细节丰富。
```

## 本会话验证的店主播报格式

> 适用于店主本人出镜、真人照直传火山的场景。

```
@图1 作为真人[性别][年龄][脸型五官发型穿搭]全部特征不变不戴墨镜眼神自然；
照片级写实，无CG感，天然肌肤质感；
[景别]机位[场景]占画面三分之二人物从[方向]走向[位置]占四分之一；
[时间/天气]自然光暖调，[环境细节]；
[人物]从[方向]走向[位置]，脚步自然视线看向[方向]，走到[位置]前自然停步，略微侧身看向[方位]，眼神[情绪]；
动态强度[数字]%；
同步生成中文[旁白/探店人声]：[语速/语气/情绪]；
旁白内容：[台词，不加引号]；
@图2 作为[场景]实景照，[场景特征]完整露出不虚化；
[运镜/画质]；[帧率]fps；

专属负面：[具体禁止项]
```

**注意：** 最后一行「专属负面」虽与官方「全正向」建议不同，但本会话实测保留该行不产生负面影响，用户也已确认此格式为工作版本。不主动删除。
