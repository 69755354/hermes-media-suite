# Seedream 写真人像五层提示词结构

> 来源：天行者定稿 2026-07-21
> 适用模型：Seedream 4.5（doubao-seedream-4-5-251128）
> 默认尺寸：1440×2560（9:16竖屏，满足最低368万像素）

---

## 五层固定结构（权重从前到后逐级降低）

### 层级1：主体基础层（最高权重）
**作用：** 锁定人物长相，防止每次生成长相大变
**要素：** 年龄、身高、人种、脸型、五官细节（眼/鼻/唇/眉）、发色发型刘海、气质约束

**⚠️ 铁律：**
- 只写AI能执行的具体描述，不写抽象词（如「邻家感」「真实感」「像身边认识的女孩」— AI无法理解）
- 「校园风格，非网红精致路线」「五官比例普通标准」比「自然不极致精致」更有效
- 固定年龄+身高（如24岁、170cm）锚定体型区间

### 层级2：肤质妆容层（第二权重）
**作用：** 单独管控皮肤质感，只写正向生理细节
**要素：** 妆面程度、毛孔/油光/唇纹/细纹、肤色过渡

**⚠️ 铁律：**
- 无否定词（否定词全部归到负面提示词模块）
- 可用英文关键词提升精确度：`vellus hair, subsurface scattering`
- 保留「保留原生肤色不均、自然皮肤纹理」而不是强调「干净均匀」

### 层级3：体态情绪穿搭层（独立情绪模块）
**作用：** 控制画面氛围感，避免摆拍感
**要素：** 构图（半身/全身）、穿搭（上衣/下装/鞋/首饰）、身材描述、姿态微表情

**⚠️ 铁律：**
- 穿搭要写完整（上衣+下装+鞋+配饰），否则AI自由发挥
- 「松弛浅笑」比「温柔浅笑」更具体
- 「正常正面平视角度」比「不要俯拍」更有效（正向指令优于负向）

### 层级4：镜头光影构图层
**作用：** 统一光影逻辑，固定镜头规格
**要素：** 光源方向位置、光圈焦段、景深

**⚠️ 铁律：**
- 「窗边侧光45度方向」比「室内暖柔光」更真实（光线越柔越假）
- 全身像时浅景深要合理（35mm f1.8在全身像上景深不会太浅）
- 不写「手机前置摄像头质感」除非明确要手机风格

### 层级5：场景氛围画质层（最低权重）
**作用：** 限定场景、色调、质感风格兜底
**要素：** 场景环境、色调、颗粒质感、画幅比例

**⚠️ 铁律：**
- 分辨率写到层级5末尾（如「竖屏9:16，输出尺寸1440×2560」）
- 不写8K（与低分辨率矛盾），只写「高清」或直接写实际尺寸

### 负面提示词（独立模块）
**功能：** 集中拦截所有禁止元素

**核心拦截词（已验证有效）：**
- 皮肤：`塑料假皮肤，重度磨皮，零瑕疵完美肌肤，wax figure，plastic skin，airbrushed，flawless`
- 风格：`网红美颜滤镜，流水线AI美女，棚拍商业广告大片，厚重网红妆`
- 畸形：`畸形五官，脸部不对称，多余手指`
- 具象排除：`苹果肌过大，俯拍角度，挑眉，紧绷面部，夸张大笑`
- 类型拦截：`卡通二次元，CG渲染，油画插画`

## 完整模板（直接复制用）

```
{层级1}。{层级2}。{层级3}。{层级4}。{层级5}
```

最新完整版见 `scripts/seedream_gen.sh` 中的 LAYER1~LAYER5 + NEGATIVE 变量。

---

## 脚本使用方法

```bash
# 文生图（默认出小鹿形象）
bash /home/ubuntu/.hermes/scripts/seedream_gen.sh

# 文生图（带自定义描述，替换层级3位置）
bash /home/ubuntu/.hermes/scripts/seedream_gen.sh "穿红色连衣裙"

# 图生图（需先上传参考图到ARK拿file ID）
bash /home/ubuntu/.hermes/scripts/seedream_gen.sh --ref_url "file-xxx" "自定义prompt"
```

---

## 参考图上传（ARK File API）

```bash
# 上传图片拿file ID（可在image_list中引用）
curl -s "https://ark.cn-beijing.volces.com/api/v3/files" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -F "file=@图片路径" \
  -F "purpose=user_data"
# 返回: {"id":"file-xxxxxxxxxxxx", ...}
```

`image_list` 参数支持 `file-xxx` ID 或公网URL，最多14张。
