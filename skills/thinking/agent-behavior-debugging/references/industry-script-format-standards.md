# 行业脚本/分镜格式标准（2026-08-07 多源验证）

> 触发：改节点模板/产出物格式前，先看本文件；本文件内容来自网上多源搜索验证，不是拍脑袋。
> 验证来源：EasyClaw 短视频脚本模板页、火山引擎标准剧本格式文档、中影人教育分镜教程、编导教材、掘金 LLM 分镜实践、微短剧转换规范。

## 三类产出物标准格式

### 1. 文案 / 口播稿 = 纯文本台词（不是表格）

- EasyClaw 6 类模板（带货/知识/个人IP/剧情情感）全部是纯文本逐字稿，无表格
- 格式：按段落+说话人+台词逐行写

```
段1 钩子
说话人：小鹿
台词：说出来你可能不信，株洲有家茶馆不单单只是品茶。
语气：压低声音，像分享秘密，尾音上扬卖关子
情绪：贱兮兮/分享欲
```

- 30秒 80-150字（行业通识）；口播结构：钩子→痛点→方案→信任→CTA

### 2. 短剧 / 影视剧本 = 场次纯文本（不是表格）

- 火山引擎标准剧本格式（短剧生成官方文档）：场次编号/场景/人物/画面(△)/台词
- 格式：场号 场景[内/外][日/夜] + 人物列表 + △画面动作 + 角色名（情绪）：台词

```
第1集
1-1 日 外 江边广场
人物：小帅、小美
△小帅和小美一起坐在长椅上，小帅递给小美奶茶
小帅（开心）：没想到在这里遇见了你。
```

- 短剧铁律：前三秒最狠冲突、每60-90秒一个情绪峰值、单句台词≤15字（微短剧转换规范）

### 3. 分镜脚本 = 行业标准表格（8列）

- 中影人教育/编导教材/掘金 LLM 分镜实践/分镜大师教程多源一致：分镜**必须用表格**
- 标准列：镜号 | 景别 | 运镜 | 画面内容 | 台词/旁白 | 音效/音乐 | 时长 | 备注（转场/光影/道具）
- 景别白名单：远景/全景/中景/近景/特写（禁止「温柔的镜头」这类无法执行描述）
- 运镜白名单：固定/推/拉/摇/移/跟
- 台词每条 ≤12 字（超了观众听不全）

```
| 镜号 | 时间 | 景别 | 运镜 | 画面内容 | 台词/旁白 | 音效/音乐 | 备注 |
|:---:|:---:|:---:|:---:|:---|:---|:---|:---|
| 1 | 0-5s | 远景 | 跟摇 | 门头全景，招牌特写，人物走入画面 | 「xxx」 | 环境音：街市 | 转场：硬切 |
```

## 反例（我们犯过的错，2026-08-07）

- ❌ 节点4 文案用 Markdown 表格（段落/说话人/台词/语气/情绪）→ 模型照抄成剧本/分镜
- ❌ 分镜用自定义 YAML（功能/景别/运镜/场景/台词/情绪）→ 缺行业必有的画面描述/音效/备注，字段错位
- ❌ 文件名带「剧本」（节点4_剧本定稿.md）→ 暗示模型产出带镜号画面的剧本
