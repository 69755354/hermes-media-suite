# 3点法与5步法 · 正交关系分析

> 来源：2026-06-29 用户与Hermes的5步法深度推演对话
> 结论已固化进 SOUL.md 和两个skill的配置中

## 核心结论

**3点法和5步法不是平级关系，也不是高低关系，它们是正交关系。**

```
方法论坐标轴：
       思维深度
          ↑
      5步法 │
          │
          └─────────→ 流程步骤
              3点法
```

| 维度 | 3点法 | 5步法 |
|:----|:-----|:-----|
| **解决什么问题** | 「先做什么再做什么」——做事流程 | 「怎么把问题想透」——思考深度 |
| **适用范围** | 创作类任务（写剧本/做视频/出画面/写文案） | 分析/策略/决策/优化类任务（不限行业） |
| **步骤数** | 3步（搜→拆→写） | 5步（拆解→推演→质疑→复盘→结论） |
| **终点** | 出作品（视频/文案/画面） | 出结论（分析报告/策略建议） |
| **能不能叠加** | 创作中的「拆」这一步可以调用5步法 | 分析中的「推演」可以调用搜索 |

## 为什么是「正交」不是「平级」

**如果平级** → 意味着它们是同一个层面上的两种选择，要么走3点法要么走5步法。
但实际情况是：同一任务中可以同时用两者。

**如果上下级** → 意味着一个比另一个更底层。
但实际情况是：5步法不能替代「搜→拆→写」的流程，3点法也不能替代5步法的深度推演。

**正确理解**：

```
3点法 = 流程轴：「先搜，再拆，再写」
5步法 = 思维轴：「拆之前多想几个维度，推演正反两面，质疑自己的结论」
```

就像汽车的油门和方向盘——不是谁高谁低，是不同维度，可以同时操作。

## 交叉调用场景

### 场景1：创作中需要深度分析

```
用户说：「帮我分析这个选题值不值得做」
→ 这本质是分析/决策问题，不是创作问题
→ 应该调用5步法，而不是走3点法的「搜→拆→写」
→ 但在5步法的推演环节，可以搜索同类选题数据做支撑
```

### 场景2：分析中需要调研素材

```
用户说：「帮我分析竞争对手的内容策略」
→ 走5步法
→ 在「正反推演」这一步，调用搜索获取竞品数据
→ 调研完成后回到5步法继续推演
```

### 场景3：创作卡壳时切分析

```
用户说：「写这个剧本写不下去了」
→ 其实是创作中遇到了分析瓶颈（为什么这个结构不爆？）
→ 暂停3点法 → 切到5步法深度拆解问题 → 找到根因 → 切回3点法继续写
```

## 规则总结

| 触发词 | 走哪个 |
|:------|:------|
| 「帮我做/写/剪/出/生成X」 | 3点法（创作） |
| 「帮我分析/对比/评估/决策/推演X」 | 5步法（分析） |
| 「为什么X」「怎么优化X」「X的问题在哪」 | 5步法（分析） |
| 「先搞」「别分析了」「直接跑」 | 听用户的 |
| **混合指令**（「分析这个选题，然后写个剧本」） | 先5步法分析选题 → 再3点法创作 |
