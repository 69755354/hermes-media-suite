# 决策机制（2026-08-03 定稿，v1.1 按问题类型分轨）

## 触发条件
用户提出任何「观点 / 方案 / 决策 / 商业想法 / 选题 / 文案方向」→ 自动按问题类型分轨分析，不等用户要求。

## 第一步：按问题类型分轨（2026-08-03 修正）

**不是按金额/不可逆分——是按「问题类型」分：**

| 问题类型 | 用哪个 | 原因 |
|:---|:---|:---|
| **策略/决策/分析类**：给客户定打法、运营分析、数据复盘、定价、合作、产品方向、要不要做X | 🎩 **完整版结合框架**（深+全） | 影响大、错了全链路错、不可轻易试错 |
| **文案创作类**：选题、标题、文案、内容方向、CTA写法 | 📋 **决策卡片**（10分钟） | 试错成本低（不好就重写）、要快 |

**判据一句话：这个决定错了，是「重写一次文案」还是「全链路返工」？**
- 重写一次就够 → 卡片
- 全链路返工/丢客户/方向错 → 完整版

## 完整版：结合框架（策略/决策/分析类）

```
【第一轮：五智囊对抗】
  反驳者（黑帽）：最可能怎么死？真实数据/失败案例/反例
  本质追问者：哪个假设没验证？凭什么这么想？
  机会发现者：除了a/b还有c/d/e？
  外行人（红帽）：不懂行业的人会怎么问？
  无情执行者：明早第一步干嘛？不能落地的拦下
【第二轮：六顶查漏】
  ⚪白帽：事实漏了吗？数据齐不齐？
  🟡黄帽：价值面看了吗？（五智囊偏负，黄帽补价值）
  🟢绿帽：机会列全了吗？
  🔴红帽：直觉说透了吗？
【第三轮：主席综合 + 行动收尾】
  主席：综合对抗结论 + 查漏结论
  执行者：明早第一步
```

## 卡片式：决策卡片（文案创作类，10分钟）

```
决策卡片
├─ 反驳者：这想法最可能怎么死？
├─ 本质追问者：哪个假设没验证？
├─ 机会发现者：漏了什么可能？
├─ 外行人：一句人话说明白吗？
├─ 执行者：明早第一步干嘛？
├─ 黄帽补价值：好在哪？（1条）
├─ 白帽补事实：关键事实？（1条）
├─ 主席结论：1-3句
└─ 行动：一句话
```

## 为什么这个组合（经验验证）

- 五智囊 = 深度（对抗挖假设、逼行动）；六顶 = 广度（查漏不遗漏、黄帽补价值）
- 策略类用完整版：「运营助手」分析——五智囊挖出「付费意愿没验证」，六顶黄帽补上「体系是护城河」——深+全
- 创作类用卡片：选题/标题试错成本低，卡片够用且快
- 完整版太重（3000字/次）→ 只给策略/决策/分析类

## 坑点

- 分析框架最大的坑 = 太重被弃用 → 创作类必须用卡片（轻）
- 策略类不能用卡片糊弄——影响大，必须完整版（用户2026-08-03明确）
- 「重大」判定不要凭感觉——用「错得起/错不起」判据
- 分析完必须给「行动」，不能只给分析

## 验证标准

- 策略/决策/分析类 → 完整版；文案创作类 → 卡片
- 每次分析输出：卡片 ≤ 一页纸；完整版 = 三轮结构
