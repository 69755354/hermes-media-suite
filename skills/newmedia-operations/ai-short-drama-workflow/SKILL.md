# AI短剧工作流（融合版）

> 来源：开源 ai-short-drama-workflow（GitHub tianqing-Y/ai-short-drama-workflow，TRAE社区）+ huoshan 三通道流水线 + content-review-gate（原 ai-ad-creative-methodology 未注册，2026-08-09 确认断链）
> 完整参考：wiki/concepts/ai-short-drama-workflow-merged.md

## 定位

补 huoshan 流水线缺的四个能力：**阶段诊断 / 视觉圣经 / 迭代修复 / 成片质检**。
文案创作（台词/盲评）用我们自己的体系（ai-ad-creative-methodology + content-review-gate），本 skill 不碰文案。

## 一、阶段诊断（接需求第一步）

用户提需求后，先判断处于哪个阶段，只输出当前阶段的关键问题+下一步交付物：

```
只有模糊想法 → 信息收集+范围收窄
已有完整故事 → 提炼主题/删支线/确定结构
正在定主题 → 主题句/核心信息/情绪落点/视觉母题
需要视觉统一 → 角色卡/场景卡/色调/镜头语言
准备生成参考图 → 图片提示词+反向词
需要分镜 → 分镜表/图片提示词/视频提示词
正在生成视频 → 生成顺序+失败修复
正在剪辑 → 节奏/字幕/音乐/转场/粗剪建议
准备交付 → 成片质检+投稿检查
不知道下一步 → 只输出阶段判断+下一步动作
```

用户问「我现在该做什么」→ 输出：
```
你现在处在：
最该先解决的是：
建议先不要做：
下一步交付物：
你需要发给我的内容：
```

用户发来图片/视频/粗剪 → 输出：
```
当前素材判断：
可以保留：
需要重做或补充：
下一步建议：
如果继续生成，使用这个修改方向：
```

## 二、新手默认策略

- 默认 45-90 秒（情绪需要可 90-120）
- 1 主角/主体/核心对象，1 条主线
- 1 个主要场景+少量补充，6-10 镜
- 优先旁白/字幕/屏幕信息/简单对话
- 不优先复杂口型对白/多人争吵/群演/连续动作戏
- 先生成参考图，再图生视频
- 先保证人物/场景/色调统一，再追求复杂镜头
- 先剪完整粗版，再回头修单镜头

## 三、视觉圣经

### 主角卡（含禁止变化）
```
姓名/对象类型/年龄/身份/功能用途/文化背景/
外貌特征/形态材质/发型/体型/服装/妆容/
情绪信息基调/表演方式/当前状态/变化前后状态/
禁止变化：不要换脸/换发色/突然浓妆
```

### 场景卡
```
场景名称/场景类型/时间/空间大小/
生活层次（居住/工作/公共/商业不能乱）/
主要道具（3-5个关键道具）/
光线/色调/氛围/镜头可拍细节/
禁止元素
```

### 统一风格词
3-5 个关键词：写实程度/核心场景/主色调/镜头气质/情绪基调

## 四、迭代修复

### 素材三分类
```
可用：满足镜头任务 → 进粗剪
待修：主体正确但局部问题 → 局部修
废弃：主体错误/严重漂移 → 重做
```

### 问题诊断顺序
```
1. 故事看得懂吗？ 2. 分镜连贯吗？ 3. 人物一致吗？
4. 场景风格统一吗？ 5. 单镜头可用吗？ 6. 剪辑节奏顺吗？
7. 字幕声音干扰吗？ 8. 符合交付要求吗？
```

### 修复原则
- 一次只改一个变量；优先局部修，不马上推翻
- 结构没问题→修画面/剪辑；结构有问题→回故事/分镜
- 保留可用素材，记录每次修改原因

### 常见问题修复
| 问题 | 修复 |
|:-----|:-----|
| 人物漂移 | 同一张参考图重复用/固定外貌服装/减少描述变化/先修静态关键帧再图生视频 |
| 场景不统一 | 场景卡固定/固定2-3个关键道具/固定时间光线/减少新道具 |
| 风格跑偏 | 回统一风格词/删冲突风格词/每镜复用同一风格块/先调色再决定重做 |

## 五、成片质检（node15 终审补充）

质检顺序：
```
1. 目标要求 2. 故事信息 3. 视觉一致 4. 生成瑕疵
5. 剪辑节奏 6. 字幕文字 7. 声音音乐 8. 导出格式
9. 授权署名 10. 最终判断
```

生成瑕疵处理：
- 严重影响理解 → 重做/替换
- 轻微不影响 → 保留
- 可剪辑遮盖 → 缩短/裁切/转场
- 可后期修正 → 补文字/遮挡/调色

## 六、30秒广告结构模板

```
0-5秒：视觉钩子（问题/异常/动作）
5-15秒：核心动作或信息
15-25秒：变化、反差或记忆点
25-30秒：标语、片名、产品点或情绪落点
```
镜头数 4-6 个（对齐 huoshan 剧情分支 4-6 镜限制），只表达一个点。

## 七、成片底线

- 清楚的主角/主体/核心对象
- 明确触发点/任务点/视觉钩子
- 有开始、发展、收尾
- 主角/场景/色调基本统一
- AI 痕迹不明显影响观看
- 字幕/声音/音乐不压过画面
- 符合投稿/交付/发布要求
