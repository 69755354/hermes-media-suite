## 一、阶段诊断机制（我们缺的）

用户提出需求时，先判断处于哪个阶段，只输出当前阶段的关键问题+下一步交付物，不一次性跑完整流程。

```
只有模糊想法 → 信息收集+范围收窄
已有完整故事 → 提炼主题/删支线/确定结构
正在定主题 → 主题句/核心信息/情绪落点/视觉母题
需要视觉统一 → 角色卡/场景卡/色调/镜头语言
准备生成参考图 → 图片提示词+反向词
需要分镜 → 分镜表/图片提示词/视频提示词
正在生成视频 → 生成顺序+失败修复
正在剪辑 → 节奏/字幕/音乐/转场/粗剪建议
准备交付 → 成片质检+投稿检查
不知道下一步 → 只输出阶段判断+下一步动作
```

当用户问「我现在该做什么」输出：
```
你现在处在：
最该先解决的是：
建议先不要做：
下一步交付物：
你需要发给我的内容：
```

当用户发来图片/视频/粗剪时输出：
```
当前素材判断：
可以保留：
需要重做或补充：
下一步建议：
如果继续生成，使用这个修改方向：
```

## 二、新手默认策略（我们缺的）

- 默认 45-90 秒（情绪需要可 90-120）
- 1 个主角/主体/核心对象
- 1 条主线（情绪/任务/信息/卖点线）
- 1 个主要场景+少量补充
- 6-10 个镜头
- 优先旁白/字幕/屏幕信息/简单对话
- 不优先复杂口型对白/多人争吵/群演/连续动作戏
- 先生成参考图，再图生视频
- 先保证人物/场景/色调统一，再追求复杂镜头
- 先剪完整粗版，再回头修单镜头

## 四、迭代修复（补充我们的踩坑处理）

### 素材三分类
```
可用：角色/场景/动作/情绪基本满足镜头任务 → 进粗剪
待修：主体正确，但有表情/动作/光线/构图/时长问题 → 局部修
废弃：主体错误/风格不符/角色严重漂移/动作无法理解 → 重做
```

### 问题诊断顺序
```
1. 故事是否看得懂？   （先判断，不要纠结单画面瑕疵）
2. 分镜是否连贯？
3. 人物/主体是否一致？
4. 场景和风格是否统一？
5. 单个镜头是否可用？
6. 剪辑节奏是否顺？
7. 字幕/声音/音乐是否干扰？
8. 是否符合交付要求？
```

### 修复总原则
- 一次只改一个主要变量
- 优先局部修复，不马上推翻全部
- 结构没问题→修画面/剪辑；结构有问题→回故事/分镜
- 保留可用素材，建立可用/待修/废弃清单
- 每次修改记录原因，避免越改越乱

### 人物漂移修复
```
提示词修复：同一位{角色}，保持相同外貌/服装/比例/风格，动作轻微变化，场景色调一致
```
- 回到视觉设定和角色卡
- 重复使用同一张参考图
- 固定年龄/身份/发型/服装/关键外貌
- 减少镜头提示词中的人物描述变化
- 视频失败先重新生成静态关键帧，再做图生视频

### 场景不统一修复
```
提示词修复：同一主场景，固定空间布局/关键道具/时间段/光线方向，画面风格统一
```
- 建立/补全场景卡
- 固定2-3个关键道具
- 固定时间段/光线方向/色调
- 减少提示词中的新道具

### 风格跑偏修复
```
提示词修复：同一位角色，保持相同风格，每个镜头复用同一段风格块
```
- 回到统一风格词
- 删除互相冲突的风格词
- 固定写实程度/色调/质感
- 单个镜头太突兀先调色/剪辑，再决定重做

## 五、成片质检清单（补充我们的 node15 终审）

### 质检顺序
```
1. 目标和要求：时长/画幅/平台要求/必现要素/交付物
2. 故事和信息：主角清楚/前5-10秒知道看什么/开头中段结尾/中段推进/结尾记忆点/无过度解释
3. 视觉一致性：主角配角场景是否同一世界/时间线色彩逻辑/风格跳变/关键道具稳定
4. 生成瑕疵：变脸/手部肢体畸形/动作不可理解/多余元素/拼贴感/文字乱码
5. 剪辑节奏：开头拖吗/前5秒有观看理由吗/中段重复吗/关键镜头停留够吗/结尾太快吗
6. 字幕和文字：可读性/不压画面/与口播对齐
7. 声音和音乐：不干扰/节奏匹配
8. 导出格式：分辨率/码率/平台规格
9. 授权和署名：素材版权/AI生成标注
10. 最终判断：可提交/小修/结构性返工
```

### 生成瑕疵处理原则
- 严重影响理解 → 重做或替换
- 轻微不影响观看 → 保留
- 可用剪辑遮盖 → 缩短/裁切/转场
- 可用后期修正 → 补文字/遮挡/调色/裁切

## 六、30秒广告结构模板（对应我们项目）

```
0-5秒：视觉钩子（问题/异常/动作）
5-15秒：核心动作或信息
15-25秒：变化、反差或记忆点
25-30秒：标语、片名、产品点或情绪落点
```
镜头数：3-5个（30秒）
只表达一个点，不讲复杂背景，画面快速建立识别度。

## 七、成片底线（最低交付标准）

- 有清楚的主角/主体/核心对象
- 有明确的触发点/任务点/问题或视觉钩子
- 有开始、发展、收尾
- 主角/主体/场景/色调基本统一
- AI 生成痕迹不明显影响观看
- 字幕/声音/音乐不压过画面表达
- 符合投稿/交付/发布要求
