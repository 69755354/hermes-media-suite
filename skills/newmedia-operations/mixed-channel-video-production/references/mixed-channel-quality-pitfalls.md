# 混合通道内容质量三大坑（2026-09-01 v14用户反馈）

> 来源：火龙漫剧混合通道模板v14审片反馈。用户提出三个共性问题，适用于所有H段剧情+P段口播的混合通道视频。

## 坑1：r2v多角色台词串声

### 现象
H段prompt把老板（男声）和女助理（女声）的台词混在同一个"人物说："后面交给快乐马r2v生成，模型用男声把所有台词念了。女助理台词"行业…都这样…"本应是女声，变成了男声。

### 根因
快乐马r2v（happyhorse-1.1-r2v）单段视频只支持一个说话人音色。prompt里交替写男声/女声台词时，模型无法中途切换音色，默认用第一个声部念完全部。

### 防法
1. **拆段生成（推荐）**：每个说话人单独一段r2v，合成时concat拼接。老板的台词一段，女助理的台词另一段，各自指定性别/音色。
2. **后期配音覆盖**：r2v只生成画面（可设`audio: false`或不写声音描述），用TTS分别配音再amix合成。注意口型可能不对。
3. **单段+TTS补**：如果必须单段生成，prompt里只写一个说话人的台词，另一个角色的台词后期TTS配音叠上去。

### 示例
原版H段（错误）：
```
人物说：你看看这些平台，用户刷一整天才赚几毛钱？行业…都这样…行业都这样？我们火龙漫剧不能这样！老板，我们给到一块多了…不够！往上加！让用户刷得越多赚得越多！
```
修正方案——拆成2段r2v：
- 段A（男声/老板）："你看看这些平台，用户刷一整天才赚几毛钱？行业都这样？我们火龙漫剧不能这样！不够！往上加！让用户刷得越多赚得越多！"
- 段B（女声/助理）："行业…都这样…老板，我们给到一块多了…"
- concat(A前半 + B + A后半) 按剧情时码对齐

## 坑2：景别单调——全程固定机位中近景

### 现象
H段prompt写"固定机位，平视近景起幅→中景→近景定格"，15秒全程一个机位不动，景别只有近景/中景切换。老板拍桌爆发该给特写或近景冲击但没有，视觉平淡。

### 根因
- "固定机位"约束太死，模型理解成镜头完全不动
- 景别只写近景/中景两个档位，缺少景别变化层次
- 情绪高潮点（拍桌、怒视、爆发）没有标注特写

### 防法
1. **prompt里明确写景别变化时码**：
   - "0-3秒中景（老板甩报告）→3-6秒近景（下属低头反应）→6-9秒特写（老板猛站起俯冲）→9-12秒近景（下属后退）→12-15秒大近景（拍桌爆发定格）"
2. **情绪高潮点必须标"特写"**：拍桌、怒视、爆发等动作给特写或大近景
3. **不要全段写"固定机位"**，改成"微推/微拉"让镜头有呼吸感
4. 参考夜店版模板的镜1运镜写法：有起身、有走位、有摄影机后退跟随

### 景别变化参考表

| 情绪强度 | 建议景别 | 说明 |
|---------|---------|------|
| 日常讲解 | 中景/中近景 | 建立环境关系 |
| 情绪积累 | 近景 | 进入内心 |
| 情绪爆发 | 特写/大近景 | 冲击力最强 |
| 反应/倾听 | 近景 | 捕捉微表情 |
| 收尾定格 | 大近景或特写 | 定格情绪 |

## 坑3：数字人呆滞——单人多段口播表情平缓

### 现象
P段用单个婵镜数字人（如C-049f），参数emotion="温和专业轻微微笑"+gesture_strength=0.35+gesture_frequency="low"，44秒一个人温吞水一样说话，表情和动作变化太少，容易导致跳出率升高。

### 根因
- emotion参数太温和（"温和专业"=没什么表情变化）
- gesture_strength 0.35太低（手势幅度小，看不出来）
- gesture_frequency "low"太低（手势太少，画面静）
- 单人44秒没有切换，观众视觉疲劳

### 防法
1. **换1-2个数字人增加变化**：P段拆成2-3段，每段用不同数字人ID，concat拼接
   - 例如：第一段用数字人A正式介绍，第二段用数字人B接地气推荐，第三段回A做CTA
2. **调高参数**：
   - emotion改成有情绪起伏的描述："说到赚钱时兴奋，说到不信时怀疑，CTA时热情"
   - gesture_strength从0.35提到0.5-0.7
   - gesture_frequency从"low"改"medium"
3. **分段差异化**：不同段给不同的emotion描述，让数字人有不同的情绪状态
4. 婵镜emotion参数要写到具体情绪变化而非笼统"温和专业"

### 推荐参数对比

| 参数 | 原值（呆滞） | 推荐值（有变化） |
|------|------------|---------------|
| emotion | "温和专业，日常讲解，轻微微笑" | "开头热情介绍，中段说到赚钱兴奋，后段说到不信怀疑，结尾CTA真诚推荐" |
| gesture_strength | 0.35 | 0.5-0.7 |
| gesture_frequency | "low" | "medium" |
| 数字人数 | 1人全程 | 2-3人分段 |
| 段时长 | 44秒一段 | 15-20秒/段，2-3段拼接 |
