# 什么是复刻 — 权威方案（Claude 终审，2026-08-22）

> 出具：claude 通道（复刻方法论终审），天行者确认
> 背景：火龙高颜值版复刻连续翻车（运镜自己判断、景别没照原片人物位置、LOGO 让模型生成而非素材后期贴），天行者质问「你知道什么叫复刻吗」「你为什么不按照纪律」；指出这是小鹿一直犯的错（不按纪律自由发挥），闸门防不住。Claude 出本方案。
> 适用：所有 TASK_TYPE=复刻 任务，执行通道 codex / claude / cc，调度方 Hermes

## 0. 一页纸结论

1. **复刻 = 拿原片当唯一事实源逐镜贴原稿。** 只有一个变量：人物形象与场景（且必须客户明确要求换）。其余全部照原片。
2. **「照原片」不是态度，是可 diff 的数据。** 原片必须先落成机器可读的 `remake/SHOT_REF.yaml`（逐镜：切点/景别/人物位置/运镜/动作序列/素材与贴法/台词/时长）。这张表是全链路唯一画面依据。
3. **执行器无内容自由裁量权。** prompt 里每一个画面决定（景别、人物位置、运镜幅度、手机屏内容由谁出、素材贴哪、台词一个字）都必须能在 SHOT_REF.yaml 里指回一行。指不回去的 = 自由发挥 = BLOCK。
4. **物理卡点落在付费 API 入口，不落在任务书。** 任务书闸只能保证「规则写了」，不能保证「按规则做了」。真正的卡点是 `run_seedance_exact` 提交前对 prompt 做逐镜对照校验（新增 `remake_gate.py`，闸2.5），不通过就打不出片、烧不了钱。

## 1. 复刻的定义

> **复刻 = 把原片当唯一事实源，逐镜贴原稿重做一遍；唯一允许改变的是「人物形象」和「场景」，且仅在客户明确要求时改，其余一切（结构、切点、景别、人物位置、运镜、动作序列、素材种类与摆放位置、台词逐字、时长、配音方式、字幕样式、人物数量）全部照原片。**

### 三个词的边界（混了就翻车）

| 概念 | 事实源 | 允许变的 | 判定问句 |
|:--|:--|:--|:--|
| **复刻**（本方案唯一对象） | 原片逐帧 | 人物形象、场景（客户明确要求时） | 「这一笔在原片第几秒第几帧？」答不出 = 不合规 |
| **仿拍 / 改编** | 原片的方法与结构思路 | 结构可重排、镜数可重切、台词可重写 | 「这是按原片做的，还是按我的方案做的？」答后者 = 改编 |
| **借鉴** | 原片的某个手法 | 几乎全部 | —— |

复刻里最容易犯的两个越界：
- **「按剧情切镜」是执行流程，不是内容改编依据。** 单镜 4-15s、duration 传参、英文双引号、拼接规则属于 Seedance 生成/拼接阶段的执行规范；分镜**内容**必须照原片结构，一段不落、顺序不变。把原片结构重排成「剧情切镜版」= 改编，会被打回。
- **分镜数 = 原片人物硬切点数，不是画面切换数，更不是字幕时码段数（2026-08-24 定案，废弃旧「真实画面切换数」口径）**。UI 层切换（App 页面出现/消失）不算镜界，只作段内后期贴片时点。火龙 43s 正确拆法 = 人物硬切 4 段 + 尾卡；旧 8 镜方案把 12.083/23.950/34.600 三个 UI 切换误当镜界，已废弃。用相邻帧灰度 diff（阈值 30）+ 关键帧 grid 逐帧 vision 确认**切换性质**（人物硬切 vs UI 层切换），不靠数字幕。

### 三条推论（直接杀掉「自由发挥」的合法性）

- **推论 A：复刻任务里不存在「我判断这样更好」。** 更好但不同 = 不合格。要改必须回到人（天行者/客户）拍板并写回 SHOT_REF.yaml，改表才算改需求。
- **推论 B：复刻任务里不存在「这个原片没看清，我先按常理做」。** 看不清 = 抽帧不够密 → 回去加密抽帧；仍不清 → NEED_INFO，不许脑补。反例：DS 脑补「小芸坐沙发举手机」vs 原片「左手持机 + 右手竖大拇指 + 福利中心页叠加占 70%」，镜2 作废重出。
- **推论 C：复刻任务里不存在「几个人？」这类问句。** 原片几个人就几个人，结构/时长/素材位置/配音方式同理，问 = 说明没拆片。

## 2. 逐镜复刻执行流程

拆原片（逐帧分析人物位置/运镜/景别/素材贴法）→ SHOT_REF.yaml 对照表 → 分镜 → 出片 prompt（逐项引用对照表）→ 老板确认分镜+prompt → Seedance 出片 → 合成 → QC。每个环节谁做、产出什么、对照什么，全链路唯一画面依据 = SHOT_REF.yaml。

## 3. 落地实施单（交 codex 实施 + 独立终审）

- 新增 `remake_gate.py`（闸2.5）：`run_seedance_exact` 提交前对 prompt 逐镜对照校验，不通过打不出片
- `remake/SHOT_REF.yaml` 生成器：拆片产出机器可读对照表
- 任务书模板：要求执行器「本镜 prompt 对照原片哪一帧/哪一段」逐项列出
