# 镜界判定：人物硬切 vs UI 层切换（2026-08-24 火龙定案）

> 触发：拆原片定镜界、复刻分镜数争议、「原片几段」类问题、分镜被质疑拆太细。
> 本文件是 video-remake「分镜数 = 人物硬切点数」规则的完整推理链与证据案例。

## 一、三类切点（拆镜时逐点判定性质）

| 类型 | 定义 | 是否算镜界 | 例子 |
|---|---|---|---|
| **人物硬切** | 换人、景别突变、人物状态硬断（有可验证的相邻帧证据） | **算** | 火龙 10.050 男→女、19.950 女→男、29.950 景别硬切、40.000 尾卡 |
| **UI 层切换** | App 页面出现/消失、贴纸变化、页面遮挡露出；人物底层连续 | **不算**，只作段内后期贴片时点 | 火龙 12.083 现金页消失、23.950 选集页消失、34.600 播放页消失 |
| **未定性过渡** | 底层被页面遮挡无法观察，scene detect 高阈值未命中 | **不算**（不许擅自定为硬切） | 火龙 34.600（31.250-34.600 被孙悟空播放页遮挡） |

**判定铁律**：不能只凭「画面变了」就拆镜。工具（ffmpeg 抽帧 + 灰度 diff + scene detect）找的是**候选切换点**，必须再用 vision 逐帧确认**切换性质**（换人？景别跳？还是页面盖住露出？）。

## 二、工具的正确用法与坑

- `frame_change_detect.py` / 灰度 diff（阈值 30）找大切换：**输出是候选点，不是镜界**。阈值 12-15 会被口播动作/字幕闪烁干扰出 78 个假切换。
- **scene detect 测的是「画面变化」，不是「人物切换」**——高阈值（0.30）未命中 ≠ 没有切点，只说明不是画面级硬切；UI 层切换可能命中低阈值（0.20）但人物没断。
- 判定切点性质的标准证据：FULLSCAN 式逐帧扫描（60fps 取证、0.02-0.05s 步长），看①人物是否换人②人物尺度/位置是否连续③遮挡前后露出时人物状态。

## 三、火龙完整案例（8 镜错拆 → 4 段定案）

旧拆法（08-22 前 5 分镜按人物切换 → 08-22 工具实测细化 8 镜）把 3 个 UI 层切换当镜界：

| 段 | 时段 | 时长 | 切点性质 | 正确归属 |
|---|---|---|---|---|
| S01 | 0.000-10.050 | 10.05s | 开场 | 段1（男主） |
| S02 | 10.050-12.083 | 2.033s | 10.050 人物硬切 | 段2（女主） |
| S03 | 12.083-19.950 | 7.867s | **12.083 UI 切换（现金页消失，人物连续）** | 段2（女主） |
| S04 | 19.950-23.950 | 4.0s | 19.950 人物硬切 | 段3（男主） |
| S05 | 23.950-29.950 | 6.0s | **23.950 UI 切换（选集页消失）** | 段3（男主） |
| S06 | 29.950-34.600 | 4.65s | 29.950 人物硬切 | 段4（男主） |
| S07 | 34.600-40.000 | 5.4s | **34.600 UI 切换（播放页消失，未定性）** | 段4（男主） |
| S08 | 40.000-43.000 | 3.0s | 尾卡（不生成） | 尾卡（可删） |

**正确生成分段 = 人物硬切 4 段 + 尾卡**：0-10.050／10.050-19.950／19.950-29.950／29.950-40.000，全部 10s 整数秒。

**用户视角验证**：老板看原片说「后面男的不就两段？」= 19.950-29.950 + 29.950-40.000 两段，与人物硬切判定一致。**用户看原片的直觉优先级最高**——文档/报告/分镜被用户观感推翻时，先认再核对证据，不拿文档分段压用户。

## 四、生成侧联动（分镜归分镜、生成归生成）

- **Seedance 2.0 Mini duration 4-15 整数秒**：低于 4s 的镜头（如 S02 2.033s）不能单独生成，按人物连续性合并到相邻段（S02+S03=9.9s 一段生成），UI 切换点段内按时点贴。
- 正好 4.0s 的镜头可单独生成（卡下限）。
- 4.65/5.4 等非整数时长取整（4.65→5、5.4→5），多余部分后期裁切；整数秒段不用裁。
- 拆得越细 ≠ 越好：每多拆一段 = 多一次付费生成 + 多一次取整裁切 + 多一次贴片对位。合并依据只有「人物底层连续」这一条。

## 五、汇报口径

先给「人物段」（老板能对原片验证的），再给「生成段」；旧 8 镜/分镜口径只作内部技术细节，不拿来反驳老板观感。
