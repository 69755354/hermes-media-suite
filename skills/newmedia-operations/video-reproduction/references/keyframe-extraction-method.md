# 关键帧驱动抽帧方法（2026-08-26 定案）

> 触发：拆解参考视频时确定抽帧策略。
> 用户原话：「你拆视屏的时候就需要每帧都拆，不然你中间会漏掉很多东西」

## 为什么不用3秒抽1帧

3秒抽1帧（fps=1/3）会漏：
- 画面切点（关键帧附近的变化）
- UI层变化（App页面出现/消失）
- 画中画出现/消失
- 字幕大字变化
- 贴纸/Logo出现位置变化

## 正确方法：关键帧驱动抽帧

### 步骤

1. **拉关键帧时间戳**
```bash
ffprobe -v quiet -print_format json -show_frames -select_streams v \
  -show_entries "frame=key_frame,pict_type,pts_time" <视频> 2>/dev/null \
  | python3 -c "
import json,sys
d=json.load(sys.stdin)
kf=[f for f in d.get('frames',[]) if f.get('key_frame')==1]
for f in kf:
    print(f'{float(f.get(\"pts_time\",0)):.3f}s')
"
```

2. **每个关键帧±1帧抽取**（切点前后帧）
```bash
# 关键帧时间列表，每个时间点抽前1帧、当前帧、后1帧
for t in $KF_TIMES; do
    ffmpeg -y -ss $t -i <视频> -frames:v 1 kf_${IDX}_${t}.jpg 2>/dev/null
done
```

3. **关键帧之间按0.5秒间隔补抽**（覆盖中间内容）
```bash
ffmpeg -y -i <视频> -vf "fps=2" frame_%04d.jpg 2>&1
```

4. **全部 vision_analyze 逐张看**
   - 关键帧附近：看切点性质（人物切换/UI层/过渡）
   - 0.5秒帧：看中间内容（字幕大字变化、App界面滚动、画中画状态）

## 关键发现：3秒抽帧 vs 关键帧驱动

3秒抽1帧（13帧）只catches到关键帧时间点附近的画面，但漏掉了：
- 画中画在哪些页面出现、哪些页面不出现（选集页/筛选页有画中画，热播榜/播放页没有）
- 字幕大字随口播关键词同步变化的具体内容
- App界面内部的滚动/交互细节
- 火龙Logo出现的确切时间和位置

关键帧驱动118帧全部catches到，且不浪费——只在切点附近密集、中间0.5秒足够。
