# 角色图生图（img2img 锁脸工作流）

## 触发
生成「特定角色」的图片（小鹿等固定形象）时，用图生图锁脸，不用文生图。
文生图只能出「一个穿角色衣服的陌生脸」，图生图才能锁定五官。

## 核心规则（2026-07-24 天行者定稿 img2img 模板）
1. **图生图不写五官外貌文字**——面部靠参考图锁定，写五官反而干扰
2. **参考图必须用定稿三视图**（小鹿=xiaolu_sheet.jpg，禁用旧版）
3. **空变量直接删除整条**（不留占位符）
4. **人脸漂移兜底**：标准版末尾追加「, 保持参考图人物面部五官、脸型基础特征不变」
5. 执行通道：**codex gpt-image-2 首选**（--image 垫参考图），Seedream 图生图备选

## img2img 正向标准版
```
{gender_age},原生均匀肤色，自然皮肤质感，杜绝过度腮红，无面部大面积泛红色块,生活化纪实摄影，胶片轻微颗粒，相机直出原图，无重度美颜磨皮，保留皮肤自然肌理，拒绝过度精致广告写真质感,{frame_setting},{camera_rule},{light_setting},{lens_param},{expression_emotion},{clothes_info},{scene_environment}
```

## 负向 A 包（常驻）
塑料肌肤，CG，动漫，3D 渲染，五官扭曲，面部畸形，肢体残缺，超高饱和度，僵硬人脸，数字人塑胶感，画面出现文字、水印

## 负向 B 包（按需）
俯拍，仰拍，极端高机位，极端低机位，不自然蹲姿，肢体严重扭曲，极致背景虚化，生硬强烈硬阴影，画面整体偏浓重橘暖色调，厚重蜜桃腮红

## 假人感红线（0917用户定案）

用户原话：「这个一股浓浓的假人味」「一点都不像真人」

**规则：**
1. 角色三视图/定妆图/场景图必须像真人照片，不能像3D建模、游戏角色、蜡像
2. 负向必须加：3D渲染, 游戏角色, 建模感, 蜡像, 塑料质感, 数字人, CGI, 虚拟偶像, 不真实皮肤
3. 正向必须强调：真实皮肤质感, 毛孔可见, 胶片颗粒, 相机直出, 纪实摄影
4. 生成后自检：看起来像游戏截图=不合格，看起来像手机拍的真人=合格
5. 用户看到假人感=直接删掉重出，不修补

## 双模型人脸风格实测（2026-08-09）
- **codex gpt-image-2**：偏中国面孔（训练数据以中/日/韩为主）——客户是国内选它
- **Seedream 5.0**：偏混血网红脸（高鼻梁深眼窝立体轮廓）——要中国脸需正向加「中国面孔特征锁定」+负向禁「混血脸/欧美立体五官/高鼻梁/深眼窝/外国面孔/白人特征」
- 同提示词同尺寸对比才公平（尺寸差 = 像素差，不说明画质）

## codex 生图安全墙（2026-08-09 实测，重大踩坑）
OpenAI gpt-image-2 的图像安全系统比火山 Seedream 严格得多：
- **「比基尼」直接触发 sexual 类别拦截**（input 阶段），codex 换措辞重试也被连坐拒绝
- **「泳衣」也可能被 output 阶段拦**（生成结果被判 sexual）
- **能过的写法**：「高领全覆盖连体泳装」「专业冲浪泳衣」等保守表述
- 场景本身（海边/夕阳/奔跑/回眸）没问题，卡点在服装措辞
- 遇到 `moderation_blocked` / `safety_violations=[sexual]` → 换保守服装词重试，不要硬刚

## codex 看图方法（2026-08-09 实测）
- `codex exec -i <图片路径> "问题"` 可以看图分析（OpenAI 视觉通道，比豆包 vision 稳）
- **必须配合 stdin 管道**传 prompt：`echo "问题" | codex exec -i <图> ...`（0.147 版本加 -i 后直接传参会被忽略）
- **必须加 `-c sandbox_mode=danger-full-access`**，否则 bwrap 沙箱读不了图片文件（loopback 权限错误）
- codex 生图尺寸：`--size` 自定义，支持到 8K/3840px（默认 auto 约 1672x941）；用 2160x3840 出 4K 竖版
