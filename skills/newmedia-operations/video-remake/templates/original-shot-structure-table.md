# 原片画面结构对照表（复刻 prompt 唯一画面依据）

> 用途：写每个分镜 prompt 前，先把原片对应时段逐帧看清，落盘成表。后续所有 prompt 以表为唯一画面依据，避免每次重新抽帧 / 凭记忆脑补。
> 制作方法：`ffmpeg -vf fps=2` 抽帧 → 按分镜时段拼时间轴 grid（每段 4-9 帧）→ vision 逐段核验 → 填表。

## 总结构（人物切换点）

| 时码 | 人物 | 画面结构 | 对应台词 |
|---|---|---|---|
| 0-14s | （原片人物身份/穿着） | （姿势/手机内容占比/景别/动作序列） | （该时段台词，简体照画面字幕） |
| 14-22s | ... | ... | ... |
| 22-35s | ... | ... | ... |
| 35-40s | ... | ... | ... |
| 40-43s | ...（可能无尾卡段！先截片段发用户确认） | ... | ... |

## 各镜画面结构要点（prompt 必须照此）

### 镜1（0-14s）
- 姿势变化：...（如：坐姿双手握手机 → 前倾 → 站立举手机展示）
- 手机：屏幕内容/占比（留空后期贴）
- 景别：...

### 镜2（14-22s）
- 姿势：...（如：左手持机+右手竖大拇指）
- 素材摆放：...（如：福利中心页叠加放大占画面约70%，人物在侧）
- 景别：...

### 镜3（22-35s）
- 姿势：...
- 素材摆放：...（如：手机屏幕主体=弹窗→剧库→双列流）
- 景别：...

### 镜4（35-40s）
- 姿势：...（如：站立左手举手机+右手摊开讲解）
- 景别：...

### 镜5（40-43s）
- ⚠️ 先确认原片到底有没有独立尾卡段（`ffmpeg -ss <start> -t <len> -i 原片.mp4 -c copy 尾段.mp4` 截片段发用户确认）
- 无尾卡 → 不造尾卡（DS 脑补龙形特效/品牌尾卡 = 加戏，会被打回「原视频有这个吗」）
- 有尾卡 → 记录素材摆放（暗底/居中/内容结构），后期贴素材

## 关键纪律

1. **素材用户提供**（「素材会另外提供给你，但是你要记住素材的位置」）——生成阶段屏幕/贴图区留空，不造素材
2. **只换人物形象+场景**——姿势/占比/景别/动作序列照原片一字不差
3. 每镜 prompt 必须含「动作照原片/动作序列照原片」+「画面结构照原片/约占画面X%」关键词（自查用）
4. 每镜台词写进 prompt 前，抽原片对应时段字幕区放大逐字核验（简体照画面，不信 ASR 繁体）
