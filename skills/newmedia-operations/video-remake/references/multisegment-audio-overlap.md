# 多段拼接人声重叠排查（2026-08-24 火龙 v12 实测）

## 触发

用户看多镜合成成片后说「前面的人说话都没完，后面的人就出来了」「素材也是乱七八糟」。症状 = 段间人声重叠或同一句被念两遍。

## 排查链（从浅到深，每层验证后再进下一层）

### ① 素材实际时长 vs 画面 trim 时长

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 seedance_clips/镜N.mp4
```

Seedance 按「10s 口播」提示词常生成 11.104s——素材本身超时是常态。画面 trim 到 10.050/9.900 等，音频全段保留 = 每段多出 ~1.1s。

### ② 合成脚本 adelay/atrim/atempo 心算

读合成脚本，重点：
- `adelay=10050|10050`：下一段音频从 10.050s（画面切点）起播
- `atrim=start=0:end=10.000` + 尾部 `atrim=start=10.000:end=11.104,atempo=0.613333`：尾段 1.104s 放慢成 1.80s

心算每段实际音频长 = 原速段长 + 尾段时长/atempo。**adelay 按画面切点排、却没把尾部变速的延长度算进去 → 段间重叠 1.3-1.85s 人声**。脚本注释/设计文档可能写「延迟 11.800/21.800/31.300」的意图值，但实现里 adelay 却按画面切点写——以实际 filter 参数为准，不信任注释。

### ③ faster-whisper 带时间戳转写（核心武器，本机已装 faster-whisper 1.2.1）

```python
from faster_whisper import WhisperModel
model = WhisperModel('small', device='cpu', compute_type='int8')
segments, _ = model.transcribe('seedance_clips/镜1_v2_20260824.mp4', language='zh', vad_filter=False)
for s in segments:
    print(f'[{s.start:6.2f} - {s.end:6.2f}] {s.text.strip()}')
```

**逐句对照分镜设计台词表，标出「尾句属于下一镜」的跨界句。** 火龙 v12 实锤：
- 镜1 素材 0-9.24s 念自己的 8 句，**9.24-11.04s 多念了句9「火龙币也能直接换成现金提走」**（设计归镜2 女主）
- 镜2 素材 0-8.88s 念自己的 6 句，**8.88-11.04s 多念了句16「平台所有漫剧全部免费观看」**（设计归镜3）
- 镜3/镜4 正常念完自己的尾句

全段保留拼接 = 句9 在镜1 尾拖音（10-11.8s）和镜2 头句（10.05s 起）重叠响；句16 同理。**听感崩的根因不是合成参数单点错，是素材生成时就埋了跨界句，合成忠实执行了错误设计。** 复核报告（如 REVIEW_4SEG）可能已点名「跨界句规则混乱」——生成后必须实测转写验证，别把「已评审」当「已修正」。

### ④ 尾段是否有效人声（决定能不能直接裁）

```bash
ffmpeg -hide_banner -ss 9.5 -i clip.mp4 -af volumedetect -f null - 2>&1 | grep -E "mean_volume|max_volume"
```

响度与开头段同量级（火龙实测尾 mean -14~-21dB vs 头 -13~-19dB）= 有实字，**不能裁**。`silencedetect` 常因阈值/BGM 无输出，用 Python wave+numpy RMS 分 0.2s 窗算活动区间更可靠。

### ⑤ 尾段画面有效（拉长方案的前提）

抽 10.3s 和 11.0s 两帧 vision 对比：画面在动、口型在变 = 素材尾段有效，拉长成片物理可行；黑屏/冻结 = 可裁。

## 硬矛盾与修复选项

N 段 × ~11.1s 音频总长（火龙 44.4s）> 时间轴（40s）时，**无重叠、无丢字、口型准三者不可兼得**。向用户摆选项，不悄悄重叠硬塞：

| 方案 | 做法 | 代价 | 状态 |
|---|---|---|---|
| 拉长成片 | 每段画面/音频用满素材全长（11.104s），段间紧接零重叠；切点变 11.104/22.208/33.312 | 时长变长（可能更接近原片 43s）；贴片 21 个 + 字幕 28 句 + BGM 时间轴全部重排 | 火龙 v12 推荐，待用户拍板 |
| 保持原时长裁尾 | 每段裁到画面段长 10s | 跨界句/尾句丢字（句9 整句只在镜1 出现一次，裁掉 = 整句丢失） | 用户不接受 |
| 整体加速 | atempo=1.11 压进 10s | 口型漂移 11%、语速变赶（atempo 保音调但不保口型同步） | 风险高 |
| 重新生成素材 | 提示词加「只念本镜台词，不念下一镜第一句」+ 限 10s | 付费 API 重出，需用户授权 | 正路但烧钱 |

**跨界句归属错误时先确认句子的唯一存在位置**：一句台词只在一个素材里出现一次时，把它从所在段裁掉 = 整句丢失，不是「裁尾音」；从错误位置剪切挪到正确段会破坏口型同步（画面人物口型对应的是素材自己念的内容）。

## 陷阱

- 合成脚本 NOTES/注释可能写「声音不按画面切点截断」（L-cut 设计），但 L-cut 重叠 1.3s+ 就是灾难；合理 L-cut 只该 0.2-0.5s。
- 40s 内硬塞 44.4s 音频没有「全对」解；向用户给出选项表 + 代价，拍板权在用户。
- 交付后用户「素材乱七八糟」可能同时指：跨界句重复、段序错位、贴片时码错——先转写核台词，再核画面，分开定位。
