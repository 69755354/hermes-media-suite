# 复刻素材：动态视频片段截取与用户素材管理（2026-08-18 火龙漫剧实战）

## 动态素材截视频（贴视频不贴图）

原片里 App 界面/弹窗/福利页/尾卡是**动态素材**，合成阶段贴视频，不贴静态图。
截取流程（用户「视频素材要截整个视频下来」定案）：

1. 读项目内「原片画面结构对照表.md」——列所有动态时段（福利中心叠加/解锁弹窗/录屏/尾卡）
2. 列出现有 `复刻素材_v2/视频/*.mp4` 片段覆盖
3. 缺的时段用 ffmpeg 截：
   ```bash
   ffmpeg -y -v error -ss <start> -t <len> -i 原片.mp4 -c copy 片段_名称.mp4
   ```
   `-c copy` 快且无损；原片在 `wiki/teardowns/原始素材/<批>/videos/<抖音id>.mp4`（meta 目录有标题可对）
4. **抽帧 vision 验证内容**（别截成人物特写）：
   - 福利中心叠加页 = 火龙币/签到7天/日常福利，占画面约60%
   - 解锁弹窗 = 「没有充值解锁」选集页（《秒杀大帝》139集、第1集可看、2集后灰）
   - 录屏 = 剧库/题材/双列流浏览
5. 更新「素材位置记录.md」视频素材表：文件/时段/用途

实例（火龙漫剧 43s）：0-5/5-11/11-17/18-20s 人物参考 + 14-22s 福利中心叠加（8s，镜2 贴图）
+ 22-24s 解锁弹窗（2s，镜3 开头）+ 24-35.8s 录屏（镜3 主体）+ 40-43s 尾卡（镜5）。

## ⚠️ 从原片截的「整段片段」可能含原片人物，不能直接整段当贴图（2026-08-18 合成前发现）

**坑：** `片段_福利中心叠加_14-22s.mp4` 是用 `-ss 14 -t 8 -c copy` 从原片整段截的——**画面 = 原片人物 + 福利页叠加**（1s 是原片女性持机、7s 切原片男性），不是纯 App 界面。合成时若把整段叠到复刻版小芸的画面上 = **原片人物叠在小芸身上 = 穿帮**。

**根源：** `-c copy` 截的是「原片该时段完整画面」，动态素材 ≠ 纯界面素材。原片 14-22s 的画面结构本来就是「人物+福利页叠加（页面占中 40-50%，19s 时页面遮挡人物脸部）」。

**合成前必须做：** 对每个从原片截的贴图片段，抽帧 vision 确认「是否含原片人物」。含人物的片段不能整段贴，处理选项：
1. **裁页面区域**：从片段裁出界面主体区域（如福利页中间区域）当动态视频贴，人物部分裁掉——贴视频但页面可能不完整
2. **用静态图兜底**：无水印静态图（如 `福利中心_无水印.png`）页面完整干净——但用户定案「贴视频不贴图」时需先问
3. **整段贴**：接受原片人物短暂露出（不推荐，穿帮）

**判断标准：** 用户说「贴视频」指的是 App 界面动态（录屏/弹窗/福利页动效），不是「把原片整段画面搬过来」。合成前把含人物风险片段列出来让用户拍板，别默认整段贴。

## 静态截图去重清理（有视频覆盖的删掉）

**用户定案（2026-08-18）：「如果你已经有了动态素材，你就把那些静态的图片删掉就行了」。**
流程：

1. 列原片动态时段（对照表）→ 列已有视频片段覆盖
2. 逐张判断静态界面截图（`界面_XXs_crop.png`）对应时段是否**已有视频素材**
   - 有视频覆盖（如 19s 福利中心→14-22s 视频、23s 弹窗→22-24s 视频、25-35s 剧库→24-35.8s 录屏）→ **删**，贴的时候贴视频不贴图，静态图冗余
   - 无视频覆盖（如 11s 提现页，原片该时段手机屏不对镜头、没有对应动态片段）→ **留**
3. 删除前在「素材位置记录.md」记一行清理说明（哪些删了、为什么），避免下次以为素材丢失
4. ⚠️ 删之前先 vision 确认截图内容确实是 App 界面（不是原片人物特写——人物帧直接删不留）
5. ⚠️ **保留的素材也要逐张发用户过目**（用户「保留的没给我看的发出来看看」）：清理完冗余后，把保留清单逐张发完（一次一张，等确认），不能只发待确认的、跳过已留的

## 同镜内多 UI 素材按时段切换：从原片裁剪弹窗素材（2026-08-18 镜2 用户「他这个应该不止一个素材吧」后固化）

**一个镜内可能多个 UI 素材按时段切换，每个对应一段台词。** 复刻时先抽原片全程帧（每 1-1.5s 一帧）vision 逐帧问「当前画面有什么 UI 素材」，记录素材切换时码；合成时每个素材 `enable='between(t,start,end)'` 叠加，底页全程。

**从原片裁剪弹窗素材流程（镜2 实测）**：
1. 定位弹窗出现时点（如「添加到主屏幕」弹窗在原片 16.5s）
2. numpy 白色块检测（`gray>230` 连通域，area>5000）拿像素 bbox——**用像素检测，不用 vision 估坐标**（vision 坐标每次不同且分辨率基准混乱）
3. PIL 按 bbox 裁剪 → 保存 → vision 验证内容完整（标题/按钮/卡片齐全）、无截断、背景干净无人物水印
4. 合成时按台词时段叠加，scale 保持原比例（`scale=338:409` 照原尺寸）

**火龙漫剧镜2 实测弹窗数据（720x1280）**：
- 「添加到主屏幕」弹窗：原片 16.5s，bbox x191-529 y517-926（338x409），对应台词「添加桌面也有收益」（镜内 2.8-4.7s 时段叠加）
- 「恭喜获得火龙币」奖励弹窗：原片 19.5s，bbox x246-484 y424-679（238x255），对应台词「刚注册的新人一登进去…新人福利」
- ⚠️ 已有素材（如福利中心_无水印.png）可能自带某个弹窗（是后段状态）——**不要全程贴**，前段台词没讲弹窗内容时弹窗已显示 = 穿帮；需要「纯底页」版本时从原片更早时点抠（无弹窗帧）或处理素材去掉弹窗

**验证「素材跟台词匹配」**：抽帧时画面出现什么 UI，台词正在讲什么，两者对齐 = 对。

素材确认/清理完后，用户会要求「去对齐一下那个参考视频」：
1. 放的位置（每个素材在画面里的位置/占比）
2. 什么时候放图片素材
3. 什么时候放素材视频
4. logo 放手机屏幕哪里（如用户提供的霓虹手势logo贴到原片 10s 手机屏 logo 位置）

**派活流程（走 codex，智力活外包）：**
1. 读「原片画面结构对照表.md」→ 已有逐帧核验证据（各分镜素材位置/占比/时机）
2. 读 A_PROMPT_PACKAGE.md（每镜屏幕留空说明，确认贴图区在哪）
3. 抽原片关键帧 vision 复核素材摆放（如 3s/10s 手机屏 logo、16s/19s 福利页叠加、26s/34s 剧库/播放页、41s 尾卡）——不能只靠对照表，写作前重新核对
4. 整理素材全景清单：用户提供（assets/materials/）优先、原片提取无水印大图兜底、动态视频片段（贴视频不贴图）、人物锁定图（不参与贴图）
5. 任务书产出要求：按分镜 1-N 输出 贴图内容/文件绝对路径/位置/时机/类型(图片or视频)/备注，每个判断标注原片证据（时码+抽帧内容）；落盘 `artifacts/media_prep/A_MATERIAL_ALIGNMENT.md`
6. 派 codex 时任务书必须写「执行方法」（读对照表→读提示词包→读素材记录→必要时抽帧复核→产出），只写「对齐一下」= 方法缺失 = BLOCK

**关键原则：** 用户提供的三张素材优先用（logo/闪屏页/品牌页各有用途：logo=片头尾卡、品牌页=手机屏贴图）；原片提取静态图（福利中心_无水印/播放页_无水印）只在视频素材缺失时兜底；禁止新增原片没有的素材。

## 用户通过飞书发素材（图片）

- 飞书图/视频消息修复后（2026-08-18 起 image/video 放行），入站图片缓存到 `~/.hermes/cache/images/`
- 落盘流程：vision_analyze 看清内容 → `cp` 到项目 `assets/materials/`（按用途命名，如 `火龙漫剧_logo_用户提供.jpg`）→ 更新「素材位置记录.md」素材表（文件/内容/用途）
- 用户发素材时可能同时说明用途（如「这个是放手机屏的素材」）——**用途必须记进素材位置记录**，合成阶段按用途贴
- 用户发图连续多张时，逐张落盘，别攒批；用户逐张确认界面截图时一次只发一张（见主 SKILL.md 素材确认交互规范）

## ⚠️ 素材用途确认：多张相似素材时别猜，逐张确认用途（2026-08-18 火龙漫剧实战）

**场景：** 用户发了三张视觉相似的素材（512x512 霓虹手势 logo / 竖版品牌页含「火龙漫剧」文字+卡通龙 / 闪屏页），名称都带「火龙漫剧」。我一度把「品牌页」当成 logo 用途，用户连续纠正「这个才是我发的」「小的就是logo，长的那个是贴手机屏的」——**相似素材的用途必须逐张问清，禁止按文件名/外观猜测**。

**正确做法：**
1. 每张素材落盘后，**单独发回给用户 + 问用途**（「这张是 logo 还是贴手机屏？」），等用户确认再记用途
2. 用户纠正用途后，**立即更新素材位置记录**（标注「用户确认 2026-08-18：X 用途」），不要口头记住
3. 素材对齐方案（A_MATERIAL_ALIGNMENT.md）引用素材时**绑用户确认过的用途**（logo=霓虹手势小图；贴手机屏=品牌页长图），方案里标注「用户确认」字样
4. 用户说「这个才是我发的」= 前面某张理解错了，**回查自己哪张记错了用途，不是追问用户**
