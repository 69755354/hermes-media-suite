# 纯音频抽帧改词（画面不动）— 2026-08-24 火龙 v16 实测

## 场景
Seedance 素材人声把字念错（如「零」念成「平/小」音），用户明确要求「把 XX 字的帧抽掉」——不是重生成、不是改字幕，而是把错字音频剪掉，让前后字相接成新词：
- 「现在看漫剧也能赚零花钱了」→ 抽「零花」→「现在看漫剧也能**赚钱**了」
- 「边赚零花钱的快乐」→ 抽「零花」→「边**赚钱**的快乐」

**关键：只剪音频，画面不动**（画面抽帧 = 人物口型跳变穿帮；口型本来就跟错读音对不上，但画面保持连续比跳变安全）。

## 前置确认（2026-08-24 用户「你都不问我需要怎么修改么」教训）
1. 先确认是真念错不是 whisper 转写误差：两个模型（small+medium）都听成非目标音（平/小 ≠ 零）+ 原片同句对照（原片 whisper 转出「零花钱」正确 = 素材真念错）
2. **把修法选项摆给用户拍板**：剪帧（不花钱、丢字改词）/ 重生成（烧钱、保原词）——用户说剪才剪

## 步骤
### 1. 定位错字区间
```python
from faster_whisper import WhisperModel
model = WhisperModel('medium', device='cpu', compute_type='int8')
segs, info = model.transcribe('镜X.mp4', language='zh', vad_filter=False, word_timestamps=True)
for seg in segs:
    for w in seg.words:
        print(w.word, w.start, w.end)
```
实测（火龙 v16→v17 最终定稿）：
- 镜1 句2「赚零花钱」：whisper 听成「赚平花钱」→ 错音节「平」(2.060-2.200) +「花」(2.200-2.320)，但**最终抽帧区间 = 2.060-2.295**（不是 2.320！）
- 镜4 句28「边赚零花钱」：whisper 听成「边赚小花钱」→ 错音节「小」(10.120-10.360) +「花」(10.360-10.480) = **10.120-10.480（0.36s）**——第一版即正确，中途改小全错

## ⚠️ whisper word_timestamps 时间戳不可直接信任（2026-08-24 v17 用户「钱字感觉被吞了」血泪）

直接按 whisper 给的错音节区间抽，**会把下一个字（「钱」）的起音切掉**——「钱」的 q 声母（送气音）实际比 whisper 标注的起点早开始：
- 镜1 实测：whisper 标「钱」2.320 起，波形显示 2.31s 能量已回升（q 声母）→ 抽到 2.320 把「钱」头 0.01-0.03s 切了 → 用户听出「钱字被吞」
- 镜4 实测：whisper 标「钱」10.480 起，波形 10.48-10.52 低能量 q 送气 → 抽到 10.480 正确保留

**精确边界定位 = 波形 RMS 能量谷（10ms 窗口），不信 whisper 毫秒值**：
```python
import wave, numpy as np
# ffmpeg -ss <句起点-0.1> -t 1.0 -i 素材.mp4 -vn -ac 1 -ar 16000 /tmp/x.wav
w = wave.open('/tmp/x.wav','rb'); sr = w.getframerate()
data = np.frombuffer(w.readframes(w.getnframes()), dtype=np.int16).astype(np.float32)/32768
win = int(sr*0.01)  # 10ms
rms = np.sqrt(np.mean(data[:len(data)//win*win].reshape(-1,win)**2, axis=1))
# 逐 10ms 打印 RMS：找「零花」能量谷底（抽帧终点）和「钱」起音爆发点（抽帧终点必须在其之前）
```
判读：错字区间尾 = 能量谷底（如镜1 2.27-2.30 RMS 降到 0.03）；「钱」起音 = 谷底后能量首次明显回升（镜1 2.31s；镜4 10.32s）。**抽帧终点 = 谷底，不是 whisper 的错字 end**。镜1 修正：2.060-2.295（留 2.295-2.31 过渡）；镜4 修正：10.120-10.480（whisper 完整区间恰好对，因为「花」的韵尾本身在谷底 10.42-10.48）。

## ⚠️ 抽帧区间改错方向 = 残留错字，每次改完必须转写验证（2026-08-24 v17 血泪）

镜4 第一版 10.120-10.480 转写「边赚钱的快乐」✓ 是对的；因镜1「钱被吞」连带把镜4 改成 10.170-10.315 → 转写「边赚**花**钱的快乐」（「零」10.12-10.36 留 0.05s +「花」10.36-10.48 全留）；再改 10.100-10.320 仍「边赚**花**钱」（花 10.32-10.48 未删）。教训：
- **「零花」这类二字错音节区间 = whisper 识别出的完整二字区间**（「小」10.120-10.360 +「花」10.360-10.480 = 10.120-10.480），不是中间某个能量段——「零」的鼻音韵尾和「花」的元音段能量都在，凭波形目测「10.25-10.31 能量低 = 花尾」会误判
- **每次改抽帧区间后必须 medium 模型转写成片验证**：目标词通顺（「赚钱」）且无残留字（无「零/平/小/花」）才算过；第一版验证过就不要动
- 波形验证的是「终点别切到下一字起音」，不是「把区间改小」——区间改小 = 错字没删完

### 2. ffmpeg 纯音频抽帧（filter 内直接做）
```
[0:a]atrim=start=0:end=2.060,asetpts=PTS-STARTPTS[a0_head];
[0:a]atrim=start=2.320:end=11.104,asetpts=PTS-STARTPTS[a0_tail];
[a0_head][a0_tail]concat=n=2:v=0:a=1,aresample=48000,aformat=...[a0];
```

### 3. 连锁重算（⚠️ 最易漏，三处都要改）
抽帧后每段新时长 = 原时长 - 抽掉时长。本案例：
| 段 | 原时长 | 抽掉 | 新时长 |
|:--|:--|:--|:--|
| 镜1 | 11.104 | 0.26 | 10.844 |
| 镜2 | 11.104 | 0 | 11.104 |
| 镜3 | 11.104 | 0 | 11.104 |
| 镜4 | 11.104 | 0.36 | 10.744 |

- **adelay 重算**：段2 = 10.844（10844）、段3 = 10.844+11.104 = 21.948（21948）、段4 = 21.948+11.104 = 33.052（33052）——原 v15 是 11104/22208/33312
- **总时长**：33.052+10.744 = 43.796 → `-t 43.800`
- **BGM**：duration 43.800、afade out st=38.8:d=5
- **字幕时码**：所有 Dialogue 前移「前面段累计抽掉时长」（镜1 内句3-9 减 0.26、镜2/3 全段减 0.26、镜4 句23-27 减 0.26；被抽句28 的 end 再减本句抽掉的 0.36）
  - 例：句9 原 9.24-11.04 → 8.98-10.78；句28 原 42.99-44.35 → 42.77-43.73
- **字幕文本同步改**：句2「现在看漫剧也能赚钱了」、句28「边赚钱的快乐」（不显示没念的字）
- **贴片时间不动**（锚定画面，音频提前 0.26s 的小错位人眼不可察）

### 4. 验证
- 成片转写（medium）：句2「现在看漫剧也能**赚钱**了」、句28「**边赚钱**的快乐」通顺
- 时长核对：ffprobe duration = 43.800
- 注意：抽帧后句2 结束提前，后续字幕/音频整体前移 0.26s，画面切点仍 11.104/22.208/33.312（画面 trim 不变）——音画错位 0.26s 可接受

## 为什么不能画面一起抽
画面抽帧 = 人物说话中间跳 0.26s，口型/动作跳变比音画错位更明显。只有用户明确说「音画同步剪」（2026-08-19 镜3「弹窗」案例，剪 0.24s 整段）才画面+音频一起剪；「把字抽掉」= 纯音频。

## 复用要点
- whisper word_timestamps 的错字区间 = whisper 识别出的错音节（它把「零」听成「平/小」的那个音节的 start-end），**区间本身可信（尤其二字错音节要整段抽）**；但**抽帧终点不能直接取 whisper 的 end**——先用波形 RMS 10ms 窗口找「错字尾能量谷底」和「下一字起音爆发点」，终点 = 谷底（见上「whisper 时间戳不可直接信任」）
- 抽帧区间可以跨两个字（「平」+「花」连续两个 word），一次 atrim 两段拼接即可
- 后续段 adelay 用「前段新时长累加」而不是原时长——这是最常漏的重算点
- **每次改抽帧区间后必须转写验证**（目标词通顺 + 无残留字），验证通过后不要再动区间
