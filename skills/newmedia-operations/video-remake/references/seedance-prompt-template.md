# Seedance 提示词写作模板（2026-08-18 火龙漫剧实战验证）

> 参数状态：结构模板。镜数、时长、字数、动态强度和台词格式统一以 `director-thinking/SKILL.md` 为准。

> 使用时机：任何 Seedance 出片/融合版重出任务写 prompt 时。
> 原则：9 段式结构 + 每条关键规则都是踩过坑的，照抄别自创。

## 9 段式模板

```
@图1仅作人物参考，@图2仅作场景参考，@图3是手机屏幕内要显示的素材。（需要手机屏内容时才有@图3）

① 人物段：从@图1彩色铅笔人物准确还原为同一位XX岁中国女性XX：五官/发型/服装/配饰全部固定列出（圆方脸、自然眼角纹、黑棕耳下微卷三七侧分短发、固定灰粉细针织开衫、米白圆领上衣、深灰直筒裤、小颗金色耳钉）
② 场景段：场景严格锁定@图2中国县城自建房客餐厅：暖灰白乳胶漆墙、中棕色木门、方形木餐桌、桌上有透明玻璃杯和素色保温壶、米灰色布艺沙发区、下午侧窗自然光
③ 动作序列段：动作序列照原片：开始是坐姿…；0-4秒坐姿说前两句台词，身体微微前倾；4-10秒站起来…；10-14秒手机保持在胸前…
④ 手机屏渲染段（仅手机屏要显示素材时）：手机屏幕内完整显示@图3素材内容：醒目「火龙漫剧」艺术字、白色卡通龙、粉色到蓝色渐变背景，原图内容保持不变，禁止重绘篡改文字图案；图像跟随手机摆动同步做透视形变，被手机圆角边框裁切，不浮在画面表层、不溢出屏幕、不绘制在手机外壳上；手机玻璃带有微弱环境高光，高光随手机姿态角度同步变化
⑤ 景别机位段：中近景（胸部以上），人物占画面主体。平视机位，35-50mm等效焦距，手机纪实感，轻微手持晃动，缓慢推近，9:16竖屏
⑥ 光影段：下午侧窗自然光从右后方照入，人脸与墙面形成真实明暗差
⑦ 动作约束段：人物口型与台词节奏自然，不做夸张表情。全程人脸不变形，身体比例正常，画面丝滑流畅，无抖动闪烁。画面中不出现任何其他中文文字、Logo、二维码、红包、现金。手部动作自然简单
⑧ 台词段：开头先停顿半秒，然后直接开口说台词，不说任何多余的字。语速平稳适中偏慢，字字清楚，不赶不抢，句与句之间自然停顿。台词内容直接开口说出："喂你知道吗""现在看漫剧也能赚零花钱了"（英文双引号连写）
⑨ 负面词段：负面：不要多余的话，不要乱语，不要念错台词。语速不要快，不要赶，不要吞字，不要连读，不要漏字，不要改词。不要出现任何其他手机界面内容、其他文字、Logo
```

## 关键规则（每条踩过坑）

1. **@图引用不带路径**：正文用干净的 `@图1仅作人物参考`；文件路径是脚本 payload 的事（reference_images 数组传路径）。正文出现路径 = 发给用户确认时被骂「你不需要@的吗」。
2. **人物参考图必须彩铅三视图**：写实定妆图被 Seedance 审核拦（`InputImageSensitiveContentDetected.PrivacyInformation`，may contain real person），彩铅图能过。人物段写「从@图1彩色铅笔人物准确还原为真人照片级写实」= 绕检关键词。
3. **动作序列必须照原片逐段写**：坐姿→前倾→站起→举手机展示，每段带时码。只写「站立讲述」= 没台词没动作序列 = 用户打回「完全跟我们的要求不一样」。
4. **画面结构照原片写比例**：「人物口播为主，手机为辅助展示，不叠加放大页面」这类结构描述必须写。脑补画面（小芸坐沙发举手机 vs 原片女主左手持机+右手竖拇指+福利页叠加放大占70%）= 镜作废重出。
5. **台词用英文双引号连写**：`"台词1""台词2"`（中文引号概率性念错），单镜台词 ≤20 汉字（超了拆镜）。
6. **开头停顿半秒**：`开头先停顿半秒，然后直接开口说台词，不说任何多余的字` 防 Seedance 开头乱出音。
7. **语速约束全片统一**：每个口播镜都写同一句「语速平稳适中偏慢，字字清楚，不赶不抢」+ 负面「语速不要快，不要赶，不要吞字，不要连读，不要漏字，不要改词」，禁止只给某镜单独加。
8. **负面词兜底**：`不要多余的话，不要乱语，不要念错台词…不要出现任何其他手机界面内容、其他文字、Logo`。
9. **手机屏渲染段插进原 prompt 动作序列后面**，不是单独生成「举手机展示」画面——单独生成 = 没台词没动作 = 废片（镜1 血泪）。
10. **发提示词给用户确认时用干净 @ 引用版**（不带路径、不解释）；用户说「明白了就把提示词发过来」= 只发文本，等确认再提交生成。
11. **duration 4-15s**：传 3 返回 400 `InvalidParameter`；原片段只有 3s 时按 duration 4 生成、剪辑裁到 3s。
12. **复刻不造素材**：屏幕内容如果用户会提供素材 → prompt 写「屏幕区域留空，不生成任何UI/文字」，素材后期贴；只有用户明确要求手机屏显示品牌素材时才用 @图3 直出。

## 融合版（手机屏直出素材）附加说明

- 三图引用：`@图1仅作人物参考，@图2仅作场景参考，@图3是手机屏幕内要显示的素材`
- 手机屏约束段（插动作序列后）：「手机屏幕内完整显示@图3素材内容：…原图内容保持不变，禁止重绘篡改文字图案；图像跟随手机摆动同步做透视形变，被手机圆角边框裁切，不浮在画面表层、不溢出屏幕、不绘制在手机外壳上；手机玻璃带有微弱环境高光，高光随手机姿态角度同步变化」
- 参考图传 3 张（人物彩铅 + 场景 + 素材图），role 均 reference_image
- 生成后抽帧核验三件事：文字是否保留（无错字）、素材是否跟手机走、是否圆角裁切不溢出
