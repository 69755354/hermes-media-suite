# Seedance 直接配音参数（红果验证，2026-08-06~07 踩坑固化）

> 参数状态：A/B 实测记录。当前生产规则为英文双引号、实际试读拆段、口播单段不超过10秒；其他具体秒数和字数仅作历史证据。

> 来源：wiki/cases/红果漫剧_复盘.md（A/B 对照实验验证）

## 核心结论

**Seedance 口播的「念错」大多是 prompt 写法问题**（引号类型/台词长度/开场约束），不是模型废。先自查 prompt 再怀疑模型。

## 参数表

| 项 | 做法 | 验证 |
|:--|:--|:--|
| 台词引号 | **英文双引号 `""`** 包裹 | A组「」中文引号概率性念错；B组 "" 全对（控制变量实验） |
| 单镜台词 | **≤20 汉字**，超了拆镜 | 镜3 22字念错 → 拆 15+9 字全对 |
| 开场约束 | prompt 加「开头先停顿半秒，然后直接开口说台词，不说任何多余的字」+ 负面「多余的话、乱语」 | 模型开场即说话不稳定，加约束后稳定 |
| 时长 | **每镜 5s 完整口播，不压缩**（段时长≥口播实际时长） | 7段×4.3s截断 → 尾字被切；5s完整口播 35s 总长 OK |
| 语速 | **同一支视频多镜语速必须统一**：所有口播镜写同一句语速约束（「语速平稳适中偏慢，字字清楚，不赶不抢，句与句之间自然停顿」+ 负面「语速不要快，不要赶，不要吞字，不要连读，不要漏字，不要改词」），禁止只给某镜单独加 | ⚠️ **2026-08-18 火龙镜3 修正（血泪）**：起初 13s 10句没写语速 → 用户「语速太快了吧」，whisper 转出「免费→免翻」疑似错读；以为语速是根因，加语速约束重跑 → 错读反而更多（玄幻/竖屏/广告弹窗全错），用户拍板「就用第一版」「之前的语速又没问题」——**语速不是错读根因**（Seedance 对特定词 G2P 拟合差是模型固有），用户对单镜的反馈不要推广成全片问题，改前先问，确认要改才动 |
| 高危字 | 同义换词绕开（豪门争斗→豪门角逐、奇幻悬疑→奇幻探案） | 模型 G2P 对部分音节拟合差，换词有效 |
| 结尾复读 | 重跑抽卡，多版选最优 | 模型 5s 内复读尾句，重跑解决 |
| 验证 | **口播对错以人耳为准**，whisper 只辅助 | whisper-small 中文同音字不可靠（甜宠→填储） |

## 复刻场景注意

- 复刻任务 = 文案逐字保留 → 台词写进 Seedance prompt 直接生成人声（口型同步）
- **不要**用 edge-tts 后期叠音（TTS 音轨叠在 Seedance 画面上，人物嘴型不同步 → 用户说「配音跟口型完全对不上」）
- 火山 Seedance 拦真人脸：参考图用**彩铅/彩绘**（绕检），prompt 写「从彩绘还原为真人照片级写实」
