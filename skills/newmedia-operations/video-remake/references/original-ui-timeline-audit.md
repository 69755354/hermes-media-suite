# 原片 UI 贴片时间线实测审计（2026-08-24 火龙 v14 实测）

## 触发
复刻成片交付后用户说「素材贴的乱七八遭 / 素材不对 / 贴的位置错了」——或合成前想确认贴片方案——先做本审计，别信执行器自拟的贴片表。

## 核心结论（火龙 40s 案例）
1. **执行器（codex/DS）自拟的贴片时间表可能整张是编的**：v12 NOTES 表凭空加了原片没有的元素（红信封红包 10.633s / 签到返回 / 白底加载 / 闪屏页 31.25s），还漏了原片真实存在的（福利来袭横幅 5s / 竖屏孙悟空页 33s / 品牌页贴手机 37s）。
2. **贴片时间必须跟「素材实际台词时码」同步**，不跟设计台词时码、不靠段偏移。原片 UI 出现/消失基本跟着台词走（钞票=句2、福利来袭=句5、播放页=句6-7、提现页=句9、福利中心=句10-11、添加桌面=句13、签到=句14、3888=句15、播放页=句16、选集=句17、筛选=句18、双列=句20、竖屏=句23、箭头=句26、金币=句28）。用 faster-whisper 转写复刻素材拿每句实际 start-end，UI enable 窗口照实际台词时码排。
3. **位置按复刻画面实际构图调**，不照原片坐标死贴：Seedance 生成画面人物位置/大小/朝向跟原片不同（火龙：原片钞票图标在人物左胸 x≈25-40%，复刻画面人物左胸在 x≈50-70%），同一坐标贴出去差 30% 画面宽。悬浮小元素先抽复刻画面帧 vision 定位人物实际位置，再定 overlay x/y。
4. **形态分两类照原片**：
   - **大界面覆盖式**（播放页/提现页/福利中心/选集/筛选/双列/竖屏页）：覆盖画面中上部大半个屏幕，人物部分被遮挡，坐标影响小、尺寸要够大（火龙播放页 500x820 覆盖中上）
   - **小元素悬浮**（钞票金币/logo/灰度窗/箭头/金币）：固定画面位置悬浮，不跟手机走，坐标必须按复刻构图对准
5. **删原片没有的、补原片有的**：每个贴片都要能回指原片某秒的实测证据；「原片有但没有对应贴片」= 要补素材（从原片帧 crop，如福利来袭=原片_5s.png crop 350:90:225:455、竖屏页=原片_33s.png crop 370:660:175:95）。

## 实测方法
1. `ffmpeg -ss <t> -i 原片.mp4 -frames:v 1 /tmp/ori_ui/t_<t>.jpg` 每秒一帧 0-40s
2. PIL 拼 7 列网格（每段 ≤14 帧，一次 vision 看 10-14 格，多了超时）→ vision 逐格问：UI 元素？大界面还是小贴片？位置？出现/消失时点？
3. 输出「时码 | UI 元素 | 形态 | 位置」表，作为贴片方案唯一依据
4. 特殊素材直接 vision 问 crop 区域（720x1280 坐标系的矩形边界），如「福利来袭界面 x 225-575 y 455-545」「竖屏页 x 175-545 y 95-755」
5. 缺失帧直接 ffmpeg 从原片抽（静态目录只有奇数秒时）

## 质检方法（原片 vs 成片并排）
1. 每个贴片出现瞬间：`ffmpeg -ss <t> -i 原片.mp4` 和 `-ss <对应成片时间> -i 成片.mp4` 各抽 1 帧
2. PIL 左原片右成片 hstack → vision 逐项问：贴片是否出现？位置/内容/大小一致？是否自然贴合（悬浮不突兀、大界面覆盖到位）？
3. 只看成片单帧会漏：原片 10.6s 根本没有红包，成片却有——不并排对比发现不了「编造元素」
