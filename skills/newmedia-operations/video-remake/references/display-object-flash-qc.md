# 展示物「一闪而过」复刻质检法（2026-08-23 火龙 S01 实测）

## 触发

用户看完成片说「手机一闪而过」「XX看不清就过去了」「闪太快了」——**不要理解成物体消失，先查「有没有停留展示时间」**。

## 案例

S01 成片 montage 证明：手机 2.5s 拿起、3-3.5s 最显眼、之后全程握持在场、无消失段——但用户仍说「手机一闪而过」。

根因：**屏幕内容没有放大展示段**。
- 原片男口播段 0.5-6s：手机从 0.5s 就举在胸前；**2.5-4s 有手机屏幕放大特写（屏幕几乎占满画面，红圈标功能入口）**，全程展示屏幕内容约 5.5s。
- 成片：手机 3-3.5s 举到近镜头但只占画面 5-10%，3.5s 后起身走动手机缩在手里——观众没机会看清闪屏页内容。

## 诊断法（montage 对比，两步）

1. **成片轨迹**：`for t in $(seq 1.0 0.5 9.5); ffmpeg -ss $t -frames:v 1` 抽帧 → `tile=4x5` 拼 grid → vision 问「手机/展示物每帧的位置、大小、可见性轨迹——什么时候出现？什么时候最显眼？有没有完全看不到的时间段？」→ 确认物体是否全程在场。
2. **原片同段对照**：原片对应时段同样每 0.5s 抽帧拼 montage → vision 问「原片怎么展示这个物体：有没有放大特写/停留段/标注？」→ 差异即根因。

## 修法

prompt 动作序列补展示停留段（只调动作序列，台词/时码/参考图不动）：

> 3 秒举手机后**保持坐姿把手机举近、屏幕放大至画面主体、停留约 2 秒**，4.5-5 秒再起身，5 秒后走三步。

## 通用化规则

- 复刻任何「展示物」（手机屏/福利页/弹窗/CTA）的呈现方式必须照原片：**原片有特写停留段的，prompt 必须有对应段**；原片是悬浮大界面的，成片就不能是举手机小图（见 SKILL.md 悬浮大界面节）。
- 用户反馈「X 一闪而过/看不清」→ 先对比原片同段呈现方式，别只查「物体在不在」。
- 交付节奏：用户等视频时，出片完成立即发本体，montage 深核验放交付后做（见 seedance-render-submission 交付纪律）。
