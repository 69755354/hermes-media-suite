# 标题与封面策略

## 触发条件
- 出文章/头条/公众号/小红书内容时
- 用户要求改标题/换封面时
- codex写完文章后进入标题环节

## 一、标题生成流程

### 步骤
1. 文章定稿后，根据内容类型和目标平台，套用下方公式
2. 每篇生成 5-10 个标题候选，标明用的哪个公式
3. 用户挑选，不代用户决定
4. 多平台分发时，每个平台单独出标题（同文不同标题）

### 头条标题公式（三段式为主）

| 公式 | 模板 | 示例 |
|:--|:--|:--|
| 数字冲击 | 具体数字+核心信息+悬念 | 「2亿灵活就业者注意：居民医保折算职工医保，一年省下多少钱？」 |
| 反常识 | 常识断言+转折+真相 | 「以为交了医保就万事大吉？灵活就业者最容易忽略的这个细节，亏大了」 |
| 身份标签 + 痛点 | 目标人群+具体困境+解决暗示 | 「外卖骑手、网约车司机注意：你的医保可能白交了，一招教你折算」 |
| 对比冲突 | A方案 vs B方案+代价 | 「职工医保585元/月，居民医保795元/年，灵活就业者到底选哪个？」 |
| 紧迫感 | 时间窗口+政策+行动 | 「医保折算政策还在探索期，现在不办，以后可能没机会」 |
| 悬念好奇 | 抛问题+不给答案+暗示价值 | 「灵活就业者医保折算，算完这笔账的人都不淡定了」 |
| 案例/故事 | 具体人物+转折+结果暗示 | 「37岁外卖骑手算完医保折算这笔账，果断改了缴费方式」 |

### 头条标题铁律
- **三段式结构（教程核心方法）**：标题必须分三段——事实A + 吸引眼球B + 留悬念C，用冒号/逗号/问号分隔
  - A段=讲事实（事件/数据/人物）
  - B段=吸引眼球（情绪/冲突/反差）
  - C段=留悬念（不给答案/抛问题/暗示价值）
  - 6大引爆元素池：金钱、生死、异常、对比、转折、刺激——每个标题至少命中1个
- 必须有引爆词（数字、对比、冲突、悬念、身份词）
- 控制在 15-30 字
- 禁用极限词（最/第一/绝对/100%）
- 标题里的事实必须跟正文一致，不编造
- **投喂式标题法（教程方法）**：先给AI看10-20个对标爆款标题让它学结构（A+B+C拆解+元素分析），再根据素材生成标题。比直接生成更贴合平台调性

### 小红书标题公式

| 公式 | 模板 | 示例 |
|:--|:--|:--|
| 痛点+方案 | 痛点场景+解决方案 | 「灵活就业医保交了两年才知道能折算！省了好几千」 |
| 数字清单 | 具体数字+干货清单暗示 | 「3分钟算清医保折算这笔账，灵活就业必看」 |
| 身份共鸣 | 身份标签+经历+结果 | 「外卖骑手自述：我的医保终于没白交」 |
| 反差对比 | 认知反差+真相揭示 | 「以为居民医保便宜划算？折算成职工医保才知道亏了多少」 |
| 求助/讨论 | 抛出选择+引发互动 | 「灵活就业选职工医保还是居民医保？算了笔账太难选了」 |

### 小红书标题铁律
- 控制在 20 字以内
- 带情绪词（终于/竟然/才知道/必看/太亏了）
- 禁夸张承诺

### 抖音/视频号标题（口播类）
- 口语化，念出来顺口
- 15 字以内
- 一个钩子+一个悬念

## 二、封面策略

### 封面生成流程

**头条三图封面法（教程核心方法）：**
- 头条支持三图封面（上传3张图做封面轮播）
- **直接从文章配图中选3张做封面，不另外生成**——文章正文配了哪些图就拿来做封面
- 3张图要有层次感：第1张做主图（最强冲击力），第2-3张补充信息/场景
- 如果文章配图不够3张，补到3张（可AI生图补），但优先用文章已有配图

**AI生图封面（非头条/文章配图不足时）：**
1. **先出方案再出图**：写一段封面方案（画面描述+情绪+文字+色调），给用户确认
2. **确认后才调 ARK 生图**：不在方案未确认时浪费生图配额
3. **生 2-3 个候选**：不同构图/色调，用户选
4. **禁抽象概念图**：天平/齿轮/灯泡等抽象图不要

### 封面铁律
1. **跟文章内容直接相关**：画面里要有文章实际写到的场景/人物/物品
2. **有人物+情绪+场景**：不只是一张空场景图
3. **有视觉冲击力**：高对比度、暖色调优先（除非内容调性不符）
4. **可叠加标题文字**：画面留出文字空间（上方或下方）
5. **尺寸 800×800**（正方形，ARK 生成 1920×1920 后 ffmpeg crop）
6. **色调多样化**：不每次用同一种色调，轮换暖橙/灰蓝/雾蓝/深绿等

### 封面方案模板
```
画面：[具体场景描述，含人物动作/表情/环境]
情绪：[传达什么情绪]
色调：[主色调]
叠加文字：[封面上的文字，8-12字]
构图：[人物位置/留白方向]
关联内容：[为什么这个画面跟文章相关]
```

### 封面反面案例（已踩过的坑）
- ❌ 天平图配医保文章 → 太抽象，用户问「这封面跟文章有关系吗」
- ❌ 每次都暖橙色调 → 用户说「不要老用一种风格色调」
- ❌ 纯场景无人物 → 缺情绪冲击力
- ✅ 外卖骑手持手机看单据+皱眉+暖调 → 通过

## 三、平台差异速查

| 维度 | 头条 | 小红书 | 抖音/视频号 |
|:--|:--|:--|:--|
| 标题字数 | 15-30字 | ≤20字 | ≤15字 |
| 标题风格 | 三段式+信息密度 | 情绪+场景感 | 口语化+悬念 |
| 封面方式 | 三图封面（正文配图选3张） | AI生图800×800 | AI生图720×1280 |
| 封面重点 | 信息+冲突 | 美感+干货感 | 人物+情绪 |
| 文字叠加 | 可多行 | 核心词8-12字 | 大字≤8字 |

## 四、与写作流程的衔接

- 标题生成在「文案定稿」之后、「交付」之前
- 封面方案在标题确定后出（封面文字跟标题呼应）
- **头条三图封面**：标题定稿→文章配图完成→从配图中选3张做封面（主图+补充图），不再另外生成封面
- **AI生图封面（小红书/抖音）**：标题定稿→出封面方案→用户确认→调ARK生图
- 多平台分发时：母稿→平台标题→平台封面方案→生图
- 标题和封面方案写入 task_brief 交给 codex，不自己写标题
