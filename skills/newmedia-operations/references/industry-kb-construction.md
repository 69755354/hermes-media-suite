# 行业知识库搭建方法

从本次会话中提炼的可复用流程。

## 何时用

- 需要为某个行业（餐饮/教育/美妆/母婴等）建立平台内容策略时
- 现有知识库缺少行业真实案例时
- 需要判断某个赛道在某个平台是否有机会时

## 流程

```
① 搜平台行业报告/趋势数据
   → 千瓜/新榜/飞瓜报告（小红书/抖音各赛道数据）
   → 搜索公式：平台名+行业名+趋势+数据+年份

② 搜爆款案例/账号
   → 搜索公式：平台名+行业名+爆款案例+涨粉+播放量
   → 找真实数据（涨粉数/播放量/点赞/收藏）

③ 提取结构规律
   → 标题公式 封面特点 正文结构 开头钩子
   → 每个赛道提炼3-5个标题公式

④ 建知识库文档
   → wiki/concepts/industry-{赛道名}.md
   → 包含：行业概况表、视频/笔记结构、标题公式、开头钩子、真实案例

⑤ 更新工作流引用
   → 在节点5（文案）的行业适配表里加调用文档路径
   → 格式：`wiki/concepts/industry-{赛道名}.md`

⑥ 三轮自检
   → 文件存在？引用路径正确？内容无矛盾？
```

## 注意事项

- 真实案例必须有数据支撑（播放量/涨粉数/点赞量），不能编造
- 同一行业在抖音和小红书的策略完全不同，需分别建文档
- 先做总览再拆独立文档，避免重复信息
- 每个赛道至少3个真实案例才有参考价值
- 数据来源标注出处（新榜/千瓜/飞瓜）
