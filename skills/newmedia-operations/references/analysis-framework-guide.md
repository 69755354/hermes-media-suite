# Analysis Framework Guide (Bot Advice)

## 分析思维（拆解问题）- 6个工具叠加使用

| 工具 | 定义 | 使用场景 |
|:----|:-----|:---------|
| **第一性原理** | 拆到最底层再重建逻辑，不盲从行业经验 | 客户说"别人都这么做"时，问"为什么这么做？底层逻辑是什么" |
| **行为心理学** | 恐惧/从众/懒惰/占便宜/虚荣/共鸣 | 分析客户行动动机，不只看表面需求 |
| **消费心理学** | 触发→搜索→评估→决策→购后 | 分析购买决策路径，找转化卡点 |
| **MECE+逻辑树** | 相互独立、完全穷尽 | 拆问题不重不漏，确保分析全面 |
| **共情深度** | 场景→行为→心理→情绪→羞耻→自我合理化 | 共情的终点不是感动，是让客户觉得"这家店懂我" |
| **底层焦虑** | 身份焦虑/死亡焦虑/孤独焦虑/失控焦虑 | 每案必过，判断客户的真实恐惧 |

## 表达框架（给建议）- 一个结构

**先给结论，再给过程**

> 先说「我建议你做X」
> 再说「为什么：你现在情况是这样→问题出在这→所以应该这么做」

客户不想听推理时看结论就够了，想深挖时可以往下看过程。

## 5步法核心原则

1. 别急着下结论
2. 全程保持高强度的逻辑链条
3. 禁止使用「可能」「或许」「大概」
4. 输出带前置条件和风险提示
5. 每次分析前先搜同类爆款内容

## 给客户建议的铁律

- **禁止迎合** — 有问题直接指出来，带证据带理由
- **先分析隐性需求** — 表面/真实/遗漏/真实处境，确认后再回答
- **合规是底线** — 每个行业开搞前先摸清红线
