# 线下实体店周氏无厘头 AI 短视频全流程教程（扣子工作流 + 新手落地版）

本教程专为同城实体店引流设计，全程围绕周氏无厘头喜剧风格打造，核心逻辑是「离谱剧情 + 强反差反转 + 自然落店引流」，从选题、文案、分镜、提示词到扣子自动化工作流全链路标准化输出。

## 一、周氏无厘头同城爆款选题公式

### 3 个万能选题公式

1. **奇葩身份 + 同城痛点 + 店铺神反转**
   「XX（离谱身份）来 XX（本地地名），被 XX（店铺对应痛点）难住，居然靠这家店解决了？」

2. **正经名场面 + 魔改剧情 + 产品救场**
   「原版 XX（经典影视名场面），要是有我们家 XX（店铺产品/服务），结局直接反转！」

3. **日常场景 + 离谱意外 + 店铺兜底**
   「XX（本地普通人）干 XX 事时翻车，本以为社死，结果被这家店救了场」

### 分品类选题示例
- 视力保健类：古代书生赶考近视看不清路，靠这家眼镜店秒中状元
- 餐饮卤味类：武林高手比武输了，因为没吃我们家的卤味
- 美业类：如花相亲被嫌弃，做完项目直接逆袭成同城女神

## 二、30 秒文案标准化模板

四段式结构：**离谱钩子(0-3s) → 夸张困境(3-12s) → 神反转落品(12-22s) → 无厘头引导(22-30s)**

台词复刻周氏风格：一本正经地胡说八道，小人物视角，市井幽默感，全程口语化。

## 三、5 镜分镜标准

| 镜号 | 时长 | 功能 | 反差设计 |
|:---:|:---:|:----|:--------|
| 1 | 0-3s | 离谱场景+夸张动作 | 与实体店形成第一层反差 |
| 2 | 3-10s | 困境特写+痛点放大 | 夸张表演放大普通痛点 |
| 3 | 10-13s | 转场：进入店铺 | 虚拟→真实，核心反差 |
| 4 | 13-24s | 体验产品+表情变化 | 正经讲卖点形成反差萌 |
| 5 | 24-30s | 门头+地址+引导 | 真实信息落地+无厘头话术 |

## 四、AI 提示词工程

### 通用风格基底
9:16竖屏，周星驰无厘头喜剧风格，90年代港片暖黄调色，荒诞反差感强烈。真人实景与虚拟场景自然融合，1080P高清，色彩饱满。

### 工具专属优化
- **即梦AI**：补充「抖音原生画质，同城探店真实感，人物面部自然无崩坏」
- **可灵AI**：补充「电影级运镜，港片胶片质感，景深效果自然」
- **剪映AI**：补充「自动匹配经典港片BGM，自带无厘头贴纸特效」

## 五、扣子7节点工作流

### 节点1：开始节点
输入变量：shop_name, local_area, shop_type, core_selling, activity

### 节点2：选题生成（豆包4.0）
生成5个30秒剧情选题，含本地地域关键词，JSON输出

### 节点3：文案生成
四段式结构，口语化台词，每句不超过15字

### 节点4：分镜+提示词生成
5镜30秒标准化分镜，每镜含完整AI提示词

### 节点5：视频生成（核心插件节点）
3种方案：即梦AI官方插件 / 可灵自定义API / 简化批量方案

### 节点6：发布素材生成（可选）
标题+5个话题标签，含地域关键词和无厘头梗

### 节点7：结束节点
输出视频链接+文案+分镜+发布素材

- 风格跑偏 → 强制加入「对标《国产凌凌漆》喜剧质感，真人实景，非动漫」
