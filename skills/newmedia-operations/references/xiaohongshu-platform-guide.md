## 一、核心算法：CES评分

**CES（Community Engagement Score）公式：**
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8

**权重关键：** 评论、转发、关注的权重远高于点赞。引导互动时优先引导「收藏」「评论」，而不是「点赞」。

**时间衰减：** 发布后2小时内的互动对流量跃迁影响最大（黄金2小时），后续互动×时间衰减系数（λ≈0.1-0.3）。

**推荐得分公式：**
推荐得分 = 基础质量分×0.3 + 用户互动分×0.4 + 商业价值分×0.2 + 社交关系分×0.1 - 违规扣分

**流量池晋级门槛：**
| 流量池 | 曝光 | 晋级指标 |
|:------|:----|:--------|
| 种子推荐（1h） | 100-500次 | CTR>3%（图文≥2.5%，视频≥4%） |
| 二阶段（2h） | 1K-5K | 互动率≥5%，收藏率≥3% |
| 三阶段 | 10K+ | CES达标，评论质量高 |
| 大推荐池 | 100K+ | 转化率>2%，日均增量>300 |

连续3天互动率下降30%可能停止推荐。

**2026年算法变化：** 更侧重互动质量——长评论、深度阅读、截屏等高质量互动权重更高；完播率权重降低，收藏/关注/观看时长权重提升。

## 二、内容形式要求

### 图文笔记（小红书核心载体）

| 维度 | 要求 |
|:----|:-----|
| 图片比例 | **3:4竖版（推荐）**，1:1或4:3可选但展示效果差 |
| 图片数量 | **6-9张**（少于6张影响推荐权重） |
| 封面尺寸 | 1242×1660px（3:4），必须加2-5个大字标题 |
| 图片风格 | 真实感＞精美感，实拍图优先，AI图注意标注 |
| 标题长度 | 15-25字，含2-3个emoji，前10字权重最高 |
| 标题公式 | 痛点+数字+解决方案+emoji |
| 正文字数 | ≥600字，原创度≥60% |
| 正文结构 | emoji小标题分段（1️⃣2️⃣3️⃣），关键信息加粗，空行分明 |
| 标签 | 3-5个，覆盖关键词+行业词+流量词 |

### 视频笔记

| 维度 | 要求 |
|:----|:-----|
| 比例 | 竖屏3:4或9:16（推荐），横屏16:9（黑边限流） |
| 时长 | 15秒-30分钟，**2026年主推2分钟以上中长视频** |
| 分辨率 | 1080×1920，≤50MB，MP4格式 |
| 封面 | 3:4（1242×1660px），文字居中，≤5MB |
| 互动率 | 视频比图文高5-8倍 |
| 算法 | 完播率权重降低，收藏/关注/观看时长权重大幅提升 |

## 三、标题公式与SEO

**标题公式（5种）：**
- 痛点式：再[痛点]也不怕，靠这[X]个[方案]解决了😭
- 数字式：[X]个[品类]宝藏，[人群]必看🔥
- 对比式：别买[A]了！[B]才是真的[效果]👍
- 踩坑式：我花了[X]元买的教训，[人群]一定要看💔
- 干货式：保姆级[主题]教程，[X]步搞定📚

**标题铁律：**
- 含2-3个emoji
- 前10字含核心关键词（搜索权重最高）
- ≤28字（手机端不截断）
- 避免标题党

**SEO关键词布局：**
- 标题前10字含核心搜索词
- 正文前100字自然融入2-3次关键词
- 标签3-5个（关键词+行业词+流量词）
- 评论区预设关键词引导
- ❌ 禁止生硬堆砌关键词

**搜索流量占笔记总流量的30-65%。**

## 四、正文结构模板（5种）

**种草推荐型：** 个人缘起→核心卖点（3-5个）→价格→小tips
**干货攻略型：** 步骤1→2→3→避坑提醒→时间/预算参考
**个人体验型(探店)：** 环境→推荐→价格→小提醒→总结
**合集清单型：** 第1个→第2个→第3个→评论区互动
**避坑型：** 坑1→坑2→建议→总结

**完整样板文案见 `wiki/concepts/xiaohongshu-title-and-copy-templates.md`**（种草/攻略/测评/合集/干货5种完整范文）。

## 五、封面设计

- 比例：3:4（1242×1660px）
- 2-5个大字，居中对齐
- 明亮柔和配色，≤3种主色
- 禁止过度美颜/滤镜（虚假种草认定）

---

## 六、合规红线

**七类违禁词：**
1. **绝对化用语：** 最/第一/顶级/极致/完美（替代：个人认为很好）
2. **医疗效果暗示：** 治疗/治愈/根治（替代：改善/缓解）
3. **成分夸张：** 100%纯天然/医用级
4. **效果保证：** 无效退款/保证见效
5. **导流行为（0容忍）：** 加微信/二维码/电话
6. **虚假种草：** 虚构体验/过度滤镜
7. **2026新增：** 婴儿可用/提高智商/明星同款/AI诊断/改变命运/加密货币

**AI内容规则：** 必须标注「AI生成」；对比图须注「原相机+拍摄时间」；功效宣称需资质。

**完整违禁词表见 `wiki/references/xiaohongshu-community-rules.md`。**

## 七、发布与复盘

| 维度 | 建议 |
|:----|:-----|
| 发布频率 | 图文每天1-2篇，视频每周2-3条 |
| 最佳时间 | 早7-9 / 中12-14 / 晚18-22 |
| 互动引导 | 优先引导评论(×4)和收藏，其次点赞 |

**复盘指标：** 小眼睛 / 互动率3-5%+ / 收藏率≥3% / CES评分 / 搜索词排名

```

```
