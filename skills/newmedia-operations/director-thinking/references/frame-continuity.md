## 一、总纲

### 1.1 帧间延续的目标

帧间延续不是简单重复“保持一致”，而是同时锁定五个连续性维度，并明确动作如何从上一段尾帧自然进入本段首帧：

1. **人物延续**：脸型、五官比例、发型、气质、服装、配饰、道具不变。
2. **场景延续**：空间布局、背景物位置、材质、陈设、时间状态不变。
3. **光线延续**：主光方向、色温、明暗关系、阴影位置、曝光不突变。
4. **机位延续**：景别、角度、镜头高度、人物画面位置、运动方向不突变。
5. **特效延续**：粒子来源、运动方向、亮度、密度、颜色和消散过程连续。

五个维度之外，必须再增加一条动作桥接指令：

> 参考@图2延续画面状态，上一段结尾人物处于 `{尾帧状态}`，本段开头从该状态慢慢 `{继续动作}`，继续表演/说话，画面不硬切。

### 1.2 “不硬切”的执行定义

“不硬切”不是抽象风格词，必须写成可观察的连续变化：

- 上一段低头 → 本段从低头状态慢慢抬头。
- 上一段右脚迈出 → 本段右脚落地后左脚继续向前。
- 上一段右手抬到胸前 → 本段从胸前位置继续向外展开。
- 上一段法术光球形成 → 本段光球保持原位置并继续旋转、扩散。
- 上一段人物看向画外左侧 → 本段先保持该视线，再缓慢转回镜头。

禁止只写：

- 延续上一帧。
- 自然衔接。
- 动作连贯。
- 保持一致。

这些词必须和具体的尾帧状态、起始动作共同出现。

### 1.3 延续适用边界

帧间延续主要用于“同一镜头被拆成多个生成段”的接力，不替代正常的镜头切换。

- **同一镜头内部接力**：锁人物、场景、光线、机位和动作惯性，要求不硬切。
- **同场景换景别**：保留人物、场景、服装和光线，但允许机位按分镜明确变化。
- **新场景切换**：使用@图3建立新场景，不要求旧场景继续存在；@图2只继承人物动作状态时，必须明确“仅继承姿态，不继承背景”。
- **大幅动作镜头**：优先继承动作惯性，不能同时强制躯干和站位完全固定。
- **多人镜头**：必须锁定每个人的空间位置、朝向和身份，不能只写“人物保持一致”。

## 二、参考图体系

### 2.1 图片职责

| 图片 | 职责 | 允许控制 | 禁止控制 |
|---|---|---|---|
| @图1 | 人物身份基准图 | 脸型、五官、发型、神态基线、整体气质、人物身份 | 不决定本镜姿态、场景和机位 |
| @图2 | 上一段尾帧图 | 起始姿态、站位、场景状态、光线、构图、机位 | 不得覆盖@图1的人物长相 |
| @图3 | 新场景参考图 | 空间布局、陈设、光线方向、色温、环境材质 | 不参与人物身份判断 |

### 2.2 固定置顶指令

```text
图像职责与优先级：
@图1为人物基准图，锁定人物脸型轮廓、五官比例、发型走向、眉眼特征、鼻口比例、神态基线与整体气质，决定人物身份。
@图2为上一段尾帧图，仅用于延续人物动作姿势、站位、场景状态、机位、光影与构图，不得改变人物长相。
@图3仅用于锁定新场景的空间布局、环境材质、光线方向和色温，不用于人物身份。
人物身份发生冲突时，最高优先遵循@图1，不能被@图2或@图3改变。
```

### 2.3 按镜头使用

- **镜头1，已有人物基准图**：传@图1。
- **镜头2及后续同镜接力**：传@图1＋@图2。
- **切换新场景**：传@图1＋@图2＋@图3。
- **没有人物的纯环境镜头**：可只使用场景图，不套人物身份锚。
- **同一镜头内部不得任意改变图片编号含义。**
- **使用首尾帧插值模式时，不得再混用 reference_image；应改用独立的首尾帧流程。**

新场景衔接句：

```text
@图2仅用于继承上一段结尾的人物姿态和动作方向，不继承@图2背景；本段场景切换为@图3所示空间。人物从上一段尾帧姿态自然完成动作后进入新场景，人物身份仍以@图1为唯一基准。
```

## 三、分场景帧间延续提示词

以下模板均需放在完整Prompt的“尾帧接力锚定”及“分时动作与表演”字段内。

### 3.1 口播镜头

#### 标准版

```text
参考@图2延续画面状态。上一段结尾人物处于{具体姿态}，本段开头从该状态慢慢{继续动作}，继续面对镜头说话，画面不硬切。身体站位和躯干朝向基本不动，仅嘴唇按台词自然开合、自然眨眼、头部轻微晃动，并完成不超过一个小幅介绍手势。人物外貌、发型、穿搭、配饰不变；机位、构图、室内灯光和色调完全延续。动态自然真实，无大幅转身，主播形象稳定。
```

#### 精简API版

```text
参考@图2从{尾帧姿态}慢慢{继续动作}，继续说话，不硬切；半身站位不变，仅唇部、眼神和手部小幅自然动作。人物身份以@图1为准，服饰不变，机位光影延续@图2。
```

#### 参考图衔接

```text
@图1锁人物身份；@图2锁本段起始姿态、口播场景、机位、构图和光线；新口播空间才使用@图3，且@图3不得改变人物。
```



## 五、时长、动作与动态强度

### 5.1 生成时长

- 成片总时长不等于每次生成时长。
- 口播按实际试读拆段，每段不超过10秒；模型硬上限另按当前接口约束。
- 完整内容按台词和动作完成点拆成若干生成段，不预设固定段数。
- 每段台词必须先按实际口语时长拆句，不能把长台词硬塞进短生成段。
- 同一生成段最多两个主要动作；口播通常一个手势已经足够。

### 5.2 动态强度

动态强度不在本连续性参考中另设数值。按 `director-thinking/SKILL.md` 的四档百分比起测区间选值，并记录模型版本与试跑结果。

动态强度和图像参考权重不是同一参数：

- 动态强度越高，动作空间越大，但身份和姿态漂移风险增加。
- 图像参考权重越高，人物与尾帧更稳定，但动作幅度和自然度可能下降。

| 场景 | 建议权重 | 使用理由 | 调整方向 |
|---|---:|---|---|
| 口播半身近景 | 0.40—0.50 | 人物身份、口型和构图稳定优先 | 脸漂移则上调；嘴部僵硬则小幅下调 |

### 6.1 调参顺序

一次只调整一个变量：

1. 先修正尾帧描述是否具体。
2. 再检查@图1/@图2/@图3职责是否冲突。
3. 再减少动作数量。
4. 再调整动态强度。
5. 最后调整图像参考权重。

不得同时改Prompt、动态强度、权重和尾帧，否则无法归因。

## 八、生成与验证流程

### 8.1 生成前

1. 建立角色身份基准图或角色卡。
2. 明确本段是同镜接力、同场景切镜，还是新场景切换。
3. 按实际试读拆句，确保每段能在声明时长内自然说完，且口播单段不超过10秒。
4. 记录上一段尾帧状态：
   - 头部朝向；
   - 视线方向；
   - 左右手位置；
   - 躯干朝向；
   - 身体重心；
   - 行走或动作方向；
   - 道具所在手及空间位置；
   - 特效位置和运动方向。
5. 从视频倒数0.2—0.3秒截取尾帧，不使用绝对最后一帧。
6. 组装@图1/@图2/@图3。
7. 按十二字段模板生成Prompt。
8. 检查本段主要动作不超过两个。
9. 开启画面与原声同步生成。

### 8.2 ASR台词验收

1. 提取生成视频音轨。
2. 使用ASR逐镜转写。
3. 对目标台词和ASR文本执行规范化：
   - 去除标点差异；
   - 统一数字和常见量词写法；
   - 保留专有名词、价格、品牌和关键承诺的逐字要求。
4. 比对目标文本和识别文本。
5. 发现缺字、改字、重复、顺序错误时，人工复听对应时间点。
6. 专有名词被ASR误识别但人工复听正确，可判通过并记录。
7. 实际吞字、抢字或末字不完整，必须重生成或重新拆句。
8. ASR通过后再进入视觉连续性验收。

### 8.3 帧间连续性检查

至少检查以下三个位置：

- 本段首帧；
- 本段中间帧；
- 本段倒数0.2—0.3秒附近的有效尾帧。

并与上一段有效尾帧对照：

| 检查维度 | 通过标准 | 常见失败 |
|---|---|---|
| 人物 | 同一脸型、五官、发型、年龄感和气质 | 换脸、脸型变窄、发型重绘 |
| 服装道具 | 颜色、纹样、配件、持有关系一致 | 玉佩消失、武器换手 |
| 姿态 | 首帧从上一段动作阶段继续 | 重新回到站直、手臂归零 |
| 场景 | 同镜接力时空间布局和背景物一致 | 立柱移位、桌椅增减 |
| 光线 | 光源方向、色温和阴影位置一致 | 左侧光变右侧光 |
| 机位 | 同镜接力时景别、角度、高度一致 | 突然推进、人物位置漂移 |
| 动作 | 有中间过程，符合惯性 | 瞬移、跳步、动作方向反转 |
| 多人 | 人数、身份、站位、相对距离一致 | 增人、少人、换位 |
| 特效 | 来源、位置、方向、颜色和亮度连续 | 光球重置、粒子突然消失 |
| 口型 | 与语音同步，末字后再闭合 | 提前闭嘴、无声张嘴 |
| 画面 | 无黑帧、闪烁、跳帧和风格断层 | 曝光跳变、清晰度突变 |

### 8.4 验收裁决

- **通过**：ASR、人物、场景、动作、口型和有效尾帧全部通过。
- **可后期修复**：仅存在轻微色差、环境声不足或非主体背景小瑕疵。
- **必须重生成**：换脸、吞字、动作重置、人物增减、关键道具变化、明显肢体畸形、光线方向反转。
- **必须重新拆镜**：多人复杂走位持续失败、大动作与长台词冲突、单段动作超过两个、台词无法在目标时长完整说完。

### 8.5 归档

每个通过镜头保存：

- 镜头编号和生成段编号；
- 最终Prompt；
- 使用的@图1/@图2/@图3；
- 模型、通道、时长、分辨率；
- 动态强度和参考权重；
- 原视频；
- ASR文本及比对结果；
- 有效尾帧；
- 连续性验收记录。
