# 文艺国风/探店视频 提示词反推模式库

> 来源：2026-07-11 真实国风探店AI视频深度分析
> 模型：豆包Vision帧分析 → 反推7要素提示词
> 适用：茶馆/民宿/国风咖啡/围炉煮茶等探店类AI视频生成

## 文艺国风风格 6大统一要素

| # | 维度 | 实现方式 |
|:-:|:----|:---------|
| 1 | **色调统一** | 全程低饱和复古胶片，暖灰+柔绿基底，无高对比色彩跳变 |
| 2 | **叙事统一** | 完整探店动线：外景→进店→备茶→茶席→休憩，有头有尾 |
| 3 | **视觉纽带统一** | 同一角色+同一套穿搭贯穿所有镜头，画面之间自动产生连贯感 |
| 4 | **光影统一** | 全程柔和漫射自然光，室内外均避免硬阴影 |
| 5 | **运镜统一** | 固定机位为主 + 浅景深特写 + 前景虚化框架构图，减少机械感 |
| 6 | **画质统一** | 复古胶片颗粒感，轻微柔焦朦胧，降低CG感 |

## 7要素反推提示词语序

按以下语序组装，每段专注一个场景：

```
[空间描述]+[人物/动作]+[光影描述]+[运镜类型]+[风格基调]+[画质约束]
```

## 同城实体店适配指南

当拆解参考视频并将风格迁移到实体店短视频时：

| 原始元素 | 替换为 |
|:---------|:-------|
| 闽南老街/老洋房 | 店所在的地域特色建筑（如株洲老街区） |
| 豆绿色旗袍 | 小鹿/郭襄的固定穿搭（不变，保持角色一致性） |
| 围炉煮茶元素 | 店内特色（熹园=茶盏+竹椅，亮瞳=护眼仪器等） |
| 复古胶片色调 | 保留（通用美学，不限于地域） |

**核心原则：** 色调/光影/画质/运镜风格直接迁移，场景和角色替换为门店实际内容。
