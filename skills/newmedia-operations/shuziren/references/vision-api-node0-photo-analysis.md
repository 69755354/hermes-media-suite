# 豆包Vision API：门店实景照分析指南

## 适用节点

shuziren 节点0（信息采集）

## 为什么需要这个

用户发来的门店实景照（门头/店内/服务/产品），需要自动提取店名、地址、服务项目、价格信息、宣传语等结构化数据。人手写等于白搭，OCR单独用又没上下文理解能力。

## API配置

| 参数 | 值 |
|:----|:----|
| 端点 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions` |
| 模型 | `doubao-seed-1-6-vision-250815` |
| 认证 | `Authorization: Bearer $ARK_API_KEY` |
| 温度 | 0.1（纯信息提取不需要创意） |
| max_tokens | 2048 |

## 调用方式

### 1. 准备图片

用户发来的图片保存在 `/home/ubuntu/.hermes/image_cache/` 目录。

每张图用 base64 编码：
```python
import base64
with open(img_path, 'rb') as f:
    b64 = base64.b64encode(f.read()).decode('utf-8')
```

### 2. 构造messages

每张图作为一个 content item，先加文字标识再加图片：

```python
messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "分析指令（见下方）"},
            {"type": "text", "text": "--- 图：门头 ---"},
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{b64_1}"}},
            {"type": "text", "text": "--- 图：店内环境1 ---"},
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{b64_2}"}},
            # ... 继续加图
        ]
    }
]
```

### 3. 分析指令模板

```text
请详细分析这N张图片，输出JSON格式：

1. 这是什么行业的店（餐饮/美容/服装/其他）？
2. 店名叫什么（从门头和招牌文字识别）？
3. 门店地址/地标信息（如果有的话）
4. 卖什么产品/服务？价格多少？
5. 装修风格和环境描述
6. 服务场景里在做什么项目？
7. 有什么明显的宣传语/活动信息？

输出JSON：{"行业":"","店名":"","地址":"","产品/服务":"","价格信息":"","装修风格":"","服务场景":"","宣传信息":"","完整文字OCR":""}
```

## 注意事项

### 不要做
- **不要单张图单独调API** — 多张图一起传，API自动关联上下文理解，比拆开调准确
- **不要用本地OCR替代** — 豆包Vision自带文字识别，精度够
- **不要手动补信息** — 图中没有的价格信息，等用户补，不瞎编

### 规范做法
- 用户说明"门头/店内/服务"分类后，直接在content里标注 `--- 图：xxx ---` 分类
- 所有图一次性传完，不要分批调
- 拿到JSON后，需与用户手动补充的价格/套餐信息合并
- **电话隐私：** OCR提取到的电话号码不得出现在任何交付物中（JSON里可保留供内部使用，但最终给用户的视频成品/文案里不能出现）
