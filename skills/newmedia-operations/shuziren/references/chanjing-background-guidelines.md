# 婵镜数字人背景图指南（2026-07-15 会话沉淀）

## 场景选型

### 心理咨询/情感口播
- 书房/工作室暖色调
- 书架+台灯+柔光
- 浅灰/米白/暖木纹背景
- 不要冷白墙（像咨询室不像办公室）

### 探店/本地生活
- **直接用实景照** — 门头/店内/茶台实拍图当背景
- 婵镜 `bg.src_url` 传实景图URL
- 不要AI生成的幻视背景（观众一眼假）

### 商务/产品介绍
- 展厅/简约商务风
- 浅灰渐变 / 深蓝沉稳
- 背景有空间感（景深+光影），不要纯色平涂

## 通用原则

| ✅ 正确 | ❌ 错误 |
|:-------|:--------|
| 背景有景深感（实景/光影/纹理），不扁平 | 纯白/纯黑背景 → 显假，像抠图没抠干净 |
| 颜色跟穿搭不打架（衣服深→背景浅，反之亦然） | 背景色和衣服同色系糊在一起 |
| `bg.src_url` 传图，1080×1920竖版，公网可访问 | `background.file_id` 传图（实测不生效） |

## 技术参数

```
bg.src_url:  公网可访问的图片URL
bg.width:    1080
bg.height:   1920
```

## 注意事项

- 背景图不要有人脸/人物，婵镜可能识别冲突
- 背景图不要有文字/水印，出片后观众注意力被拉走
- 色彩饱和度不要过高，抢数字人焦点
- 背景与穿搭色调呼应，但色相不重复
- 纯色背景建议加微纹理（木纹/布纹/大理石），不要平涂
