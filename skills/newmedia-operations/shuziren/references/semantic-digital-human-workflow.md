# 语义驱动型数字人口播工作流

> 来源：用户提供（2026-07-14），2026-07-15更新：SSML→纯文本标点控节奏
> 核心原则：数字人的动作/表情/手势必须根据文案语义动态生成，不能机械复刻参考视频动作。

---

## 一、核心流程

```
用户文案 → 语义拆分 → 动作编排 → 标点控节奏（替代SSML） → 婵镜参数生成 → 视频生成
```

---

## 二、语义拆分规则

不要整段丢给婵镜。先拆成语义单元：

| 单元类型 | 示例 |
|:--------|:-----|
| 开场问候 | 大家好，欢迎来到我们的展厅。 |
| 引入话题 | 今天我带大家看一款核心产品。 |
| 卖点1 | 它的第一个优势是效率更高。 |
| 卖点2 | 第二个优势是使用更简单。 |
| 卖点3 | 第三个优势是成本更低。 |
| 行动引导 | 如果你也想提升效率，可以重点了解一下。 |

**每句控制在15字以内，太长必须拆分。**

## 四、标点控节奏（替代SSML）

**婵镜REST API不支持SSML标签（`<break>`/`<emphasis>`/`<prosody>`），传了返回400。**

**替代方案：纯文本+标点控制停顿和语气，听觉差距极小。**

### 替换规则

| 节奏 | 写法 | 效果 |
|:----|:-----|:-----|
| 短停顿 | `，` | 约200ms停顿 |
| 中停顿 | `。` | 约400-500ms停顿 |
| 长停顿/情绪留白 | `\n……` | 换行+省略号，约1s停顿 |
| 重点加重 | ` 关键词！` | 前后空格+感叹号，自动加重 |
| 开头悬念 | 第一句结尾用`……` | 制造钩子停顿 |
| CTA收尾 | 双感叹号`！！` | 拉高语气感染力 |

### 示例

```xml
<!-- ❌ SSML（婵镜返回400） -->
大家好，欢迎来到我们的展厅。<break time="0.4s"/>
今天我带大家看一款核心产品。<break time="0.3s"/>
第一，<emphasis level="moderate">效率更高</emphasis>。

<!-- ✅ 纯文本（无报错） -->
大家好，欢迎来到我们的展厅。
今天我带大家看一款核心产品。
第一， 效率更高！
```

## 五、婵镜参数模板（纯文本版）

```json
{
  "person": {
    "id": "数字人ID",
    "lip_sync_precision": "high",
    "face_detail": true,
    "face_smooth": false,
    "blink_interval": 8,
    "head_sway": true,
    "body_breath": true
  },
  "audio": {
    "tts": {
      "audio_man": "音色ID",
      "speed": 0.95,
      "pitch": 1.0,
      "emotion_enhance": true,
      "text": ["口播文案（纯文本，无SSML标签）"]
    }
  },
  "motion": {
    "auto_gesture": true,
    "gesture_strength": 0.3,
    "gesture_frequency": "low",
    "head_sway": true,
    "body_breath": true
  },
  "bg": {
    "src_url": "背景图公网URL",
    "width": 1080,
    "height": 1920
  },
  "emotion": "开场微笑点头，介绍产品时轻微转向，讲第一点时单手抬起强调，整体亲和专业",
  "screen_width": 1080,
  "screen_height": 1920
}
```

⚠️ `background.file_id` 实测不生效，改用 `bg.src_url`。

## 六、优化要点

1. **文案短句化**：每句≤15字
2. **每句用标点控节奏**：逗号=短停，句号=中停，换行+省略号=长停
3. **重点词加空格+感叹号**：自动加重
4. **emotion字段写动作提示**：告诉模型表演基调
5. **gesture_strength ≤ 0.45**：超过会机械挥手
6. **face_smooth: false**：避免塑料脸
7. **不要全程一个动作**：短句+标点节奏+emotion提示共同驱动变化

## 七、Hermes系统提示词

```
你是一名数字人口播导演。
用户需要生成婵镜数字人视频时，先完成以下步骤：
1. 将口播文案拆成短句，每句≤15字
2. 根据每句话的语义，判断对应的表情、手势、头部动作和情绪
3. 生成结构化脚本，包含：文案、动作、情绪、手势强度、停顿
4. 将脚本转换成纯文本口播文案，用标点控制节奏（不用SSML标签）
5. 根据文案内容生成婵镜create_video参数
6. 默认竖屏1080x1920
7. 动作强度不要太高，手势幅度控制在自然商务口播范围
8. 输出前检查：不要长句、不要频繁挥手、不要夸张表情、不要机械朗读
9. 文案中不能有任何XML/HTML标签（<break>、<emphasis>等会被婵镜API拒绝）
```
