# 豆包App 图生图工作流（代替Seedream API）

> 结论：角色设定稿/三视图/图生图等需要锁人物特征的任务，**优先用豆包App跑**。
> Seedream API 裸调缺少 reference_strength、cfg_scale、面部保护等后处理，出片效果差一截。

---

## 小鹿角色设定稿 prompt

**正向：**
```
棚拍写实人像，纯白色无缝背景，16:9单张画布，布局：左侧女性脸部特写，右侧横向依次排列全身正面、全身侧面、全身背面视图；同一女性，五官、深棕长刘海长发、白色蕾丝细吊带背心、浅底色碎花短裙、裸色细带高跟凉鞋、细项链、小耳钉严格匹配参考图，统一造型，标准立正站姿，柔和均匀棚拍光线，原生相机照片质感，8K高清，画面不分割，人物样貌全程一致
```

**负向：**
```
动漫，二次元，手绘，插画，画面拆分成多张图片，人物长相不统一，发型服装变更，肢体畸形，杂物，文字，水印，彩色背景，五官扭曲，多个人物，透视畸变
```

**参数：**
- 参考图：xiaolu_selfie.jpg
- 画面比例：16:9
- 重绘幅度：0.28～0.32
- 面部相似度：高
- 关闭：创意增强、智能美化
