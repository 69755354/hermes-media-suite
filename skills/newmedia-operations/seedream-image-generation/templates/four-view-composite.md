# 四视图/展示图 Prompt 模板

## 版式A：左侧半身特写 + 右侧三张全身（横版长条）

> 用途：人物形象展示卡，模特卡，角色参考图
> 尺寸：2560×1440（16:9 横版，满足368万像素最低要求）
> 模式：图生图（--ref_url 传人物参考照）
> 重绘幅度：0.28 ~ 0.32 | 面部相似度：高 | 关闭：创意增强、智能美化

### 正向

```
严格沿用参考图内同一名年轻东亚女性，完整复刻五官、脸型、[发色]长卷发、肤色、面部神态，全程为同一个人物，禁止换人、禁止改动面部五官特征。
统一穿搭：[完整穿搭描述]，所有视图服装花纹、款式完全一致。
纯白色背景，16:9横版角色设定稿排版，无任何道具。画面最左侧占据画面1/3宽度，放置超大胸部以上面部特写；右侧占据2/3宽度，横向整齐排列三张完整全身站立人像，从头到脚完整展示，依次为正面全身视图、标准侧面全身视图、背面全身视图。三个人物高度统一、脚底对齐、尺寸相同、间距均匀规整。
全部画面柔和自然光统一，光影色调完全一致，平视机位，镜头与人眼等高，禁止俯拍、仰拍。写实真人摄影质感，保留原生皮肤肌理、发丝层次、服装面料褶皱细节。
无边框、无分割黑线、无文字、无水印、无多余杂物。
约束：禁止过度美颜、磨皮、瘦脸微调；五官无扭曲变形；不存在肢体畸形；无画面色差；不添加滤镜；拒绝卡通、CG、3D渲染画风。
```

### 负向

```
更换人物，改动五官，变换性别，男性，男性骨架，换装，改变鞋子样式，改变发型，过度美颜，重度磨皮，瘦脸，五官重塑，动漫，卡通，3D渲染，肢体畸形，手脚变形，画面光影色差，边框，分割线条，文字，水印，多余道具，俯拍，仰拍
```

### 填写示例（小鹿）

```
[发色] = 深棕色
[完整穿搭描述] = 白色蕾丝细吊带背心，浅底色碎花短裙，裸色细带高跟凉鞋
```

## 版式B：六宫格三视图（已废弃）

> 此版式已由版式A替代。完整三视图建议用原工具生成，不在Seedream中跑。

## 已知坑点

- **Seedream 4.5 图生图锁不住参考图的穿搭、发型、五官细节**。即使prompt明确指定，输出仍可能跑偏（卷发变直发、深棕变黑色等）。
- **不要自作主张换参考图**。图生图效果不好时，先问用户该用哪张图。每次换图相当于换一个人，输出一致性会被破坏。
- 如果必须输出精准的人物特征，建议用原工具（即梦/其他）直接生成，不在Seedream中做角色设定稿。
