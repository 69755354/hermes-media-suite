# 短视频引流文案·句式库 v1
> 来源：冷酸灵双11 15条脚本实战拆解（3轮返工后定稿）。
> 用法：先定方向→选句式→填变量→过违禁清单→过合规。禁止自由发挥句式骨架。

## 零、判定只有两条

1. **说完一半还留着后半句**——观众得想知道后半句
2. **推翻了他以为对的事**，或把一个模糊感受说成具体动作

不满足这两条的钩子，写得再美也重写。

## 一、钩子句式（前3秒）

### S1 场景肉身型（场景痛点方向主力）
`[具体时刻/地点] + [身体第一反应]，[错判或让步]`
- 冰美式第一口，牙一哆嗦，后面那杯你只敢小口抿。
- 火锅刚滚，一口热汤下去，你捂着脸等那阵酸过去。
- 早起刷牙牙根一激灵，你以为是空调干的。
**硬要求**：必须有身体动作（哆嗦/捂脸/激灵/缩手/停一下）。
**废稿特征**："很多人都有敏感问题""你是否也遇到过"——抽象、无动作。

### S2 时间账单型
`[长期行为] + 到第N年/用了N年，[身体开始还债]`
- 奶茶喝到第三年，你的牙开始怕冰了。
**作用**：慢性伤害变"到账了"，制造紧迫。

### S3 认知纠偏型（最抗用，优先选）
`[大家都在做的事]，[一半/大部分人]错在[一个具体动作]`
- 抗敏牙膏第一步就错的人，一半是沾了水。
- 泡沫多不等于刷得干净，这条骗了太多人。
**硬要求**：错必须具体到可执行动作。
**废稿特征**："方法不对""用错了方式"——不可执行，等于没说。

### S4 否定误因型（慎用，全片最多一次）
`[现象]不是[大众以为的原因]，是[真因]`
- 牙缝变大不是老了，是牙龈边缘先撑不住了。
**风险**：这就是"不是A而是B"的AI指纹，出现第二次就露馅。

### S5 二分法+反问型
`[品类]分两种：一种[X]，一种[Y]。你买的是哪种？`
- 抗敏牙膏分两种：一种麻，一种封。你买的是哪种？
**硬要求**：二分必须真能盖住品类，生造的二分一眼假。

### S6 算账评价型（转化向）
`[常见买法/行为]，是[最X的Y]`
- 双11买单支牙膏，是最不会算账的一种买法。
- 没用过的牙膏先囤一年量，是最贵的试错。

### S7 引语反驳型
`[身边人常说的话]，你别真信。`
- 爸妈说牙酸"忍忍就过去了"，你别真信。

### S8 新事实反问型（时效型，适合大促）
`[刚变化的事]，你还在[旧做法]？`
- 今年双11抖音没预售了，你还守着付定金？

## 二、正文三段

### 第2段 机制：必须过"人话转译"
写法：`它走的是[X]的路子，不是[YC]` + 一句白话比喻 + 一句"跟别人的差别在哪"
- 反例（成分说明书）："含生物活性玻璃陶瓷与重组角蛋白，形成保护层"
- 正例："走的是'堵'的路子，不是让你麻一下。碰到口水就贴在牙面上，把一受刺激就发酸的小通道盖住。"
**铁规**：一段最多2个专业名词，每个紧跟一句白话解释。第三个名词直接砍。

### 第3段 用法：给可执行动作，不给形容词
格式：`怎么做（动作）+ 做到什么程度 + 一个自检方法`
- 正例："牙刷先别冲水，挤一指节，从牙龈和牙那条交界线开始，小圈刷，每颗牙八到十下……刷完用舌头舔一圈，滑的，就是刷到位了。"
**自检方法**必须落到身体感受（舔一圈是滑的／泡沫变少别慌）。
**废稿特征**："轻柔护理""深度清洁""温和不刺激"——形容词不算内容。

### 第4段 转化：不带感叹号，不催不吼
格式：`[时机] + [动作] + [降低门槛的一句]`
- "双11这几天现货直降，下面链接拍下就发，不用凑单。先来一套，合适了再回来囤。"

## 三、变量填充

| 变量 | 来源 | 禁用 |
|---|---|---|
| [具体时刻] | 真实场景（早起/吃完火锅/洗完牙） | "日常生活中" |
| [身体反应] | 能被拍出来的动词 | "感到不适" |
| [具体动作] | 手能做的 | "正确使用" |
| [真因] | 客户给的卖点机制 | 自己推的机理 |
| [X][Y] | 客户文案原词 | 自造概念 |

---

## 四、字数与时长

字数 ÷ 5.5 = 秒。钩子 ≤25字（3秒念完），全稿 280–320 字。
超了先砍第3段重复动作，不砍第4段。

---

## 五、开工顺序

1. 定方向（场景痛点／认知纠偏／转化）
2. 每方向配1–2个句式，15条里同一句式不超过3条
3. 填变量，不改句式骨架
4. 过违禁清单
5. 过合规（不宣称疗效、不做横向对比、不用医疗动词）
6. 跑 check_copy_style.py，不过不许交
