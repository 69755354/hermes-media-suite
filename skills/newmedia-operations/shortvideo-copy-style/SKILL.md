# 短视频引流文案：句式库 + 自动检查

## 何时用

- 写抖音/小红书短视频引流脚本、口播稿、信息流文案
- 客户说"钩子太啰嗦""不像人说的话""太AI了"
- 一批15–30条需要控制重复度
- 文案改了两轮以上还没过

## 核心判断：文案好坏的唯一两条线

1. **说完一半还留着后半句** —— 观众得想知道后半句是什么
2. **推翻了他以为对的事** —— 或把一个模糊感受说成具体动作

不满足这两条，写得再美也重写。这两条代替不了审美，但能拦住80%的废稿。

## 为什么文案是全链最难的一环

| | 其它节点 | 文案 |
|---|---|---|
| 对错线 | 数据错了能查、图崩了能看 | 只有"像不像人说的" |
| 模型强项 | 信息准确 | 信息准≠语感对 |
| 返工代价 | 局部重做 | 一改全链废（分镜+图全重做）|

所以文案必须**前置锁死**，且必须给模型**句式骨架**而不是让它自由发挥。

## 用法（四步，不许跳）

1. 读 `references/句式库_v1.md` —— 按方向选1–2个句式，同一句式15条里不超过3条
2. 填变量，**只填不改骨架**。改了骨架就等于放弃约束
3. 读 `references/违禁清单.md` 自查
4. 跑检查器，分数 <90 不许交：

```bash
python3 scripts/check_copy_style.py <定稿.md>
```

输出每条扣分明细 + 15条互查重复度，0–100分，判定：≥90可用 / 75–89小修 / <75重写。

## 实测基线（冷酸灵双11，15条）

- 定稿：100分
- 典型AI味反例：40分（拦住成分堆砌、医疗动词、催促吼叫、感叹号、钩子超长）

工具必须两头都能验：好稿过、差稿拦。只验好稿等于没验。

## 硬规则（血泪）

1. **钩子≤25字**，超了就是3秒念不完，直接重写
2. **第2段最多2个专业名词**，每个紧跟一句白话解释；第三个名词砍掉
3. **第3段必须有可执行动作+一个身体自检方法**（"舌头舔一圈是滑的"），形容词不算内容
4. **一条片只用一次"不是A而是B"**，这是AI指纹句式
5. **第4段禁感叹号、禁催促吼叫**（赶紧/最后一天/手慢无）
6. **字数÷5.5=秒**，全稿280–320字
7. 牙膏/化妆品类：禁疗效宣称、禁医疗动词、禁横向对比

## 接到"改钩子"指令时

不要连着全文一起改。**钩子单独一轮**：一次出20条候选→筛5条→定完再写正文。带着全文改钩子必然越改越啰嗦。

## 常见误判（工具会报，需人工裁决）

- "别马上刷"里的"马上"是禁止性用法，不是催促 → 脚本已排除否定前缀
- 破折号单次使用正常，≥2次才算泛滥
- 检查器只做机械判定，**不替代人工通读**，分数100也可能是废话

## DS 写文案专项（2026-10-30 实测，冷酸灵双11）

**症状**：DeepSeek 直出文案「语感差、不流畅、没网感」——钩子爱写说明腔（"很多人都有""你是否也""说的就是你"），爱导流喊话（"先别划走""这条一定看完"），爱疑问句+感叹号，缺身体动作。

**实测结论（同 prompt 三组，各 2 轮）**：

| 投喂方式 | 结果 |
|---|---|
| 只给产品+方向，自由发挥 | 6 条里 5 条是说明腔/喊话/感叹号，动作缺失 |
| 给违禁清单+规则，不给骨架 | 仍飘，长度不可控 |
| 给骨架 S1/S2 + 硬约束 + 禁抄 | 全合规、18–21 字、动作齐 |
| 骨架 + 3 条例句 | 合规 **但整句照抄例句原场景**（冰美式第一口/火锅刚滚/奶茶第三年） |

**规则**：
1. **DS 不准自由发挥**——必须先给骨架（见 `references/句式库_v1.md`），只填变量。不给骨架 = 必然退回说明文腔，这是模型默认，不是运气问题。
2. **例句只当节奏标尺，必须加一条硬约束**："例句只看节奏，场景必须换；出现例句里的原场景原句即重写"。否则 DS 直接抄句子，15 条撞车。
3. 硬约束最少写这五条：≤25字 / 必须有身体动作 / 说完一半留后半句 / 禁说明腔与导流喊话 / 禁感叹号与"不是…而是…"。
4. 出稿必过 `scripts/check_copy_style.py`，<90 不许交；它同时查 15 条互查重复度，能抓出抄例句。

**模型差异（实测）**：同一骨架 prompt，GPT-6 Astra 的句子口语度更高（"午饭喝冰水缩了脖，还以为…"），DS 偏模板化但仍可用。**结论：DS 的短板主要是缺约束，不是能力**——先补骨架；真要更高语感再考虑文案环节换模型，结构/信息活继续留给 DS。
