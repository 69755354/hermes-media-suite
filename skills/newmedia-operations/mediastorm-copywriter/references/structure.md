# 结构骨架模板

## A. 黄金七段式（深度议题 / 纪实科普，默认）
```
① 钩子(1-3句)         举起实物/反常识设问/锚定"你"的处境
② 升维立意(2-4句)     "但你有没有想过…" → 背后更大的意义（可选列出2-3个问题）
③ 合作方植入(可选1段) "正好/一拍即合…作为<品牌>的合作伙伴…"
④ 分点主体(3-5段)     每点 = 现象 + 数据(带换算) + 类比 + 样片/案例
⑤ 转折深入(1-2段)     "但是…" "那有没有解法呢?有" —— 制造波折
⑥ 升华畅想(1段)       拉高到时代/人生/情怀，情绪递进，落一句金句
⑦ CTA 收尾
```

## B. 产品评测变体
```
① 购买决策疑问开场     "当你点开这个视频，说明你一定考虑过要不要买/值不值"
② 改框架/给预期        "这次不妨先改改节目框架，先看样片再聊硬件";先剧透最大亮点
③ 逐维度拆解(多段)    外观→重量手感→镜头/参数→画质(量化测试)→续航→配件
                       每维给"在/不在我们预期之内" + 客观数据 + 主观体验
④ 平衡表达             优点讲透，也讲"但是我也得说<缺点>"
⑤ 值不值收束           "你多花的钱其实买在了…我不知道你觉得值不值"
⑥ CTA（常带"你会选A还是B?"互动）
```

## C. 游记 vlog 变体
```
① 栏目IP + 仪式开场    "去了一趟系列<地名>" / "抛硬币，节目开始" / "样片日记"
② 双人互动 + 反差吐槽  主持人互相调侃
③ 边走边科普          穿插当地历史/文化/数据
④ 贯穿式悬念小游戏     一条钩子贯穿全片，不断回扣
⑤ 情怀升华            上升到情感/格局
⑥ CTA（常带"下一期去哪?评论区告诉我们"）
```

## 时长与篇幅对照（样本实测）
| 目标时长 | 建议字数 | 分点主体段数 |
|---|---|---|
| 3-4 分钟 | 1500-2000 | 2-3 |
| 5-8 分钟 | 2500-4500 | 3-5 |
| 10 分钟+ | 5000+ | 5-7 |
