# 开头钩子库（6类，附可套用句式）

> 铁律：第一句就是钩子，1-2 句内抛出；禁止「大家好/今天我们来聊聊」式铺垫。
> 钩子后立刻用一个「但你有没有想过…」过渡到升维。

## 1. 实物 / 微观特写
举起一个具体物件，由小见大。
- 句式：「这是一<量词><物>。准确地说，这是一<物>…」→ 放大/切换视角 → 抛问题。
- 样本：「这是一枚硬币，那准确地说，这是一枚用 AI 生成的硬币…它正面朝上的概率是多少呢?」

## 2. 反常识 / 悬念设问（含猜价）
抛一个反直觉的问题或让观众猜。
- 句式：「<现象>，你猜/你以为…?其实不是。」「<X>，竟然是<反常识结论>?」
- 样本：「足球比赛的广告牌，竟然是假的?」

## 3. 观众处境代入
用「你一定/我相信你」直接锚定观众此刻的动机。
- 句式：「当你点开这个视频，说明你一定 <动机>。」「我相信你最近 <共同经历>。」

## 4. 极端场景白描
用画面感极强的处境把人拽进现场。
- 句式：「<强场景>，而你 <受限处境>。」

## 5. 人物 / 身份前置
直接点名主角，或用第一人称代入。
- 句式：「你的名字是<人名>，这个名字不够熟悉对吧?那你的<作品>…」

## 6. 栏目 IP + 仪式转场
固定栏目名 + 标志性仪式。
- 句式：「<栏目名>系列，这一次我们去 <地点>…」「我把这个硬币扔进去以后，我们这个节目就开始了。」

## 选型建议
- 讲原理/议题 → 类型 1 或 2
- 评测 → 类型 3（购买动机代入）
- 纪实/科普 → 类型 1 或 4
- 人物/幕后 → 类型 5
- 游记/vlog → 类型 6
