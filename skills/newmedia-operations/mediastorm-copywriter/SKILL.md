# 影视飓风口播稿生成器

> 来源：开源 mediastorm-copywriter（GitHub imfangli/mediastorm-copywriter，基于影视飓风最新19条视频字幕的结构化分析）
> 定位：**长口播（3-10分钟）专用**。30秒短广告/短剧文案用 content-review-gate + huoshan 分支（ai-ad-creative-methodology 未注册，2026-08-09 确认断链）。

## 使用流程

### 第 1 步：收集输入（缺失则询问用户，可用合理默认）
- **选题**（必填）：这期口播讲什么。
- **内容类型**：深度议题 / 产品评测 / 纪实科普 / 游记vlog / 人物访谈（默认按选题自动判断）。
- **目标时长**：默认 5-8 分钟（约 2500-4500 字，对应样本均值）。
- **合作方/植入**（可选）：品牌名 + 卖点；无则跳过植入段。
- **关键信息/素材**：可提供的数据、案例、观点；不足时用 `[待补充: …]` 占位，不要编造具体数字。

### 第 2 步：选骨架
按内容类型套用对应结构：
- 深度/科普/纪实 → **黄金七段式**（钩子→升维→植入→分点主体→转折→升华→CTA）
- 产品评测 → **评测变体**（购买疑问→改框架→逐维度拆解→值不值→CTA）
- 游记vlog → **栏目变体**（栏目IP+仪式开场→互动吐槽+边走边科普→贯穿悬念→情怀升华→CTA）

### 第 3 步：写作（严格执行 10 条硬规则）
1. 第一句就是钩子，无「大家好」式铺垫
2. 钩子后 2-3 句完成升维，点出更大意义
3. 全程第二人称「你」；平均每 100-150 字有一个设问
4. 主体分点，每点含 现象+数据+类比+例证
5. 所有抽象数据做生活化换算；抽象概念打比方
6. 至少一次「但是/其实」转折
7. 合作方自然植入，不生硬
8. 有个人观点、诚实表达（优缺点都讲）
9. 结尾有升华 + 一句金句
10. 用 CTA 模板收尾，以「那么我们下次再见」结束
11. 未编造未经核实的具体数字/事实（用占位符标注）

### 第 4 步：自检（交付前逐项打勾）
- [ ] 第一句就是钩子，无「大家好」式铺垫
- [ ] 钩子后 2-3 句完成升维
- [ ] 全程第二人称「你」；每 100-150 字一个设问

## 钩子库（6类，附可套用句式）

> 铁律：第一句就是钩子，1-2 句内抛出；禁止「大家好/今天我们来聊聊」式铺垫。

### 1. 实物 / 微观特写
- 句式：「这是一<量词><物>。准确地说，这是一<物>…」→ 放大/切换视角 → 抛问题
- 样本：「这是一枚硬币，那准确地说，这是一枚用 AI 生成的硬币…它正面朝上的概率是多少呢？」

### 2. 反常识 / 悬念设问（含猜价）
- 句式：「<现象>，你猜/你以为…?其实不是。」「<X>，竟然是<反常识结论>?」
- 样本：「足球比赛的广告牌，竟然是假的?」

### 3. 观众处境代入
- 句式：「当你点开这个视频，说明你一定 <动机>。」「我相信你最近 <共同经历>。」
- 样本：「当你点开这个视频，说明你一定考虑过这个问题。」

### 4. 极端场景白描
- 句式：「<强场景>，而你 <受限处境>。」
- 样本：「你只有一个人，边上有500万只蜜蜂在倾尽全力攻击你，而你不能动。」

### 5. 人物 / 身份前置
- 句式：「你的名字是<人名>，这个名字不够熟悉对吧?那你的<作品>…」

### 6. 栏目 IP + 仪式转场
- 句式：「<栏目名>系列，这一次我们去 <地点>…」「我把这个硬币扔进去以后，我们这个节目就开始了。」

**选型建议：** 讲原理/议题→1或2；评测→3；纪实/科普→1或4；人物/幕后→5；游记/vlog→6

## 结构骨架

### A. 黄金七段式（深度议题/纪实科普，默认）
```
① 钩子(1-3句)     举起实物/反常识设问/锚定"你"的处境
② 升维立意(2-4句)  "但你有没有想过…" → 背后更大的意义
③ 合作方植入(可选) "正好…作为<品牌>的合作伙伴…"
④ 分点主体(3-5段)  每点 = 现象+数据(带换算)+类比+样片
⑤ 转折深入(1-2段)  "但是…" "那有没有解法呢?有"
⑥ 升华畅想(1段)    拉高到时代/人生/情怀，落一句金句
⑦ CTA 收尾
```

### B. 产品评测变体
```
① 购买决策疑问开场  "当你点开这个视频，说明你一定考虑过要不要买"
② 改框架/给预期    "这次不妨先改改节目框架，先看样片再聊硬件"
③ 逐维度拆解       外观→重量→镜头参数→画质(量化)→续航→配件
④ 平衡表达         优点讲透，也讲"但是我也得说<缺点>"
⑤ 值不值收束       "你多花的钱其实买在了…"
⑥ CTA（常带"你会选A还是B?"互动）
```

### C. 游记 vlog 变体
```
① 栏目IP+仪式开场  "去了一趟系列<地名>" / "抛硬币，节目开始"
② 双人互动+反差吐槽
③ 边走边科普       穿插当地历史/文化/数据
④ 贯穿式悬念小游戏 一条钩子贯穿全片，不断回扣
⑤ 情怀升华         上升到情感/格局
⑥ CTA（常带"下一期去哪?评论区告诉我们"）
```

### 时长与篇幅对照
| 目标时长 | 建议字数 | 分点主体段数 |
|---|---|---|
| 3-4 分钟 | 1500-2000 | 2-3 |
| 5-8 分钟 | 2500-4500 | 3-5 |
| 10 分钟+ | 5000+ | 5-7 |
