# 游戏攻略类文章官方数据源核验（王者荣耀实战记录 2026-08-14）

适用：评审《王者荣耀》等 MOBA 英雄攻略时，核验技能/连招/装备/出装流派是否真实。
web_search / web_extract 后端挂掉时，直接 curl 官网，不依赖搜索工具。

## 官方数据源（curl 直连，已验证可用）

```bash
# 英雄资料页（妲己=109；其他英雄 ID 在官网列表页查）
curl -s "https://pvp.qq.com/web201605/herodetail/109.shtml" -o hero.html
# 装备全量 JSON（121 件）
curl -s "https://pvp.qq.com/web201605/js/item.json" -o items.json
```

### 编码坑（必踩）
英雄资料页是 **GBK** 编码，直接 python 读会乱码。必须：
```bash
iconv -f GBK -t UTF-8 hero.html > hero_utf8.html
```
item.json 是 UTF-8，不用转。

### 解析要点
- 技能描述、被动、Tips 都在 `<p>...</p>` 标签内，用正则 `re.findall(r'<p[^>]*>([^<]{5,300})</p>', html)` 提取，过滤长度>10 去重。
- 官网 Tips 区直接写明连招：妲己写「231」（先2技能魅惑→3大招→1技能收尾）——文章写 213 或把 231 解释成 3→2→1 都是错的。
- item.json 是数组，字段 `item_name` / `des1` / `des2`。

### 流派名真伪验证
搜装备库有没有带该流派名的装备：`[i['item_name'] for i in items if '蛇' in i['item_name']]`。
「6蛇流」检索结果=0 件 → 不是官方/通用流派，是作者自造名词。

## 已核验事实锚点（2026-08-14 官网）

### 妲己技能
- 被动：技能命中减目标法防 30~72 点，持续 3 秒，最多 3 层
- 1技能灵魂冲击波：范围伤害 570/635/.../895（+120%AP）。**官网无任何「目标身上有减速则增伤」机制**——文中出现即编造
- 2技能偶像魅力：锁定抛出爱心，285~460（+66%AP）+ 1.5 秒晕眩
- 3技能女王崇拜：5 团狐火随机攻击范围内敌人，每团 325/405/485（+75%AP）；同一目标吃到后续狐火只造成 50% 伤害

### 妲己相关装备（官网 item.json 实测）
- **冰霜法杖已不存在**，现为「凝冰之息」：减速 5%~10% 最多 2 层，持续 1.5 秒（不是 20%）
- 极寒风暴：**受击触发**（单次伤害超当前生命 10%），减速 15%~30%，持续 2 秒（不是固定 30% 主动减速）
- 不祥征兆：减攻速 20%~40% 与移速 7.5%~15%（不是 30%）
- 冰痕之握：减速 15%~30% 但 **远程攻击减半**（妲己是远程，实际 7.5%~15%）
- 疾步之靴：跑图鞋（脱战加速），无减速效果
- 冷静之靴：15% 冷却，无减速
- 永夜守护：受击回复 + 减 50% 受到的减速
- 名刀司命：保命装

### 减速叠加规则
MOBA 减速**不线性叠加**。「冰霜法杖 20% + 极寒风暴 30% = 50% 减速」这种加法是编造。
多减速取最高/按规则衰减，不能简单相加——写 50% 叠加必查装备当前数值。
