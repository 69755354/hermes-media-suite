# 图生图（img2img）模板 — 2026-07-24 最终版

来源：天行者定稿。**文生图/图生图是两套体系**，图生图必须用这套。

## 核心规则
- 图生图**不写五官外貌文字** —— 面部靠参考图锁定
- **空变量直接删除整条**
- 人脸漂移时用兜底加强版：标准版末尾追加「, 保持参考图人物面部五官、脸型基础特征不变」
- 参考图用 `xiaolu_sheet.jpg`（最终定稿三视图），**禁用旧版参考图**

## 正向模板（标准版）
```
{gender_age},原生均匀肤色，自然皮肤质感，杜绝过度腮红，无面部大面积泛红色块,生活化纪实摄影，胶片轻微颗粒，相机直出原图，无重度美颜磨皮，保留皮肤自然肌理，拒绝过度精致广告写真质感,{frame_setting},{camera_rule},{light_setting},{lens_param},{expression_emotion},{clothes_info},{scene_environment}
```

## 负向 A 包（常驻）
```
塑料肌肤，CG，动漫，3D 渲染，五官扭曲，面部畸形，肢体残缺，超高饱和度，僵硬人脸，数字人塑胶感，画面出现文字、水印
```

## 负向 B 包（按需）
```
俯拍，仰拍，极端高机位，极端低机位，不自然蹲姿，肢体严重扭曲，极致背景虚化，生硬强烈硬阴影，画面整体偏浓重橘暖色调，厚重蜜桃腮红
```

## 变量表
| 变量 | 内容 |
|:--|:--|
| gender_age | 年轻东亚女性 |
| frame_setting | 画幅 + 构图（如：竖屏半身构图） |
| camera_rule | 机位 + 姿态（如：平视机位，自然站立） |
| light_setting | 光线 + 色温（如：窗边 45 度侧自然光） |
| lens_param | 镜头焦段（如：85mm 定焦） |
| expression_emotion | 神态 + 情绪（如：松弛浅笑） |
| clothes_info | 服饰 + 配饰（如：白色蕾丝细吊带方领内搭，细项链小耳钉） |
| scene_environment | 场景 + 背景（如：室内日常门店环境） |
