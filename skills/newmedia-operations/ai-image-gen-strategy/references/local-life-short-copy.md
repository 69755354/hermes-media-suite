# 本地生活探店短视频方法论（2026-08-09 茗希项目实战沉淀）

> 适用：抖音同城探店/本地生活门店 30s 短内容生产（文案→素材→生图）。
> 归入本 skill 的原因：素材规划与生图/角色图强相关；文案与知识库部分为前置准备。

## 一、写文案前必须真读知识库（用户 2026-08-09 纠正：「你还是不会去引用知识库」）

写任何文案/分析/选题前，**实际 read_file 打开读内容**（不是列清单）：

1. `read_file(wiki/concepts/industry-index.md)` → 查行业落哪个文件
2. 按索引 `read_file` 对应行业文档（养生/美容无直接匹配 → 落 `industry-fitness.md` 或 `industry-strategy-overview.md`，禁止凭感觉跳过）
3. `skill_view(content-redlines)` → 合规红线（极限词/送客词/功效承诺）
4. `skill_view(content-review-gate)` → 评审门禁四维权重

实例：茗希 v1-v3 文案只有浅层「怕被坑」共情，补读 fitness 爆款结构 + content-redlines 后 v4 才达标（94分）。

### 物理卡点（2026-08-09 落地，不可绕）

写文案的不只是 Hermes——**codex 写产物时是 codex 自己读**（「谁写谁读」，用户纠正：Hermes 代读没用，codex 换任务又裸奔）：

- 打包 prompt 必须写「第一步 read_file industry-index.md 查表 → 第二步读行业文档 → 第三步写 `_预读_<节点>.md`（**必须含文件名**，只写「健康健身」这种描述会被 BLOCKED）→ 第四步写产物」
- 卡点脚本：`scripts/codex_preload_manifest.py check <项目目录> <节点号>`；`data_source_gate.py node4_body` 查 `_知识库引用.md`；`review_gate.py` node4_review 查 `_预读_5.md`、node12_pre 查 `_预读_10/11.md`
- 新节点加预读要求 → 改 `scripts/codex_preload_manifest.py` 的 PRELOAD_REQUIRED（唯一真相）
- ⚠️ codex 写记录漏文件名 → 让它补写，**不要放宽卡点**

## 二、探店文案结构（industry-fitness 爆款结构，30-60秒）

```
0-3秒    结果前置（首句制造变化感/痛点画面）
3-15秒   问题展示（场景+情绪+羞耻）
15-40秒  知识/体验展示（套餐规则/服务流程）
40-50秒  验证（规则透明/卫生/资质）
50-60秒  引导（CTA：评论区留关键词/点定位）
```

## 三、共情六层（写文案时逐层对照，深层必须到位）

| 层级 | 含义 | 探店文案示例 |
|:--|:--|:--|
| 场景共情 | 这场景我经历过 | 「肩颈僵得像生锈」 |
| 行为共情 | 这动作我也做过 | 「总把自己排最后」 |
| 心理共情 | 这想法我也有过 | 「不是矫情」 |
| 情绪共情 | 这不就是我吗 | 「30多岁脸色蜡黄」 |
| **羞耻共情** | 替她说出说不出口的话 | 「不敢素颜」 |
| **自我合理化** | 给她买得心安理得的理由 | 「花299对自己好，比买衣服值」 |

底层焦虑每案必过：身份（怕老/怕脸色差）/死亡/孤独/失控。

## 四、素材规划先行（用户 2026-08-09 纠正：「文案的话你要想好素材该怎么放吧」）

写文案时必须同步想镜头素材分配，不是写完文案再想：

1. 先盘点已有素材（实景照尺寸/横竖版）
2. **横版实景 → 抖音 9:16 竖版需「横切竖」**（中段裁切 + 上下模糊延伸），后期必做
3. 缺镜头素材的用 AI 生成补位（角色出镜镜头）
4. 缺门头照替代方案：店内柜台实景 + 字幕配店名（客户确认可行）
5. 每镜标注素材来源：AI生成 / 实景硬切 / 字幕卡

## 五、合规软化（保健养生类重点）

客户原始活动文案**一字不改**（刹车规则），但做视频/口播内容时必须合规软化：

- ❌ 绝对化疗效承诺：胸部饱满/腰线收紧5-8公分/痛经缓解80%/立竿见影
- ❌ 医疗属性词：荷尔蒙疗法/温控月经调理/药熏排毒/电磁波消脂（资质未核验不发）
- ❌ 「无效退全款」：效果保证型表达，公开宣传应删
- ✅ 中性词替换：「养护调理项目」
- ✅ 保留：299元/9项目/前20名赠品/到店体验（赠品写清规则）
- 终极策略：**先卖透明和安心，再卖体验**

## 六、辅助文档也过合规门（踩坑）

⚠️ **data_source_gate 扫整个项目目录**——评审报告/分析文档里的「最强/最高/第一」也会触发极限词 BLOCKED。写辅助 .md 同样避开极限词（用「表现突出」替代）。

## 七、交付格式

- 文档交付直接发 Word（.docx）不发 md（2026-08-09 用户定案）
- docx skill spec 的 styles 段**不能含内置样式名**（Title/Heading 1/Normal 会 ValueError；去掉整个 styles 段即可）

## 八、平台打法要「组合策略」不是执行清单（2026-08-09 用户纠正）

用户问「打法」时，**只给执行清单（日更配比/发布设置/评论区）会被打回**——必须给组合拳。六维度框架：

1. **内容组合**：信任型/体验型/活动型配比 + 具体日历节奏（冷启动14天=57%信任+29%体验+14%活动，日更；成长期每周6-7条；稳定期5-6条）
2. **流量组合**：自然流量/本地推投流/POI/团购/直播/私域怎么分阶段投（0-3天不投、4-14天小测、成长期60%投优胜素材、素材花到1.5倍CAC无单立即停投）
3. **渠道组合**：一鱼四吃不原样搬运——抖音20-30s挂POI找新客 / 视频号35-60s弱化价格吃熟人 / 朋友圈9-15s精华+主理人口吻 / 企微不群发按购买状态发预约核销
4. **阶段策略**：冷启动→成长期→稳定期每阶段内容/流量/直播组合变化；阶段升级看数据条件（不靠日期硬切）
5. **转化组合**：内容→POI→团购→到店→复购，每环给下一环理由；链路诊断组合看（有人看没人点POI=地域钩子问题；有人点没人买=商品页信任问题…）
6. **风险对冲**：三条内容线保留、每周选前30%迭代只改一个变量；合规被卡直接删除不做谐音替换；团购库存绑定预约量防接待崩盘

主席结论模式：不走「低价轰炸」，走「甜妹吸引→真实体验→规则透明→礼包成交→到店复购」组合闭环。
