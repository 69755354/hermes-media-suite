# 复杂风格化场景生图实测（2026-08-09 仙侠案例）

## 场景
小鹿参考图 → 仙侠战袍图（云海仙山/雷电/金色符文法阵/仰天大笑）。同一提示词分别跑 codex 和 Seedream。

## 实测结论（codex 视觉对比）
- **codex 综合胜出**：锁脸准（保留性别/年龄/长发刘海/椭圆脸）、仙侠氛围完整（仙山云海+飘逸长袍+法术环流）、光影材质统一
- **Seedream 跑偏严重**：角色直接变成男性，违背人物一致性——复杂风格场景下锁脸不可靠
- 缺陷分布：codex 手部/脚靴局部粘连可精修；Seedream 伪文字、拳头蜡感、角色换人

## 分场景选型（用户定案后补充）
| 场景类型 | 选型 | 原因 |
|:--|:--|:--|
| 复杂风格化（仙侠/特效/战袍/商业海报） | **codex** | 锁脸+构图+光影全胜 |
| 简单真实感（海边/探店/生活） | Seedream 备选 | 真实抓拍感强 |
| 泳装/贴身 | Seedream | codex 安全墙拦比基尼 |

## 仙侠提示词（可复用模板）
```
保留参考图人物写实五官脸型不变。主角身穿金红色霸气战袍，悬浮在云端仙山之上，云海翻涌仙山隐现。主角双手紧握举于胸前，双手雷电环绕闪烁，意气风发，仰天大笑，表情豪迈震撼。脚下金色符文法阵旋转，周身金色能量光带，天空金光万丈。全景构图，电影级光影，明亮金色调。写实人脸+仙侠战袍，无Q版，无二次元化脸部，无水印
负向：Q版,萌系,水印,残缺肢体,五官扭曲,多手指,模糊,畸变,多余杂物,整容脸,二次元化脸部,动漫脸
```

## 对比方法
让 codex 看两张图（`-i 图1 -i 图2` + 管道 stdin prompt）输出逐张分析+对比表+最终结论，重点看：
1. 参考脸一致性（性别/五官/发型是否跑偏）
2. 场景氛围完整度
3. 光影材质统一性
4. 明显缺陷（六指/断肢/伪文字/角色换人）
