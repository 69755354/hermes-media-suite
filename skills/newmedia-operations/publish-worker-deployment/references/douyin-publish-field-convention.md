# 抖音/星图发布：字段规矩 + 三条发布通道

来源：业务方 2026-10-15 当场纠正（原话：「你直接把那段话打在那个作品描述里面。作品描述里面只要写那个三个井号，红漫剧那些东西。你那些描述，那描述的话写标题里面」）。

> ⚠️ **客户可配，不是写死的**（业务方 2026-10-15：「别人做的不一定是火龙漫剧哦」）：
> 本文里 `#火龙漫剧 #漫剧 #腾讯漫剧`、火龙币话术、星广/星川任务类型、账号、标题词表 都只是**第一个客户的配置样例**。
> 产品化必须做成**每客户一份配置**（话题标签集 / 标题来源与词表 / 风控话术 / 任务类型 / 账号与 profile），
> 代码里不得出现任何客户专有字样；配置对不上白名单→停在待确认，绝不猜。

固定的是「分工」，不是内容：**标题＝该客户的文案那句话；描述＝该客户配置的内容**（标签集／话题模板／其它要求）。哪些客户描述就只放标签、哪些客户还要带别的、甚至描述留空，全部按配置来；**不得把火龙的标签当通用默认值**。

## 一、字段怎么填（硬规矩）

发布页两个字段，别填错位置：

| 字段 | 填什么 | 例子 |
|---|---|---|
| **标题** | **那句话（描述性文案）**，10–55 字 | `看剧就能攒火龙币，等公交也不浪费` |
| **作品描述/正文** | **只放话题标签**，别的都不写 | `#火龙漫剧 #漫剧 #腾讯漫剧` |

往期实证：2026-10-12 起的火龙币系列＝标题填主文案、描述只填话题（正确）；≤2026-10-08 的老片＝标题留空、整段塞描述（老毛病，会吃「标题字数不符」退回）。卡片/接口里的 `description` 是「标题＋描述」拼接，别拿它当字段证据——要验字段必须打开「编辑作品」页看两个框。

## 二、发布前必做

1. **输入框先清空再填**（`[contenteditable]` 直接打字会叠字，历史事故：文案被粘两遍 → 标题超长被判「标题字数不符」）
2. **重发前先下架/删掉旧作品**（否则判「与线上视频重复度过高」；顺序：先下架再发新）
3. 发完**回星图读回投稿状态**才算闭环

## 三、三条发布通道（产品要同时支持）

| 通道 | 场景 | 怎么发 |
|---|---|---|
| **A 纯抖音后台** | 达人没接任何任务 | 直接在抖音创作者后台发，不挂任务 |
| **B 星广任务** | 星图选星广任务 | 星图→去投稿→跳 `creator.douyin.com/.../upload?order_id=…`→发布（已实跑通） |
| **C 星川任务** | 星图选星川任务 | 入口/选法与星广同为星图任务 → **从星图后台直接提交，不经抖音后台**（2026-10-15 业务方口述，**页面细节未实测，待实机确认**：是否需先传文件、是否有任务ID/order_id 回填或回读） |

## 四、作品状态口径（抖音创作者中心）

- **橙色「审核中」**＝真在审（留）
- **灰色「审核中」**＝已拒（业务方口径「审核中显示灰色的，那是已经被拒掉的」；其形态＝筛选器停在「未通过」时已拒作品的渲染）→ 可删
- **灰色「减少作品推荐 / 流量减少」** 贴在**已发布**作品上＝限流标记，**不是被拒**，不动
- 「投放状态异常」类**不删**，等它自己过
- 删除不可恢复：逐条先打证据（标题/文案/日期/状态）核对 → 删 → 读回确认消失
