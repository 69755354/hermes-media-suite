# 电商素材方法论（甲方媒介经验）

> 来源：2026-10-30 冷酸灵双11项目，客户方媒介马森在群里 5 条需求 + 4 次退稿的完整磨合过程。他每次退稿都不是在改文案，是在把「品牌广告的做法」逐条掰成「电商素材的做法」。这套判据适用于食品、家居、美妆、日用等品类的抖音/视频号信息流。

## 0. 一句话

电商素材不是作品，是转化工具：**前 3 秒让人停，10 秒内让人信，最后一句让人动。**

## 1. 五条铁律

1. **钩子一句话，20 字内**。不带品牌名、不带背景铺垫、不写「今天带大家了解」。第一句能单独拎出来当标题才算过。
2. **用平台语言，不用品牌语言**。对标同品类抖音爆款：用「你」称呼、短句、具体动作、口语；不写四字词堆砌。
3. **素材形态要原生**。手机直拍、自然光、生活场景、保留手抖/水渍/杂音；布光、轨道、升格、分屏、电影感一律不要。
4. **一条只讲一个点**。一个卖点讲透，不靠堆三个卖点求安全。
5. **以客户给的参考文档/样例为准**。他说「参考样例」＝句式、节奏、结构照它，不是自由发挥。

## 2. 三段式（判断一条素材成不成立）

```
0–3s   钩子：他为什么停下来？（痛点 / 反常识 / 结果先行）
3–10s  证明：凭什么信？（机制 + 可感知结果 + 现场证据）
结尾    动作：现在干什么？（点哪里 / 买哪个 / 什么时候）
```

三段抽出来单独看：钩子能不能当标题；证明里有没有一个「看得见」的证据（水珠、对比、实测、真人口述）；动作是否具体到可执行。缺一段，这条素材就是废的。

## 3. 脚本的固定四段结构

| 段 | 写什么 | 判据 |
|---|---|---|
| ① 噱头开头 | 一句话痛点/反常识结论 | 一句话说完、不带背景、能停 1 秒 |
| ② 核心差异卖点/机制 | 只有这个产品才有的机制、成分、结构 | 说清「为什么是它」，不是「它很好」 |
| ③ 卖点解析 | 机制翻译成用户能感知的结果 | 具体到场景/动作/时间，不堆形容词 |
| ④ 转化引流话术 | 明确动作 + 时间或数量限定 | 一句话，短 |

交付量：3 个大方向 × 每个方向 5 条 = 15 条；**条与条重复度 ≤10%**（按句子层面比对，不是只换标题）；单条约 300 字。

## 4. 客户语言翻译表（改稿时直接用）

| 客户说法 | 真实含义 | 下次怎么预防 |
|---|---|---|
| 噱头太啰嗦 | 钩子不成立，观众不会停 | 第一句能单独当标题；超 20 字重写 |
| 参考参考文档的样例 | 他已有过审/爆量模板 | 开工先把样例拆成结构，照结构填 |
| 语言参考竞品爆款 | 要平台语言 | 扒 3 条爆款，抄句式节奏、不抄卖点 |
| 太 TVC | 不是画面丑，是素材形态错 | 手机视角、生活场景、有瑕疵 |
| 不要过度精细化 | 越精致越像广告 | 保留手抖/水渍/杂音 |
| 简单直给 | 一条只讲一个点 | 一个卖点讲透 |
| 满足目标人群观看爆点 | 按秒给刺激 | 每 3–5 秒一个新信息（反转/证据/结果） |
| 重复度≤10% | 平台判重 + 人群疲劳 | 换钩子、换场景、换证明方式 |

## 5. 分镜脚本：固定 9 栏

纯文字表格，列名固定不增减：

`镜号 | 机位 | 景别 | 画面内容描述 | 台词/文案 | 花字 | 转场特效 | 特效 | 备注`

- **镜号**：序号+时长，如「1｜3s」；一条 8–13 镜，单镜 2–5 秒
- **机位**：写实拍动作（「手机竖持自拍，怼脸，手抖不修」），不写「中景推轨」
- **景别**：大特写/特写/近景/中景/半身，一条至少 3 种
- **画面内容**：只写看得见的动作和物件，要可执行
- **台词/文案**：脚本原句，口语，允许不完整句
- **花字**：3–6 个字的字眼，重复关键词，不写整句
- **转场**：默认「直接切」「遮镜头切」
- **特效**：默认「无」；只写声音或真实物理反应（水花溅镜头）
- **备注**：给拍摄的执行提醒（「手机直拍不打灯」「屏幕别出现价格数字」）

## 6. 参考图（分镜定稿后的下一步）

客户会要「根据文字描述生成对应镜头的参考图」。规则：

1. **逐镜对应，一镜一图**，文件名带镜号（A1_01.jpg）
2. **跨镜一致性靠写死的描述**：同一段人物描述 + 同一段场景描述在每张图里复用；不要靠模型记
3. **质感统一**：手机拍摄截图、阴天自然光、轻微手抖、轻微噪点、非写真、无美颜磨皮
4. **产品镜不带脸**：只拍手和产品，避免人物形象跨镜不一致
5. **管身/包装不出现可读文字**（避免 AI 乱码，也避开未审的宣传语），背景不出现文字水印 logo
6. 参考图是给拍摄对齐用的，不是成片；不要拿来当交付视频

## 7. 迭代 SOP

- 每轮**只改他点出来的那一层**（他改开头就只改开头，不要顺手重写分镜）
- 交付时给「改前 → 改后 → 为什么改」，让他一眼看到差异
- 一次给全量（15 条 / 3 条分镜 / 全部参考图），不挤牙膏
- 改完先自检再发，不带已知问题交付

## 8. 接活前三问（缺一样就先要）

1. **参考文档/样例**在哪？——决定句式、节奏、合规口径
2. **对标爆款**是哪几条？——决定语言和镜头形态
3. **投放目标**是什么？——转化 / 种草 / 拉新，决定三段式重心

客户没给就主动要；要不到就先用同品类爆款顶上，并在交付时标一句「参考了哪几条」。

补充（2026-10-31 客户口径，见第 16 节）：第 1、2 问合并成一件东西——**「大盘里现在正在跑的样片」**。他要的是扒现役跑量视频的文案、让 AI 出结构或仿写，不是拿历史爆款或我们自选的竞品。

## 9. 品类差异

- **洗护/口腔**：功效机制可讲，但不得承诺疗效、不得绝对化；价格对比不写具体数字
- **食品**：讲口感/分量/场景，价格锚点要真实；不写「最」「第一」
- **家居/日用**：讲使用场景与对比，避免夸大功能参数

## 10. 提交前自检（缺一条不算过）

- [ ] 第一句是一句话痛点，20 字内，无品牌名
- [ ] 四段结构齐全，每段能指出对应句子
- [ ] 15 条没有换汤不换药（同句式只换名词＝重复度超标）
- [ ] 没有 TVC 词：布光、轨道、升格、分屏、电影感、质感大片
- [ ] 9 栏齐全、列名一字不差、每栏都填
- [ ] 参考图逐镜对应、人物/场景描述一致、无可读文字
- [ ] 合规：功效、价格对比、绝对化用语逐条过平台规则
- [ ] 客户样例的句式节奏对得上

## 12. 批量需求背后的投放逻辑（分来源层级，推断部分未经客户确认）

**原话层（客户明确要求）**：3 个方向 × 5 条、重复度≤10%、四段结构、约 300 字、9 栏分镜、逐镜参考图。

**推断层（从其需求结构反推，尚未口头确认）**：

1. **3×5 不是凑数量，是测试矩阵**：方向＝不同的人群/场景假设（如「冰美式刺痛」「刷牙方式错」「大促不会算账」），同一方向 5 条＝同一假设下的 5 个钩子变体。投放后用消耗和转化反推哪个假设成立，再在那个方向加量。
   → 写法：同一方向内变的是钩子和证据，不变的是卖点；不同方向之间变的是「打谁、打什么场景」。
2. **重复度≤10% 是平台判重 + 人群疲劳的双重约束**，不是文风要求：同句式换名词会被系统归为同一条素材，跑不出新人群。
3. **先要行业/竞品报告，再要脚本**：卖点必须来自「竞品没讲或讲不好的差异点」，报告是脚本的前置，不是附赠。
4. **先要文字分镜，再要参考图**：文字阶段改成本最低；图是给拍摄执行对齐用的，过早出图等于把错误固化。
5. **他每次只提一个维度**：钩子 → 形态 → 执行。说明他的审片优先级是「停不停得住 > 像不像原生内容 > 细节好不好」，改稿按这个顺序自查，别一上来抠细节。

## 13. 甲方审一条素材会问的四个问题

1. 前 3 秒他会不会划走？（钩子）
2. 他凭什么信？（证据看不看得见）
3. 看完记得住哪一句？（记忆点/花字）
4. 他现在知不知道干什么？（动作指令）

任何一个答不上来，就回去改那一段，不靠加特效或加文案补救。

## 14. AI 生产边界与人工介入（客户口径，压价/排期时先用这条对齐预期）

客户 2026-10-30 对整个 AI 制作流程的验收结论，分两项看：

| 环节 | 客户结论 | 级别 |
|---|---|---|
| 数据抓取、素材分析、素材生成的细节度 | 「都是OK的」 | L2 能力项认可（不是单条素材过审） |
| 固定数字人模型 + 单一场景 → 做人设、出视频 | 「其他的功能我觉得还是ok的」「就可以做人设，出视频了」 | L2 能力项认可 |
| 文案 | 「文案上是个大难题」 | L1 客户口径 |
| 脚本 | 「脚本也是我们现在遇到的难题，需要人工介入，还做不到完全靠AI写」 | L1 客户口径 |

**落地规则：**

1. 默认假设「AI 文案/脚本不能直接交付」。AI 出的是方向、钩子候选、四段结构草稿，定稿必须人工过一遍再交。
2. 报价/排期里把人工写稿工时单独列，不要承诺「全自动出稿」——客户自己已经认定这块 AI 做不到，硬承诺等于给自己埋退稿。
3. 交付时说清哪部分是人工改写的，别让客户以为整条都是 AI 生成的（他上一句就是在问「咱们不用修改或者写新的吗」）。
4. 视觉侧可以按标准交付：固定数字人 + 单一场景这套组合客户认可，不必额外堆场景换形象来「显专业」。
5. 这是能力边界判断，不是素材判据：别拿它替代第 1–3 节的三段式和四段结构，两套分开用。

## 15. 标准分级与验收闭环（别把客户口径当行业真理）

本文件里的判据分三级，引用时必须说清是哪一级：

| 级别 | 含义 | 能不能对外说「标准」 |
|---|---|---|
| L1 客户口径 | 某个客户明确提的要求，未经投放验证 | 不能说，只能说「某客户要求」 |
| L2 客户通过 | 他认可了这一版（口头/定稿） | 可以说「该客户认可的写法」 |
| L3 市场验证 | 投放后数据达标且可复现 | 才能叫经验证的打法 |

**现状**：1–13 节全部来自 2026-10-30 冷酸灵项目一个客户的磨合，目前处于 **L1–L2 之间，零投放数据**。使用时当假设用，不要当定论；不要对下一个客户说「行业都这么做」。

2026-10-30 客户对「数据抓取 / 素材分析 / 素材生成细节度 / 固定数字人+单场景出人设视频」四项能力口头 OK（L2 能力项认可），同时对文案与脚本明确判定「做不到位、需人工介入」（L1，见第 14 节）。**本轮客户没有对任何单条素材版本表示通过**，不要在交付记录里写成「素材已过审」。

2026-10-31 客户继续补充文案口径（语感为王、结构固定、钩子靠人工、扒现役样片），见第 16 节，级别仍为 L1；**这一轮同样没有任何素材版本被通过**。

2026-10-31 后半程客户又给了一次整体「现在看还都ok」的口头确认，并明确「跑量文案和开头素材是最关键的」——记为 **L2 能力项整体认可 + L1 优先级口径**（见 16.8），仍**不是**任何单条素材过审。

**升级条件（缺一不升）**：同一条判据在 ≥2 个客户、≥3 条素材上投放，且下列指标不低于账户均值——3s 完播率（钩子）、平均播放时长/完播率（结构）、点击率（卖点与封面）、转化成本（动作话术）。

**每个项目收尾必做**：写一行结论——哪条判据被数据证实、哪条被证伪、哪条没测到。证伪的就从本文件改掉，不要留情面。

**条目格式**：每条新沉淀后面标 `[日期 客户名 L级别]`，方便以后回溯它是谁的经验、验没验过。

## 16. 客户口径追加：语感、结构固定、钩子靠人（2026-10-31 冷酸灵群，L1）

2026-10-31 马森在同一群里继续补充他对文案/脚本的判断。**这一轮没有通过任何素材版本**，全部按 L1 记录。

**16.1 文案的第一判据是语感，不是结构**

- 原话：「核心问题是语感，语言流畅性和网感」。
- 含义：结构对不对他已经不问了，卡在「读起来像不像人说的、像不像现在在跑的片」。所以自检时先通读一遍，读着别扭、书面化、AI 腔，结构再齐也是废稿。
- 落地：交付前必须朗读式通读一遍，逐句问「这句人会说吗」；删掉所有为了对称、为了完整而补的句子。

**16.2 客户现行人机流程（我们对齐这个节奏，不承诺一次成稿）**

- 原话：「我们现在是让AI出大纲，出结构，人工修改，然后AI扩写，在过一遍人工修改」。
- 拆解：① AI 出大纲/结构 → ② 人工改结构 → ③ AI 扩写 → ④ 人工再过一遍。
- 落地：我们的交付按这四段走，交付物上标明当前处在哪一段；别把「AI 出稿」当终稿交。人工两道工序（②④）要计入工时（与第 14 节一致）。
- 推论（未经客户确认）：他抱怨语感差，很可能是他自己那一步「AI 扩写」的质量不够——扩写阶段是语感崩坏的重灾区，我们提供的价值点应落在「扩写后读起来仍像人话」。

**16.3 换工具解决不了语感**

- 原话：「文案处理上，现在市面的工具都差不太多」。
- 落地：不要拿「换个更强的模型/新工具」当解法或卖点讲给他听，他不认。差异只能靠样片、结构、人工改这三样做出来。

**16.4 方法：扒现役跑量样片，出结构或仿写**

- 原话：「这个就是需要样片，现在大盘里正在跑的视频，扒他的文案，让AI出结构，或者仿写」。
- 落地：接活第一件事是要「大盘里正在跑的样片」（不是历史爆款、不是我们自选竞品）。拿到后先扒文案 → 出结构 → 再仿写。顺序不能倒。

**16.5 结构固定，所有片子挂在同一套结构上**

- 原话：「这个是我们给连咖啡做的跑量结构」「结构没有重大问题的话，基本上就不会变了」「所有视频都是基于这3个结构写」。
- 落地：结构层不许自创。客户一旦给定跑量结构，后续所有脚本只填变量（人群/场景/钩子/证据），不改骨架；要改骨架必须先拿到他口头同意。
- **待补**：连咖啡 3 个跑量结构的原文，客户 2026-10-31 说「周日我弄一下吧」，尚未提供。收到后原样补进本节，不要自己猜结构长什么样。

**16.6 钩子必须人工想，AI 只出候选**

- 原话：「开头就得靠人工去想创意，AI扩写的就都差很多意思」。
- 落地：AI 出的钩子只当候选池，定稿钩子由人写。报价/排期里这一项单独算人工（与第 14 节第 2 条一致）。这也反向印证第 1 节铁律一：钩子是整条素材最贵的一句。

**16.7 「过时了」——旧玩法被否，指向待确认**

- 原话：「过时了」「好多都是之前的老套路了，不是现在引流的玩法了」。
- 状态：**指向不明**（未说明否的是哪一版素材/哪套玩法，可能是我们给的参考，也可能是他手上的旧模板）。
- 落地：下次交付前先跟他确认「当前引流玩法基准」，不要拿旧模板直接顶；把这两句当「旧套路不可再用」的信号，不当成对具体某条稿的判决。

**16.8 优先级排序：跑量文案 + 开头素材最关键，其他功能差一点不要紧**

- 原话：「现在看还都ok，因为其他功能差一点不要紧的，跑量文案和开头素材是最关键的」[2026-10-31 00:09 马森，冷酸灵群]
- 级别：前半句是整体能力项的口头确认（L2 能力项认可，**非**素材过审）；后半句是优先级判断（L1）。
- 含义：
  1. 整体交付能力他认了，但这是「功能层面都ok」，不等于任何一条素材过关——不要写成「素材已通过客户」或「本轮过审」。
  2. 决定成败的只有两件事：**跑量文案**（脚本/正文）和**开头素材**（0–3s 的钩子台词 + 首帧画面）。形象、场景、细节精细度等差一点他明确说不要紧。
- 落地：
  1. 工时和自检权重压到这两项上；不要为画面细节反复返工重跑（呼应第 13 节四问、16.6 钩子靠人工）。
  2. 被挑毛病时先自查这两项；画面上的小瑕疵不主动放大、不主动重做。
  3. 「开头素材」= 第一句话 + 第一眼画面一起设计，只改台词不改首帧等于没改。
  4. 报价/排期的人工工时集中在「钩子创意 + 文案定稿」；视觉侧按第 14 节第 4 条标准交付（固定数字人 + 单一场景）即可，不必堆场景换形象。

**本节级别**：全部 L1（单客户口头口径，零投放数据）。不要对外说成行业标准；也不要覆盖第 1–3 节的三段式/四段结构——那些仍是写作骨架，本节是骨架之上的语感与工序要求。
