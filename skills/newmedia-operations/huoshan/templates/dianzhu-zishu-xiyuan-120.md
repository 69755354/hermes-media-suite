# 店主自述型模板 · 熹园知味120字版（2026-07-11验证）

**行业：** 心理咨询+茶馆（解惑型门店）
**角色：** 店主本人出镜（心理工作者）
**模式：** 叙事模式（旁白·不看镜头·沉浸动线）
**时长：** 6镜×5秒=30秒 | **总字数：120字**

---

## 叙事线

```
我是谁 → 我看见什么 → 所以我开了这里 → 在这里怎么解 → 套餐明细 → 来坐坐我等你
```

## 逐镜台词

| 镜号 | 叙事功能 | 台词 | 字数 |
|:---:|:--------|:-----|:---:|
| 镜1 | 自我介绍（我是谁/做什么） | 做了这么多年心理咨询，看多了大家被困住的样子。 | 16字 |
| 镜2 | 看见什么问题（痛点共情） | 被情感困住，被生活压得喘不过气，有委屈也不肯讲。 | 20字 |
| 镜3 | 开店动机（所以开了） | 所以开了熹园，院里绿植环绕，没有嘈杂。 | 16字 |
| 镜4 | 价值主张（怎么解） | 在这里喝茶，不止品茶味，更安抚你的内心。 | 18字 |
| 镜5 | 套餐价格地址 | 情缘38，分析情感事业；纳福98，指明方向。珠江北路华人街，熹园知味。 | 28字 |
| 镜6 | 情感收尾+邀约 | 迷茫焦虑难过的时候，不用事事都强撑。解不开的，来坐坐，我等你。 | 22字 |

---

## 复用指南

1. 替换镜1：换成店主自己的身份（做了XX年XX工作）
2. 替换镜2：换成门店对应的用户痛点（不是心理咨询的就换别的痛点）
3. 替换镜3：开店/开店的动机描述
4. 替换镜4：核心服务描述
5. 替换镜5：套餐名+价格+地址
6. 替换镜6：收尾邀约，用店主身份收「我等你」

**字数控制：** 90-120字范围，语速偏慢自然叙述
