# 场景-镜头对照表模板

每次写多镜prompt前，在脚本或wiki中建立此表。写prompt时对照着写，不用记忆猜。

---

## 模板

| 镜号 | 场景 | 实景图路径 | 关键特征 | 运镜 |
|:---:|:----|:----------|:---------|:-----|
| 镜1 | XXX | /path/img.jpg | 门在左/中/右？桌椅在哪？招牌在哪？ | 跟摇/固定/推近 |
| 镜2 | XXX | /path/img.jpg | 同上或不同场景描述 | 同上 |
| 镜3 | XXX | 同上或新图 | 同上 | |
| 镜4 | XXX | 新图路径 | 不同场景特征 | |
| 镜5 | XXX | 新图路径 | 不同场景特征 | |
| 镜6 | XXX | 一般为镜1同图 | 与镜1闭环 | 与镜1呼应 |

---

## 已确认的文件路径（勿凭记忆写）

```
角色图: /home/ubuntu/assets/characters/<角色名>_<风格>.png
场景图: /home/ubuntu/.hermes/image_cache/<img_filename>.jpg
```

## 预检

- [ ] 每镜的 @图2 场景文件路径实际存在
- [ ] 镜1和镜6如果用同一张图，已标注「构图闭环」
- [ ] 对照表中的文件路径与节点10实际传参路径一致
- [ ] 每个场景的布局关键特征写清楚了（不仅是场景名）
