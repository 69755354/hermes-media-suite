# 抖音爆款搜索+验证+分析完整工作流

> 2026-07-18 实测验证，适用场景：找同赛道高赞视频做爆款拆解

---

## 总览

```
Tavily搜 → 找到高赞视频URL+缓存数据（标注可信度）
  ↓
CDP浏览器 → 打开视频页 → 截图（验证实时数据）
  ↓
ARK Vision → 分析封面画面（真实视觉分析，不编造）
  ↓
我 → 出原创复刻脚本（不搬运原视频素材/文案）
```

## 第一步：Tavily搜索

**目的：** 找到同赛道高赞视频的URL和缓存数据

```python
web_search("site:douyin.com/video AI偶像 虚拟人 万赞 2026")
```

**返回数据：**
- ✅ 抖音视频URL
- ✅ 标题、话题标签
- ⚠️ 缓存赞数（可能不准确，见下）

**必做：** 在接力文档中标注数据来源

## 第二步：CDP浏览器验证（重要）

**目的：** Tavily赞数可能虚高（实测差8.5倍），必须用CDP验证

**前提：** Chrome已启动 `--remote-debugging-port=9222 --remote-allow-origins=*`

**流程：**
1. 新开CDP tab
2. 设置手机UA（iPhone）
3. 导航到抖音视频URL
4. 等待6秒加载
5. 截图
6. 获取页面文字（标题/赞数/评论）

**关键发现：** CDP页面显示的赞数（如「9000+」）比Tavily缓存更接近真实值

## 第三步：ARK Vision分析

**目的：** 分析视频封面画面（角色风格/场景/色调/文字）

**调用：** ARK Doubao Vision endpoint

**分析维度：**
- 角色：性别/年龄/发型/服装/表情/动作
- 场景：室内/室外/风格/道具
- 色调：暖/冷/滤镜
- 文字：封面上的标题/字幕

## 第四步：出原创复刻方案

**原则：**
1. 不搬运原视频素材/文案/镜头
2. 基于分析结果重新设计
3. 标注「基于画面分析原创复刻，非原视频逐字稿」

**输出格式：**
```
选题: xxx
角色: xxx
结构: 
  0-3秒 钩子
  3-15秒 痛点
  ...
出片方式: Seedance/婵镜数字人
```

## 第五步（新增）：参考视频源地址提取+逐帧分析

**适用场景：** 用户提供了具体视频链接并说「做一个一样的」「参考这个视频」

**流程：**
```
① 用 browser_console 获取视频源地址：
   browser_console(expression='document.querySelector("video").currentSrc')
  ↓
② curl 下载原视频：curl -sL -o /tmp/reference.mp4 "<src_url>"
  ↓
③ ffmpeg 抽帧（短视频<30s用fps=2）：ffmpeg -i reference.mp4 -vf "fps=2" frames/frame_%02d.jpg
  ↓
④ ARK Vision 逐帧分析：人物/动作/背景/风格/贴纸
  ↓
⑤ 输出帧序列表 → 写复刻方案
```

**注意：** 抖音「疑似AI生成」标签不代表画面真的是AI生成的，必须通过帧分析确认。

## 数据可信度速查

| 来源 | 可信度 | 标注 |
|:-----|:------|:------|
| 抖音App内实测 | ✅ 最高 | 「抖音App实测：X,XXX赞」 |
| CDP页面实时 | 🟡 高 | 「CDP页面显示：X,000+」 |
| 用户发截图 | 🟡 中高 | 「用户提供」 |
| Tavily缓存 | ⚠️ 低 | 「Tavily缓存：X万⚠️，非实时精确值」 |
