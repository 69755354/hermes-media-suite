## 会话完整复盘

### 需求链路
1. 用户发抖音链接 → CDP端口配置错误（config写9226，实际跑9222）→ `hermes config set browser.cdp_url`修复
2. 扒到视频信息 → 拆结构 → 出分镜方案（原方案含猫咪）
3. 用户说「不用猫也可以，就直接小鹿」 → 简化方案
4. 用户说「你随便加个类似的bgm」 → 本地BGM叠轨
5. 用户说「直接出片吧」 → Seedance单镜5秒 → ffmpeg合成 → 交付

### 关键技术决策

#### 1. 无台词Seedance prompt写法
```python
@图1 作为甜妹探店博主小鹿，保留全部面部特征和穿搭不变；
照片级写实，无CG感，天然肌肤质感，明亮自然光线；
中近景镜头，画面稳定柔和，浅色干净背景；
小鹿跟着轻快音乐节奏左右轻轻摇头晃脑，头发跟随动作自然摆动，嘴角带着甜笑，眼神灵动看向镜头，可爱治愈感；
动态强度35%；
# 不加"同步生成中文探店人声"
# 不加任何台词内容
# 不需要@图2场景引用
```

#### 2. API调用参数
```python
model: doubao-seedance-2-0-mini-260615
duration: 5
参考图: 小鹿_探店形象.b64（固定角色资产）
单镜token消耗: 108,900 tokens（≈1.52元）
```

#### 3. BGM处理
- 本地已有BGM `/tmp/bgm_free.mp3`（约6分钟）
- 截取前5秒 + 淡出处理
- ffmpeg叠轨：BGM音量0.3（无台词可略高）
- **平台发布策略：** 告知用户在抖音发布时选 #跟着猫咪一起摇头晃脑 同款BGM（蹭流量池+0版权风险）

#### 4. ffmpeg合成命令
```bash
ffmpeg -y -i raw_video.mp4 -i bgm_8s.mp3 \
  -filter_complex "[1:a]atrim=0:5,volume=0.3[a_bgm];[0:a][a_bgm]amix=inputs=2:duration=first[a_out]" \
  -map "0:v" -map "[a_out]" -c:v copy -c:a aac -b:a 128k -shortest final.mp4
```

#### 5. 视频元数据
- 分辨率: 720p, 9:16
- 时长: 5秒
- 文件大小: ~3.2MB
- 交付方式: 微信MEDIA直接发送
