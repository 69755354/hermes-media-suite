# 数据复盘报告模板

> 用于节点15（数据复盘）的输出格式规范。
> 输入：节点14发布的各平台数据（播放量/互动/转化）
> 输出：复盘报告（含数据汇总+爆款因子分析+优化建议+反哺）

## 标准输出格式

### 1. 数据汇总

| 维度 | 本期数据 | 对比上期 | 判断 |
|:----|:--------|:--------|:----|
| 播放量 | 5,200 | +30% | ✅ 增长 |
| 完播率 | 28% | +5% | ✅ 提升 |
| 点赞率 | 3.2% | -0.5% | ⚠️ 下降 |
| 评论数 | 48 | +12 | ✅ 增长 |
| 分享数 | 15 | +5 | ✅ 增长 |
| 转化线索 | 3条 | +2 | ✅ 增长 |

### 2. 爆款因子分析

- **钩子有效性**：本次用了「认知反差型」钩子，完播率高于上期「痛点共鸣型」5%
- **发布时间**：周五晚8点发布 vs 周中白天发布，播放量高40%
- **内容结构**：店主自述型叙事 → 评论互动数显著高于纯探店展示
- **视频时长**：30-35秒完播率最高，超过40秒掉率明显

### 3. 优化建议

1. 下期继续用「认知反差型」钩子
2. 发布时间锁定周五晚
3. 评论区互动环节前置（在视频结尾加提问）
4. 视频长度从35秒压缩到28秒（完播率曲线显示20-25秒开始掉人）

### 4. 反哺到下一期内容

| 方向 | 动作 |
|:----|:-----|
| 选题 | 继续深挖同城服务类痛点共鸣 |
| 文案 | 钩子位置提前到0-2秒 |
| 发布 | 固定周五晚8点 |
