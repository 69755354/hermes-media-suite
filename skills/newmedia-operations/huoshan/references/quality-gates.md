# 视频质量管线 · 逐节点质量门

> 2026-07-18 会话定稿。选题→剧本→分镜→提示词四个节点的质量门汇总。

## 总体原则

1. **数据驱动选题** — 不凭逻辑推，从真实爆款里归纳
2. **一次过剧本** — 不反复改，定稿后下游才开工
3. **分镜先于提示词** — 先定怎么拍，再写机器指令
4. **四层校验** — 文件对得上→prompt规范→上下游一致→全镜统一

## 节点3：选题 — 质量门

```
□ 已读节点2爆款拆解结果（≥3条）
□ 已填「爆款要素→本题映射」表
□ 选题方向已校准（搜同赛道验证）
□ 校准结论写进节点3_外部校准.md
□ 校准通过才进节点5
```

## 节点4：剧本 — 质量门

```
动笔前确认：
□ 选题定稿已通过校准
□ 爆款映射表已填完
□ 行业合规红线已读
□ 选定模板（6选1）

定稿自检：
□ 总字数115-140字（30秒）
□ 0-3s有钩子
□ 第一句不介绍店名
□ 5段完整：钩子→痛点→方案→信任→CTA
□ 每句≤20字，读起来像人话
□ 价格/地址与客户实际数据一致
□ 无行业红线词

定稿后：
□ 写进节点4_文案定稿.md
□ 不准再改——下游开工后改=全部重来
```

## 节点5：分镜 — 质量门

```
□ 动线逻辑合理（门头→走进→落座→体验→收尾）
□ 无场景硬跳
□ 每镜功能不重复（6镜6个叙事功能）
□ 景别分配正确（远景/中景/近景各有用处）
□ 场景-文件对照表已建
□ 输出节点5_分镜定稿.md
```

## 节点9：提示词 — 质量门

```
写prompt前：
□ 已读节点5_分镜定稿.md
□ 已读节点6_人设定稿.md
□ 已读节点7_生图记录.md
□ 已读节点8_素材清单.md
□ 已选定声音模式（口播/旁白/内心独白）

写完后四层校验：
□ 层1: @图1/@图2 跟实际文件对得上
□ 层2: 无emoji、无引号、无红线词
□ 层3: 场景跟分镜一致、角色跟人设一致
□ 层4: BASE VOICE全镜统一

输出：
□ 节点9_提示词.md
```

## 执行铁律

1. **质量门不过，不准往下走**
2. **定稿后下游开工 → 上游再改 = 全部重来**
3. **每次只改一个节点 → 改完重新校准**
