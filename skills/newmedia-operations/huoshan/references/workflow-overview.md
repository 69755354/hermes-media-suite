## 工作流总览

### 🚦 第一判别维度：内容类型（2026-07-20 定稿，替代旧通道选型）

**所有客户需求的第一问是内容类型，不是客户类型：**
> 「你想做探店视频、剧情类还是口播视频？」

| 内容类型 | downstream | 视频通道 | business_type | 单人镜头上限 | Broll要求 |
|:--------|:---------|:---------|:-------------|:----------:|:--------|
| **探店** | 节点4→6镜剧本，节点5→场景分镜 | Seedance API | shop | 8s(人物)/12s(特写) | 产品特写高频 |
| **剧情** | 节点4→6镜剧本，节点5→场景分镜 | Seedance API | drama_single/drama_duo | 8s(人物) | 场景氛围为主 |
| **口播** | 节点4→口播稿，跳过节点5 | 婵镜 create_video 数字人 | oral | N/A(数字人) | 无 |

**判别流程：**
1. 客户说「做视频」→ 问内容类型（探店/剧情/口播）
2. 探店/剧情 → 走 Seedance 通道（节点4→6镜剧本→节点5分镜→…→节点12 Seedance视频）
3. 口播 → 走 婵镜通道（节点4→口播稿→跳过节点5→…→婵镜create_video）

### 🚦 平台选择与打法分析（2026-08-05 用户定案 v2：用户画像后选平台，爆款拆解前）

**时序定位：** 节点1用户画像完成后 → **平台选择** → 节点2爆款拆解

**选择逻辑（用户画像驱动，不是客户说选哪个就选哪个）：**

| 用户画像特征 | 推荐平台 | 理由 |
|:------------|:--------|:-----|
| 实体店店主+同城流量 | 抖音 | 同城流量精准，探店视频自带地理标签 |
| 实体店店主+图文能力 | 小红书 | 图文门槛低，搜索流量长尾 |
| 个人IP+下沉市场 | 快手 | 老铁经济，信任转化高 |
| 个人IP+社交裂变 | 视频号 | 微信社交链传播，熟人背书 |
| 内容创作者+长视频 | B站 | 中长视频深度内容 |

**决策树：**
```
用户画像完成（节点1）
  ├─ 实体店？ ──→ 同城流量需求？
  │    ├─ Y → 抖音（同城探店）
  │    └─ N → 图文能力？
  │         ├─ Y → 小红书
  │         └─ N → 抖音（非同城）
  ├─ 个人IP？ ──→ 下沉市场？
  │    ├─ Y → 快手
  │    └─ N → 社交裂变？
  │         ├─ Y → 视频号
  │         └─ N → B站（长视频）
  └─ 内容创作？ → B站
```

**输出格式：**
```
## 平台选择结果
- 推荐主平台：[平台名]
- 推荐副平台：[平台名或无]
- 选择依据：[用户画像特征→平台匹配理由]
- 打法策略：[参考行业适配规则]
```

### 🏗️ 两域架构（2026-07-12 本会话定稿）

```
┌─────────────────────── Bot域（小鹿干）───────────────────────────────┐
│                                                                     │
│  客户 ←→ 飞书/微信 ←→ Hermes Agent (小鹿)                           │
│                           │                                         │
│                           ├─ 段1：客户服务（搜爆款/写文案/做分析）    │
│                           │    └→ 客户确认后 → 进入段2              │
│                           │                                         │
│                           └─ 段2：视频工作流（节点0→17）              │
│                                └→ 节点12 Seedance视频生成            │
│                                └→ 节点13 ffmpeg合成                   │
│                                └→ 节点15 交付                        │
│                                                                     │
└───────────────────────────────────────────────────────────────────────┘
                                │
                    剧本JSON（节点4定稿后）
                                │
                                ▼
┌─────────────────────── API域（Helper API 干）─────────────────────────┐
│                                                                       │
│  POST /execute                                                        │
│    ├─ 节点5 分镜                                                       │
│    ├─ 节点8 Seedream生图                                               │
│    ├─ 节点10 提示词                                                    │
│    ├─ 节点12 Seedance视频                                              │
│    └─ 节点13 ffmpeg合成                                                │
│                                                                       │
│  返回：成品视频URL                                                     │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

**Bot域触发条件：** 客户说「做视频」→ 小鹿走段1客户服务（搜爆款/写文案/做分析）→ 客户确认后进入本工作流节点0开始。

**API域触发条件：** 小鹿输出剧本JSON → POST 到 `/execute` 端点 → 返回成品视频。
