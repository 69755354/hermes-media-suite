# 参考视频运镜分析流程（熹园实测案例 2026-07-11）

> 运镜 / 镜头语言的权威源见 `/home/ubuntu/workflow/wiki/video-shotcraft/`；本文只保留熹园这次实测的抽帧拆解与映射记录。

## 分析步骤

1. 用ffmpeg抽帧：`ffmpeg -i 参考视频.mp4 -vf "fps=1" /tmp/frames/frame_%02d.jpg`
2. 分三批调ARK Vision分析（0-18s / 18-36s / 36-54s）
3. 提取运镜序列
4. 映射到目标视频的各镜

## 参考视频（54秒探店）运镜序列

```
0-3s:    跟摇（横向跟拍人物从右向左走来）
3-6s:    推近+跟拍（镜头推近人物上楼）
6-12s:   固定机位（展示建筑外景全景）
12-15s:  推镜头（从室内全景→中近景）
15-17s:  固定俯拍（展示室外茶桌全景）
17-18s:  固定平视（倒茶特写）
18-36s:  近景/特写/中景切换（茶桌操作、撸猫、生火等）
36-54s:  固定远景（树林空镜→阳台人物全景收尾）
```

## 关键规律

| 位置 | 运镜 | 作用 |
|:----|:-----|:-----|
| 入场 | 跟摇 | 建立空间感，人物自然走进画面，不硬切 |
| 进门/落座 | 推近+固定 | 从大景别过渡到小景别，观众注意力聚焦 |
| 场景展示 | 固定 | 稳定展示环境，给观众观察时间 |
| 细节 | 固定特写 | 近距离展示细节（品茶/手部动作） |
| 收尾 | 固定 | 稳定收束，不做额外运镜 |
