# 五层标准固定结构 Prompt 模板

> 适用：Seedream 文生图/图生图
> 层级权重从前到后逐级降低，每层功能独立无交叉

---

## 层级1：主体基础层（最高权重）
锁定人物长相、年龄、五官、发型、基础气质

```
[年龄] [人种/性别]，[脸型]，[眼型][瞳孔色]，[双眼皮类型]，
[鼻型]，[唇型][唇色]，[眉型]，[发色][发型][刘海]，
[整体气质约束]
```

## 层级2：肤质妆容层（第二权重）
单独管控皮肤质感，只写正向生理细节，无否定词

```
[妆面程度]，[肤质描述]，[毛孔/绒毛/皮下散射]，
[唇纹/细纹/油光]，[肤色明暗过渡]
```

## 层级3：体态情绪穿搭层（独立模块）
可单独微调表情姿态，不干扰人脸皮肤

```
[画幅/构图]，[身体姿态]，[视线方向/眼神]，
[笑意/微表情]，[面部肌肉状态]，[服装描述]
```

## 层级4：镜头光影构图层（统一光影逻辑）
固定镜头规格、光源方向、景深

```
[焦段/光圈]，[景深程度]，[光源位置/角度]，
[脸部与肩颈明暗阴影逻辑]
```

## 层级5：场景氛围画质层（最低权重）
环境、色调、质感风格兜底约束

```
[室内场景]，[背景虚化程度]，[整体风格/色调]，
[颗粒质感]，[画幅比例/尺寸]
```

## 独立模块：负面提示词
集中拦截 plastic skin, beauty filter, CG, cartoon 等

## 使用规则

1. **用户传入自定义描述时** — 替换层级3位置（体态情绪穿搭层），其他四层不动
2. **用户无描述时** — 完整五层拼接
3. **图生图模式** — 层级1和层级2可精简，由参考图提供基础特征，prompt侧重层级3-5
4. **生成时去掉分层标题**，只保留正文文字

## ⚠️ 本会话验证的常见矛盾（2026-07-21 追加）

### 层级内矛盾
| 矛盾写法 | 问题 | 修复 |
|:---------|:-----|:-----|
| 「轻薄遮瑕底妆」+「保留细微肤色不均」 | 遮瑕=盖瑕疵，保留=不盖，互斥 | 统一为「近乎素颜无粉底」 |
| 「干净温柔邻家气质」+「保留毛孔、细纹」 | AI理解「干净」≈无瑕疵，「保留」≈有瑕疵 | 去掉「干净」，统一走自然路线 |
| 「自然裸色唇妆」（层级2）+「M形唇自然唇色」（层级1） | 层级1说没涂东西，层级2说涂了裸色唇妆 | 去掉层级2的唇妆描述，由层级1统一控制 |
| 「无磨皮不精修」（层级5）+ 层级1堆叠精致五官特征 | 负向词不让修，正向词又在描述精修脸 | 负向词和正向五官描述要自洽 |

### 分辨率矛盾
| 矛盾 | 问题 |
|:-----|:-----|
| 层级5写「720*1280」但API实际传1440x2560 | 文字描述和实际参数不一致，必须统一 |

### Seedream 4.5 模型偏好的限制
- 文生图模式下，Seedream默认输出接近「标准美女脸」，靠文字很难打破
- 文字prompt只能描述方向，锁不住具体长相
- 要稳定出特定人物风格（如章若楠风格邻家脸）→ 必须用图生图垫参考图
- 官方Best Practice也确认：**"Use reference images to control identity and consistency, not just text descriptions"**（来源：Evolink.ai Seedream Prompt Guide, 2026-04-13）
