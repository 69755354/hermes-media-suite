### 数据获取方式

| 平台 | 数据拉取方式 | 可获取数据 |
|:----|:-----------|:----------|
| **抖音** | Chrome CDP 自动登录创作者中心 | 播放量、完播率、点赞、评论、分享、粉丝画像 |
| **小红书** | Chrome CDP 自动登录创作中心（先手动登录存Cookie） | 笔记曝光、阅读、点赞、收藏、评论 |

### 复盘报告输出

**抖音复盘指标：** 播放量、完播率、2秒跳出率、点赞率、评论率、分享率、涨粉数

**📕 小红书复盘指标（不同抖音）：**
| 指标 | 说明 | 参考线 |
|:----|:-----|:------|
| 小眼睛（阅读量） | 笔记曝光次数 | - |
| CES评分 | 赞×1+藏×1+评×4+转×4+关×8 | ≥100为良好 |
| 收藏率 | 收藏数÷阅读量 | ≥3%为良好 |
| 搜索排名 | 核心关键词下的搜索位置 | 前10为优 |
| 互动率 | （赞+藏+评）÷阅读量 | 3-5%良好，5%+优秀 |
| 搜索流量占比 | 搜索页带来的流量占总流量比例 | - |

**快手/视频号复盘指标（同抖音体系）：** 播放量、完播率、点赞率、评论率、分享率、涨粉数
| **视频号** | 视频号助手手动查，截图发我 | 播放量、点赞、评论、分享、关注转化 |

### 节点流程

状态文件路径：`/tmp/projects/<项目名>/_状态锁.json`

```json
{
  "project": "熹园",
  "current_node": 5,
  "status": "分镜定稿",
  "previous_output": "节点4_文案定稿.md 已签收",
  "checksum": "sha256_of_upstream_file",
  "timestamp": "2026-07-19T10:00:00Z",
  "retry_count": 0
}
```

**执行前检查：**
1. 读 `_状态锁.json` → 确认 `current_node` 等于当前节点号
2. 读 `previous_output` → 确认上游文件已完成校验签收
3. 计算上游接力文档的sha256 → 对比 `checksum`，不一致则终止（文件被改）

**执行后写入：**
1. 当前节点输出写入接力文档 → 计算sha256
2. 更新 `_状态锁.json` → `current_node+1`，`previous_output` 指向本节点
3. 写 `_校验日志.md` → 记录本次执行结果
