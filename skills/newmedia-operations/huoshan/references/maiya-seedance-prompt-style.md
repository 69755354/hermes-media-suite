# 麦芽菜 Seedance 专业提示词结构

> 来源：抖音@麦芽菜「AIGC情绪表演提示词」合集
> 提取时间：2026-07-18

## 结构总览

专业 Seedance 提示词分四个部分：

```
一、基础设定（全局参数）
二、分镜动作设定（逐段时间戳+肌肉级控制）
三、负面提示词（禁止项）
四、画质要求（技术参数）
```

## 一、基础设定

镜头参数、光影、背景、物理约束、视线落点、人物锚点。

```
全程禁止眼泪流出，禁止出现泪痕
固定机位50mm定焦近景，镜头零位移零变焦
冷调冬日侧逆光仅在发丝边缘留1px淡金边
背景全虚化无清晰人脸，只有模糊移动的人影光斑
人物所有面部肌肉全局最大位移≤2mm
所有情绪切换全是0.1秒瞬变，没有慢过渡缓冲
全程没有任何转头、扫视、多余动作
视线仅停留在两个落点（画外左侧肩膀水平 / 围巾中心点）
人物锚点100%对齐（发丝/耳机/泪痣/围巾纹理）
全程禁止眼泪流下来
```

## 二、分镜动作设定

每个时间段格式：`[时间] [情绪标签]：` + 肌肉控制指令

```
0-2s 幸福态：
起始帧视线落在围巾中心点，下眼睑完全放松，
眼内光偏柔，以快速向左后抬头把视线移到画外左方的人脸上，
最后半帧才抬出全部6颗下齿露笑，
笑肌的抬升过程在2秒内极慢完成，
没有突然爆发出笑容的动作，眼睛无泪。

2-5s 藏得意：
转过头微低，笑肌0.1秒瞬间卸力，
把笑容完全收回到口腔内，只在嘴角留下1mm的浅括弧，
瞳孔极微收缩半格，眼底的亮光悄然上浮0.5度，
全片没有任何多余的眼球转动，眼白露出面积始终不变。

5-7s 瞬生委屈：
下眼睑泪腺附近1mm范围突然泛出薄红，
完全不扩散到眼白区域，
虹膜对焦突然虚掉0.3秒，
0.2秒后上唇不受控跳了一下，
微微抿嘴才把那点刚涌上来的委屈压下去，
没有撇嘴、皱眉的大动作，全是眼部肌肉的本能颤动。
```

### 关键原则

1. **不要写情绪** — 写肌肉：不写「开心」，写「笑肌抬升50%，嘴角展开2mm」
2. **不要写感觉** — 写物理：不写「眼神温柔」，写「瞳孔收缩半格，亮光上浮0.5度」
3. **不要写过渡** — 写瞬变：不写「慢慢变得委屈」，写「0.1秒瞬间卸力」
4. **每个数字都是调参经验** — 不是随便写的，是反复试出来的精确值

## 三、负面提示词

```
大颗滚落的泪珠、眼部全范围泛红、眼泪流出产生泪痕
挤眼皱眉、大幅度转头、多余手部动作
B级片式夸张表情
```

## 四、画质要求

```
所有动态精度对齐24fps原生胶片级顺滑度
没有抖动、卡顿、撕裂、掉帧等瑕疵
```

## 与普通提示词的差距对比

| 维度 | 普通写法 | 麦芽菜写法 |
|:-----|:---------|:-----------|
| 微笑 | 「开怀大笑，眼睛弯起」 | **「笑肌2秒极慢抬升，最后半帧露6颗齿」** |
| 失落 | 「低头抿嘴，眼神低垂」 | **「笑肌0.1秒卸力，嘴角留1mm括弧，瞳孔收缩半格」** |
| 委屈 | 「眼角泛红」 | **「下眼睑1mm范围泛薄红，虹膜虚0.3秒，上唇跳0.2秒」** |
| 定泪 | 「含泪」 | **「泪光积满不落，鼻翼扩张0.2mm，锁骨隆起0.5mm」** |
| 眼动 | 「眼神移开」 | **「虹膜左移→虚焦→静止，全程无多余眼球转动」** |

## 使用方式

在 huoshan 节点10（提示词）中写prompt时，按此结构组装：

1. 先写 一、基础设定（全局不可变参数）
2. 再写 二、分镜动作设定（每段[时间] [情绪标签]：+ 肌肉指令）
3. 然后写 三、负面提示词
4. 最后写 四、画质要求

**不准简化、不准缩写、不准自己编数字。**
