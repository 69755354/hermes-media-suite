# 麦芽菜专业Prompt结构（本会话验证 · 2026-07-18）

> 来源：抖音@麦芽菜 · 合集「AIGC情绪表演提示词」
> 这是目前看到的专业级Seedance情绪表演prompt结构，适用于微表情/情绪递进类视频。

## 一、结构框架

任何情绪表演类prompt必须包含以下四部分，顺序不可乱：

```
一、基础设定（全局）
二、分镜动作设定（逐段，时间标签+情绪标签）
三、负面提示词
四、画质要求
```

## 二、基础设定怎么写

| 要素 | 写法规范 | 示例 |
|:-----|:---------|:------|
| 镜头参数 | 焦段+景别+位移约束 | `固定机位50mm定焦近景，镜头零位移零变焦` |
| 光影 | 光源方向+颜色+精确位置 | `冷调冬日侧逆光仅在发丝边缘留1px淡金边` |
| 背景 | 虚化程度+内容 | `背景全虚化无清晰人脸，只有模糊移动的人影光斑` |
| 肌肉约束 | 全局最大位移量 | `人物所有面部肌肉全局最大位移≤2mm` |
| 动作约束 | 禁止的动作 | `全程无多余转头、扫视周边、手部动作` |
| 视线控制 | 精确落点 | `视线仅停留在两个落点：画外左方肩膀水平 / 围巾中心点` |
| 全程禁令 | 贯穿全片的禁止项 | `全程禁止眼泪流下、泪痕` |

## 三、分镜动作设定怎么写

**核心原则：不要写情绪词，要写肌肉指令。**

### ❌ 错误写法（文学描述）
```
开怀大笑，眼睛弯起，露齿笑，开心明媚
```

### ✅ 正确写法（肌肉指令）
```
0-2s 幸福态：
起始帧视线落在围巾中心点，下眼睑完全放松，眼内光偏柔
最后半帧才抬出全部6颗下齿露笑，笑肌的抬升过程在2秒内极慢完成
没有突然爆发出笑容的动作
眼睛无泪
```

### 每段必须包含

| 要素 | 量化要求 | 示例 |
|:-----|:---------|:------|
| 时间标签 | 精确到0.x秒 | `0-2s`, `5-7s`, `第5s整帧的节点` |
| 情绪标签 | 一个词 | `幸福态`, `藏得意`, `瞬生委屈` |
| 视线落点 | 空间坐标 | `视线落在围巾中心点`, `锁定画框外左侧` |
| 肌肉动作 | 部位+方向+速度 | `笑肌0.1秒瞬间卸力`, `眼睑以0.3秒匀速下放` |
| 量化数据 | 精确数字 | `嘴角1mm括弧`, `瞳孔收缩半格`, `亮光上浮0.5度` |
| 负约束 | 每段独有的禁止 | `眼睛无泪`, `没有撇嘴、皱眉的大动作` |

### 情绪切换规则

- 所有情绪切换 **0.1秒瞬变**，没有慢过渡缓冲
- 每段结束到下一段开始之间没有过渡帧
- 情绪变化靠肌肉瞬时到位，不靠慢动作过渡

## 四、负面提示词怎么写

```
大颗滚落的泪珠、眼部全范围泛红、眼泪流出产生泪痕、
挤眼皱眉、大幅度转头、多余手部动作、B级片式夸张演技表情
```

## 五、画质要求

```
所有动态精度对齐24fps原生胶片级顺滑度，没有抖动、卡顿、撕裂、掉帧等瑕疵
```

## 六、完整示例（16秒刘浩存风格）

```
一、基础设定
seedance2.0完整分镜提示词
全程禁止眼泪流出，禁止出现泪痕，固定机位50mm定焦近景，镜头零位移零变焦，冷调冬日侧逆光仅在发丝边缘1px淡金边，背景全虚化无清晰人脸，只有模糊移动的人影光斑。人物所有面部肌肉全局最大位移≤2mm，所有情绪切换全是0.1秒瞬变，没有慢过渡缓冲，全程没有任何往画面右侧转头、扫视周边的多余动作，视线仅停留在两个落点：要么锁定画框外左侧与肩膀水平位置站立的人，要么下巴落在胸口围巾的中心点。人物锚点100%对齐。

二、分镜动作设定

0-2s 幸福态：
起始帧视线落在围巾中心点，下眼睑完全放松，眼内光偏柔，以快速向左后抬头把视线移到画外左方的人脸上，最后半帧才抬出全部6颗下齿露笑，笑肌的抬升过程在2秒内极慢完成，没有突然爆发出笑容的动作，眼睛无泪。

2-5s 藏得意：
转过头微低，笑肌0.1秒瞬间卸力，把笑容完全收回到口腔内，只在嘴角留下1mm的浅括弧，瞳孔极微收缩半格，眼底的亮光悄然上浮0.5度，全片没有任何多余的眼球转动，眼白露出的面积从始至终保持一致，只有对面的人能接住那点暗喜，眼睛无泪。

5-7s 瞬生委屈：
第5s整帧的节点：下眼睑泪腺附近1mm范围突然泛出薄红，完全不扩散到眼白区域，虹膜对焦突然虚掉0.3秒，快速向左抬头视线还钉在对方脸上，但眼神瞬间失焦，0.2秒后上唇不受控跳了一下，微微抿嘴才把那点刚涌上来的委屈勉强压下去，全程没有撇嘴、皱眉的大动作，全是眼部肌肉的本能瞬间颤动。

7-11.5s 沉入沉思：
缓慢将头转正低头，上眼睑匀速下移，把虹膜上沿盖住35%，睫毛以1次/秒的频率轻颤3次，第9.2s半闭眼的瞬间眼缝留1mm缝隙，虹膜彻底失焦没有任何视觉落点，第10s下唇被下牙轻蹭压出0.5mm浅压痕，眼睛无泪。

11.5-13s 彻底释怀：
没抬头瞳孔视线重新转向对焦落回画外左方的人脸上，下眼睑的薄红以肉眼可见的速度退散，第12.3s鼻孔微扩张0.2mm，上唇掀开1mm缝隙维持0.5s，锁骨顶端极微隆起0.5mm。

13-15s 意难平定格：
快速向左侧转头至肩膀方向微微上抬直视画外左侧的人的脸，眉头非常轻地蹙着，眉心带极淡的褶皱，眼周全是淡淡的薄红，眼眶里已经积满了泪光，瞳孔亮得发湿，眼泪已经在眼眶里打转转却强忍着没掉下来。嘴角非常努力地往上扯，想摆出一个安抚对方的笑，可这个笑意完全是硬挤出来的。整个人的状态已经到了情绪临界点。

三、负面提示词
大颗滚落的泪珠、眼部全范围泛红、眼泪流出产生泪痕、挤眼皱眉、大幅度转头、多余手部动作、B级片式夸张演技表情。

四、画质要求
所有动态精度对齐24fps原生胶片级顺滑度，没有抖动、卡顿、撕裂、掉帧等瑕疵。
```
