# 熹园·店主自述·6镜完整prompt（2026-07-12 用户确认版）

> 参数状态：固定六镜项目的历史案例。仅用于溯源，不得复用本文的时长、动态强度、裸台词或固定镜数；当前规则以 `director-thinking/SKILL.md` 为准。

## 确认的prompt格式（按此顺序写每镜）

1. `@图1` 人物描述（特征全部保留+不戴墨镜眼神自然）
2. 照片级写实，无CG感，天然肌肤质感
3. 镜头语言（景别+运镜+构图比例+呼吸感+fps）
4. 光影（光源+方向+氛围+色调）
5. 动作（自然动作，全程不看镜头）
6. 动态强度X%
7. 声音（同步生成中文内心独白/旁白+语速+语气）
8. 独白/台词内容（不加引号）
9. `@图2` 场景实景照（完整露出不虚化）
10. 专属负面（隔一行）

## 叙事线（每镜一个功能，不重复）

```
镜1：我是谁
镜2：我看见什么（痛点共情，非环境描述）
镜3：所以我开了这里（开店动机）
镜4：怎么解决（品茶+内省）
镜5：价格地址（同一叙事空间，不跳场景）
镜6：收尾邀约（与镜1同一场景闭环）
```

## 内心独白 vs 旁白 vs 口播

| 模式 | 写法 | 适用 |
|:----|:-----|:-----|
| 内心独白 | `同步生成中文内心独白：语速偏慢轻声自然，像说给自己听；` | 店主自述、文艺治愈 |
| 旁白 | `同步生成中文旁白：语速中等自然叙述，像跟朋友介绍自己；` | 沉浸探店、叙事 |
| 口播 | `同步生成中文探店人声：...；台词自然开口说出：` | 快节奏引流、促销 |
