# 角色头像生成工作流（Chatbot形象照）

> 用于给聊天机器人/角色生成自拍风格的头像，不是视频工作流的节点。

## 触发场景

- 用户说「给小X设计个形象」「自拍头像」「头像图」
- 用户给了一张参考人物照片（如「用小鹿的照片」）
- 需求是**一张静态图**，不是视频角色的彩铅三视图

## 执行流程

### 第一步：定风格

直接问用户，或从上下文推断：

| 维度 | 示例 |
|:----|:-----|
| 风格类型 | 治愈系小姐姐 / 清爽小哥哥 / 国风 |
| 参考人物 | 「用小鹿的照片」→ 找assets已有参考图 |
| 背景氛围 | 温暖居家 / 茶室 / 户外阳光 / 工作室 |
| 画风 | 高清写实 / 卡通 / 文艺 |

### 第二步：找参考图

1. 如果用户给了参考人物照片 → 从照片提取外貌特征（脸型/五官/发型/穿搭）
2. 如果用户只说风格描述 → 自行设计外貌方案，写入prompt
3. 检查 `/home/ubuntu/assets/characters/` 是否有现成参考图可复用
4. 已有资产的角色（小鹿/郭襄等）复用特征描述，不重新设计

### 第三步：调用Seedream生成

**入口：** Helper API `/seedream`（localhost:1888）

**请求格式：**
```bash
curl -s -X POST http://localhost:1888/seedream \
  -H "Content-Type: application/json" \
  -d '{"prompt": "详细的画面描述文案"}'
```

**返回格式：**
```json
{"status": "ok", "image_url": "https://...", "prompt": "原prompt"}
```

**下载图片：**
```bash
curl -s -o /home/ubuntu/assets/characters/<name>.jpg "<image_url>"
```

### 第三步：Prompt写作要点

**人物部分（必须保持一致）：**
- 脸型/五官/发型/穿搭要写具体
- 每项都是可渲染的视觉元素，不写抽象描述

**背景部分（可单独改）：**
- 用户说「温馨些」→ 改背景描述，不改人物
- 用户说「换个风格」→ 改穿搭+背景，改五官不改变本质特征

**画质部分（固定模板）：**
```
高清写实，皮肤质感真实
```

### 成功案例：小天·治愈系自拍头像

**参考人物：** 小鹿（assets已有形象图）
**风格：** 治愈系小姐姐
**初版prompt：**
```
治愈系小姐姐自拍头像，白色方领吊带，碎花短裙，茶棕微卷锁骨发，
金色项链和耳钉，温暖居家氛围，暖光落地窗边，木质地板上洒满午后阳光，
绿植盆栽，米白色棉麻沙发，原木茶几上一杯热茶冒着白气，
画面整体暖黄色调柔和温馨，浅笑看镜头，自然光自拍视角，
高清写实，皮肤质感真实
```

**用户反馈：「背景可以温馨些」→ 迭代策略：**
- ✅ 保持人物完全不变（外貌/穿搭/表情）
- ✅ 不触发重新生成角色，在原图基础上改prompt重跑
- ✅ 把"温暖居家"具体化为暖光窗边+绿植+热茶+沙发
- ❌ 不改五官、发型、穿搭、表情

**保存路径：** `/home/ubuntu/assets/characters/<bot名>_warm.jpg`

### 典型Prompt结构

```
治愈系小姐姐自拍头像，[人物外貌描述]，[背景场景描述]，
画面整体[色调]柔和温馨，[表情]看镜头，自然光自拍视角，
高清写实，皮肤质感真实
```

### 常见修改方向 & 陷阱

| 用户说 | 改什么 | 不改什么 |
|:-------|:-------|:---------|
| 背景温馨些 | 背景描述 → 暖光窗边/绿植/热茶 | 人物五官/发型/穿搭 |
| 换个风格 | 穿搭+背景风格 | 脸型/五官/发色 |
| 换个表情 | 表情描述（浅笑→微笑→看着远方） | 全部外貌+背景 |
| 换个色调 | 色调描述（暖黄→冷白→日落金） | 全部内容和构图 |
| 太像本人了/暴露 | 重新设计人物（新发型/穿搭/气质词） | 保留风格方向（治愈/文艺等） |

### 🚨 常见陷阱

#### 坑1：用真实人物照片生成bot头像 = 暴露身份

**症状：** 用户说"太宝路了，暴露"。

**原因：** 用真实人物（如小鹿本人照）做参考图生成bot头像 → 头像太像真人 → 客户一眼看出"这是那个小鹿"，bot角色的独立人格感被破坏。

**正确做法：**
- 用真实人物照做**灵感参考**（描述prompt时借鉴风格/氛围），**不要做reference image**
- prompt中描述"像小鹿一样干净"等气质类词汇，但不锁定五官
- 让Seedream自由发挥，生成一个"有这个feel但不是同一个人"的新形象

#### 坑2：多版本迭代保持人物一致

用户可能会要多个版本（全身/大头/不同背景），每次重新生成时：

1. **不要换脸** — 保存上一版prompt的人物描述段，新版本只改背景/构图/视角段
2. **每一版都保存** — 命名规则：`<bot名>_<版本名>.jpg`
3. 示例：xiaolu_portrait.jpg → xiaolu_warm.jpg → xiaolu_closeup.jpg

### Prompt迭代技巧速查

| 需求 | 做法 |
|:----|:-----|
| 用户说"背景温馨点" | 保留人物段，替换背景段：暖光窗边、绿植、毛毯、热茶、暖黄色调 |
| 用户说"来个大头照" | 保留人物段，构图改为"胸部以上特写"、"背景虚化奶油感" |
| 用户说"换个穿搭" | 保留五官/发型段，替换穿搭描述 |
| 用户说"太像本人了" | 重新设计人物（换发型/换穿搭/微调气质关键词），不锁参考图 |
