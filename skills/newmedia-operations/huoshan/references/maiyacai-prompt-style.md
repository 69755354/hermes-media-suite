# 麦芽菜专业提示词风格指南

> 来源：抖音@麦芽菜「AIGC情绪表演提示词」合集第8集（2026-07-18采集）
> 适用场景：情感/情绪/演技类 Seedance 2.0 提示词写作
> 核心特征：导演级精确性 · 0.1秒级情绪瞬变 · 毫米级微表情控制

## 麦芽菜prompt原稿（逐字）

```
0-2s 幸福感，起始帧视线落在围巾中心点，
眼睑完全放松，眼内光偏柔，以快速向左后抬头
把视线移到画外左方的人脸上，最后半帧才抬出
全部6颗下齿露笑，笑肌的抬升过程在2秒内
极慢完成，没有突然爆发出笑容的动作，眼睛无泪。

5s 藏得意：转过头微低，笑肌0.1秒瞬间卸力，
把笑容完全收回到口腔内，只在嘴角留下1mm的括弧，
瞳孔极微收缩半格，眼底的亮光悄然上浮0.5度，
全片没有任何多余的眼球转动，眼白露出的面积
从始至终保持一致，眼睛无泪。

5-7s 瞬生委屈：下眼睑到眼白区域，
虹膜对焦突然虚掉0.3秒，快速向左抬头视线还在
对方脸上，但眼神瞬间失神，0.2秒后上唇不受控
跳了一下，全是眼部肌肉的本能瞬变。
```

## 结构拆解

**每段三部分：**
- [时间段] [情绪标签] → 0-2s 幸福感 / 5s 藏得意 / 5-7s 瞬生委屈
- [动作/肌肉描述] — 精确到肌肉级别（笑肌/眼睑/上唇）
- [负面排除] — 每段结尾必写（眼睛无泪）

**定量化规范：**
- 时间精确到0.1秒级：0.1秒瞬间卸力 / 2秒内极慢完成 / 最后半帧
- 距离/角度精确到毫米/度：1mm括弧 / 上浮0.5度 / 瞳孔极微收缩半格
- 身体部位精确到肌群：笑肌 / 下眼睑到眼白区域 / 上唇 / 虹膜

**核心原则：不写情绪词，写肌肉动作**
- ❌「她很不舍」→ 情绪词，AI不知道怎么渲染
- ✅「上唇不受控跳了一下」→ 肌肉动作，AI能照着做
