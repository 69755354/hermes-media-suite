### 🚨 融合版出片铁律（2026-08-22 天行者定案，必须调用，禁止自行改写）

**定义：** 融合版 = 郭襄那一套 + 两段直连动作连接。郭襄那一套 = 每镜 prompt 必含的完整表演指导（外貌锁定/台词原文/表演指导/环境音/BGM/字幕/@图引用 7要素，见 `templates/guoxiang-30s-6shot-template.md`）。两段直连动作连接 = 上镜尾帧是下镜动作起点，不是复制目标；下镜从该状态继续完成后续动作，全程运动轨迹不断线（见项目 `节点5_分镜_第1条_融合版_导演思维_20260821.md`「运动轨迹链接」章节）。

**硬规则（违反=违纪）：**
1. 出片 prompt 必须按融合版执行——郭襄 7 要素一个不能少，表演指导（手势/自然感基线/情绪放眼神呼吸）不可删、不可简化
2. 两段直连动作连接必须保留：每镜结尾闭口保持 0.3-0.5 秒留稳定尾帧；上镜尾帧作为下镜动作起点继续完成动作，禁止直接复制尾帧、禁止重置动作
3. 禁止自行添加融合版之外的额外约束（如自定义发音段/自定义构图段/删手势），要改先问天行者
4. 出片前对照融合版逐项核对：□郭襄7要素 □两段直连 □尾帧接力 □无字铁律（如项目要求无字幕）

### 🚨 每镜prompt标准模板（强制遵守，2026-07-28合并去重）

按以下顺序写每镜prompt，禁止跳序或混排：

```
1. @图1 人物特征（全部保留+不戴墨镜眼神自然）
2. 照片级写实，无CG感，天然肌肤质感
3. 镜头语言（景别+运镜+构图比例+呼吸感+fps）
4. 光影（光源+方向+氛围+色调）
5. 动作（自然动作，全程不看镜头）
6. 动态强度X%
7. 声音（同步生成中文内心独白/旁白+语速+语气）
8. 独白/台词内容（不加引号）
9. @图2 场景实景照（完整露出不虚化）
10. 专属负面（隔一行）
```

### 🚨 写完后的四层校验

| 层 | 查什么 | 怎么查 |
|:---|:-------|:-------|
| 1. 文件对得上 | @图1/@图2 引用的文件实际存在？ | 对照节点9素材清单逐一打钩 |
| 2. prompt规范 | 有emoji吗？有引号吗？有红线词吗？ | grep扫一遍 |
| 3. 上下游一致 | 场景跟分镜定稿一致吗？角色跟人设一致吗？ | 读节点5、节点6校对 |
| 4. 全镜统一 | BASE VOICE一致吗？声音模式统一吗？ | 6镜逐行对比 |

**四层全过才能出提示词。一层不过退回重写。**

**叙事模式prompt写法：**
```diff
- 同步生成中文探店人声：年轻女声28岁，音色清亮偏甜……
- 台词自然开口说出：株洲老街边上……

+ 同步生成中文旁白：年轻女声28岁，音色清亮偏甜，语速偏慢自然叙述感；
+ 旁白内容：株洲老街边上，藏了一家不太一样的茶馆；
```

**角色动作描述在叙事模式下的写法：**
```
✅ 小鹿站在门头前侧身看向店内，推开门走进庭院，穿过竹木茶座走到椅前坐下，动作自然不看镜头
❌ 小鹿微微前倾凑近镜头压低声音开口（口播写法）
❌ 小鹿站着说（动作太少）
```

**检查清单：**
□ 确定了口播模式还是叙事模式
□ 全片统一，不混用
□ 口播模式→同步生成中文探店人声+台词自然开口说出
□ 叙事模式→同步生成中文旁白+旁白内容，角色全程不看镜头
□ 叙事模式下，角色有完整行动线（推门/走进/落座/起身/走远），不仅是站坐切换

**核心原则：导演意图是你写给自己看的，不是写给Seedance的。**

```
内部想：像个周末午后偶然路过，被门头吸引，压低声音分享秘密的惊喜感

### 🚨 Seedance prompt融合写法指南：画面词+机器词不分层不分段（2026-07-11 新增）

**原则：不发抽象比喻，不发分层分段结构。参考视频prompt写法——一句话同时包含画面+参数+氛围+运镜。**

| ❌ 错误 | ✅ 正确 |
|:-------|:--------|
| 「在暮色里亮着温和的光」抽象氛围 | 「暖黄灯光亮着，招牌字发光清晰可见」具体可渲染 |
| 「50mm定焦固定机位动态强度32%」纯参数堆砌 | 「画面稳定固定镜头，人物微动光影轻晃」画面带参数 |
| 分层分段发：导演意图段+全局锁定段+正向补充段 | 一段话融合：场景+人物+动作+光影+机位+参数+声音，不分层 |

**参考视频prompt（已验证有效）：**
```
80年代闽南老巷街角，斑驳掉漆的老旧居民楼小店，复古做旧金属招牌，
穿豆绿色无袖旗袍的短发女生侧身步行过马路，阴天树荫下的柔和自然光，
复古胶片颗粒感，低饱和灰调色调，跟拍横移镜头，治愈市井国风探店氛围
```

**熹园融合版：**
```
傍晚株洲老街，熹园门头木质青瓦暖黄灯光亮着，招牌字发光清晰可见，
绿植沿墙边垂下光影在墙面轻晃；小鹿站在门头前白衣碎花裙茶棕微卷发，
侧脸被暖光打亮；画面柔和稳定固定镜头轻微胶片感；
小鹿微微前倾凑近镜头压低声音开口，尾音上扬；
同步生成中文探店人声：年轻女声28岁，音色清亮偏甜，语速偏慢带气声，尾音上扬；
台词自然开口说出：说出来你可能不信株洲有家茶馆不单单只是品茶
```

**检查清单：**
□ 导演意图只内部过，没写进prompt
□ prompt没有比喻（不像、仿佛、如同、温和的、柔和的抽象词）
□ 每个词都是Seedance能具体渲染的画面元素
□ 画面+参数+氛围混合在一段中，不分层不分段

### 🚨 参考视频运镜分析法（2026-07-11 新增，本会话实测）

**原则：** 当用户提供了参考视频时，拆解其运镜并复用到Seedance prompt中，不要凭想象写固定机位。

**标准流程：**

1. **抽帧** — `ffmpeg -i 参考视频.mp4 -vf "fps=1" -q:v 2 /tmp/frames/frame_%02d.jpg`
2. **分批分析** — 每18-20秒一批，用ARK看图端点分析运镜类型：
   ```
   分析prompt：这是参考视频第X-Y秒的连续帧。只分析运镜：
   1. 固定机位还是移动机位？如果有移动是推/拉/摇/移/跟拍？
   2. 景别变化了吗？全景→中景→近景？
   3. 具体在哪个时间点运镜发生了变化？
   ```
3. **映射到本视频** — 按参考运镜序列写镜号对照表：
   ```
   跟摇(入场)→推近(进门)→固定(场景展示)→推(室内)→固定特写→固定收尾
   ```
4. **写入prompt** — 将运镜描述写到Seedance prompt的动作段，与场景描述融合

**典型运镜-场景映射：**

| 运镜 | 适用场景 | Seedance prompt写法 |
|:-----|:--------|:-------------------|
| 跟摇/横移 | 人物入场/沿街走来 | 横向跟摇镜头从右侧跟拍人物沿街走来，镜头跟随人物移动平行摇摄 |
| 推近 | 从全景到人物近景 | 从XX机位平稳推近到人物上半身占画面约三分之二 |
| 固定中景 | 落座/展示场景 | 固定中景机位，镜头稳定不动 |
| 固定特写 | 品茶/细部 | 固定镜头浅景深虚化背景，极近距离拍摄 |
| 跟拍→固定 | 走进室内 | 跟拍镜头跟随人物从XX走向XX，到位后镜头平稳过渡到固定 |

**自检：**
□ 参考视频的运镜已逐段分析完毕
□ 本视频的每镜运镜类型已与参考视频对应映射
□ 运镜描述写进了prompt的动作段（不是仅在注释里）
□ 起始镜和收尾镜的机位形成闭环（如都跟拍/都固定，或跟摇入→固定收）

### 🚨 角色动作自然度检查（2026-07-11 新增，本会话用户纠正点）

**原则：** Seedance prompt中的人物动作应该模仿真实探店者的自然行为，不要写多余的设计感动作。

**对比：**

| ❌ 多余动作（被用户纠正） | ✅ 自然动作 |
|:------------------------|:------------|
| 走到入口前停步微微侧身，**抬头看了一眼青瓦屋檐和左侧木柱发光字** | 从街边走向凉亭，**视线看向凉亭方向**，走到入口前自然停步 |
| **抬头看了一眼青瓦屋檐**，然后走进…… | 视线看向目的地，自然走进 |
| **侧身回头**看了一眼凉亭的方向 | 走到门口自然停住，**略微侧身回头**看了一眼 |

**写前自问：** 一个真实客人来探店，她会做这个动作吗？→ 不会就删掉。

**正确的动作原则（参考参考视频）：**
- 视线始终看向目的地（走路看路，不东张西望）
- 脚步自然，手臂随步伐摆动
- 停步就是停步，不需要额外加「抬头看招牌」「看屋檐」等表演
- 回头只看一次、自然、不刻意停留太久

### 🚨 人声一致性铁律（2026-07-11 新增）

**问题：** Seedance每镜独立生成人声，各镜声音描述不一致→出片后音色不同→拼接违和。

**解决：所有镜共用一个 BASE VOICE 模板，只改每镜的表演指导行。**

**BASE VOICE（全片统一，复制粘贴）：**
```
同步生成中文探店人声：[性别][年龄][音色描述带具体质感]，声音特征全程一致不变；
```

**PER SHOT（每镜只改这一行，写具体不要写笼统）：**
```
镜1（钩子）：语速偏慢带气声，尾音上扬卖关子
镜2（痛点）：语速中等，三个问题渐慢，第三个叹一口气
镜3（方案）：语速中等，关键词带笑意
镜4（无台词）：（不写人声描述）
镜5（价格）：语速轻快，价格数字带笑意
镜6（CTA）：语速略慢，地址字字清楚，尾音轻松自然不带推销感像顺口一提的邀请
```

**⚠️ 声音描述的质感铁律（2026-07-11 新增，本会话用户纠正点）：**
- ❌ 笼统写法：「年轻女声28岁，音色清亮偏甜，语速偏慢」
- ✅ 具体写法：「年轻女声28岁，音色清亮偏甜带温暖沙感，语速偏慢自然叙述感，关键词后自然停顿留气口，尾音询问式上扬不卖关子」

**非口播模式（镜4无台词等）：** 不写人声描述行，留空即可，不是写「无」。

**规则：**
1. BASE VOICE 的性别/年龄/音色描述在所有镜中完全一致，一字不差
2. 每镜只改「语速/停顿/情绪」三个维度，不改音色描述
3. 无台词镜（如喝茶展示）不写人声描述，不是写「无」
4. 节点10调API时,所有prompt的BASE VOICE部分必须逐字校对一致

### 🚨 Seedance不渲染环境音（2026-07-11 新增，本会话实测）

**问题：** Seedance 2.0 Mini 的prompt中写了「环境音」，但生成视频中**没有**对应的环境音轨。Seedance只处理人声（探店人声/旁白），背景环境音不会被渲染到输出中。

**正确做法：环境音在节点13（ffmpeg合成）阶段手动叠轨。** 节点8写prompt时，环境音描述只作为「氛围提示」写在prompt中，不要期望Seedance直接生成。

**节点13环境音叠轨方案：**
- 从FreeSound/Pixabay等免费音效库下载环境音轨
- 用ffmpeg的amix叠到目标镜头的音频层上，音量0.08-0.12
- 或使用白噪音/粉红噪音模拟环境氛围

**自检：** 节点8 prompt中的环境音描述仅作为氛围提示，节点13必须准备对应的环境音wav/mp3文件并手动叠轨。

**每镜必须明确指定 @图1（角色）和 @图2（场景）的真实图片文件引用，禁止只用「背景XX完整保留」让Seedance脑补。**

**正确写法 ✅**
```
@图1 作为小鹿严格保留[外貌穿搭]全部特征不变；
@图2 作为熹园门头实景照，木质青瓦招牌「熹园」暖黄灯光完整露出不虚化；
```

**错误写法 ❌**
```
@图1 作为小鹿严格保留全部特征不变；
背景熹园门头绿植暖黄灯光完整保留不虚化；
```

**规则：**
1. 每镜全局锁定段必须有明确的 `@图2 作为[场景类型]实景照，[场景特征]完整露出不虚化`

### 🚨 Seedance字幕防生成铁律（2026-07-11 实测）

**问题：** Seedance 2.0 Mini 会将 prompt 中的 `「」` 中文引号识别为字幕生成指令，导致画面出现多余文字。

**解决：台词描述中禁止使用任何格式的引号、书名号。**

| 写法 | 结果 |
|:----|:-----|
| ❌ `「说出来你可能不信」` | Seedance生成字幕 |
| ❌ `关键词「单单」后停顿` | Seedance生成字幕 |
| ✅ `台词自然开口说出：说出来你可能不信` | 无字幕 |
| ✅ `关键词单单后停顿` | 无字幕 |

**台词书写规范：**
```
# ✅ 正确
台词自然开口说出：内容不加任何引号

# ❌ 错误（会被Seedance渲染为字幕）
台词自然开口说出：「内容」
```

### 🚨 动作/情绪场景微表情逐帧描述铁律（2026-07-11 新增）

**原则：** 任何动作/情绪场景的prompt，**禁止只写「XX表情」或「XX动作」**。必须拆成逐帧过渡，写清楚每一帧的身体部位、动作幅度、时长、情绪变化。

**错误示范 ❌：**
```
小鹿喝茶，表情满足。
```
→ Seedance生成结果是死板的举杯放下，没有情绪层次。

**正确写法 ✅：**
```
小鹿端起白色茶盏到嘴边，凑近先闻茶香，闭眼轻吸一口气；
低头小抿一口，茶汤入口时嘴角微弯不明显；
咽下后缓缓睁眼，嘴唇轻抿回味，抬眼看向镜头，眼神柔和满足。
```

**逐帧情绪过渡模板（面向Seedance机器的微表情语言）：**

| 帧号 | 身体部位 | 动作 | 情绪 | 时长 |
|:---:|:--------|:----|:----|:----:|
| 1 | 手+鼻 | 端起茶盏凑近闻香 | 期待 | 1.5s |
| 2 | 唇+眼 | 小抿一口，嘴角微弯 | 确认 | 1.5s |
| 3 | 眼+唇 | 咽下后缓缓睁眼，轻抿回味 | 满足 | 1.5s |
| 4 | 眼 | 抬眼看向镜头，眼神柔和 | 分享感 | 0.5s |

**自检清单（每个动作/情绪镜写完后逐项打钩）：**
□ 没有出现「XX表情」「XX动作」这种概括性描述
□ 拆成了3-5个逐帧微动作
□ 每帧写了具体身体部位（手/眼/唇/肩/头）
□ 每帧写了情绪变化（期待→确认→满足→分享感）
□ 有参数控制时长（1.5s/匀速/缓慢等）

### 🚨 Seedance人物穿模/家具重叠的负面词（2026-07-11 新增，本会话实测）

**问题：** Seedance有时渲染出人物身体穿过/嵌入桌子、椅子等家具的情况，尤其是坐下动作，人物与桌子重叠。本会话镜5（包间）出现「人坐到桌子里去了」。

**解决方案：**
1. **在动作描述中强化正确位置：**
   ```\n   走到中央竹木餐桌前在靠外侧的椅子上坐下，身体位置在桌子外侧椅子座位上，人坐在椅子上不坐在桌子上不穿过桌子\n   ```

2. **在专属负面词中加入穿模相关术语：**
   ```\n   身体穿过桌子、人物嵌入桌子、人与桌子重叠、人物与家具重叠\n   ```

**适用场景：** 所有涉及坐下/靠近家具/经过狭窄空间的动作。
