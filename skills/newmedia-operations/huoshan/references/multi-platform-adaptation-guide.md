## 二、各节点按平台调整

### 节点0 信息采集
按平台问不同问题（见SKILL.md「渠道适配信息采集」表）。

### 节点1 用户分析
- 抖音/快手：泛人群消费决策分析
- 小红书：女性为主、种草→拔草决策链
- 视频号：私域信任导向、中老年用户占比高
- B站：年轻、高知、批判性强
- 公众号：订阅粉丝为主、深度阅读习惯

### 节点2 爆款拆解
- content-hunter 按平台切换搜索源
- 小红书：还需拆解评论区作为选题来源
- B站：拆解3-10分钟长视频结构

### 节点3 选题
- 抖音/快手：痛点共鸣/认知反差/信任建立
- 小红书：攻略型/测评型/合集型/踩坑型/干货型
- 视频号：情感共鸣/实用干货/热点结合
- B站：干货深度/创意鬼畜/行业揭秘
- 公众号：热点解读/深度故事/行业洞察

### 节点4 文案（按平台切换模板）
- **抖音/快手**：现有30秒转化脚本模板（五段式）
- **小红书图文**：标题(痛点+数字+emoji 15-25字) → emoji分段正文 → 收藏引导
- **小红书视频**：种草风15-60秒，偏攻略分享
- **视频号**：社交裂变风格，转发引导>点赞引导
- **B站**：3-10分钟长文案，开头1分钟钩子+中间干货+结尾求三连
- **公众号**：干货长文/故事文，1500-3000字，标题在订阅号列表吸引点击

### 节点5 人设
- 抖音：强IP/夸张/老板人设
- 小红书：真实体验分享/专家干货/素人真实
- 视频号：真实信任感/熟人背书
- B站：专业/幽默/创意人设
- 公众号：专业作者/行业洞察者

### 节点6-12 视频制作链
- **小红书（图文）模式**：跳过节点6-12全部，改为「生成6-9张配图+封面设计+图文排版」
- **小红书（视频）模式**：仅调整比例(4:3或16:9)，时长1-3分钟
- **视频号**：同抖音流程，时长可拉长到60秒
- **B站**：3-10分钟长视频，需调整结构为多段式
- **公众号**：不制作视频，输出排版好的图文

### 节点9 合规
按平台切换合规清单：
- 小红书违禁词：导流(微信号/二维码)、绝对化用语、医疗暗示更严
- 视频号：社交裂变规范、微信导流限制
- B站：敏感话题更严

### 节点13 交付
- 抖音/快手/视频号/B站：视频链接
- 小红书（图文）：图文包（文案+6-9张图+封面+话题标签）
- 公众号：排版好的图文

### 节点14 发布
| 平台 | 发布方式 |
|:----|:--------|
| 抖音 | 开放平台API（个人可申请） |
| 快手 | 开放平台API |
| 小红书 | 开放平台API（门槛较高） |
| 视频号 | 手动发布 |
| B站 | 开放平台API |
| 公众号 | 手动发布 |

### 节点15 数据复盘
| 平台 | 核心指标 |
|:----|:---------|
| 抖音 | 完播率、点赞率、评论数 |
| 快手 | 完播率、互动率 |
| 小红书 | CES评分、收藏率、评论率、小眼睛 |
| 视频号 | 转发率、关注转化 |
| B站 | 完播率、点赞投币收藏、评论 |
| 公众号 | 打开率、在看、分享 |

## 三、工作流结构改动

在节点0之前插入「渠道选择」步骤后：
1. 客户选平台 → 标记 `channel:` 字段
2. 小红书选图文/视频分支
3. 后续节点按 channel 参数走对应分支

### 小红书图文特有流程（跳过6-12，替换为）：
```
节点0 → 1 → 2 → 3 → 4 → 5 
→ 生成6-9张配图（Seedream/PIL/实拍）
→ 封面设计（3:4比例，标题文字+视觉焦点）
→ 合规（小红书版）
→ 交付（图文包）
```
