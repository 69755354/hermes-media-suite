# 火山通道 声音提示词模式参考

> 参数状态：声音模式参考。文中动态强度数值为历史实测，不是生产标准；当前区间以 `director-thinking/SKILL.md` 为准。

> 适用模型：`doubao-seedance-2-0-mini-260615`
> 场景：火山引擎ARK Seedance 2.0 Mini + 彩铅三视图绕真人检测

## 核心问题

火山通道卡在真人检测上，必须用彩铅三视图做reference_image，prompt写「从彩绘/素描还原为真人照片级写实」。这个「彩绘→真人」的翻译层会**影响声音生成的还原度**——同一个声音描述在火山通道的效果不如婵镜直传通道。

## 「丐版」vs「完整版」对比

### ❌ 丐版（这次被纠正的写法）

```
同步生成中文探店人声：年轻女声，28岁，音色柔和清亮带温暖沙感，
语速适中偏慢，治愈共情基调，关键词后自然停顿留气口，
尾音带询问式上扬，语气词自然带"呢"。
台词内容自然开口说出：「工作卷不动？感情理不清？未来看不清？」
```

问题：声音描述是独立的一段，没有和画面锁定/动态强度/专属负面形成结构约束。Seedance把声音当孤立参数处理，不是当整体表现的一部分。

### ✅ 完整版（V2格式四层结构嵌入式，成功出片的写法）

```
【第二层：全局锁定】
@图1 作为[角色名]严格保留全部外貌穿搭不变；
照片级写实，无CG感，天然肌肤质感；
正面微侧半身站位，身体全程不动、肩膀不偏移；
50mm定焦中近景，固定机位零位移零变焦；
动态强度32%；24fps胶片质感；
全程无手部肢体动作，躯干固定不动。

【第三层：正向补充】
开口说台词，压低声音，嘴型自然张合与音频同步，语速偏慢；
眼神关切看向镜头，嘴角微收不笑，像轻声说秘密；
关键词后留气口，后自然停顿，尾音询问式上扬。
台词自然开口说出：内容不加任何引号

【第四层：专属负面】
嘴型错位、频繁无意义张嘴、面部抽搐、不匹配语音、
眼神空洞、瞪眼、频繁眨眼、咧嘴笑、面部表情僵硬
```

关键区别：声音描述被拆解到全局锁定的动态强度（控制嘴部动作幅度）→正向补充的表演指导（控制语速/停顿/情绪）→专属负面（控制嘴型崩法），三层合力锁定声音质量。

## 声音描述四层写法

| 层 | 控制什么 | 例句 |
|:--|:---------|:-----|
| 全局锁定 | 动态强度（口播段32-35%） | 动态强度32%；躯干固定，仅头部微动 |
| 正向补充 | 语速/停顿/情绪/眼神 | 语速偏慢，关键词后留气口，尾音上扬 |
| 正向补充 | 表演指导（控制声音情绪） | 像轻声说秘密，嘴角微收不笑 |
| 专属负面 | 嘴型崩法 | 嘴型错位、频繁无意义张嘴、不匹配语音 |

## 火山通道 vs 婵镜通道 声音差异

| 维度 | 火山 | 婵镜 |
|:----|:-----|:-----|
| 参考图风格 | 彩绘→需翻译为真人 | 写实→直达 |
| 声音还原度 | 中等（额外翻译层损失） | 高（无翻译层） |
| 动态强度敏感度 | 高（35%以上容易嘴型崩） | 低（可到38%仍稳定） |
| 专属负面 | 必须严格写嘴型崩法 | 可略松 |

## 常用表演指导句式

- 「像闺蜜小声说秘密」
- 「压低声音，语速放慢，关键词后留气口」
- 「说到[关键词]时眼神微抬，尾音上扬」
- 「嘴角微收不笑，眼神关切又不失神秘」
- 「语气像在分享一个只有你俩知道的秘密」
