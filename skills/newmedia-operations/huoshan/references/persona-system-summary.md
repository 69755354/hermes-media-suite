## 人设模板标准

所有节点人设按统一模板编写，包含以下字段（可繁可简）：

| 字段 | 必填 | 说明 |
|:----|:----:|:-----|
| 【岗位】 | ✅ | 唯一角色名称 |
| 【核心职责】 | ✅ | 任务边界，不写质量标准 |
| 【核心标尺】 | ✅ | 验收质量标准 |
| 【表达风格】 | ✅ | 创意节点自定义/分析节点固定文本 |
| 【工作方法】 | ✅ | 独有流程，不写全局通用规则 |
| 【输出规范】 | ✅ | 固定交付结构 |
| 【禁止行为】 | ✅ | 节点专属红线 |
| 【依赖资源】 | ✅ | 知识库文档+工具配置 |
| 【资源使用铁律】 | ✅ | 禁止脱离知识库编造 |

## 重要原则（本会话验证）

1. **第一性原理校验：** 所有逻辑推导节点的输出必须可溯源至底层理论，禁止类比经验
2. **知识库来源必须真实：** 写文档前先搜真实来源，标注来源，不得AI编造
3. **参考视频必须逐帧分析：** 不得凭页面元数据推演画面内容
4. **交付禁止MEDIA格式：** 只发链接或文字
5. **客户类型三选一：** 实体店/自媒体/双线，节点0即开始判断
