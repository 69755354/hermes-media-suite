参考片（客户跑的 4 条高消耗横版）结尾 = **堆量排比收口**，口播不喊任何 CTA：

我方落地 = **5 句堆量排比 + 1 句落点**（参考片无落点句是因为他们靠尾卡，我方无尾卡，落点必须留在口播/字幕里）：

- 裁定⑫仍有效：**口播**不写「点击下方链接」；「点击下方链接 免费观看全集」只出现在**官方尾贴上**（官方物料，属合规）。

## 2. 卡片口径（关键澄清）
- 参考片尾卡 = **给自家号引流/涨粉**：「抖音号：XXX」+ 搜索框「抖音搜索｜<自家号名>」+「来抖音 发现更多创作者」。**不可照抄**。
- 火龙的下方卡片 = **下载入口** → 口播可以正当说「**点下方卡片，下载火龙漫剧**」；字幕兜底「应用商店搜火龙漫剧」。
- 判断准则：卡片是下载就喊下载；卡片是关注就别喊下载。

## 3. 语速硬线（最硬的一条）
- 参考片实测 **≈5.17 字/秒**，21.6–28.2s → 全片 **110–146 字**；句均 7.7 字。

- 排产硬线：**全片 130–145 字 / 28s 左右（≈5 字/秒）**，字数没写够 = 信息密度不达标。
