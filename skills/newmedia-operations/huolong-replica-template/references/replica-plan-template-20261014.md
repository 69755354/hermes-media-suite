# 复刻线成片模板（2026-10-14 定稿，用户认定版）

来源：`projects/huolong-copy-20261011/work/gen/build_plan_ref.py` + `compose_ref2.py` + `assets/台词本_复刻01_执行表.md`。
性质：用户亲自定的“素材怎么放、文案怎么写”模板。做复刻类/口播类竖横版都先套这份，不要自己发明。

## 1. 文案模板（怎么写）

台词本是一张表，**表头只有三列**：`| 序 | 说话人 | 口播文案 |`。

- 台词 100% 照参考片，只换人物与场景；一句一行，不改写、不合并、不删句。
- 说话人用代号（甲/乙），甲=主推方，乙=被说服方；一问一答推进，乙只负责抛问题/质疑。
- 单句短：**7–14 字**；长句拆成连续短句（例：「喜欢的漫剧打开就从第一集」「看到最后，全部敞开让你看」）。
- 卖点按顺序推进，每句只讲一个点：自动连播 → 不用解锁 → 全剧看完 → 资源齐全 → 画质/流畅 → 收口 CTA。
- 开头第一句就是钩子（反问/质疑），不铺垫；结尾一句落到「点击视频下方链接下载」。

## 2. 贴片模板（素材怎么放）

**核心：素材跟着台词走，不是从头铺到尾。** 按句号段绑定，一句/几句讲什么，就放对应那块素材。

模板里的绑定表（复刻-01 实例，直接照结构改）：

| 句段 | 素材 | 标签 |
|:--|:--|:--|
| 5–7 | `clip:动态_播放页滑动_裁净.mp4` | 自动连播·播放页 |
| 8–10 | `clip:动态_选集页_全屏.mp4` | 选集全解锁·动态 |
| 13–14 | `clip:动态_剧集录屏_穿越.mp4` | 从第一集看到最后 |
| 15–17 | `clip:动态_唐僧跪拜_正片.mp4` | 题材齐全·唐僧西游 |
| 19–20 | `clip:动态_正片录屏_112533_1.mp4` | 画质清晰·播放丝滑 |

规则：
1. 窗口 = 对应首句 `start - 0.25` 到末句 `end + 0.15`，四舍五入到 0.01。
2. 相邻贴片**不许同时出现**，前一块提前 0.12s 收掉。
3. 手机壳窗口 = 第一块开始 → 最后一块结束；没素材的段落**不显示手机壳**。
4. `page:` 前缀 = 静态 App 页（纯裁切，不套壳）；`clip:` 前缀 = 真录屏（套壳）。
5. 吐槽/痛点句不得出现品牌 App 画面（C2），品牌画面只跟在正面句之后。
6. 全片 App 画面累计 ≥5 秒。

## 3. LOGO 规则

不是全程挂：**只在念到「火龙漫剧」的那一刻出现**，窗口 = 品牌词起点 -0.3s 到 +1.2s；出现两次就两个窗口，间隔 <0.3s 则合并。

## 4. 字幕样式（复刻线默认）

`黄字 + 红边`（PrimaryColour `&H0030EAF0`、OutlineColour `&H000000FF`）、**句句单行**（`single: True`，超长按标点折行）、`size 54`、`marginv 120`。
（与 3D 卡通竖版套版那套白字黑边不同，不要混用。）

## 5. 其它硬参数

- BGM `0.20`，`amix ... normalize=0`，`loudnorm I=-14:TP=-1.5:LRA=9`；语音侧 `equalizer f=3000 g=3` + `acompressor -18dB 3:1`。
- 手机壳：`210×454`（9:19.5 真机比例），inset 7 → 屏幕 196×440；不要做成大宽框。
- 后期不加速（2026-10-01 起作废 1.1/1.2 倍速）。
- 风险提示 5 行 + 左侧竖排「累计签到后可提现」用字幕轨画（`风险` / `侧边` 两个 Style，17px / 26px）。

## 6. 检查清单

① 每块贴片都对得上当时那句台词；② 贴片互不重叠；③ 无素材段不显示手机壳；④ LOGO 只在品牌词窗口；⑤ 字幕黄字红边单行；⑥ App 画面累计 ≥5s；⑦ 痛点段无品牌画面。
