# 台词念全闸 + 音色闸（2026-10-14 落地，多轮实测）

## 一、为什么必须过闸
快乐马 happyhorse-1.1-r2v 两个坑，都是「出片后才看得出、但已花钱」的：
1. **漏句/丢尾句**：25s 两段片（21 句）漏「全程免解锁追漫」「那画质怎么样」。
2. **男女音色串位**：把男角色的台词（含开场「女士，你怎么还在手动点下一集」）配上女声，女角色的问句配上男声——用户直接骂「她对那个男的喊女士」。
用户硬规则：**没念全 → 重新生成，绝不删台词**。

## 二、出片前两道闸
```
生成段 → 逐段 ASR → 与台词本该段 difflib 对齐
   ├─ 缺字块 <3 字 → 同音字假阳性，放行
   └─ 缺字块 ≥3 字 → 只重出该段（ONLY_SEG），最多 3 轮
   ↓ 通过
concat → ASR 全片 → 计划 → **逐句基频校验（音色闸）** → 合成
```
脚本：`work/gen/gate_regen.py <item> <轮数>`；命令链 `python3 gate_regen.py <item> 3 && python3 run_ref2.py <item>`。

### 音色闸怎么判（无需听，用基频 F0）
逐句取 40ms 帧自相关 F0 → 中位数：男声约 118-190Hz、女声约 180-260Hz（情绪激动会抬高 30-60Hz，所以两段会轻微重叠）。
判据：**同角色各行应落在同一区间**；某行明显越界（如男角色行 275Hz）才判串音。不要用绝对阈值硬切，会出现「情绪句被误判成女声」。

## 三、三个必踩的坑
1. **段名**：job id 是 `复刻-02-seg1`（连字符），落盘文件名是 `复刻-02_seg1.mp4`（下划线）。用 id 拼路径 → No such file。路径取 `j["output"]`。
2. **闸要非 0 退出**：`STILL_MISSING` 时必须 `sys.exit(3)`，否则 `&&` 链会带着漏句的段继续合成。
3. **自动交付去重是按完整路径**：重出的片覆盖同名文件 → 发件台账里已有该路径 → 哨兵会跳过、用户拿不到新版。**重出版的产物必须换名**（如 `复刻-02_v3_仿真人.mp4`）再交给 `auto_deliver.py`。

## 四、段长与语速（直接影响念全率）
- 一段塞 82 字 / 12 秒（≈6.8 字/秒）→ 模型连续 3 轮丢尾句。
- 改为 **每段 ≤60 字（3 段）+ 语速字数÷5.5＝秒**（用户 2026-10-11 口径）后一轮通过。
- 结论：单段 ≤60 字、语速 5.5 字/秒 是当前模型的稳过区间；不必追参考片的 6.85。

## 五、口播文本改字要与字幕同步
用户要求「截掉某段话」时：改台词本 → 口播与字幕自动同步去掉（字幕来自同一张表）→ 重新生成对应段。**不要再单独去剪音频**（剪接会错位、还得重排全部时间轴）。
