## 记账命令（出片后立刻执行）

```bash
python3 /home/ubuntu/workflow/projects/huolong-guide/ledger/log_cost.py \
  --name "片名" --project "模板/项目" --model happyhorse-1.1-r2v --res 720p \
  --seconds 35.4 --segments 3 --render-sec 168 --note "备注" --path /abs/成片.mp4
```

- `--seconds` 填**实际生成秒数合计**（含重出、重试、废段），**不是成片时长**。一段底片=一次生成调用=该段秒数进账；重试一次就多算一次
- `--segments` 填实际提交生成了几段（含重试段），用于复盘
- `--render-sec` 填本机渲染耗时（HyperFrames 实测，15 秒片约 170 秒）；**重渲染/换素材重出不产生生成费，不重复计秒**

## 硬要求

1. **不许事后补记**：出片即记，视频发出去之前账要落。
2. **每行只记一条成片**，版本迭代（v15/v16）各记一行，不要合并。**只按“交付成片一次”记账 = 少算**（重出/重试全丢）——2026-09-22 已犯，用户当场指出。
3. **被覆盖的重试段本地查不到**（同名 `seg1.mp4` 直接覆盖）：能核实的是**下限**，报数时必须说明“实际高于此值”；要平台实扣去百炼控制台用量/账单对账。
3. 渲染/质检占用本机资源不折算成钱（本机无按量成本），只记渲染耗时。
4. **失败/重试/弃用的生成也算钱**（2026-09-22 用户追加要求）：每次提交就往 `台账_提交流水.csv` 记一行，跑了就导——`python3 log_attempt.py --import-log <本次 run 的 log> --source <文件名>`。日志不落盘/同名覆盖后就永远补不回来了。
5. 报数时必须说清口径：**平台实扣（`台账_平台用量.csv`）> 落盘可核=下限 > 提交流水=参考**。不许拿估算当实扣报。
