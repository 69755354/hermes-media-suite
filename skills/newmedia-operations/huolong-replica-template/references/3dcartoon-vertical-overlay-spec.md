## 2. App 界面贴片（成片的硬需求）

- 形式：**静态 App 截图**放进手机壳（历史交付片就是静态，非录屏）。
- 位置：竖版右侧 `x=500,y=200`，208×433，压在人物右侧空白区，禁压脸、禁压字幕、禁压底部套版文字。
- 内容映射：
  - 找片/分类/双列流 → 讲「内容多、好找剧」的段
  - 选集页 → 讲「集数全」的段
  - 播放页 → 讲「看得清楚/在追哪部」的段（剧名、集数必须和台词一致）
- 累计露屏 ≥5–10s，至少 2 张卡；每张卡出现在对应台词段内。
- 卡内画面：`contain` 适配内屏（不裁内容），空隙用同图高斯模糊填底；禁把界面横向裁掉控件。
- 生成画面本身**不得**出现手机/屏幕/界面/文字，全靠后期贴片。

## 3. 后期参数

- 字幕：ASS，白色 54px + 黑描边，`MarginV≈215`（压在套版文字上方，不叠字）。
- BGM：`volume=0.2` + `amix=inputs=2:duration=first:normalize=0`，尾部 1.2s 淡出。
- 语速：5.5 字/秒，段时长 = ceil(字数÷5.5)，**一律不加速**。
- 输出：H.264 CRF18 / 30fps / yuv420p / AAC 128k 48k / faststart。

## 4. 成片自检（缺一不可）

抽帧看：① 人物同一角色不换装 ② 无手机/屏幕/文字 ③ 手机壳只有一个 LOGO，不与底片图标同框 ④ 字幕不压脸不压套版 ⑤ 贴片不裁控件 ⑥ 左侧竖排与 5 行风险句齐全。
ASR 实念率 ≥96%（同音字差异不算错）。

## 5. 已知坑

- 直接用录屏（`动态_播放页滑动_全屏.mp4` 540×1116 等）会在内屏露出源片上下黑边 → 要么先 `crop` 掉黑条，要么直接用静态截图。
- `-stream_loop -1` + 长时间轴在低配机易拖到分钟级甚至截断文件；静态 PNG 贴片更快更稳。
- 剧名/集数对不上是最常见的废片原因：截图里是哪部剧，台词就得说哪部。
