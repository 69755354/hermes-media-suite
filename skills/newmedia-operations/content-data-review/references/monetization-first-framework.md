# 变现方式第一性框架（完整版）

> 来源：2026-08-08 会话（李玟篇数据复盘）。用户三连纠正后定案，与知识库 data-review-template.md 第0步 / ad_investment_guide.md 第0步同步。

## 一、核心原则

**数据好坏没有绝对标准。复盘/投流/内容评估前，先回答两个问题：**

1. **Q1 核心目的是「品牌曝光」还是「转化变现」？** —— 两者指标权重完全不同
2. **Q2 如果转化变现：流量/获客/带货哪种？**

不谈变现方式就谈数据好坏 = 耍流氓。同一组数据，变现方式不同，结论可能完全相反（实测案例见第五节）。

## 二、目的二分（Q1）

### 目的A：品牌曝光（不直接考核转化）
- 一级指标：曝光量、触达精准度、CPM、声量、搜索指数、认知度
- 过程指标：互动率、完读/完播
- 红线：目标人群触达率达标；CPM低于行业均值
- 判定语言：谈「触达/声量/认知」，不谈「成交」
- ROI口径：品牌价值难以直接算钱，不强行ROI

### 目的B：转化变现
| 变现方式 | 一级判定指标 | 过程指标 | 核心红线 | ROI口径 |
|:---|:---|:---|:---|:---|
| 流量变现（流量主/广告） | 阅读量、打开率、完读率 | 转发率、收藏率 | 阅读稳定增长；完读率>50% | 流量主收入÷投放成本 |
| 获客变现（私域/咨询/课程/服务） | 客资数、加微率、咨询转化 | 转发率、收藏率、评论质量 | 每篇有客资沉淀；转化路径清晰 | LTV÷CAC |
| 带货变现（电商/团购） | GMV、转化率、客单价、复购 | 收藏率（加购）、评论 | ROI>1 | GMV÷投放成本 |

## 三、判定规则（复盘+投流通用）

1. 先定目的（曝光 or 转化）→ 再定变现方式 → 指标权重绑死
2. 品牌曝光目的：权重全在曝光侧，不考核成交；转化目的：权重全在转化侧，曝光只是过程
3. 过程指标不单独判「缺陷」，只做归因
4. 判定语言跟目的走：曝光谈「触达」、获客谈「客资」、带货谈「ROI」
5. 数据不足 → 标【数据不足，无法判定】，禁拿替代指标硬判
6. 未知 → 先按转化从严（多数本地/服务类客户核心诉求是转化）
7. 投流专属：获客变现号投「播放量」=浪费钱（播完不转化）；别拿播放量当KPI；ROI按变现方式算（获客=LTV/CAC，不是简单收入÷成本）；评判语言分开（流量投流看数据指标，商业转化只看后端私信/留资/核销）

## 四、四方案对比模板（每个变现方式一套方案）

对同一篇内容/同一个号，按4种变现方式各出一套分析方案：

```
【变现方式X】
- 一级指标评估（实际值 vs 红线）
- 结论（好/中/差/不适用 + 一句话）
- 方案（按这个方式该怎么做）
```

最后总表对比 → 定最优路径。此模板可复制用于任何客户文章。

## 五、实测案例：李玟篇（公众号《读懂李玟：精神内耗如何吞噬一个天后》）

数据：阅读5825 / 转发55(0.94%) / 收藏1(0.02%) / 评论8 / 在看9。号=心理资源师（获客变现）。

| 变现方式 | 判定 | 一句话 |
|:---|:---|:---|
| A 流量变现 | 中 | 阅读起步OK（17-87元/篇收入天花板低），缺完读率 |
| B 获客变现 | 灾难 | 5825精准潜在客户0客资，获客链路全断 |
| C 带货变现 | 不适用 | 心理情绪内容推商品=破坏信任瞬间 |
| D 品牌曝光 | 合格（缺记忆点） | 精准触达但无品牌露出，曝光资产没沉淀 |

最优路径：B获客变现为主业 + D品牌曝光做放大器。

**链路拆解（获客变现视角）：**
```
阅读5825（流量池✅精准）→ 转发触达【断】→ 信任建立【断】→ 客资沉淀【断：0】→ 咨询转化【无】
```
结论定性：不是「内容差」，是「转化断」——吸引环节成功，中间+终点全断。

## 七、送客词 pitfall（同源事件）

给客户做内容，凡是把读者导向「第三方免费替代服务」的词=送客词，全行业禁止（客户明确要求才豁免，`_豁免送客词.flag`）。
- 实证词：心理援助热线/400-161-9995/12356/全国心理援助/心理危机干预热线/免费在线问诊平台/官方挂号/政府免费培训/公益免费咨询热线
- 客户自己的转化渠道（自己的店铺/企微/预约入口）不算送客
