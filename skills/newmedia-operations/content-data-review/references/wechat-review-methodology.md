# 公众号图文数据复盘（内容级分析）

## 触发条件

- 用户发公众号后台截图/数据，要求分析、复盘、判断爆不爆
- 「结合文章和数据分析」「做完整分析」「这篇为什么爆/为什么不爆」
- 工作流节点17 数据复盘、节点16_发布记录.md 回传数据复盘

## 铁律（本技能最高优先级）

1. **先搜基准，再下判断** — 分析前必须 web_search 行业基准（分享率/收藏率/互动率/打开率），禁止凭经验说「中等偏上/不错/及格线」。本会话教训：第一轮凭经验说「分享率中等偏上」，搜索验证后 0.94% 实际**低于**行业平均 1-2%。凭经验判断高低=等着被打脸。
2. **不算比率等于没分析** — 绝对阅读量说明不了问题，必须算：分享率=分享/阅读、收藏率=收藏/阅读、点赞率、评论率、在看率、互动率=(赞+评+看+分+藏)/阅读。
3. **数据盲区必须说** — 完读率/涨粉数/阅读来源构成/粉丝基数四项缺失时，明确说「成色判断有天花板」，不给过度自信的结论。
4. **结论带来源** — 每个基准数字标注来源（平台名/URL），禁止编行业数字。

## 复盘流程

### 第一步：算比率（1分钟内完成）

对每篇目标文章算：分享率、收藏率、点赞率、评论率、在看率、互动率。同时算账号内对比（本篇 vs 前几篇）——同账号对比是第一个基准。

### 第二步：搜行业基准（必做，不可省）

web_search 关键词：公众号 爆文 分享率 转发率 数据 基准 / 公众号 平均打开率 2026 / 公众号 算法 完读率 权重。
现成基准表见 `references/wechat-metrics-baselines.md`（搜索验证过，可直接引用，但一年后建议重搜确认）。

### 第三步：三维度拆解

1. **流量结构** — 阅读从哪来：标题点击红利 vs 内容自传播。判断信号=分享率。分享率<1-2%平均线 → 大概率是推荐/标题流量一波流，吃不到长尾推荐。
2. **内容质量** — 留存价值。判断信号=收藏率。收藏率≈0 → 情绪浓度高但干货密度低，读者「看过即走」；每个心理/知识概念后没有「可带走的东西」（自查清单/行动提示/金句）。
3. **转化能力** — 商业闭环。判断信号=互动率+CTA。互动率<3%行业线 → 评论区冷清无二轮传播；结尾无CTA/关注引导/免责声明 → 流量零沉淀。

四象限归类（橙子法）：阅读高转发少 / 阅读低转发高 / 都高（真爆文）/ 都低。

### 第四步：盲区清单（输出前必列）

- 完读率（若>65%，2026算法权重35%第一名可弥补分享率不足，悲观结论翻盘）
- 涨粉数（阅读高≠涨粉）
- 阅读来源构成（朋友圈/好友转发>40% = 有传播循环）
- 粉丝基数（几百粉 vs 几千粉，结论完全不同）

### 第五步：分层优化建议（按优先级）

- **L1 内容层（治本）**：情绪:干货 7:3；每篇给「可带走的东西」拉收藏率；结尾加分享钩子拉分享率；标题去归因（「精神内耗吞噬天后」→「那个永远在笑的天后，为什么救不了自己？」）
- **L2 转化层**：结尾三件套（关注引导+客户自有咨询钩子+免责声明）；私域钩子使用客户自己的闭环，禁止默认导向第三方免费服务
- **L3 运营层**：评论区战役（全回复+置顶互动问题）；错峰发布（工作日晚8-9点打开率峰值）；发后不修改（编辑=违反红线）
- **L4 数据层**：补后台四项数据；72小时对比打开率建标题模型库；发完填 节点16_发布记录.md
- **L5 合规层**：标题去归因、免责声明、行业红线自查

### 第六步：30天行动计划（可选，用户要落地时给）

周粒度：W1 补数据+评论区+发同款验证结构 → W2 标题库+错峰+私域钩子 → W3 多篇对比归因（账号阶段问题 vs 内容问题）→ W4 客户复盘报告。

## 输出约束

- 用户偏好：结论先行、短消息分条、不折叠、每条完整可读
- 「做完整分析」= 基准搜索验证 + 多维度 + 盲区 + 优化建议一整套成文，不是几条聊天式结论
- 完整报告存文件（`<主题>_完整分析报告_<日期>.md`），微信里分条发核心内容
- 不迎合：数据不健康就直说，即使阅读量数字好看
