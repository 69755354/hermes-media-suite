# Seedance 出片提示词踩坑（2026-08-23 火龙 S01 实录）

> 归属说明：seedance-2-0-mini-workflow / seedream-image-generation 为 user-owned skill（需 hermes curator adopt 后可迁入），本知识暂存于 task-brief-gate references，打包出片/复刻任务书时引用。

## 1. 一镜到底运镜「先退后近」：模糊导演词给模型拉远权限

- **现象**：S01 v2 一镜到底内人物占比 5.3s 87.7% → 5.4s 62.1% 暴跌后重新走近（不是硬切，是 Seedance 同镜内重构景别）
- **根因**：prompt 写「镜头后退跟随并横向换位，后退量小于人物前行量」——「后退跟随」「横向换位」是导演给人工看的模糊术语（无方向/无幅度/无量），模型拿到拉远权限后没有精确执行「后退量<前行量」的相对约束，直接拉远
- **判定方法**：逐帧量测人物在画面中的占比（抽帧 0.5s 间隔，vision 或程序量测），画出占比变化曲线，标出暴跌时间窗，对照原片同段（原片持续走近占比一直增大）
- **修法**：运镜段改成纯正向可量化约束（「人物持续向镜头走近、占比持续增大、镜头全程不得远离」），删掉给权限的模糊词；**用户明确说「不用删横向换位」时以用户定案为准**，别反复推销自己的修法
- **注意**：同样提示词在不同版可能表现不同（高颜值版「持续推近」没问题；下午豆包优化版加「后退跟随横向换位」后才引入拉远）——改提示词要溯源哪一版引入的问题词

## 2. 吞字验证：faster-whisper ASR 逐句对照台词

- **现象**：用户听出「火龙漫剧」的「剧」被吞——ASR 显示「就是這個火龍漫」直接接下一句
- **验证方法**：
  1. 抽音频：`ffmpeg -y -v error -i 成片.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 /tmp/check.wav`
  2. ASR：faster_whisper 模型在 hub 缓存（非 skill 旧记的 ~/.cache/huggingface/faster-whisper-small 路径）：
     `/home/ubuntu/.cache/huggingface/hub/models--Systran--faster-whisper-small/snapshots/<hash>/model.bin`（find 定位实际 hash 目录）
  3. `WhisperModel(path, device="cpu", compute_type="int8")` + `transcribe(wav, language="zh", beam_size=5)`，逐句对照台词原文找吞字/漏字
- **注意**：ASR 识别误差与真吞字要区分（「零」听成「停」是识别误差，「剧」整字消失是真吞）——对照台词原文逐字看，消失的是真吞
- **处置**：台词原文一字不改（本来就是对的），重跑观察是否再吞；再吞再单独处理

## 3. 三视图标准排版（角色设定 turnaround，打包生图任务书用）

行业标准：**16:9 横版**（如 2560x1440）；**左 1/3 面部特写**（头顶至锁骨）；**右 2/3 横向并排正视图 | 正侧视图(90°) | 后视图**；三视图严格等高、脚底对齐同一基线。竖版 2x2 四宫格不是标准（v1 被打回，v3 改 16:9 1x4 才过）。生成 prompt 写死排版 + 生成后 vision 核验（尺寸/特写位置/等高/脚底对齐/侧面 90°）。
