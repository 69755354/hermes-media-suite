# 游戏/攻略类内容事实核验方法（2026-08-14 妲己攻略双稿评审沉淀）

用于评审《王者荣耀》等游戏攻略稿：判断「游戏知识是否真实」不靠模型记忆，靠官网一手数据核验。

## 核心原则

- 模型记忆里的技能/装备/数值会过时（冰霜法杖已改名凝冰之息），**一律抓官网当前数据核验**
- 攻略稿里出现「官方没说但我实测」= 编造机制，一票否决
- 「我朋友」「我打了一千多场」「对面公屏打字」= 无法核验案例，只能当叙事不能当证据
- 伪概念识别：编造流派名（如「6蛇流」）+ 编造机制 + 编造百分比，三件套同时出现 = AI/采集站稿

## 王者荣耀官网核验步骤

### 1. 抓英雄资料页（GBK 编码，必须转码）
```bash
curl -s "https://pvp.qq.com/web201605/herodetail/109.shtml" -o /tmp/hero.html
iconv -f GBK -t UTF-8 /tmp/hero.html > /tmp/hero_utf8.html
# 然后提取技能描述 <p> 标签
```
注意：**官网页面是 GBK 编码**，不转码直接正则提取会得到乱码。英雄 ID 在 URL 里（妲己=109）。

### 2. 抓装备数据（JSON，直接解析）
```bash
curl -s "https://pvp.qq.com/web201605/js/item.json" -o /tmp/items.json
python3 -c "import json; items=json.load(open('/tmp/items.json')); [print(i['item_name'], i.get('des1',''), i.get('des2','')) for i in items if '关键词' in i['item_name']]"
```
装备属性、被动、数值全在这个 JSON 里，比任何攻略站都准。

### 3. 核验清单（攻略稿必查项）
| 检查项 | 方法 | 典型错误 |
|:---|:---|:---|
| 连招顺序 | 官网 Tips 明确写（妲己=231） | 稿子写 213 或 321 且无条件解释 |
| 装备是否存在 | 在 item.json 搜装备名 | 用已移除装备（冰霜法杖→凝冰之息） |
| 装备数值 | 读 item.json 的 des1/des2 | 减速写成固定 20%/30%，实际是区间+触发条件 |
| 被动/技能机制 | 读英雄页技能描述 | 「命中减速目标增伤」这种官网没有的机制 |
| 百分比数据 | 无来源百分比全部标记 | 「胜率提升50%」「击杀率提升54%」 |
| 流派/术语 | 官网或权威攻略站是否真有此说法 | 「6蛇流」官网121件装备无一件带"蛇"字 |
| SEO残留 | 搜「关于XX的更多内容」「。。」 | 采集站模板未清洗 |

### 4. 减速叠加类装备的常见坑（妲己案例实测）
- 减速类被动多数是**条件触发**（受击/技能后普攻），不是常驻
- 远程英雄用冰痕之握减速效果**减半**（妲己=远程，30%→实际15%）
- 简单相加算总减速（20%+30%=50%）不成立，官网无此叠加规则
- 同一目标被多团狐火命中后续只造成 50% 伤害（三技能分叉）——稿子讲「大招收割」却漏了这个决定爆发上限的机制，是专业度缺失

## 评审输出格式

参考 `评审报告6蛇流_20260814.md` 结构：综合判定 → 游戏知识硬伤表（稿件表述/核验结论/发布处理）→ AI痕迹与SEO残留 → 标题钩子与内容匹配 → 结构逻辑 → 实用性（可保留/误导性）→ 数据来源审核 → 优先级修改（P0发布阻断/P1专业性/P2表达结构/P3复审）→ 最终结论。
