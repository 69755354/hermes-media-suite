|---|---|---|

## 根因分析

### 算法层面（主因）

头条冷启动流程：发布 → 审核消重 → 投放几十~几百试探曝光 → 收集四类信号：
1. 点击率（用户愿意点）
2. 读完率（用户愿意看完）
3. 互动（评论/点赞/收藏/转发——用户愿意产生行为）
4. 关注转化

本条数据：①②双优（24%点击率+71.8%读完率），但③④全零。

**算法判定**：内容「看着还行，但不值得扩大推送」→ 停止追加展现 → 卡在20-50量级。

**核心认知**：高点击率 + 高读完率 ≠ 必然放量。这两个只是入场券，互动行为才是放大流量的开关。

### 内容侧隐性原因
1. **同质化/模板化风险**：AI生成内容过高，容易触发模板化识别，压缩冷启动测试量
2. **题材受众池子小**：选题过于小众，可分发候选用户少
3. **标题高点击陷阱**：标题与内容匹配度偏差会触发权重修正

### 账号层面原因
1. **账号标签不稳定**：过往发文赛道杂乱，算法无法锁定推给谁
2. **账号处于观察期**：新号/改过简介/删改历史作品
3. **隐性风控过滤**：文本命中敏感词或边缘风险领域

## 实操排查顺序
1. 头条搜索完整标题，确认作品可被搜到（入库正常）
2. 账号检测工具跑一遍，确认无违规记录
3. **不要修改已发布作品**——改稿会重置冷启动状态
4. 下一篇重点：正文末尾强制埋评论钩子+收藏引导

## 产线系统改动（6个prompt文件 + SKILL.md）

### 问题

旧提示词系统**明文禁止**互动钩子——6个prompt文件都写着「禁止点赞收藏式引导」。系统设计时把「点赞收藏引导」当AI味禁了。

但数据证明：不引导互动 = 零互动 = 冷启动卡死 = 没流量。

### 改动清单

| 文件 | 改了什么 |
|---|---|
| `prompts/01_outline_step3.txt` | 大纲层：结尾从「禁止点赞收藏引导」→「必须埋评论钩子+收藏引导」 |
| `prompts/02_feed_write.txt` | 写作层：3处，结尾段定义为互动钩子结构 |
| `prompts/03_selfcheck.txt` | 自检层：共鸣度评分标准改为「缺钩子≤60分」 |
| `prompts/04_humanize_10.txt` | 拟人化层：保留钩子结构，禁止删掉改成升华 |
| `prompts/05_deai_card.txt` | 去AI味层：明确区分「互动钩子≠乞讨式引导」，去味不得删钩子 |
| `prompts/09_format_rewrite.txt` | 格式回炉：回炉精简时不得删钩子 |
| `SKILL.md` | 新增「冷启动互动钩子规则」章节，优先级最高 |

### 关键区分

| 类型 | 定义 | 示例 | 处置 |
|---|---|---|---|
| 乞讨式引导 | 求关注求点赞求转发的空洞话术 | 「求点赞关注转发三连」 | ❌ 禁止（是AI味） |
| 互动钩子 | 设计具体的评论动机和收藏动机 | 「你试过哪条路？踩了什么坑？欢迎留言聊聊」+「收藏这篇，下次想动手时拿出来照着挑路径」 | ✅ 必须（是流量开关） |

### 互动钩子结构

每篇文章结尾必须包含两层：
1. **评论钩子**：围绕核心痛点提一个开放式问题，制造评论动机
   - 示例：「如果你已经在用AI接单，最赚的是哪条路？月收入大概什么区间？欢迎留言说一下」
   - 反面（太弱）：「你怎么看？」
2. **收藏引导**：一句话告诉用户收藏后能用来做什么
   - 示例：「收藏这篇，下次想动手的时候拿出来照着挑路径、算成本、避开坑」

### 与去AI味环节的关系

去AI味（05_deai_card）和格式回炉（09_format_rewrite）在旧系统里会删除互动钩子（因为误判为「点赞收藏式AI引导」）。改后明确：
- 去AI味不得删除互动钩子
- 格式回炉不得删掉钩子
- 03_selfcheck 共鸣度维度：缺钩子≤60分

## 验证方法

### 文章质检脚本
```python
# 检查文章是否含互动钩子
text = open('article.txt').read()
has_comment_hook = any(w in text for w in ['欢迎留言', '评论区聊聊', '你怎么看', '欢迎评论'])
has_save_guide = '收藏这篇' in text or '收藏' in text
print(f'评论钩子: {has_comment_hook}')
print(f'收藏引导: {has_save_guide}')
```

### 完整质检项
- 汉字数 1800-2000
- 无「不是…而是…」否定排比句式
- 无「X、Y、Z」三段顿号列举
- 破折号 ≤ 2 个
- 无过渡词（综上所述/首先/其次/最后）
- 无卖课/割韭菜倾向词
- 含评论钩子 ✅
- 含收藏引导 ✅
- 数据关键词全部命中（可溯源）
