## 四之补、GLM-5.2 vs DS v4-pro 文章质量实测对比（2026-08-30 同素材双跑）

用朱雀三号素材分别跑 GLM-5.2 和 DS v4-pro，对比结论：

| 维度 | GLM-5.2 | DS v4-pro |
|---|---|---|
| 速度 | 5-8 分钟/篇（API 响应慢，每环节7-8s vs DS 2-3s） | 2-3 分钟/篇 |
| AI味 | 3.45（低于阈 8.4） | 5.05-7.98（险过或超阈） |
| 原创 | 98.15% | 96.57-96.94% |
| 编造 | PASS（0 处） | PASS（0 处） |
| 合规极限词 | ❌ 「唯一」「绝对」3 轮回炉都没改掉 | ❌ 「第一」「修复」3 轮回炉都没改掉 |
| 句式重复 | ❌ 「意味着」用 10 遍，每段同模板（描述→总结→意味着→普通人为何关心） | ✅ 句式变化多，无重复模板 |
| 信息密度 | 2158 字但信息量不到 1000 字，车轱辘话多 | 2192 字信息密度高，五个技术环节+商业逻辑+争议全讲清 |
| 通俗化 | 用力过猛（「白花花的银子」「刀尖上跳舞」堆多了像老师硬讲方言） | ✅ 有画面感（「像跑完长途站住没倒」「闭眼走钢丝」） |
| 成本 | 走本地代理 18890 免费 | 0.08-0.36 元/篇 |
| 耗时 | 5-8 分钟 | 20-30 分钟（回炉多，AI味偏高触发额外轮次） |
| 格式门 | 第3轮回炉后过 | 3 轮都没过（加粗段不够，兜底补加粗才过） |

**GLM 写文章结论**：流水线工人——活干了，没有灵魂，重复严重。出初稿可以，但不能直接发，人工修一遍是必须的。

**DS v4-pro 写文章结论**：讲故事能力明显更强，句式有变化、信息密度高、有画面感。但 AI 味偏高（5-7.98 vs 阈 8.4），格式门适配差（加粗段反复不够），回炉轮次多导致耗时翻倍。极限词也中招（「第一」「修复」）。两个模型都没达到直接发的标准——都卡在行业红线词上，需要人工改。

**模型选择建议**：DS 质量优先（文笔好但慢且贵），GLM 成本优先（免费但质量差）。折中方案 = GLM 出初稿 → Claude 精修。

**产线 LLM 通道配置坑**：
- `config.yaml` 里 DS 通道的 `hermes_key_path: model.api_key` 指向 Hermes config 的 `model.api_key` — 这是 GLM 的 key 不是 DS 的
- DS 通道需要单独设环境变量 `DEEPSEEK_API_KEY` 或写 `~/.hermes/config/deepseek.key`
- GLM 通道 base_url 应指向本地代理 `http://127.0.0.1:18890/v1/chat/completions`，不是智谱直连
- Hermes config 里 DS key 在 `providers.custom_custom.api_key`，GLM key 在 `providers.custom_glm.api_key`
