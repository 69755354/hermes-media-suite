# 行业进化宏观视角写头条文章（2026-09-05）

## 用户纠正

旧稿用个体焦虑切入（「阿凯剪视频赚钱」「我焦虑不会用AI」），用户纠正：

> 「你不要拿单独的个体，你要拿整个AI行业的事情来引起别人的共鸣。就说AI现在进化以后，后面一些传统的行业会怎么怎么样」

## 正确角度

- 从AI行业进化的宏观视角切入，不是个人小故事
- 讲AI对传统行业的冲击：零售/制造/建筑/服务业逐个过
- 共鸣点：你在哪个行业？你有没有感觉到这股力量已经到你门口了？
- 用真实数据说话，不煽动不贩卖焦虑
- 结尾给可操作的判断框架

- 代际分化加剧
- 把岗位拆成任务清单
- AI难以拿走的能力：现场感知、对人的理解、信息不完整时做取舍

## 写作约束

- 1600-2000汉字
- 3个小标题（一、二、三、独立行纯文本）
- 禁止「不是…而是…」否定排比
- 禁止「X、Y、Z」三段顿号列举
- 禁止破折号超过2个
- 禁止过渡词（综上所述/首先/其次/最后）
- 禁止AI味升华结尾
- 禁止编造数据/案例/时间点
- 交付用纯文本无Markdown符号

## codex写作任务书模板

任务书里必须包含：
1. TASK_TYPE: 文案
2. 用户原话（角度指令）
3. 角度说明（行业宏观视角，不是个体故事）
4. 真实素材清单（标注来源，禁止编造）
5. 情绪要求（写实不煽动，数据说话，给可落地判断框架）
6. 格式硬要求（字数/小标题/禁用句式/禁标AI）
7. 标题方向参考

codex exec命令：
```
codex exec --skip-git-repo-check -c model_reasoning_effort=high -c sandbox_mode=danger-full-access "读 /tmp/brief.md 内容，按要求写头条文章。纯文本输出，不要Markdown符号。"
```

effort=high创意写作需5-6分钟，stdout前期为空正常。codex可能中途遇到model capacity错误（rc=1），但大部分内容已输出到stdout，需手动补全开头。

## 教训

1. 用户要的是「行业大画面引起共鸣」，不是「个体故事代入」
2. 真实数据足够有力时不需要虚构案例——数据本身就是最好的钩子
3. codex写宏观分析类文章质量OK，但需要手动检查AI味（否定排比/三段式）和补全截断
