# 头条文章质检教训总结

来源：2026-09-06 "广西女子递离职申"选题实操，GLM初稿→产线verdict FAIL→人工9大问题→豆包对标5条→codex GPT重写→通过

## 产线 verdict.json FAIL 三项全挂案例

文件：runs/20260906_1023_广西女子递离职申/verdict.json

- 极限词命中："绝对"（"绝对弱势"）
- 格式硬门不过：正文1897字超1800上限 + 加粗比例11/16段（要求≥70%段）
- 配图0/3张：产线没搜到合格配图

## 产线质检盲区（verdict.json PASS 但实际有问题）

以下9类问题产线质检检测不到，即使verdict判pass也必须人工读一遍：

1. **内部术语泄露**："素材"一词出现5次（"素材里那个数字""素材没写这员工的岗位细节"等），直接暴露创作过程
2. **段落重复**：导语"看到这新闻我后背直冒冷汗"出现两次，像复制粘贴没删干净
3. **数字反复出现**：1650和1870各出现4-5次（1650元、一千六百五十块、1650、1870元、一千八百七十块）。标准：数字事实只首次完整出现
4. **小标题带编号**："一、数据落差的核查"——标准是去编号。注意：产线只数小标题个数，不检查小标题是否有内容文本。GLM会写出"一、"后面直接空行的空心小标题
5. **正文混bullet points**：多个"-"开头的列表。头条正文应为叙述体
6. **互联网黑话/论文腔**："企业薪酬分配机制""岗位价值评估彻底失衡""信息不对称""透明度破局"——不是打工人说话口气
7. **人称突兀切换**：全文用"我"第一人称，结尾突然变成"你捏着工资条"——跳跃太大
8. **标题像说明书**："拿到工资条先拍照存档，若低于1870元法定底线，带齐凭证去劳动监察大队维权"——不像文章标题
9. **暴露素材来源**："薪资倒挂"后紧跟"素材里明明白白写着这词"——直接告诉读者这个词是从素材抄的

## 豆包对标5条优势（写入产线prompt）

1. 删掉大量重复语句，节奏顺滑不啰嗦
2. 补齐官方权威依据（桂政发〔2025〕16号），真实可信不踩AI稿虚数据坑
3. 三段黄金结构：事件共情→职场痛点→落地实操
4. 补齐合规免责，规避平台风险
5. 强化收藏、评论钩子，自然引流不生硬

## 模型对比

| 维度 | GLM初稿 | codex GPT重写 |
|------|---------|---------------|
| 内部术语 | "素材"出现5次 | 无 |
| 数字重复 | 1650/1870各4-5次 | 首次出现后不再重复 |
| 小标题 | 带编号或空标题 | 有内容（"那行工资炸场"） |
| 论文腔 | 严重 | 无，打工人人话 |
| 编造 | 编造表妹录音情节 | 无，对不确定事实明确说"公开信息并未说清" |
| 免责声明 | 无 | 有 |
| 收藏钩子 | 生硬 | 自然融入正文 |

结论：头条文章写作用codex GPT（model_reasoning_effort=high），不用GLM直写。GLM产线初稿可以跑流程，但终稿必须codex重写或人工精修。

## 图片生成教训

- codex image_generation 默认生成英文文字图片（RESIGNATION FORM / PAY SLIP）
- 必须在prompt中明确要求："画面中所有文字必须是中文"或"画面无任何文字"
- 验证方式：vision_analyze 检查是否有英文文字

## 标题写作要求

- 标题不能像操作指南/说明书
- 爆款标题要素：数字冲击+悬念感+情绪钩子
- 好标题示例："离职月薪1650元，对比最低1870元，全场目光转向副总"
- 坏标题示例："拿到工资条先拍照存档，若低于1870元法定底线，带齐凭证去劳动监察大队维权"

## 文章结构：自嘲代入 > 政策科普（冷启动号铁律）

零粉号冷启动阶段，文章结构选错比内容写差更致命。两种结构对比：

**政策科普结构（信息全但数据差）**：冲突案例开头→政策背景→人群分档→政策依据→操作指引→结尾钩子。信息量大、逻辑顺、合规好，但读者第一反应是"这是个案例"不是"这是我"。适合有粉丝基础的账号。

**自嘲代入结构（信息少但数据好）**："你是不是也这样？"开头→替读者说出痛点→自嘲反转→单点深挖一个方法→给读者一个照着做的动作。信息量小但代入感强，读者第一句就被拉住。适合零粉冷启动号。

自嘲代入结构的关键：前三句话必须让读者觉得"这说的就是我"。开头用"你是不是也这样""你是不是也遇到过"比用案例数据开头代入感强十倍。结尾给读者一个能照着做的动作（"回去翻翻你文章的开头"），比"评论区聊聊"有效得多。

17.5万展现爆款拆解（自嘲代入结构）：标题"发了3天文章，阅读量还是个位数，我的账号是不是废了？"→开头"你是不是也这样？辛辛苦苦写了一两千字…展现几十个，阅读零蛋"→反转"不是你写得差，是你写得太好了"→举例"老张放弃"小故事→方法"把最狠的那句话怼到最前面"→钩子"回去翻翻你文章的开头，问自己：陌生人刷到这段字，会想看第二句吗？"。点击率2.7%、评论119条。

对比同期政策科普稿：展现86/20/29/36，阅读2/0/0/0，评论全0。差距2000倍。不是内容质量差距，是结构差距。

## 用 Playwright 抓头条文章正文

头条文章页 JS 渲染+反爬，curl/jina reader 抓不到正文。Playwright 可抓但必须用 `wait_until='domcontentloaded'`，用 `networkidle` 会超时（头条页面持续加载跟踪脚本不会到达 networkidle 状态）。抓取后用 `document.querySelector` 逐选择器试 `article`/`.article-content`/`.content`/`[class*="article"]` 等，正文长度>200才算抓到。展现量等数据藏在 HTML 中 URL 编码的 JS 变量里，用 toutiao_metrics.py 脚本提取。
