# 选题来源=文档站而非平台爆款的坑（2026-09-04 实测）

## 问题

用户问「你有没有去搜过爆款啊」后查证发现：

### 选题池现状
- tp003 material.json 的 `source_urls` 指向 `https://m.book118.com/html/2026/0813/8032074037010117.shtm`（原创力文档）
- `hotlist_meta.score=null` / `hot_value=null` / `rank_in_source=null`
- `search_keyword` 全部为空
- 选题池 31 条，来源分布：CSDN（8条）、juejin（2条）、book118（2条）、blog.csdn.net 子域（多条）、toutiao.com（少数）
- 没有一条来自头条/抖音/小红书的真实高互动爆款文章

### 文章效果

用文档站素材（book118「AI副业主流接单平台全解析」）写出来的头条文章：
- 像知识科普（列举6个平台+7个渠道）
- 缺真实情绪痛点（开头「凌晨的屏幕泛着冷光」是AI模拟的假嗨）
- 信息密度均匀（每段都是「描述→数据→解释→总结」同模板）
- 没有爆款的标题钩子和情绪冲突结构

### 根因

三点法（搜→拆→写）的第一步「搜」搜错了地方：
- 搜的是搜索引擎能搜到的文档站知识整理
- 不是平台内的真实爆款文章
- 爆款基因（标题钩子、情绪痛点、节奏结构）只能从平台爆款里拆，文档站素材天然没有

## 正确流程

1. 用豆包/360搜索搜头条/抖音/小红书上「副业」相关的高互动文章
2. 筛选标准参考选题教程视频：粉丝<5万 + 阅读>1万 + 24小时内
3. 拆爆款的标题结构、开头钩子、情绪痛点、结尾设计
4. 从拆解结果提炼选题角度（不是从文档站现成内容抓）
5. material.json 的 source 必须是平台文章 URL

## 已有选题池修复需求

topic_pool_career.json 里 20 条选题的 source_url 大部分是文档站/技术博客，需要：
- 逐条核实 source_url 是不是平台爆款
- 不是的用平台搜索数据重新校准或替换
- search_keyword 字段必须填写
- 补充 hot_value/rank_in_source 等热度数据

## 教训

- 选题素材的来源决定了文章的爆款基因
- 文档站知识整理 ≠ 平台爆款内容
- 三点法「搜」搜的是平台爆款，不是搜索引擎搜知识文档
- 汇报选题来源时要能说清「这条来自哪篇爆款、为什么爆」
