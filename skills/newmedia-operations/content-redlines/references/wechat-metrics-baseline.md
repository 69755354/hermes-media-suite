# 公众号好坏指标基准（2026-08-08 实证对比）

## 知识库基准（内部红线，来源：《2025新媒体内容生态研究报告》+壹伴助手行业数据，见 wiki/concepts/data-review-template.md）

| 指标 | 行业均值 | 头部 | 参考线 |
|:-----|:--------|:-----|:-----|
| 打开率（订阅号） | 0.89% | 2.1% | 1%+=超60%运营者；2%+=优秀；5%+=爆款 |
| 打开率（服务号） | 1.32% | - | 口径=图文阅读总人数÷图文送达人数 |
| 转发率 | ≥5% | - | 社交裂变核心指标（公众号社交权重约35%） |
| 收藏率 | ≥3% | - | 干货型内容指标 |

## 网上工具基准（参考线，来源：jzl.com 公众号数据分析、zhangfensi.com 转发率基准、smzdm.com 2026算法解读）

| 指标 | 行业平均 | 优秀线 |
|:-----|:--------|:------|
| 分享率 | 1%-2% | 3%+ |
| 收藏率 | 1%左右 | 2%+ |
| 互动率 | 3%以上=行业不错 | - |
| 情感类爆文转发率 | - | 可破10% |

2026公众号算法：完读率权重35%第一、分享率30%第二；完读率>50%+转发率>3%触发持续推荐；互动率>3%=行业不错。

## ⚠️ 口径差异（重要）

- 知识库基准（转发≥5%、收藏≥3%）比网上工具数据（分享率平均1-2%、收藏平均1%）**严格**——行业报告线 vs 工具统计线
- **复盘判断用知识库基准当红线**（内部统一标准），网上数据当参考
- 打开率算不了时（缺送达人数/粉丝基数），用转发率+收藏率+互动率组合判断

## 实证案例（李玟公众号文章，2026-08-08）

数据：阅读5825/分享55/点赞27/在看9/评论8/收藏1（2天）
- 转发率 0.94% vs 知识库红线 ≥5% → 差5倍，传播结构不健康
- 收藏率 0.02% vs 知识库红线 ≥3% → 差150倍，无留存价值
- 互动率 1.72% < 3% 行业线
- 归类：四象限「阅读高、转发少」=标题驱动流量文，非内容驱动爆款
- 教训：凭经验说「分享率中等偏上」被搜索数据打脸（实际低于平均）——**判断好坏前先查基准，禁止凭经验给比率**
