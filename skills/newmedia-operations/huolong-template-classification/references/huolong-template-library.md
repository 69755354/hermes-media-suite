```
火龙模板库（40条）
├─ 视频模板（4大类 20子类）
│   ├─ 通用口播（2：G-V6居家单人 / G-YD夜店多人）
│   ├─ 硬网赚（6：W-F~W-K，口播直说赚钱/金币/提现+底部声明）
│   ├─ 软网赚（6：S-G~S-L，颜值主播+口播不提赚钱+底部声明）
│   └─ 网赚剧情（6：A~F，场景化演绎钩子+口播段）
└─ 文案模板（7大类 20变体）
    ├─ 看剧赚钱（4原始+1仿写=5）
    ├─ 综合多福利（2原始+1仿写=3）
    ├─ 见面礼（2）

    ├─ 消息通知（2）
    └─ 网赚剧情·情侣闯祸（1，合规适配版）
```

## 视频模板判别流程

```
开头有场景化剧情演绎？
  是 → 网赚剧情（A~F）
  否 → 口播提赚钱/金币/提现？
      是 → 硬网赚（W-F~W-K）
      否 → 口播有底部提现声明？
          是 → 软网赚（S-G~S-L）
          否 → 通用口播（G-V6/G-YD）
```

## 文案模板判别流程

```
口播提"赚钱/金币/红包/提现"？
  是 → 提18.8红包+1元提现？
      是 → 看剧赚钱（KJ-01~04）
      否 → 提多维度福利？→ 综合多福利
  否 → 提"免费看剧"？
      是 → 用"省钱=赚钱"话术？
          是 → 消息通知（XX-01~02）
          否 → 免费看剧（FK-01~03）
      否 → 仿写合规版（KJ-05★/ZH-03★）
```

## 合规风险三级

| 级别 | 模板 | 风险点 | 投产处理 |
|:---:|:-----|:-----|:-----|
| 高 | 硬网赚全部 + 看剧赚钱/综合多福利/见面礼(原始) + 免费看剧 + 消息通知 | 直说"免费/兑换现金/18.8红包/赚钱赚到手软/白拿" | 必须逐条过审，参照KJ-05★/ZH-03★仿写路径 |
| 中 | 网赚剧情全部 + 签到/14天(原始) | 剧情段可控；金额需核验 | 口播段控制话术，金额核验 |
| 低 | 软网赚全部 + 通用口播V6 + 仿写脚本 | 口播不踩红线 | 直接投产 |

## 视频×文案交叉适配

同一套文案可拍成不同视频模板——关键变量是口播中是否出现"金币/红包/赚钱/提现"等激励信息：
- 口播提激励 → 硬网赚（W系列）
- 口播不提激励+底部声明 → 软网赚（S系列）
- 口播不提激励+无声明 → 通用口播（G系列）
- 软网赚 = 网赚口播文案去掉激励信息只讲追剧体验 + 底部保留声明

## 夜店网赚版定位

夜店网赚口播 = 硬网赚·W-K 情绪爆发·多人轮换型。独有特征：
1. 多人轮换出场（镜1人物A→镜2人物B→镜3人物C）

生产模板见 `huolong-replica-template` skill。

## 网赚剧情脚本结构

网赚剧情脚本 ≠ 纯口播脚本，有独立四段结构：
```
[剧情钩子 5-14s] → [口播推广 20-40s] → [漫剧引流 30-75s 可选] → [CTA 3-5s]
```
- 剧情钩子段：2-3人场景化演绎，制造悬念/冲突/反转
- 口播推广段：单人面对镜头，走8步公式
- 漫剧引流段：App正片高光片段，剧目从当日可投sheet选（≥20集已上线）
- CTA段："点击视频下方链接下载"

合规适配要点（以情侣闯祸型为例）：
- "免费看"→"不用充会员不用花钱解锁"
- "兑换现金"→"边看边攒金币"
- "18.8红包"→"签到红包"
- 删模拟微信到账截图（虚假证据）
- 删"手机放那自动赚钱"引导
- 补风险提示语全文

**本批冻结参数（同源投产直接套）**
- 成片 720×1280 / H.264+AAC；时长 40–43s（台词字数÷4.5 且不低于 30s）；口播整体语速 1.2 倍（`setpts=PTS/1.2` + `atempo=1.2`，画面声音同步、口型不跑）。
- 口播生成：快乐马 r2v + 同音字占位（提现→提线、签到→千到、悬疑→悬宜、大结局→大结菊；「充会员」写「开会员」），**单人口播段只给该说话人的参考图**；段尾留 0.5–0.7s 气口、段首掐掉「先出画面后开口」的静默。
- 字幕：单屏 ≤2 行、文字取台词本原字、按段级 ASR 实测时间轴对齐、不得越镜、不加黑底卡片。
- BGM：同批每条不同曲（`assets/bgm/` 17 条），音量 0.25、落后人声 6.8–12.9dB，响度归一同片用 `linear=true`。
- 画面：官方 LOGO 全程；风险提示固定 4 句 + 侧边「累计签到后可提现」；App 界面一律做成手机壳卡片（壳 250×520 / 内屏 226×490、固定卡位、每块 ≥4.8s、不挡脸）。

**本批暴露的坑（已沉淀进 skill）**：段内串人（双参考图使模型在单人段内切到另一角色 → 用全屏 App 素材覆盖救治）；话没说完就切人（生成时长被台词填满，需留气口）；重跑单条时旧素材未移出 `output/04_raw/`、`asr_S*.json` 未清 → 字幕时间轴取到旧音频。
