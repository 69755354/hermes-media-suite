# 火龙漫剧模板分类体系

## 📌 参考素材规律库（2026-09-28 起；与视频线统一口径冲突处一律以统一口径为准）

分类、归位、改稿前先读 `wiki/concepts/huolong-ref-material-patterns.md`（客户 4 条高消耗参考）：

- 五拍骨架（只在没有参考片时作参考）：① 情绪痛点或爽感结果开场 ② 点名 App 的解法 ③ 一个主卖点 + 两个辅 ④ 一问一答说服 ⑤ 收尾堆量；有参考片就照参考片的句式、卖点顺序、节奏和拍位，缺拍、开场是闲聊式提问照样放行，不退稿（统一口径⑱、补充53）
- 通用铁律：**不承诺收益**；金额只允许 0.3/1/2/10/20/30；口播和文案里涉及小额收益的只能用⑩的 4 条固定话术，提现档位页贴片上的档位金额按白名单照常显示；剧名只用 App 内在架、已授权的，或参考片里原有的（统一口径⑩、二轮裁定13）
- 参考素材的踩线句（「没有限制」「不会被打断」类）：出自已过审参考片的，原句照用；参考片没覆盖的通用文案，高风险句才按合规重写（统一口径⑱、⑪、补充45）
- 归类判据：骨架相同＝同一模板，只换皮（客户 4 条里 A/B 就是同一条话术换画面）

## 视频模板判别流程

```
开头有场景化剧情演绎？
  是 → 网赚剧情（A~F）
  否 → 口播提赚钱/金币/提现？
      是 → 硬网赚（W-F~W-K）
      否 → 口播有底部提现声明？
          是 → 软网赚（S-G~S-L）
          否 → 通用口播（G-V6/G-YD）
```

## 文案模板判别流程

```
口播提"赚钱/金币/红包/提现"？
  是 → 提18.8红包+1元提现？
      是 → 看剧赚钱（KJ-01~04）
      否 → 提多维度福利？→ 综合多福利
  否 → 提"免费看剧"？
      是 → 用"省钱=赚钱"话术？
          是 → 消息通知（XX-01~02）
          否 → 免费看剧（FK-01~03）
      否 → 仿写合规版（KJ-05★/ZH-03★）
```

## 合规风险三级

| 级别 | 模板 | 风险点 | 投产处理 |
|:---:|:-----|:-----|:-----|
| 高 | 硬网赚全部 + 看剧赚钱/综合多福利/见面礼(原始) + 免费看剧 + 消息通知 | 直说"免费/兑换现金/18.8红包/赚钱赚到手软/白拿" | 原句出自已过审参考片的照用；参考片没覆盖或过不了审的，才逐条按 KJ-05★/ZH-03★ 仿写 |
| 中 | 网赚剧情全部 + 签到/14天(原始) | 剧情段可控；金额需核验 | 口播段控制话术，金额核验 |
| 低 | 软网赚全部 + 通用口播V6 + 仿写脚本 | 口播不踩红线 | 可直接投产，但仍要查两次合规：文案定稿后、提交付费生成前查一次；成片后再查小字、话题和 LOGO（补充46） |

## 视频×文案交叉适配

同一套文案可拍成不同视频模板——关键变量是口播中是否出现"金币/红包/赚钱/提现"等激励信息：
- 口播提激励 → 硬网赚（W系列）
- 口播不提激励+有提现声明 → 软网赚（S系列）
- 口播不提激励+无声明 → 通用口播（G系列）
- 软网赚 = 网赚口播文案去掉激励信息只讲追剧体验 + 保留风险提示

> 以上「有无声明」只用来给来料分类。自己出片时三类一律按类型加风险提示，放在左下角，用小字呈现（免费类 4 句，种草类／激励类 5 句），另加侧边竖排「累计签到后可提现」，全程叠加；不能出无声明的版本（统一口径⑨⑩、补充5）。

## 新增脚本入库流程

用户追加新脚本时：
1. 读脚本库现有结构：`workflow/wiki/concepts/huolong-wangzhuan-script-library.md`
2. 按文案模板判别流程分到对应大类
3. 追加到脚本库末尾，编号续接（如大类已有N条则编号N+1）
4. 标注钩子套路、独特要素、合规风险等级
5. 做8步公式覆盖度分析
6. 同步更新火龙模板库总表的统计数据
7. 先看脚本是否出自已过审参考片，是就原句照用；不是的，如含高危词（兑换现金/18.8/白拿等），标注合规风险为高并指明仿写路径；「不花钱看全集」是三类必带文案，不算高危词

## 闺蜜种草版定位（0915定案·已冻结为生产模板）

网赚剧情类的**首个冻结生产模板**（可直接套用骨架；`template.json`、`PRODUCTION_GUIDE.md` 里的字幕、BGM、响度、编码、贴片等参数与视频线统一口径冲突时，以统一口径和激励-06 实存脚本为准）。独有特征：
1. **双人闺蜜钩子**（两人始终同框、你来我往对话，引出用火龙漫剧的理由——原句出自已过审参考片就照用；否则按合规改写，不承诺收益，收益相关只能用⑩的 4 条固定提现话术）；生成端人物手里不拿手机，屏内不直接出 App 界面；送手机、领红包的画面一律靠后期贴片或从参考片裁切来表现（补充23）
2. **两段单人独白轮换**（黑衣女桌边口播 / 灰衣女书架口播；各段时长按 ceil(字数÷5.5)，不沿用原片时码）
3. **App 全屏段必须动态录屏素材**，禁静态截图；录屏时段和顺序按当次参考片来，参考片没覆盖时照激励-06（补充11）
4. 红包特效/到账页**从原片裁切**（已切掉原片底部合规条与抖音号水印）
5. 标准片合成走 **ffmpeg 脚本**；HyperFrames（`gen_template.py` 数据驱动写 index.html）只用来做花字和片头，渲染全局排队
6. 主字幕放画面中下、整句一行、54px 文泉驿正黑、白字黑描边无底，边距照过审片实测反推；**时码用本片自己的 ASR 逐字对齐**（不沿用原片）

冻结工程：`workflow/projects/huolong_guimi_template_v1/`
（`PRODUCTION_GUIDE.md` + `template.json` + `gen_template.py` + `hf/` + `底片提示词/` + `output/参考成片_闺蜜种草_v1.mp4`）
生产模板见 `huolong-replica-template` skill 的〇S节。

## 夜店网赚版定位

夜店网赚口播 = 硬网赚·W-K 情绪爆发·多人轮换型。独有特征：
1. 多人出场：有参考片就按参考片的拍位和换人节奏；没有参考片时，话轮真的换人才换人，不按镜头编号固定轮换，禁止机械「一人一镜」（统一口径②⑱）
2. App 画面一律后期贴片：生成端人物不拿手机、屏内不直出 App 界面、不传 @图3；有参考片照参考片，没有就按⑬贴右侧（高 60–65%、宽 22–25%，可压身体不压脸）
生产模板见 `huolong-replica-template` skill（user-owned）。

## 视频素材生成与闸的关系

用户说"生成一个视频素材看看质量"时，需要调Seedream生图+快乐马 happyhorse-1.1-r2v 生成视频（Seedance 等其他通道只在用户点名时才用）。这些调用受guard物理闸拦截：
- `BOT_DOMAIN_DIRECT_BLOCKED`：终端命令中出现ark域名/volces被拦
- `GEN_PARAM_UNATTESTED`：python脚本内联payload被拦，要求带codex/claude producer旁证
- `CONTENT_EFFECT_BLOCKED: PAID_API_DIRECT_IN_CONTENT`：content层面拦截API直调

**正确流程**：用户必须先开闸（`workflow_ticket.py open T-ORCHESTRA.INTAKE`→`kb_token_issue.sh`），闸开后生图一律经 `hermes_task_dispatch.py` 调度（不直连 ARK），视频走快乐马 happyhorse-1.1-r2v。闸未开时直接告知用户需要开闸，不绕过、不找workaround。

## 网赚剧情脚本结构

网赚剧情脚本 ≠ 纯口播脚本，有独立四段结构（各段时长按 ceil(字数÷5.5) 算，单镜不超过 15 秒，不写固定时长）：
```
[剧情钩子] → [口播推广] → [漫剧引流 可选] → [CTA]
```
- 剧情钩子段：2-3人场景化演绎，制造悬念/冲突/反转
- 口播推广段：单人面对镜头，走8步公式
- 漫剧引流段：App正片高光片段，剧目从当日可投sheet选（≥20集已上线）
- CTA段：有参考片照参考片；没有就写「搜索火龙漫剧」，不写「点击下方链接」

合规适配要点（以情侣闯祸型为例）：
- "免费看"→「不花钱看全集」（原句出自已过审参考片的照用）
- "兑换现金"→「看剧就能攒火龙币，火龙币可通过做任务兑换收益」
- "18.8红包"→「新人累计签到还有额外火龙币奖励」（金额只允许 0.3/1/2/10/20/30）
- 删模拟微信到账截图（虚假证据）
- 删"手机放那自动赚钱"引导
- 按类型补风险提示：免费类 4 句，种草类和激励类 5 句（第 1 句是「新人看剧 5 分钟后满 0.3 元就能提现」）；放左下角小字（字高约为主字幕的 1/3），侧边竖排「累计签到后可提现」，全程叠加，不口播

## 素材编号台账（2026-09-23 起，需求方要「能定位某一条」）

- **编号规则**：类型前缀 + 两位序号 —— 激励-NN / 免费-NN / 种草-NN（APP种草）/ 早期-NN（0922 前老批次）；新增只顺延，不复用旧号。
- **唯一台账**：`workflow/projects/huolong-asset-index/`（`素材编号台账.md` 内部版带本机路径 + `index.json` + `火龙漫剧·素材编号表_YYYYMMDD.xlsx` 对外版）。
- **每交付一条新成片**：先查台账取下一个编号 → 写进 md/json/xlsx → 再发群；不要事后补，否则同一素材会出现两个号。

- 群交付走 `feishu_send_file.py` 发 xlsx + `feishu_send_gate.py send` 发编号说明（@需求方）。
