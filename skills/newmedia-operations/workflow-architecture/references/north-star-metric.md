# 北极星指标（North Star Metric）— 运营周期唯一评判标准

> 2026-08-10 茗希打法定案，用户认可「这个指标好」
> 位置：GROWTH_STRATEGY 节点产物（A_GROWTH_PLAYBOOK）必含

## 一句话

变现方式定了之后，整个运营周期还要选**唯一最重要的那个数**= 北极星。它是回答客户「你们到底给我带来啥了」的唯一答案，所有其他指标围着它归因。

## ⚠️ 北极星按客户类型动态定（2026-08-10 用户纠正：「这个指数面对不同类型客户应该是不同的，自媒体客户肯定指数又不一样」）

**禁止一刀切写死单一指标**。GROWTH_STRATEGY 节点必须先判定客户类型→变现方式→北极星：

| 客户类型 | 核心目的 | 北极星指标 |
|:--|:--|:--|
| 实体店/本地生活（茗希/养生馆/餐饮） | 到店转化 | 每周可归因有效到店（或核销/预约） |
| 自媒体/达人/网红 | 粉丝增长→变现 | 可商业化精准粉/私域沉淀（非泛粉） |
| 知识付费/课程博主 | 课程成交 | 付费学员数（试听→正课转化） |
| 带货/电商 | 卖货 | GMV/复购率 |
| B端品牌曝光/招商 | 知名度→线索 | 有效咨询询盘 |
| 本地招聘/引流 | 到店/到岗 | 按目的定 |

**核心规律**：北极星 = 「客户赚钱的那个动作」的**可归因结果**。写打法前先回答「这个客户靠什么赚钱」，再定北极星。

## 本地到店客户默认北极星

**每周可归因的有效到店人数** —— 满足以下条件才记 1 次有效到店：

1. 顾客真实到达门店
2. 台账有：到店日期、顾客去重标识、来源内容ID/追踪码、接待人
3. 完成预约签到、团购验券/核销、或合规服务咨询之一
4. 同一顾客同一天只计 1 人次；新客首次到店与老客复购分开记录

## 为什么不是别的指标

| 候选 | 为什么不行 |
|:--|:--|
| 播放量 | 视频爆了但没人来 = 热闹是别人的 |
| 粉丝数 | 双峰县外的人关注再多也到不了梓园路85号 |
| 预约数 | 领先指标（到店样本未形成时临时用），但不得直接等同到店 |

## 样本不足降级

首周期有效到店样本未形成时，临时用「已确认预约数」做领先判断 —— 台账注明是预约不是到店，不冒充。

## 追踪最小字段

每条内容分配唯一追踪码（DY01 / WX01 / PYQ01 等），台账至少：

```
日期｜内容ID/追踪码｜平台｜顾客去重标识｜本地与否｜线索渠道｜意向项目
｜预约时间｜是否到店｜是否验券/核销｜成交金额｜退款状态｜接待人｜备注
```

## 复盘用法

周复盘先报北极星，再解释它由哪些过程指标驱动；不拿「有播放但无人到店」当成绩。指标分层：
- 一级结果：有效到店、验券/核销、可归因成交（判定成败）
- 一级前置：有效线索、已确认预约（到店样本形成前做领先判断）
- 二级过程：POI点击、商品访问、主页访问、私信（只归因不判罪）
- 内容过程：曝光/播放/完播/互动（判断内容是否值得继续测试，不替代经营结果）
