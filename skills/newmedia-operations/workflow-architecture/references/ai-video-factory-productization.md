# AI 短视频一键生成工具：产品化决策链（2026-08-16）

> 来源：宁老师视频《用AI一夜之间打爆同城流量》竞品拆解 → 工具实现方案 → 内部版 MVP。
> 定位：把「现有生产能力编排成内部工具」这类任务的方法论沉淀。

## 触发场景
- 用户发一个「卖 AI 工具/卖课」的竞品视频，问「这个功能怎么实现」「能不能做那种工具」
- 要把现有能力（婵镜/Seedream/ffmpeg/codex）编排成一个给内部或客户用的工具

## 决策链（天行者拍板顺序，勿跳）

1. **先拆竞品内容，再谈实现**——把完整转写打包给 codex 做商业话术/模式分析（卖什么/话术结构/省略了什么/对我们的启示），别一上来就抄功能
2. **对照现有能力**——逐功能查「我们有没有」（Playwright+whisper 提取文案/婵镜数字人/ffmpeg/Seedream 封面/codex 改写），结论常是「技术全有，差产品包装」
3. **诚实定位差异**——竞品卖「一键工具」承诺，我们卖「半托管获客系统」：诊断+原创重建+质量门禁+人工发布+数据复盘。**不复制结果夸大/成本模糊/自动发布承诺**
4. **工具形态选型**——先内部 Web 工作台（服务端渲染，不上 React 不开发机器人），稳定后客户自助；不直接暴露现有 1889 服务（无鉴权/任务状态在 /tmp/取消不真实）
5. **自动发布：设计要有，默认不用**（天行者 0816 拍板）——架构上设计完整模块（适配器/队列/重试/风控/平台授权），但 `AUTO_PUBLISH_ENABLED=false` 硬编码；实际交付只手动发布包；启用需 6 条件校验 + 天行者单独决策。**这是「能力储备」不是「默认功能」**
6. **成本诚实核算**——不学竞品「不用充值」话术：婵镜套餐摊到每条 2-20 元、封面 0.22 元/张、codex 按 tokens 记成本；每条附 cost_receipt.json。基础成片不用 Seedance（14 元/条太贵），走婵镜+ffmpeg

## 🔴 最终形态纠偏（2026-08-16 用户收口，勿再走回「一键工具」）

**用户明确定案：不是「客户粘贴对标链接→一键生成」的工具（那是宁老师那种卖课工具），而是「把我们自己的工作流做成可视化执行平台」。**

| 维度 | ❌ 错误理解 | ✅ 正确形态 |
|:--|:--|:--|
| 参考对象 | 客户粘贴对标链接，参考对标的视频 | **参考我们自己的工作流**（18/19 节点：信息采集→诊断→洞察→选题→文案→分镜→出片→交付） |
| 客户角色 | 参与各节点确认 | **客户完全不懂，不需要确认中间节点**——只做「输入需求→拿结果」（填店名/行业/城市/卖点/素材 → 看进度可选 → 拿成品） |
| 人工门 | 客户级确认 | **内部运营审**（文案/视频/封面），客户只在最后收成品 |
| 验收标准 | mock 演示看界面 | **真实跑通整个工作流**：假设一个客户→真下载/真转写/真数字人/真合成→网页操作完整流程 |

**可视化主线 = WORKFLOW_REGISTRY 19 语义节点**（PROJECT_CHARTER→…→MONTHLY_CLOSE），每个节点一个页面/卡片：状态（待开始/进行中/待审核/已完成）+ 产出物 + 门禁 + 负责人。

**流程纪律（用户 0816 三次打断教训）：**
1. **需求没讨论透，不派任何执行器**——用户明言「你一直停一直跑」「先讨论完再让他做」「你可以来追问我，直到你确保明白了我的意思，再开始动手」；连续 kill 重派 = 白烧额度
2. 方案类任务正确顺序：**先追问到理解一致 → Claude 出架构 → codex 按架构执行 → 真实跑通验收**
3. 付费 API 调用点留开关，老板通知才开（免费环节：下载/转写/改写/合成可先真实跑；付费环节：婵镜/Seedream 等指令）

## 六环节流水线（MVP 骨架）

```
S1 采集转写（Playwright下载+faster-whisper）→ S2 原创改写（codex 三版）
→ S3 合规定稿（机器扫红线+H1人工门）→ S4 数字人出片（婵镜，先mock）
→ S5 ffmpeg合成 → S6 封面交付（Seedream只画无字底图+本地排版）
```

- **人工门 H1/H2/H3**：绑定产物 SHA-256，未批准不进下一步
- **幂等**：婵镜「创建最多 1 次，有 task ID 只查单绝不重提」——防重复扣费核心
- **S4/S5 可先 mock**：把流程跑通让用户看网站，真实 API 接 P1.5

## 关键踩坑
- 把演示执行器直接包网页对外 = 串素材/任务失联/重复扣费/越门禁（P0 先修地基再做页面）
- 自动发布「默认关」被触发词分类器误判为真实发布任务——产品编排要显式 `requested_action=publish` 字段，不能只看关键词
- 多台腾讯云机器（广州 <GZ_HOST> / 新加坡 <SG_HOST> / 硅谷 <US_HOST>）容易搞混——先 ipinfo 确认归属再操作
