# 多段拼接音频重叠诊断与修复（2026-08-24 火龙 v12→v13 实测）

## 症状

用户：「剪的是个鬼啊，前面的人说话都没完，后面的人就出来了，素材也是乱七八糟」——多段 Seedance 口播素材拼一条成片，段间人声重叠。

## 诊断流程（三步转写对比）

### 1. 转写原片，拿权威台词时码表

原片是「放法」的唯一参照。转写 43s 原片拿到 28 句的精确时码：

```python
from faster_whisper import WhisperModel
model = WhisperModel('small', device='cpu', compute_type='int8')
segments, info = model.transcribe('原片.mp4', language='zh', vad_filter=False)
for seg in segments:
    print(f'[{seg.start:6.2f} - {seg.end:6.2f}] {seg.text.strip()}')
```

原片结构（火龙实测）：28 句口播 **0-40s 连续、句句首尾相接、零重叠**；人物硬切 10.5s 男→女、~20s 女→男；跨切点尾句（句9 9.96-11.84、句16 19.88-21.84）是「前句完整说完画面才切」，不是重叠。

### 2. 转写每段素材，找跨界句

`faster_whisper` 对每段 Seedance 素材转写（wav 提取：`ffmpeg -i clip.mp4 -vn -ac 1 -ar 16000 v.wav`）。

发现点：**素材实际说话内容 ≠ 分镜设计台词**。火龙实测：
- 镜1 素材尾 9.24-11.04s 多念句9「火龙币也能直接换成现金提走」（该属镜2）
- 镜2 素材尾 8.88-11.04s 多念句16「平台所有漫剧全部免费观看」（该属镜3）
- 镜3/镜4 素材正常念完自己的

配合响度佐证尾部是不是真话（不是静音尾音）：`ffmpeg -i clip.mp4 -af volumedetect -f null -` 分段测，尾部 RMS ≈ 头部说明有实字，不可裁。

### 3. 转写最终成片，验证零重叠

合成后转写成片，逐句核对：① 28 句顺序一致 ② 句间首尾相接零重叠 ③ 无句子被切半。火龙 v13 转写结果：`0.00-0.84 → 0.84-2.68 → ... → 43.04-44.40`，全部相接。

## 根因三层

1. Seedance 素材超设计时长（设计 ≤10s，实际 11.104s）且多念跨界句
2. 合成脚本全段保留音频 + 尾段变速拖音 + adelay 按画面切点排 → 段间重叠 1.3-1.85s
   - 注：拖音设计（NOTES 写「尾段拉伸至 11.800/21.800/31.300」）本身是重叠，不是 L-cut
3. 40s 成片塞 44.4s 音频是物理矛盾，v12 用重叠硬塞

## 修复（v13 关键参数）

- 成片时长跟原片走：44.416s（原片 43s），不锁 40s
- 画面/音频全取 0-11.104s（4 段相同，音画同步）
- 音频零重叠：`adelay=0|0 / 11104|11104 / 22208|22208 / 33312|33312` + `amix normalize=0` + `atrim end=44.416`
- 视频拼接：`[0:v]trim=start=0:end=11.104 ... concat=n=4:v=1:a=0`
- 每段尾句天然收在切点前 0.06s（句9 11.04s 完 vs 切点 11.104s）→ 原片式「跨切点收尾」且零重叠

## 时间轴重排（字幕 + 贴片）

**字幕**：ASS 原时码按原片设计（0.5-11.8 / 11.8-21.8 / 21.8-31.3 / 31.3-40），但素材语速跟原片差 0.5-4s（镜4 差 2s+），必须按「素材转写时码 + 段偏移」重排：

```
段偏移：段1 +0，段2 +11.104，段3 +22.208，段4 +33.312
句 N 全片时码 = 素材内转写时码 + 所属段偏移
```

转写会把相邻句合并（如句3+句4、句6+句7），按设计句时长比例拆分即可。

**贴片（overlay）**：贴片锚定的是「段内画面动作」，段起点变了就整体平移：

```
新贴片时间 = 原贴片时间 + 段偏移（段1 +0 / 段2 +1.054 / 段3 +2.258 / 段4 +3.362）
段偏移 = 新段起点 - 旧段起点（11.104-10.05=1.054 等）
```

BGM 时长、`-t` 全片时长同步改 44.416；BGM afade out 移到结尾（st=39.4:d=5）。

## 禁用的三条路

| 方案 | 代价 |
|---|---|
| atempo 整段加速到 10s | 口型漂移 11%（声音比嘴快） |
| 裁尾字/裁跨界句 | 丢内容（句9/句16 只在前段出现一次，裁了整句丢） |
| 保留重叠 | 听感崩（v12 原样） |

## 教训

- 复刻成片质检第一位是**对照原片核放法**（人物切换点/口播衔接/内容归属），ffprobe+抽帧贴片+音量全过 ≠ 合格
- 抽帧永远看不出音频重叠——多段拼接成片**必须转写验证零重叠**
- 素材转写是合成前必做的一步：素材实际说了什么 ≠ 分镜设计说什么，不转写就拼 = 盲拼
