# 红果漫剧 Seedance 直接配音参数（2026-08-06~07 复盘固化）

来源：`wiki/cases/红果漫剧_复盘.md`（Seedance 通道 · 小鹿三视图形象 · 口播推广视频）
用途：复刻口播广告时 Seedance 直接出人声的可用参数，替代 TTS 后期叠音。

## 为什么不用 TTS

TTS（edge-tts）叠在 Seedance 画面上 → 人物嘴型是生成时动的，跟 TTS 音轨不同步 → 口型完全对不上。Seedance prompt 直接写台词 = 生成时自带人声 + 口型同步。

## Seedance 口播参数（A/B 对照验证）

| 参数 | 值 | 原因 |
|:--|:--|:--|
| 台词引号 | **英文双引号 `""`** | A 组「」中文引号概率性念错（豪门争斗→豪门争争）；B 组 "" 全对 |
| 单镜字数 | **≤20 汉字** | 22 字就念错（单镜上限 ~20 字），超了拆镜 |
| 开场约束 | prompt 加「开头先停顿半秒，然后直接开口说台词，不说任何多余的字」+ 负面「多余的话、乱语」 | 模型开场即说话不稳定 |
| 时长 | **每镜 5s 完整口播，不压缩** | 段时长 < 口播时长 → 尾字被切/音频重叠 |
| 高危字 | 同义换词绕开（豪门争斗→豪门角逐、奇幻悬疑→奇幻探案） | G2P 对部分音节（zhēng/yí）拟合差 |
| 结尾重复 | 重跑抽卡选最优 | 模型 5s 内复读尾句 |
| 校验 | **以人耳为准** | whisper-small 转写中文不可靠（甜宠→填储、齐全→起钱、新作→星座），只能辅助 |

## 字幕规范（红果踩坑）

- 字体 Noto Sans CJK Bold，TTC 必须 index=2（SC 简体，index=0 是日文字形）
- 字幕文本直接复制口播文案，**禁止改写语序**（调换顺序=字幕与口播对不上）
- 渲染前测宽，超宽自动换行（798px > 690px 可用宽度会被裁）
- 重点词放大不嵌入整句（放大词独立成行 / 测宽错开）
- 「AI」ASCII 字母用 DroidSansFallback 会显示方框 → 用 Noto Sans CJK Bold

## 录屏素材（红果同款坑，本会话又踩）

客户要「手机内嵌 App 界面」形式——不是整屏录屏。从原片截录屏段会带原片人物（人举手机在说话），截的是「人+手机」不是「纯 App 界面」。截录屏前必须抽帧 vision_analyze 确认素材里只有 App 界面。
