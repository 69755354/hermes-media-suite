## 铁律：对白一字不改 → 建 _自备文案.flag

复刻任务对白 = 原片逐字稿，属于「客户自备文案」场景：
- 项目目录建 `touch <项目目录>/_自备文案.flag` → 豁免节点4三版产出检查（评审报告检查保留）
- codex 任务书里**必须把对白逐字稿原样贴入**（codex 无法自行提取，传递责任在 Hermes）；执行链强制：read_file industry-index.md → 按表读行业文档 → 写 `_知识库引用.md` → 再产出

## codex 打包（分析+创作，effort=high）

复刻方案一口气出 5 个文件（五步法先搜再写）：
1. `节点1_用户画像.md` — 目标人群画像（如 35+ 中年女性、三线以下城市），每条结论带来源或「推断依据」
2. `节点2_爆款分析.md` — ≥3 条同赛道（如漫剧App推广广告）有效样本 5 模块拆解 + 话术素材库 + 外部校准结论
3. `节点3_打法策略.md` — 复刻版在目标平台的打法定位 + 内容策略 + 风险提示
4. `节点5_分镜定稿.md` — 8 列分镜表；总时长对标原片（43s 片按 ±1s 控）；台词英文双引号；每镜声音描述（非 TTS 音色名）
5. `节点6_人设定稿.md` — 主角卡（面部/发型/服装/体态/配饰）+ 场景卡（布局/光源/色温）+ 彩铅三视图需求

## 合规风险标注（不改文案，只提示）

⚠️ **2026-09-21 新规（优矩口径，覆盖旧做法）**：原片对白里的极限词/收益承诺/无广告类表述（如「用起来确实挺顺手的（2026-09-21 新规已删原句）」「妥妥的追剧自由啊（2026-09-21 新规已删原句）」「累计签到后可提现（2026-09-21 新规替换原句）」）**必须改掉或删除**，不再「保留原样只标注」；照抄=必被拒审=白花钱。收益类只能用 4 条固定话术。做法：`COMPLIANCE: <问题点>` 或方案文件内「风险提示」小节。

## 路径坑（2026-08-17 实测）

- `WORKFLOW_SPEC.yaml` 在 `/home/ubuntu/wiki/spec/`——相对路径 `wiki/spec/...` 会 File not found，**必须绝对路径**
- `WORKFLOW_REGISTRY.yaml` 在 `/home/ubuntu/workflow/wiki/spec/`——与 SPEC **不同根目录**，两文件分家
- 拆解/产物文件若 read_file 报 Binary（UTF-8 文本被误判），用 `python3 -c "print(open(path).read())"` 或 iconv 兜底
