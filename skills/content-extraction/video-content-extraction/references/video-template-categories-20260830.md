### 网赚口播5种钩子套路

**套路F：痛点对比式**
```
别再当冤大头了→别的平台一集看30秒广告→看到20集提示付费解锁→火龙漫剧无广告无付费无跳转
```
- 画面：真人女性，文艺风场景（日系小店/咖啡店）
- 钩子逻辑：列举竞品痛点（广告/付费/解锁）→ 火龙漫剧逐条解决
- 特点：可带漫剧正片引流段（手机播放微短剧片段）

**套路G：质问+痛点式**
```
别再看了→一集一个15秒等解锁的漫剧→越看越烦人好吗→切换火龙漫剧→免费看全集
```
- 画面：AI数字人女性，居家场景
- 钩子逻辑：质问观众为什么还在用烂平台→拉踩→直接转火龙漫剧
- 特点：AI数字人可批量换形象，同文案多版本投放（实测2条同文案不同数字人）

**套路H：痛点共鸣式**
```
追剧让人头疼的就是一级一级的解锁→慢慢的等待消耗了追剧的耐心→直到我用上了火龙漫剧
```
- 画面：真人女性，居家客厅，领夹麦
- 钩子逻辑：共情观众追剧痛点→引出火龙漫剧作为解决方案
- 特点：App展示用播放器功能弹窗（倍速/清晰度/定时/小窗），强调功能体验而非内容量

**套路I：疑问式**
```
都是看漫剧，为什么火龙漫剧这么懂观众→别的平台看两三集就要充会员→全是套路
```
- 画面：真人女性前半段+真人男性后半段（同一视频切换博主）
- 钩子逻辑：用疑问句引发好奇→自答式拉踩竞品→列出火龙漫剧优势
- 特点：双博主切换增加画面变化感；带3D国漫引流段+选集页贴图

**套路J：质问自拍式**
```
不是你到底咋想的→一集一个15秒解锁漫剧还没收手吗→火龙漫剧直接看大结局
```
- 画面：真人女性，商务办公楼前台，举手机自拍姿态
- 钩子逻辑：第一人称质问式对话→营造对朋友说话的代入感→转火龙漫剧
- 特点：自拍视角+非居家场景（办公楼/咖啡店等），场景差异化

### 网赚口播 vs 网赚剧情的子分类维度对比

| 维度 | 网赚口播 | 网赚剧情 |
|:---|:---|:---|
| 分类主轴 | 钩子方式 | 钩子套路（剧情场景类型） |
| 博主类型 | 真人/AI数字人（影响生产成本） | 固定剧情角色+口播博主 |
| 素材组合 | 有无漫剧引流 × App展示方式 | 有无漫剧引流 |
| 时长规律 | 无引流30s / 有引流36s | 无引流36-55s / 有引流89-134s |
| 批量复制 | AI数字人同文案换形象（实测2条） | 换钩子场景+角色 |

### 关键发现
- **AI数字人同文案多版本投放**：吃瓜小刘子账号发了2条几乎一致文案的视频，仅数字人形象不同（长卷发vs短卷发+空气刘海），是批量测试素材的常见手法
- **漫剧引流段在口播类中也有出现**：不是网赚剧情专属——口播中段插入手机播放微短剧片段+选集页，作为"内容丰富度"的视觉证据
- **App展示方式多样化**：筛选页/选集页/功能弹窗/播放器界面，不同展示方式对应不同卖点角度（内容多/集数多/功能全/画质好）
- **双博主切换**：同一视频前半段女后半段男，增加画面变化感，防观众疲劳
- **质问式钩子是高频套路**：5种子类中3种用质问/疑问开头（套路G/I/J），直接挑战观众选择

## 三、5种剧情钩子套路（含台词模板）

### 套路A：情侣"闯祸"剧
```
女：（慌张）完了完了！闯祸了！
男：（紧张）咋了？出什么事了？
女：昨晚十点半，我下载了火龙漫剧……然后赚了不少钱……我都不敢打开了
```
- 画面：年轻情侣坐沙发，女慌张男震惊，日常居家客厅
- 钩子逻辑：用"闯祸"制造悬念→观众以为出事了→反转是"赚钱赚太多不敢相信"
- 变体：可把"情侣"换成"闺蜜"，台词模板一样

### 套路B：职场老板审问
```
老板：（严肃）他们一次提现多少钱？
下属：不是三毛就是五毛
老板：我们火龙漫剧呢？
下属：一两块
老板：（拍桌）加！再给我加！
```
- 画面：夜晚高管办公室，老板坐大班台后，下属站桌前
- 钩子逻辑：用老板权威人设+审问式对话制造紧张感→反转是"嫌竞品提现太少，要求自家加码"
- 信任设计：老板人设=成功人士背书

### 套路C：假街采
```
女采访者：（递麦克风）您平时看剧花钱吗？
大爷：（激动）花钱？我可不是傻子！我孙子给我下的火龙漫剧还给我钱呢！
女采访者：（震惊）天哪？那能看几集啊？
大爷：全集都可以看！顺便还能赚点买菜钱！
```
- 画面：户外公园步道，年轻女采访者+老年大爷，手持麦克风
- 钩子逻辑：老年人群体背书（老年人=精打细算=不会被骗）

### 套路D：闺蜜种草
```
女A：哎你干嘛！
女B：给你下个火龙漫剧，你会感激我的
女A：这怎么刚打开就领了一个红包啊？
女B：因为用火龙漫剧就能赚钱啊！哈哈哈
```
- 画面：两闺蜜坐沙发看同一台手机，居家客厅
- 钩子逻辑：闺蜜种草→用"红包"视觉刺激+笑声降低防备

### 套路E：闺蜜痛点
```
女A：（叹气）我天天追剧根本停不下来，还总看不到大结局，越看越憋屈
女B：不用强行借剧，刷火龙漫剧体验超舒服……
```

- 画面：两闺蜜穿睡衣在家，一个吐槽一个安利
- 钩子逻辑：用追剧痛点共鸣（看不到结局/憋屈）→引出"免费看全集"卖点

## 四、口播推广段·8步话术公式

剧情钩子结束后，画面切到单人面对镜头口播，所有视频的口播段都遵循同一套话术结构：

| 步骤 | 话术模板 | 心理作用 |
|------|---------|---------|
| ①注意力抓取 | "爱看漫剧的家人们注意了"/"朋友们" | 召集目标人群 |
| ②拉踩竞品 | "别再为赚钱软件几分几毛费尽做任务了" | 制造对比优势 |
| ③核心卖点 | "火龙漫剧看剧就能赚钱"/"海量漫剧免费看" | 抛出利益点 |
| ④功能演示 | App界面贴图（选集页/福利中心/提现页）+红圈红箭头标注 | 视觉证据 |
| ⑤低门槛承诺 | "满三毛就能提现"/"没有隐藏付费"/"不用拉好友" | 消除顾虑 |

## 七、批量拆解方法论（网赚剧情7条 + 网赚口播6条）

1. **下载**：`douyin_download.py` 逐条下载，Playwright手机UA
2. **ffprobe + 提音频 + 抽帧(fps=1) + whisper转写**：4步并行跑完7条
3. **vision逐帧分析**：每轮7帧并行，每帧问"口播还是剧情演绎？"——这是子分类的关键判别问题
4. **子分类矩阵**：按钩子套路×有无漫剧引流做交叉分类
5. **沉淀**：拆解报告+原始素材归档到 `wiki/teardowns/`
6. **分类分析**：把转写+画面分析打包派执行器，用V6框架做一级分类→二级子分类→对比已有框架→输出子分类矩阵+新发现。任务书标 TASK_TYPE=分析

### 关键发现技巧
- **whisper转写可区分口播段vs剧情段**：剧情段台词是对话体（A说B答），口播段是独白体。转写文本的对话/独白特征可直接判断段落属性
- **vision判别"口播还是剧情演绎"**：人物是否正对镜头=口播，人物之间互动=剧情演绎。这个问题每帧都问
- **漫剧引流段识别**：转写出现古风/穿越/婚恋等剧情台词+画面有剧名标识+"全剧免费看"引流文字
