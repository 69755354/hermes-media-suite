- 高峰时段：工作日 9:00-12:00、14:00-18:00（价格为空闲 2 倍）

- 仅 API 收费；网页端/App 端普通用户继续免费
- 最高涨幅 1100%（V4 Pro 缓存命中输入）

## 4. 对成本决策的影响

1. **DS 直调便宜优势被削**：输出价涨 3.5-4.5 倍。涨价前「直调≈2-4 万 token 很便宜」的账要按新价重算；单镜出片成本（原 ≈1.52 元/镜，输出为主）预计到 5-7 元/镜。
2. **缓存命中成为成本关键**：命中 vs 未命中输入差 30 倍（Pro：0.15 vs 4.5 空闲）。多轮 agent 循环（DSH 等 harness）如果缓存命中率高，重复上下文是白菜价；但输出 13.5-27 元/M 是硬成本，**返工一次就烧一次输出钱**——模型成功率/返工率比单次单价更重要。
3. **错峰省钱**：空闲时段=高峰一半。能挪到非工作日 9-12/14-18 的活直接省一半（注意周末全天是空闲价）。
4. **codex/claude 壳的固定注入更贵了**：DS 接 codex 壳那次实测 212,160 tokens（「回复OK」四个字），按新输出价计算成本更高——「单步任务一律直调」的结论在新价格下更成立。

### ZCode 接入姿势（仿 codex）

1. 装 `zcode cli`（新加坡机）
2. 配智谱 key（旧 key `34e34c...` 已失效，需开放平台重新生成；key 不进 AI 上下文）
3. 写 `zcode_exec_gated.sh`（仿 codex_exec_gated.sh：AGENTS.md 注入 + kb_gate + token 校验）
4. dispatch 加 `--target zcode` 路由
5. 跑真实任务验证

### 容灾结论更新

- 四条腿（codex/claude/DS/GLM）里 GLM key 失效 = 第四条腿实际不存在
- 补法不再是「给 DS 造轻量壳」（性能不行），而是**接一个成熟官方壳**（ZCode/Qoder）或换 GLM 新 key
- DS 定位不变：能验证不能发现，只干机械单步活；多步工程靠 codex/claude/成熟 harness
