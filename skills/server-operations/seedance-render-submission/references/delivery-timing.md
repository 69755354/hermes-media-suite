# 出片交付时效：完成立即发视频，深核验放交付后（2026-08-23 火龙 S01，用户「这么慢」）

## 触发

用户提交出片后催「这么慢/好了没」——大概率是**视频已经出好了但 Hermes 还在做内部核验没发**。

## 案例

S01 job 19:48 提交、19:51 出片（3 分钟，与承诺「预计 2-4 分钟」一致），但 Hermes 先做抽帧 + 3 次 vision 核验，~20:09 才发视频——用户多等 18 分钟看一个已经完成的视频，触发「这么慢」。

## 规则

1. **轮询到文件出现（output_path 有文件、大小非零、时长合理）→ 立即发视频本体给用户**，先满足「用户等的是视频」。
2. **深核验（逐帧 montage/vision 逐项）放交付后并行做**——发现问题再补一条说明（如「核验发现 X 有问题，重出中」），比让用户干等强。
3. 快速前置检查只做秒级项：ffprobe 时长 / 文件大小 / 抽 1-2 帧看不是黑帧或完全错画面。
4. 例外：提交时已明确说「出完我核验再发」且用户接受核验等待的，才先核后发——但默认先发。
