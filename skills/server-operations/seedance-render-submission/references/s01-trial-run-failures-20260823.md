# 火龙 S01 试跑失败案例（2026-08-23）

## 背景

火龙漫剧复刻项目（原片 42.95s，8 镜，S01=0.000—10.050s）。门禁修复后（briefs 误扫/S01 解析/「仅作」兼容），A_STORYBOARD 补四层结构通过 check_storyboard，清洗后 prompt 提交 S01 试跑（10s，三图直出：男主@图1/场景@图2/闪屏页@图3）。

## 试跑 7 问题清单（用户逐项反馈）

1. **语速太快**——prompt「语速适中、吐字清晰」，10s 塞 9 句台词实际明显快。已改「语速从容偏慢、吐字清晰，短句之间留出自然停顿、从容不赶节奏」（未重跑验证）。
2. **运镜反向**——要求 0—5s 明显拉远，抽帧实测人物占画面 2/3→80%→70%（0/3.1/6.3/9.4s），反向推近。
3. **念错字**——成片台词有念错，具体句待转写定位（本机无 whisper，任务书要求 codex 容器内 faster-whisper）。
4. **手机屏疑似重绘**——3s 后亮屏显示「火龙短剧」字样像是模型自己画的，非原闪屏页素材像素还原。
5. **起幅坐太近**——原片 0s 中景（人物头顶到大腿、腿部部分裁切），成片 0s 近景（头顶到胸部、腿部完全不可见），景别近一档。
6. **声音不好听**——AI 味/表演感重。
7. **缺走动过程**——原片有走动，成片站原地僵硬（用户：「原视频是有个走动的过程，我们的是站在原地不动 很僵硬」）。

## 根因链（最重要）

用户点破：「运镜差别就是因为参考视频是走动的」。

查 SHOT_REF_20260822.yaml 的 S01 动作 sequence：
- 00:00.000 坐姿前倾持手机
- 00:00.500-00:01.500 抬空闲手招呼
- 00:02.000-00:05.000 身体后移并由坐姿过渡到站立
- 00:05.000 全身站立讲解

**无「走动」**。分镜、prompt 每环忠实回指 SHOT_REF，但 SHOT_REF 是 codex 实测产物，漏了走动 → 成片自然没有。结论：复刻失真的断点在源头底稿，不是某一环写错；「分镜回指 SHOT_REF」不能当复刻到位的证据，出片后必须抽帧 vs 原片对比验证。

## 抽帧对比实测数据

- 成片 0s：近景，人物 70%（头顶到胸部，腿部全裁）
- 原片 0s：中景，人物 70%（头顶到大腿，腿部部分裁切）
- 成片 3.1s：人物比 0s 更大更近（反向），站姿，手机亮屏显示近似「火龙短剧」字样
- 成片 6.3s：人物 80%（最接近），左手举手机展示
- 成片 9.4s：人物 70%，右手伸出示意

判定法：人物占画面高度比例序列 变小=拉远 / 变大=推近 / 不变=稳定。成片序列 70%→更大→80%→70% = 整体推近趋势，与要求「明显拉远」相反。

## 修改方向

1. 补走动轨迹进 prompt 动作层（按原片实测：时点/方向/幅度/停止点），运镜配合重写
2. 起幅景别按原片实测（中景、大腿可见）修正
3. 语速从容偏慢（S01 已改），同步 8 镜
4. 声音描述往自然聊天感调
5. 手机屏强化 @图3 还原指令
6. 台词 28 句原文、时码、硬切点 10.050/19.950/29.950 一字不动

## 流程教训

- 新结构首次出片先试跑最复杂一镜（用户：「先看看效果吧」），不要闷头批量
- 问题先全部总结清楚再动手改（用户：「先不跑 把问题先全部总结清楚」）
- 一镜有问题 → 全片逐镜过一遍（用户：「把整个视频都过一遍，这个问题其他镜号肯定都有」）
- 发现复刻链路源头缺陷 → 重新逐镜实测原片 → 重新出分镜（用户：「让他重新出分镜脚本」）
