# 数据源可靠性指南

> 2026-07-18 会话总结：Tavily说8万赞，抖音App显示9396赞。差10倍。

## 各数据源可信度

| 来源 | 可信度 | 说明 | 典型误差 |
|:-----|:------:|:------|:--------:|
| **抖音App内实测** | 🥇 精确值 | 你手机上看到的赞数 | 0% |
| **你发来的截图/笔记** | 🥇 高 | 一手数据，你自己筛选过的 | 低 |
| **CDP页面实时数据** | 🥈 中等 | 未登录页面显示近似值 | 显示「9000+」而非精确9396 |
| **Tavily/搜索引擎缓存** | 🥉 低 | 搜索引擎抓取时的快照数据 | 可能差10倍（8万 vs 9396） |

## 铁律

1. **Tavily数据不准直接写进交付报告** — 必须标注「缓存数据，仅供参考」
2. **优先用CDP页面数据** — 比Tavily准，但显示的是近似值
3. **你的截图最可靠** — 你发1张截图比我扒30条还管用
4. **所有数据在接力文档里标注来源** — 不标注=隐瞒

## 数据标注格式

接力文档中每条外部数据必须标注：

```yaml
赞数: 57.6万
来源: CDP页面实时数据（未登录，显示57.6万+）
可信度: 🥈
```

```yaml
赞数: 8万
来源: Tavily搜索缓存
可信度: 🥉 — 标注「缓存数据，仅供参考」
```
