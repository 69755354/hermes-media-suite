# 搜索工具实测能力对比

> 数据来源：2026-07-18/19 多轮实测，标注可信度。

## Tavily（web_search 当前后端）

| 能搜到 | 不能 |
|:-------|:-----|
| ✅ 抖音视频URL + 标题 + 话题标签 | ❌ 精确实时赞数（8万 vs 实际9396，差10倍） |
| ✅ 缓存里的近似赞数（「4.1万个喜欢」） | ❌ 评论区内容 |
| ✅ 发布时间 | ❌ 热门榜/趋势榜 |
| ✅ 作者名 | ❌ 完整的账号数据 |
| ✅ 已搜索引的页面摘要 | ❌ 非公开/新发布的内容 |

**数据可信度：低** — 赞数差10倍，需CDP或截图二次核实。

## CDP 浏览器

| 能搜到 | 不能 |
|:-------|:-----|
| ✅ 打开单视频页 + 截图 | ❌ 热门页（404被拦） |
| ✅ 未登录显示的近似赞数 | ❌ 精确赞数（需登录） |
| ✅ 页面文字（标题/作者/标签） | ❌ 批量搜索/批量扒 |
| ✅ Vision分析封面画面 | ❌ 视频播放/字幕提取 |
| ✅ __INITIAL_STATE__ 数据 | ❌ 用户主页（反爬严重） |

**数据可信度：中** — 单页数据可靠，无法批量或获取完整账号数据。

## 结论

最稳组合：**Tavily搜链接+缓存数据 → CDP打开单页截图 → Vision分析**。要更进一步需上代理或第三方平台。
