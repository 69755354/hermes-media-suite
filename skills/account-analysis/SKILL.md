# 账号分析方法论

## 核心原则（优先级高于一切）

1. **先说知道什么、不知道什么** — 不编数据，查不到就说查不到
2. **用工具查不凭感觉说** — Tavily/CDP/截图哪个有数据用哪个
3. **不套模板** — 不用固定框架凑字数，结构跟着数据走

## 分析步骤

### 第〇步：先问自己「我手头有什么数据」

**「截图OCR几个数字+项目档案拼凑=猜，不是分析。」** ——用户原话（2026-07-19）

- OCR截图数字 + 项目文件拼凑背景信息 ≠ 分析。这是「猜」。
- 真正分析至少需要：粉丝数/作品数/近N条点赞趋势 → 逐条拆标题/开头/评论区 → 同赛道爆款对标 → 变现路径
- 如果只有一张截图而没有上述任何数据 → 只能说「截图里看到这些，但完整数据要你点进去看」
- CDP可以打开单视频页核实赞数（未登录显示近似值），但主页/搜索页被反爬。搜不到就说搜不到。

### 第一步：扒数据（标注来源和可信度）

- 截图 → 提取可见数据（粉丝/获赞/简介/作品数/播放量）
- Tavily搜 → 注意赞数差10倍，标注「缓存仅供参考」
- CDP浏览器 → 打开单视频页核实
- 标注数据来源和可信度：手头只有截图就说「只有截图数据」

### 第二步：内容诊断

- 内容方向是否垂直（三条三个方向 = 没标签）
- 播放量是否断崖（217→93→6 = 系统降权）
- 开头有没有钩子（自我介绍式开头 = 完播率锁死）
- 视频形式是否统一（出镜/空镜/口播来回换 = 没有记忆点）

### 第三步：定位判断

- 简介是否精准（「交友平台」= 引来泛粉）
- 同城标签有没有（定位+关键词 = 免费流量入口）
- 赛道在本地是否稀缺

### 第四步：转化检查

- 视频是否引导到店/私信
- 有没有低门槛体验品
- 看完全片能否知道下一步怎么行动

### 第五步：给建议（只改优先级最高的1-2个）

- 不改方向只改执行的问题优先（简介/定位/开头钩子）
- 需要大改方向的说明成本
- 不给「7天/30天目标」这种编数据的目标

### 输出约束（严格遵守）

1. **不套模板** — 不用「数据盘点→五个问题→优化方案→短期目标」这种格式凑字数。想到哪说到哪，但逻辑要通
2. **先说知道什么、不知道什么** — 结论出来前先把数据来源和局限说清楚
3. **不确定就直说** — 涉及行业/赛道/算法判断时，不知道就说不知道，不编
4. **不给编造的目标** — 「7天涨粉500」「30天到店20人」这种不知道算法阈值的数据不要给

### 独立思考（2026-07-19 新增）

**这是被用户反复纠正的核心缺陷，不是可选的：**

- 用户说出一个方向或结论时，不要直接同意
- 先自己过一遍逻辑：这个方案有什么我没看到的问题？
- 想到了就说出来，没想到就说「我想了一下，没发现问题」
- 用户自己推翻自己的方案时，不要顺势说「对，我早就这么想」
- 用户的思考过程是动态的——你不是在验证他的结论，是在帮他补充没看到的角度
