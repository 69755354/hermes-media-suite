## 各节点详细操作

### 节点1：选题策划

**选题公式**（周星驰风格）：
```
《当[本地人]去［店名］，[离谱的事]》
例子：《当郑州人去XX火锅店，老板说毛肚不要钱》
《当双峰人去测视力，差点把店员整崩溃》
```

**选题自检**：
- 3秒能让观众停下来？
- 一句话能说清笑点？
- 本地人看了有共鸣？
- 最后能自然说出地址？

### 节点2：剧本创作

**30秒结构**：
```
0-3s   钩子（悬念/离谱开场）
3-10s  铺垫（日常场景）
10-20s 反转+笑点（无厘头高潮）
20-25s 收尾（顾客震惊）
25-30s 地址+邀请
```

**周星驰技法速成**：

| 技法 | 说明 | 例子 |
|------|------|------|
| 反差 | 认真做离谱事 | 用分子料理手法煮方便面 |
| 重复变异 | 同一句话每次变一点 | "你好欢迎光临"→"你来欢迎光临" |
| 夸张 | 把小事放大到荒诞 | 试菜试到舌头冒火 |
| 错位 | 角色做了不符合身份的事 | 客人教厨师炒菜 |

### 节点3：配音生成

**策略**：30秒视频最多3段音频

```
第1段（0-8秒）：旁白/顾客台词
第2段（8-20秒）：顾客+老板对白
第3段（20-30秒）：收尾+地址
```

**工具操作**：剪映 → 音频 → 文本朗读 → 选声音 → 导出

### 节点4：AI画面生成

**何时需要AI画面**：
- 夸张表情/动作（拍不出来的）
- 荒诞场景
- 没有真人演员时，AI生成卡通角色

**AI操作步骤（即梦AI）**：
```
1. 打开 https://jimeng.jianying.com
2. 登录（手机号/抖音）
3. 创建 → 视频生成
4. 粘贴提示词 → 5秒 → 风格选「写实」或「3D卡通」
5. 生成 → 下载
```

**画面提示词要点**：
- 描述人物动作和表情
- 指定色调（暖色调/冷色调）
- 指定景别（近景/特写/全景）
- 指定风格（漫画夸张/电影感/写实）

### 节点5：实景拍摄

手机拍3张（竖屏9:16）：

| 照片 | 拍什么 | 要求 |
|------|--------|------|
| P1 | 门店招牌 | 站马路对面拍全景，招牌清晰 |
| P2 | 店内环境 | 拍全景，亮一点 |
| P3 | 产品/服务区特写 | 近距离拍细节 |

### 节点6：剪辑合成

**剪映时间轴结构（30秒）**：
```
00:00-00:03  P1门店招牌 + 旁白第1句
00:03-00:10  P2店内全景 + 旁白第2句
00:10-00:20  AI画面/实景 + 对白（笑点）
00:20-00:25  过渡画面 + 收尾台词
00:25-00:30  P1再复用 + 地址信息 + BGM渐弱
```

**转场参考**：
- 实景→实景：叠化（0.5s）
- 实景→AI画面：抖动/闪白（0.3s）
- 结尾：淡出（0.5s）

### 节点7：字幕

- 总字数不超过60字
- 每屏不超过12字
- 白字黑边，字号28-32
- 关键词单独花字（颜色+大小+动效）
- 地址用📍+红色高亮

### 节点8：BGM

- 剪映搜索"欢快""轻喜剧""港风"
- 音量15-20%（不盖过配音）
- 最后2秒渐弱
- 笑点处加音效："铛""duang""叮"

### 节点9：合规检查

```
□ 标题/台词没有极限词
□ 没有诱导互动话术
□ 地址信息准确
□ BGM已检查版权
□ 没有使用未授权素材
□ 话题标签正确
```

## 真实门店案例：葛大视力保健（双峰县）

**门店信息**：葛大视力保健 · 双峰县和森路
**视频主题**：双峰人测视力，差点把店员整崩溃
**时长**：30秒
**风格**：周星驰无厘头

**脚本核心**：
- 顾客自信满满来测视力 → 视力表最大的"E"都分不清方向 → 做完服务后世界变清晰了
- 无医疗用语，只说"眼睛舒服""看东西清晰"
- 最后3秒出地址："双峰县和森路"

**素材方案**：
- 实景照片3张：门店招牌、店内环境、服务区
- AI画面2段：①顾客在视力表前猜方向 ②顾客看窗外惊喜表情
- 演员：AI生成（不需要真人出镜）

**发布话题**：#双峰 #双峰县 #视力保健 #搞笑日常 #同城

## 常见陷阱

- ❌ 保健/医疗类使用了"治疗""治愈" → 直接下架
- ❌ 剧本超过30秒 → 完播率暴跌，没人看到地址
- ❌ 台词超过15字/句 → 语速太快听不清
- ❌ AI画面人物与实景风格不统一 → 选「写实」风格
- ❌ BGM音量太大盖过配音 → 控制在15-20%
- ❌ 忘了加定位 → 同城视频不定位就是白拍
