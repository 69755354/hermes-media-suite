# 抖音账号分析方法论

> 来源：用户2026-07-19提供的标准分析框架
> 适用于：抖音/快手/视频号等短视频平台账号诊断

## 分析框架结构（固定顺序）

### 账号基础信息
- 账号名/抖音号
- 粉丝/获赞/关注
- 定位（城市）
- 简介文案

### 一、现有数据盘点
- 核心数据：粉丝数、获赞数、作品数
- 简介文案评估：定位是否精准、能否引流到店
- 内容数据：各作品播放量、互动数据、推流趋势
- 优势分析：赛道稀缺性、人设差异化

### 二、存在的核心问题（通常3-5个）
按严重程度排序，每个问题说明：
- 为什么这是问题
- 它如何影响流量/转化

常见问题类型：
1. 简介跑偏（引错人群）
2. 内容不垂直（平台没法打标签）
3. 没有同城操作（没带定位/tag）
4. 开头没钩子（完播率低→系统降权）
5. 没有转化设计（看了也不知道怎么到店）

### 三、精准优化方案
- 简介改版（直接给出可复制版本）
- 内容垂直赛道（分类+占比）
- 每条视频的固定结构（按秒拆）
- 发布规则（频率/时间/定位/tag）

### 四、短期目标
- 7天目标
- 14天目标
- 30天目标

## 数据诚实铁律（用户明确纠正）

1. **只说你实际看到的数据** — 截图上没显示粉丝数，就说「截图没显示粉丝数」，不要猜
2. **区分看见和推断** — 「播放量217→93→6」是看见的，「系统已经降权」是推断的，要分开说
3. **不知道就是不知道** — 用户问「你查了这个账号的数据吗」——没查就说没查
4. **不套格式凑字数** — 如果分析内容跟用户自己写的差不多，说明没有新增价值，不如直接说「跟你的判断一致」
