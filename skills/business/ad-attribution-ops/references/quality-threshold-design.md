# 归因系统绝对标准线（设计反思 + 待确认清单）

> 来源：2026-08-25 用户质疑系统设计

## 用户的质疑

用户原话：「如果你整个池子的素材数据都都不好，那么你选出top 25也没什么意义呀」

## 问题分析

当前归因系统只做**池内相对排名**（同行业+同任务+同账号的素材池里，消耗前25%标记为好素材）。

缺陷：如果整个池子的素材都很差（比如完播率全是2%、3秒播放率全是10%），选出Top25%也只是"最不烂的"，没有实际指导意义。

## 需要的东西：绝对标准线

在相对排名之前，加一层**绝对标准线过滤**：

1. 先用行业基准判断池子整体水平是否合格
2. 合格池子才做Top25%排名
3. 不合格池子整体标记"池不足"（quality_insufficient），不出排名

## 待确认的行业基准指标

用户不知道具体数值，会去问豆包(Doubao)，拿到答案回来配。

需要确认的指标：

| 指标 | 问什么 |
|:--|:--|
| 3秒播放率 | 行业均值多少？多少算好？多少算差？ |
| 5秒播放率 | 行业均值多少？ |
| 完播率 | 分15秒/30秒/60秒不同时长有没有不同标准？多少算优秀？ |
| 互动率 | 行业均值多少？ |
| 消耗量 | 单条素材日均消耗多少算起量？多少算跑不动？ |
| 转化成本(CPA) | 激活成本多少算合理？（当前归因不用转化，但可选） |

分行业确认：
- **剧情**（短剧/漫剧）
- **电商**（商品推广）
- **游戏**（游戏推广）

## 平台标签标准

平台会给素材打"优质素材""首发素材""低效素材"标签，需确认这些标签的判定标准是什么——达到什么指标才会被打标。

## 实现方案（拿到基准值后）

1. config.yaml 加 `quality_threshold` 配置块，分行业配置各指标阈值
2. pools 层在排名前先判断池子整体是否达标（比如池内素材的完播率均值是否>行业基准）
3. 不达标的池子标记 `pool_insufficient`，reason=`quality_below_threshold`
4. 达标的池子正常做Top25%排名

## 用户偏好

用户不知道行业基准时会去问豆包(Doubao)，不要自己编造阈值。整理清单给用户带去问，拿到答案回来配。
