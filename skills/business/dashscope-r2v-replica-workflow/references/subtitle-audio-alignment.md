# 字幕时码对齐实际语音：silencedetect 完整工作流

> 源自 2026-08-26 火龙 V20 复刻 v3→v4 字幕对齐修复。成片字幕与语音全程错位，根因是字幕时码照搬分镜脚本预设起声时间，而快乐马实际语音节奏与分镜预设完全不同。

## 一、问题根因

分镜脚本的「台词起声时码」（如 `0.500s "喂你知道吗"；1.100s "现在看漫剧..."`）是**编剧预设的期望值**。AI 生成模型（快乐马/wan3.0）不按这个走——它自己决定语速和停顿。

**典型翻车（火龙 V20 复刻 v3）：**

| 维度 | 分镜预设 | 实际语音 | 字幕照搬预设的后果 |
|:---|:---|:---|:---|
| shot1 起声 | 0.500s | 0.785s | 差 0.3s，可接受 |
| shot1 结束 | 句9在10.0s起声 | 语音0.785-10.118s连续 | 句9字幕标到9.50-11.00s，超出shot1边界 |
| shot3a 句20 | 24.0s 起声 | 语音20.5s就开始 | **差3.5秒**，字幕比语音晚3.5秒 |
| shot3b 句27-28 | 40.0-43.0s | 语音在37.6-38.8s结束 | **超出成片**（成片40.36s） |

**核心纪律：字幕时码必须以实际音频为准，不能拿分镜时码直接用。**

## 二、silencedetect 参数选择

```bash
ffmpeg -hide_banner -i 成片.mp4 -af silencedetect=noise=-30dB:d=0.15 -f null - 2>&1 | grep -E "silence_start|silence_end"
```

| 参数 | 值 | 适用场景 |
|:---|:---|:---|
| noise | -25dB | 嘈杂背景音、BGM较大 |
| noise | -30dB | 正常人声音量（推荐默认） |
| noise | -35dB | 安静环境、轻声说话 |
| d | 0.08 | 抓词级停顿（≥80ms） |
| d | 0.15 | 抓句子级停顿（≥150ms，推荐） |
| d | 0.30 | 只抓大段静音（段落间） |

**推荐组合**：先用 `-30dB:d=0.15` 抓句子级停顿，拿到语音段轮廓。如果需要更细的句子切分，再用 `-25dB:d=0.08` 补充。

## 三、多 shot 拼接视频的注意事项

1. **每个 shot 单独测语音段**——shot 之间有拼接缝（硬切处的静音过渡），混在一起测会误判。
2. 拼接后全局时间 = shot 内相对时间 + 该 shot 在成片中的起始偏移。
3. 快乐马各 shot 都是 10.04s（24fps→30fps 重编码后），shot 边界在 10.04s、20.08s、30.12s 处。

## 四、按字数比例分配字幕时码

检测到语音段后，每个 shot 内的台词按**字数比例**分配到该 shot 的语音总时长：

```
每句字幕时长 = (该句字数 / 该shot总字数) × 该shot语音总时长
```

- 短句少分时长、长句多分时长
- 句间停顿（silencedetect 检测到的静音）分给前一句（自然收尾）
- 最后一句的结束时间对齐到该 shot 的结束边界

## 五、覆盖旧字幕重新烧录

如果成片已经硬烧了旧字幕（字幕是烧进视频的，不是软字幕轨），不能直接替换。两种方案：

### 方案 A：从 base 拼接片重新合成（推荐，干净）

如果保留了无字幕的拼接基底片（如 `base40.mp4`），直接用新 ASS 重新合成。

### 方案 B：drawbox 覆盖 + 新 ASS（快，❌ 不推荐）

> **0826 v4 实测翻车**：用户反馈"字幕怎么有黑色底框"——drawbox 画的黑块在画面底部留下明显黑色矩形，即使新字幕叠在上面，黑框边缘仍然可见，观感极差。

在旧字幕区域画黑块覆盖，再贴新 ASS：

```bash
ffmpeg -y -i 旧成片.mp4 \
  -vf "drawbox=x=0:y=830:w=720:h=85:color=black@1.0:t=fill,\
       ass=新字幕.ass" \
  -c:a copy -c:v libx264 -preset fast -crf 19 -pix_fmt yuv420p -r 30 \
  新成片.mp4
```

- `y=830:h=85` 覆盖 MarginV=380 + FontSize=56 的底部字幕区域（720×1280 分辨率下）
- **黑块会留黑框**——新字幕文字虽然清楚，但黑块矩形边缘可见，用户一眼看出是"贴了块黑布"
- **只在万不得已时用**（base片已删且无法重新拼接），否则始终走方案 A

## 六、验证

合成后抽帧检查字幕是否对齐：

```bash
# 在每句字幕的时段中间抽帧
ffmpeg -y -ss <字幕时段中间> -t 1 -i 新成片.mp4 -vf "fps=1,scale=540:960" /tmp/sub_check.png
```

用 vision_analyze 问「画面底部字幕文字是什么、是否完整、位置在哪」。如果看不清，直接听视频对应时段的音频，人工核对字幕跟语音是否同步。

## 七、可复用脚本

`scripts/subtitle-align.py` — 输入成片路径和台词列表（按 shot 分组），自动执行 silencedetect + 字数比例分配 + 生成对齐 ASS 文件。

## 八、幽灵字幕检测：台词没念但字幕在显示（0826 v4 实测）

### 问题

多 shot 提交时，**每个 shot 的提交 prompt 台词数量可能与分镜分配的台词数量不一致**。模型只念了 prompt 里有的台词，但字幕按分镜全量台词标注——没念的台词对应的时段就出现"字幕在动但没声音"的幽灵字幕。

### 翻车案例

火龙 V20 复刻：分镜分配 shot3b 承载 6 句台词（句23-28），但提交脚本 `run_shot3.py` 的 prompt 只写了 10 句台词（到"观看体验堪比电影质感"），最后 3 句"现在左下角开启火龙漫剧""马上体验边看漫剧""边赚钱的快乐"没写进 prompt。模型没念 → shot3b 视频 8.5s 后静音 → 字幕照标 → 用户反馈"现在左下角开始那一段都没念了"。

### 检测方法

合成前对每个 shot 原始视频跑 silencedetect，检查实际语音时长：

```bash
# 每个 shot 单独检测
ffmpeg -hide_banner -i shot3b.mp4 -af silencedetect=noise=-30dB:d=0.15 -f null - 2>&1 | grep silence_
```

如果某 shot 尾部出现 **>1 秒静音**且该时段仍有字幕分配，说明台词没念完。

### 修复路径

1. **重新生成该 shot**：补全 prompt 台词，重新提交快乐马/wan3.0
2. **砍掉多余字幕**：如果不想重新生成，把没念的字幕句砍掉，成片到实际语音结束处收尾

### 预防

在提交前做台词数量核对：

```python
# 核对脚本：分镜分配的台词 vs 提交prompt里的台词
script_lines = ["台词1", "台词2", ...]  # 分镜分配
prompt_text = open("submit_s03b.py").read()  # 提交脚本
for line in script_lines:
    if line not in prompt_text:
        print(f"WARNING: '{line}' 不在提交prompt里！")
```
