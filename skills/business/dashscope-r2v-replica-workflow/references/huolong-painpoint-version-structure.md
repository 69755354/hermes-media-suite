## 痛点版 payload 结构（快乐马 r2v）

每段 payload 关键字段：

```json
{
  "model": "happyhorse-1.1-r2v",
  "input": {
    "prompt": "[Image 1]中的人物坐在[Image 2]客厅沙发上，正面朝向镜头。场景锁定[Image 2]...动作：人物坐在沙发上面对口播...声音：同步生成中文口播女声，音量饱满，声音洪亮，明亮有力；情绪饱满...语速明快...人物说：<台词>...负面约束：不要出现任何字幕文字、水印...不要手持手机或任何物品...",
    "media": [
      {"type": "reference_image", "url": "http://<GZ_HOST>/huolong_new_ref.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/huolong_scene_livingroom.jpg"}
    ]
  },
  "parameters": {"resolution": "720P", "ratio": "9:16", "duration": 10, "watermark": false}
}
```

关键差异 vs 网赚版：
- **media 只有2张**（人物+场景），无 @图3 闪屏页
- **负面含"不要手持手机"**（网赚版必须举手机）
- **声音三件套**：语速写"明快"不写"适中"、情绪写"饱满口播主播爆发力"、音量写"饱满洪亮"

## 台词溯源验证流程

用户问"台词跟原片一样吗"时的排查步骤：

1. **找 payload 文件**：`find /tmp -name "*payload*.json"` 拿到每段提交的 JSON
2. **提取"人物说："后面的台词**：python3 解析 JSON → `json.loads()["input"]["prompt"]` → 正则提取"人物说：(.+?)$" 
3. **找原片台词**：查 `火龙网赚_模板_快乐马版.md` 第三节"原片台词（28句）"或 `原片画面结构对照表.md`
4. **对比来源**：痛点版台词来源 = 拆解报告（`wiki/teardowns/20260816_火龙漫剧19视频拆解.md`）中 765152.../765812... 样本的"钩子+收口"改写，非原片 765330... 的28句
5. **报告差异**：列出两版台词来源、核心卖点差异、结构差异

## 验证成片完整性的标准流程

1. `ffprobe -show_entries format=duration,size,bit_rate -show_entries stream=codec_name,width,height,r_frame_rate` 验规格
2. 4段抽帧（如 3s/13s/23s/33s）`ffmpeg -ss $t -i <file> -frames:v 1 <png>`
3. `vision_analyze` 逐张看：口型是否张嘴、画面是否口播场景、画质是否高清、人物一致性（同一人同场景）
4. 拼接验证：`cat /tmp/huolong_concat_list.txt` 确认段顺序 → ffprobe 确认总时长≈各段时长之和

## 常见混淆点

- **痛点版 ≠ 网赚版台词**：用户问"台词一样吗"时，痛点版台词是改写的不照抄原片
- **痛点版只传2图**：不传闪屏页因为不举手机不展示App界面
- **声音描述差异**：痛点版声音三件套（语速明快+情绪饱满+音量洪亮）vs 网赚版可写"语速适中"
