# 演唱会深情慢歌 prompt 实例（0826 实测跑通）

> 场景：用户要"原版歌声 + 参考视频人物形象 + 演唱会大场面"，方案3（wan3.0无声画面+ffmpeg贴原音频）
> 风格：深情慢歌氛围感
> 模型：wan3.0-video，720P，9:16，15秒，audio=false，prompt_extend=false，watermark=false

## 完整 prompt

```
15秒竖屏写实演唱会现场。图1仅作歌手人物身份与外貌一致性参考，不继承图1的背景、环境、灯光、构图或服装以外的场景信息。全场进入暗场，舞台与观众席大面积沉入黑暗，只保留一束柔和、干净的白色追光从上方落在歌手身上，形成克制的明暗层次与大片负空间。歌手独自站在舞台中央，手持麦克风深情演唱一首慢歌，身体动作极少，呼吸自然，微闭双眼，随后轻轻低头，神情内敛而真挚。台下观众安静站立或静坐，静静举着手机灯和少量荧光棒，点点微光像夜色中的星海，所有人专注听歌，不欢呼、不挥舞手臂、不跳跃、不蹦迪。镜头以中远景和全景为主，平视机位，缓慢而稳定地轻微拉远，始终保留歌手、单束追光与安静灯海之间的空间关系，不切近景，不怼脸，不频繁切镜。整体节奏舒缓，有停顿、有留白、有呼吸感，画面元素简洁，不堆叠灯效、LED动画、烟火或复杂舞美；仅有极淡薄雾让追光呈现柔和体积感。色调以深黑、低饱和冷蓝和暖白追光为主，电影感写实，情绪深情、孤独、温柔、沉静。全程保持人物身份稳定、人体结构自然、动作连贯、镜头平稳；禁止热烈狂欢、观众躁动、快速运镜、脸部特写、炫彩频闪、强烈爆闪、烟火喷射、画面拥挤、过度舞台特效、文字、水印、logo、画面抖动、闪烁、跳帧、重影和人物变形。
```

## prompt 结构拆解

1. **素材声明**：图1仅作人物参考，不继承背景
2. **场景基调**：暗场，大面积沉入黑暗，单束追光
3. **人物状态**：身体动作极少，呼吸自然，微闭眼，轻轻低头
4. **观众状态**：安静举灯，星海，不欢呼不跳跃
5. **运镜**：中远景全景为主，平视缓慢拉远，不切近景
6. **节奏**：舒缓，停顿，留白，呼吸感
7. **色调**：深黑+低饱和冷蓝+暖白追光
8. **情绪定调**：深情、孤独、温柔、沉静
9. **负向约束**：禁狂欢/躁动/快运镜/特写/频闪/特效/文字/水印

## 关键：先问感觉再写画面

用户先说"深情慢歌"，prompt 才有了情绪主轴。如果用户没说感觉，先问一句"你想要什么氛围？热血沸腾/深情慢歌/酷炫科技感？"，拿到方向再写。

## 实测结果

- 生成耗时：约7分钟（720P 15秒）
- 口型不同步：确认穿帮，但中远景+暗场+单束追光，视觉上不突出
- 整体氛围：codex 第一版"说明书"prompt 被否，这版"情绪主导"prompt 通过
