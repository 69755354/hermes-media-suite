# 快乐马 R2V Prompt 动态强度与表情描写指南

> 来源：2026-08-30 用户反馈「表情不够丰富和夸张，画面没有冲击力，表情没有细节」
> 适用：快乐马 happyhorse-1.1-r2v 原创视频生成（非复刻）

## 零、Seedance vs 快乐马 提示词方法论差异（0903 定案）

**铁律：Seedance 的肌肉级提示词方法论（麦芽菜法）不适用于快乐马。两套模型能力不同，提示词写法完全不同。禁止把 Seedance 的写法套到快乐马上。**

### 能力对比

| 维度 | Seedance（麦芽菜法） | 快乐马（实测） |
|:-----|:-----|:-----|
| 肌肉级控制 | ✅ 支持（笑肌0.1秒卸力、虹膜虚焦0.3秒） | ❌ 不支持，模型忽略肌肉指令 |
| 毫米级位移 | ✅ 面部最大位移≤2mm | ❌ 无效，当普通文本处理 |
| 0.1秒瞬变 | ✅ 支持 | ❌ 不支持，动作时码精度到秒不到0.1秒 |
| 视线落点 | ✅ 精确到画外位置 | ❌ 太细的描述模型忽略 |
| 逐句语音时码 | ✅ 支持 | ❌ 整段写，拆时码必崩 |
| 负面词 | ✅ 有效 | ⚠️ 效果弱，无 negative_prompt 参数 |
| 英文双引号台词 | ✅ 必须用 | ❌ 会渲染成画面字幕，用「人物说：」 |
| 参考图引用 | @图1 | [Image 1] |

### 快乐马实际能接住的写法

1. **动作时码**：能接，精度到秒。写「0-3秒人物眉头紧锁，右手指向桌面手机」✅；写「眉间皱眉肌1.5秒匀速收紧」❌
2. **表情描写**：写可见的表情词不写肌肉指令。「眉头紧锁如川字，双眼圆睁怒视」✅；「皱眉肌1.5秒匀速收紧」❌
3. **台词**：整段写在「人物说：」后面，不拆时码
4. **声音**：三件套——音量/风格 + 语速 + 吐字，定性描述不写数值
5. **动态强度**：冲突段55-65%，口播段45-55%，低于40%画面没冲击力
6. **参考图引用**：`[Image 1]` 语法，不描述人物外观（靠参考图锁）
7. **负面约束**：无 negative_prompt 参数，禁止条件写在正向 prompt 末尾

### 翻车案例（0903）

为快乐马 H 段写 prompt 时，直接套用 Seedance 麦芽菜法：写「眉间皱眉肌1.5秒匀速收紧，眉心出现浅竖纹」「面部肌肉最大位移≤3mm」「0.1秒瞬变无过渡缓冲」——用户质疑「快乐马能不能做到这个东西」，查知识库确认全部无效。正确写法见本指南第二、三节：用可见表情词（眉头紧锁如川字）+ 加大幅度动词（狠狠摔）+ 声音三件套。

## 零点五、风格定调与光影氛围写法（0903 定案）

**铁律：开头风格段禁止只写「照片级写实，无CG感，天然肌肤质感，24fps胶片质感」——这是 Seedance 体系的话术，快乐马不需要绕真人检测也不需要这套描述。**

**根因**：用户原话「你用快乐马，你看快乐马是适合用什么样的东西来写」「知识库里应该有光影那些东西」。查 wan3.0 官方示例库发现，快乐马同平台的 wan3.0 官方提示词风格段写的是调性+光线+材质+氛围+色调+景深，不是堆技术参数词。

### ❌ 太干（Seedance 套壳，0903 翻车）
```
照片级写实，无CG感，天然肌肤质感，24fps胶片质感。
```
就堆几个技术参数词，没有画面感。

### ✅ 有画面感有氛围（按 wan3.0 官方示例风格）
```
写实电影质感，高预算商拍级画面。日间办公室，自然窗光从画面左侧高位斜入形成丁达尔光柱，灰尘微粒在光柱中缓慢浮动，桌面实木纹理清晰厚重，西装面料有垂坠感，皮肤保留真实肌理不磨皮，额头微泛油光，整体色调暖黄低饱和，浅景深锁定人物面部，背景办公桌椅柔散但不死黑，窗外天光过曝泛白。
```

### 风格段必写维度清单

| 维度 | 说明 | 示例 |
|:-----|:-----|:-----|
| 调性 | 写实电影/商拍/水墨等风格定位 | 写实电影质感，高预算商拍级画面 |
| 光线 | 光源方向+光效类型+光质 | 自然窗光从左侧高位斜入，形成丁达尔光柱 |
| 光效细节 | 光线产生的可见效果 | 灰尘微粒在光柱中缓慢浮动 |
| 材质 | 场景和人物的材质质感 | 桌面实木纹理清晰厚重，西装面料有垂坠感 |
| 皮肤质感 | 不写「天然肌肤质感」，写具体 | 皮肤保留真实肌理不磨皮，额头微泛油光 |
| 色调 | 暖/冷+饱和度 | 整体色调暖黄低饱和 |
| 景深 | 景深+焦点+背景处理 | 浅景深锁定人物面部，背景柔散但不死黑 |
| 环境细节 | 窗外/远处可见元素 | 窗外天光过曝泛白 |

## 零点六、导演思维驱动 prompt 写法（0903 定案）

**用户原话：「你后面写这些东西的时候，你要根据那个导演思维来写这些东西」**

写快乐马 prompt 时，先用 director-thinking skill 的导演5问确定本场戏的叙事意图，再按因果链模板写 prompt。

### 导演5问（每场戏落笔前必答）
1. **功能**：这场戏只负责什么——钩子/冲突/反转/证明/收尾？
2. **反转**：什么价值或认知发生变化？
3. **视角**：观众站在谁的身体里，跟谁发现信息、共情谁？
4. **权力**：谁掌控局面？用高度、距离、画面位置和视线关系表达
5. **潜台词**：角色嘴上说什么，真实想要什么？

### 因果链模板 + 导演思维整合结构

```
[风格定调+光影氛围段]

[参考图绑定+全局锁定段]

因果链动作：
[时码段]：[Image N]可见表情+重动词动作+后果描写+视线落点
…（逐段写完）

人物说：[整段台词]

同步生成中文XX声：[声音三件套：音量/风格+语速+吐字]+情绪变化描述+环境底噪

负面约束：[逻辑维度排除项]

参数：
watermark: false
duration: [3-15]
```

### 与 director-thinking 四维编码的关系

director-thinking 的 Z/Y/X/F 四维编码在快乐马里融入「全局锁定段」写（中景，平视微仰，正面偏四分之三侧，50mm定焦），不单独列层。情绪微动作翻译成可见表情词（第二节词汇库），不写肌肉指令。

## 一、动态强度参数经验值

| 场景类型 | 推荐动态强度 | 原因 |
|:---|---:|:---|
| 职场冲突/审问/拍桌 | 55-65% | 需要大幅肢体动作+面部怒意，35%太平 |
| 口播讲解/安利推荐 | 45-55% | 需要表情变化和手势，但不能幅度过大导致变形 |
| 温和叙述/回忆 | 30-40% | 仅微表情和小幅手势 |

**铁律：动态强度低于40%时画面几乎无动作，用户评价「没有冲击力」。剧情/冲突段不低于55%，口播段不低于45%。**

## 二、表情描写具体度

### ❌ 太笼统（用户反馈「表情没有细节」）
```
眉峰轻抬，嘴角小幅上扬
```

### ✅ 有细节有层次
```
眉头紧锁如川字，双眼圆睁怒视画面左前方，咬肌紧绷，嘴角下压成怒线，鼻翼微张
```

### 表情词汇库（按情绪分类）

**愤怒/威严**：眉头紧锁、双眼圆睁、目光如刀、下颌咬紧、嘴角下压成怒线、鼻翼微张、咬肌紧绷、脖子前突

**紧张/怯懦**：眼神闪躲、下唇微颤、肩线内收缩紧、双手不自觉攥住衣角、嘴唇微张想说什么又咽回去、呼吸轻停

**兴奋/安利**：眼睛发亮、嘴角大幅上扬、身体前倾、眉峰上挑、握拳轻敲空气

**回忆/认真**：眉峰轻收、嘴角平直、表情逐渐转为惊喜、眼睛放大

**否定/不屑**：嘴角轻压、掌心向下做否定手势摇头、表情不屑

## 三、动作描写要加大幅度

### ❌ 太克制
```
0.000—1.200秒人物右手把一份报告甩到深色实木桌面
```

### ✅ 有冲击力
```
0.000—1.200秒人物右手把一份报告狠狠摔到深色实木桌面，纸张沿桌面滑向左前方，动作干脆有力带怒意
```

**要点**：
- 动词要重：甩→摔、敲→猛敲、拍→猛拍
- 加力度修饰：狠狠、猛地、重重
- 加后果描写：纸张震飞一角、椅子向后滑、摄影机产生冲击震动
- 加身体联动：身体大幅前倾、椅子向后滑

## 四、声音描述不能省音量

### ❌ 缺音量描述（模型默认小声）
```
同步生成中文男声：男性，45岁，明亮有力的成熟男声，中低音厚实
```

### ✅ 音量+风格+语速三件套
```
同步生成中文男声：男性，45岁，口播风格，声音明亮有力，音量充足，像对着镜头跟观众说话，语速偏快，吐字清晰
```

**声音描述三维度（缺一不可）**：
1. **音量/风格**：口播风格，声音明亮有力，音量充足，像对着镜头跟观众说话
2. **语速**：语速偏快 / 语速适中 / 语速适中偏慢
3. **吐字**：吐字清晰

## 五、P段（口播）不依赖r2v生成手机屏内容

### 问题
快乐马r2v传3张参考图（角色+场景+App UI），prompt写"[Image 3]仅作为手机屏幕内的显示内容"，但模型完全忽略App UI参考图，自己在手机屏区域生成AI乱码假文字+假图标。同时手部严重崩坏——多指/指节扭曲/手指与手机边框穿模。

### 解法
- P段prompt不写"手持手机""展示App界面"，改为"双手自然垂放"或"右手做讲解手势"
- 不传第3张App UI参考图，只传2张（角色+场景）
- 手机屏App UI内容全部后期ffmpeg overlay贴真实截图
- 负面约束加"禁止手持手机或任何道具"

## 六、字幕规格（参照模板格式）

| 层 | 内容 | 字号 | 颜色 | 位置 |
|:---|:---|---:|:---|:---|
| 普通字幕 | 全口播台词 | 54px | 白字黑描边 (`&H00FFFFFF`) | 底部MarginV=240 |
| 关键词大字 | 卖点/钩子词 | 88px | 黄字黑描边 (`&H0000F8FF`) Alignment=8 | 上中部 |
| 风险提示 | 固定全程 | 28px | 灰字 (`&H00D0D0D0`) | 最底部MarginV=50 |

**42px太小，用户明确反馈「字幕太小」。统一用54px起步。**

## 七、混音规格

- 人声轨：aresample统一采样率后split两路，一路混音一路做sidechain
- BGM轨：volume前置放大（选曲不同0.12-3.0不等，需实测），afade 2秒淡入+尾部淡出
- sidechaincompress: threshold=0.025 ratio=8 attack=20 release=250（人声出现时自动压低BGM）
- 最终amix后加alimiter=limit=0.89防爆音
- 验证：volumedetect mean_volume低于-20dB说明音量不够
