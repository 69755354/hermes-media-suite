> 用途：归因系统参考基准线，判断新素材各指标处于什么水平

## 计算方法

从 Excel「汇总」sheet 按「行业」字段分组，每行业取 Top100，对每个指标算分位线：

| 统计量 | 用途 |
|:---|:---|
| 最小值 | 知道 Top100 末尾长什么样 |
| P25 | 新素材低于此 = 连 Top100 末尾都够不上 |
| **中位数** | **最可靠的参考线**（均值受极端值拉高） |
| 均值 | 参考但不要当门槛（头部素材拉高均值） |
| P75 | 高于此 = 进入 Top100 前 1/4 |
| 最大值 | 知道天花板在哪 |

衍生指标（从原始字段算）：
- **互动率** = 互动数 / 播放数 × 100%
- **CPM** = 累计消耗 / 播放数 × 1000
- **CPE** = 累计消耗 / 互动数

## 使用方式

归因系统判断新素材时：
1. 按行业取对应基准
2. 新素材各指标 vs Top100 分位线定位水平
3. 低于 P25 = 连 Top100 末尾都不如，标记低效
4. 高于 P75 = 进入 Top100 前 1/4，标记优质候选
5. 注意完播率要结合视频时长看，不能跨时长直接比

## 关键发现

1. 消耗量级差异巨大：漫剧短剧日均消耗中位数381元，电商仅8元，差近50倍
2. 完播率行业差异大：电商1.39% > 游戏0.74% > 漫剧0.08%（与时长和内容类型有关）
3. 互动率全行业极低（中位0.04-0.05%），星广素材靠的不是互动
4. CPM电商最贵(165元) > 漫剧(113元) > 游戏(49元)
5. 时长中位数都在31-34秒，30秒左右是主流素材长度
6. 均值受极端值拉高严重（尤其消耗/播放），看中位数和分位线更准
7. 这是Top100消耗素材的分布，本身就是高分段样本；新素材若低于P25说明连Top100末尾都够不上
