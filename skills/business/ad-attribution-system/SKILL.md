# 广告投放归因系统（星川/星广联投）

## When to Use

触发：做投放归因系统/星川星广素材分析/素材好坏判断/消耗数据归因/分行业内容分析/腾讯云 COS 素材存储。本 skill 承载「星川素材供应商业务」的领域知识与归因系统设计基线。

## 业务背景（2026-08 确认）

我们是**素材供应商**（不是投放方）：
- 公司主体统一对星广/星川，**自建达人号 3 个**（1 个在用，2 个别人用——需唯一 ID 区分消耗归属）
- AI 生产**成品视频素材**，分行业：**剧情（短剧/漫剧）/ 电商 / 游戏**
- 以达人号投稿星川任务 → 平台审核 → **自动发布到我们账号**（抖音发布链路，技术待核验）
- 星川投流 → 广告消耗 → **按消耗分成**
- **核心价值 = 广告灌溉出来的行业归因库 + 留存数据 = 数字资产**（真实广告消耗喂出的反馈，别人没有，可复用/可迁移/可议价）

## 分成机制（搜索确认，来源：巨量星图官方）

```
星广联投高潜任务：收益 = MAX{保底, 投放消耗分成(3%) + 达人自然流量转化(CPA)}
星川任务（千川星选）：投放消耗 × 4% + 自然带货佣金
结算：效果分成 T+1；保底 14 天后
```
- **消耗量 = 第一指标（结果）**；分成比例暂按 3%-4%（待星川确认）

## 审核机制（星川任务）

| 环节 | 时效 | 查什么 |
|:--|:--|:--|
| 内容审核 | 6h | 画面/音频/违规（自动初筛+人工逐帧） |
| 任务相关性 | 6h | 匹配客户任务要求 |
| 安全性 | 1-3 天 | 平台安全规范 |
| 服务商审核 | 3 天内 | 创意/转化层面 |

- **审核状态 API 可查**：`star_video_status`（VISIBLE/UNPUBLISHED/被拒+ban_reason_detail）
- 星图预审 ≠ 投放平台最终通过（双审）
- **我们不管发布/投放**——素材在客户账号投（搜索确认）；但我们走自建号路径

## 归因指标（星广官方定义）

| 指标 | 定义/来源 |
|:--|:--|
| **消耗量 stat_cost** | **第一指标**（结果）——平台 oCPM 给好素材更多消耗=平台投票 |
| 播放量 | 发布至数据更新日累积，最长 45 天 |
| 完播率 | 完整看完÷总播放 |
| 5秒播放率 five_s_play_rate | 有效播放率（API 字段，rate×100） |
| 点赞/评论/分享率 | 互动÷播放 |
| CPM / CPE | 千次展示成本 / 单次互动成本 |
| 转化数 star_convert_cnt | 达人流量转化数 |
| 素材费 star_material_stat_cost | 基础素材费 |
| 素材分成费 star_sale_material_stat_cost | **我们分钱的核心字段** |
| 素材标签 | 低效/首发/优质（平台算法标注） |
| 流量拆分 | 营销流量 vs 自然流量 |

**核心分析逻辑**：消耗量是结果，要分析**哪些过程数据影响消耗**（转化/完播/5秒/互动）——分行业做归因分析（剧情/电商/游戏影响因素不同）。

## 触点规则（搜索确认 + 用户纠正）

- 星广监测：自然流量=点击监测；营销流量=**有效触点（点击+3s播放）**
- 字节生态默认 **Last Click 模型**（最后点击归因），窗口 7/14 日
- **⚠️ 用户纠正（2026-08-14）：「触点」不是用户接触点/Last Click 那套！在老板语境里，触点 = 归因指标**（星广全量指标：消耗/播放/完播/5秒/互动/转化/CPM/CPE/素材费）
- **「触点=1」= 每个指标独立归因到素材**（每条素材一个指标值）
- 不要再把「触点」理解成广告归因模型的接触点语义——先问老板指的是指标还是接触点

## 给 AI 下任务必须定义角色（2026-08-14 天行者示范）

飞书 DS 给 codex 下任务的正确格式（**缺角色 = 产出视角错**）：
```
[角色] 你是XX评审专家（负责XX，只产分析报告，不对话）
[背景] 现状/材料
[硬约束] 不可违反的限制
[要裁决的 N 个争议点]
[产出要求] 中文结构化 markdown + 标注「执行者: codex」+ OUTPUT 标记
```
教训：本会话给 codex/claude 下「写方案」任务没定义角色 → 它们用默认开发者/架构师视角 → 方案偏技术实现，缺运营/归因视角。**任何分析/方案/评审任务先定义角色**（全栈运营专家+广告归因分析师+产品经理 这类）。

## 数据源（巨量开放平台 API）

- 粒度：`material_id`（素材）/ `item_id`（星广视频）/ `demand_id`（任务）/ `aweme_id`（抖音号）
- 数据 T+1（次日凌晨产出，10 点后稳定）
- **自动拉取待核验**——拿不到就手动导入 CSV 降级

## 归因系统需求基线

1. **分行业沉淀**：剧情（短剧/漫剧）/ 电商 / 游戏——物料库、归因逻辑、经验全部分开
2. **循环周期**：1/2/3/4 天矩阵（起始日期固定），找 **top25% 素材**（自定方法非平台标准，先用真实数据校准）
3. **AB 测试**：同一需求多变体（前期主动 2-3 版）
4. **全程自动化，关键点人工审核**：产品质量 + 数据复盘制定下一轮打法
5. **不靠记忆，靠文件/流程**（后端子容器）
6. **数据资产化**：长期留存/可检索/可导出/安全（数字资产）
7. **进生产看工具稳定性**

## 文档生成顺序（用户硬性要求，勿乱）

**① 业务描述 → ② 条件背景 → ③ 业务流程 → ④ 架构 → ⑤ 归因 → ⑥ PRD**——一层层下来，**每层确认才进下一层**。用户会明确说「进入 2」「进」，没确认前不擅自往下写。

## 需求收集方法（用户偏好）

- **先追问直到理解需求**（用户原话：「你可以追问我，直到确保能理解我的需求」）
- 业务背景让用户讲（「我来说下业务背景」），边听边确认
- 不确定就搜（豆包搜索 doubao_search.py 为主，SearXNG 已废弃）
- 区分：指标本身=平台官方定义；指标分组/权重=用户决策（可配置，不写死）

## Top100 实测基准数据

2026-08-25 从星广后台拉取的 Top100 消耗素材实测指标分布已落盘，见 `references/top100-benchmark.md`。
- 三行业 Top100 占总消耗 77.9%（漫剧73.8%/游戏85.3%/电商94.4%）
- 含各指标最小/P25/中位数/均值/P75/最大分位线 + CPM/CPE/互动率衍生指标
- 归因系统判断新素材水平时，用中位数和分位线做参考，不用均值（极端值拉高严重）
- 注意：Top100 本身是高分段样本，新素材低于P25 = 连Top100末尾都够不上

## 素材分档与差素材归因分析

按**日均消耗**排名等分三档：1-25 好素材 / 26-50 中等 / 51-100 差素材。差素材归因分析方法见 `references/tiering-analysis-method.md`。

**分档操作**（机械执行，Hermes 自干）：
1. 读 Top100 整合版 Excel，按行业分组
2. 排名 1-25 标绿（好）、26-50 标黄（中）、51-100 标红（差）
3. 输出三 Sheet（每行业一个）+ 三档指标对比 Sheet
4. 对比指标用**中位数**不用均值
5. 产出文件：`Top100素材分档_按日均消耗.xlsx`

**差素材归因分析**（策略活，丢 codex/CC）：
- 打包三档对比数据 + 标题采样 → 丢执行器出分析报告
- 报告要求：分行业逐一分析差素材核心问题 → 指标证据 → 原因 → 改进方向 → 通用检查清单
- 产出文件：`差素材归因分析报告.md`

### cc 分析结论（2026-08-26 Claude Code 重算，纠正了 4 处数据错误）

**数据质量陷阱（cc 重算发现，后续分档必须避免）：**
1. **分档基准错**：原始 `排名` 列按**累计消耗**排，不是日均消耗——分档前必须按日均消耗重排
2. **池污染**：电商表混入泡泡星冰乐（不在电商Top100）——分档前必须核对原始导出
3. **零消耗误判**：「日均消耗¥0」实为小数截断+污染池，三行业300条素材中0条日均消耗为0
4. **CPM跨池不可比**：不同任务池的CPM差异数量级巨大（¥83 vs ¥9904），只能在同任务池内比方向

**三行业差素材是三种不同的病（cc 同池验证结论）：**

| | 漫剧短剧 | 游戏 | 电商 |
|:---|:---|:---|:---|
| 3秒率断点 | 无（差档反超） | 最严重（-33%） | 有（-26%） |
| 核心病 | 互动结构性缺失（零分享率50%） | 首帧钩子不行 | 留存全程差+老化 |
| 第一优先 | 补剧情点+标题加正文 | 重做首帧 | 先查投放条件 |
| 别做啥 | 别改前3秒 | 别加长中后段 | 别重做3秒率已达标的 |

**评估纪律（cc 总结，后续归因分析必须遵守）：**
- 只在**同任务池内**比较素材优劣，跨任务/跨产品比会把出价/账户差异误读成素材差异
- 用**日均播放**和**投放前14天窗口**评估，不用累计值（差素材投放天数长82-96%，累计值掩盖低效）
- **CPM不做归因依据**（11个可比池只有5个方向为正；电商方向完全相反）
- 剔除脏数据行再算：播放数=0但有消耗的行、完播率缺失的行
- 互动绝对值必须和播放基数一起看；电商互动指标直接弃用（样本量不足）
