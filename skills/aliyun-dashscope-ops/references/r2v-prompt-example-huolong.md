## 版本A：快乐马 r2v 提示词

> model: happyhorse-1.1-r2v | 720P 9:16 10秒 watermark=false | 预估0.56元(4.5折)

### 适配规则
- 参考图引用：`[Image 1]` `[Image 2]` `[Image 3]`
- 台词：`男主说：xxx`（自然语言，不用英文双引号）
- 禁止条件：写在正向末尾（无negative_prompt参数）
- watermark默认true，必须显式设false关闭

### API JSON

```json
{
  "model": "happyhorse-1.1-r2v",
  "input": {
    "prompt": "...(见下方prompt)...",
    "media": [
      {"type": "reference_image", "url": "http://<GZ_HOST>/char_real.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/scene_livingroom.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/huolong_splash.jpg"}
    ]
  },
  "parameters": {"resolution": "720P", "ratio": "9:16", "duration": 10, "watermark": false}
}
```

## 版本B：wan3.0 提示词

> model: wan3.0-video | 720P 9:16 10秒 audio=true prompt_extend=false watermark=false | 预估5.4元(6折)

### 适配规则（从快乐马版本改写）
- 参考图引用：`[Image 1]` → `图1`，`[Image 2]` → `图2`，`[Image 3]` → `图3`
- 台词写法不变：`男主说：xxx`（两个模型都支持自然语言台词）
- 禁止条件：从独立"禁止"段落改成正向末尾的自然描述句
  - 快乐马版：`禁止把拉远写成或生成成推近；禁止...`
  - wan3.0版：`画面保持拉远不推近，5秒后不继续明显拉远，手机不换手不翻面...`
- **prompt_extend 必须设 false**：wan3.0默认true会智能改写你的prompt，精确时码和动作描述会被重写。手写精调prompt必须关掉。
- **audio 参数**：wan3.0有 `audio` 参数（默认true），快乐马没有该参数但**输出默认含音频**（0825实测出片带aac音轨）
- watermark：wan3.0默认false（不用管），快乐马默认true（必须显式关）
- 参考图media格式完全相同：都是 `{"type": "reference_image", "url": "..."}`

### API JSON

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "...(见下方prompt)...",
    "media": [
      {"type": "reference_image", "url": "http://<GZ_HOST>/char_real.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/scene_livingroom.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/huolong_splash.jpg"}
    ]
  },
  "parameters": {"resolution": "720P", "ratio": "9:16", "duration": 10, "audio": true, "prompt_extend": false, "watermark": false}
}
```

## 共用 prompt 内容（快乐马版，用 [Image N]）

```
[Image 1]中的年轻男性站在[Image 2]中的轻奢客厅里，面对镜头边走边讲，手中持一部黑色智能手机。

画面从近到远揭示完整人物和手机，信息密度逐步上升但表演保持克制。正面近景坐姿起幅，男主居中，头部中心约x=0.50W、y=0.18H，腿部裁切。0.000—5.000秒画面明显拉远，人物从坐姿近景连续过渡为全身中景，落幅头部中心约y=0.15H、人物可见框约0.55W×0.82H；5.000—10.050秒基本稳定，仅呼吸级漂移，绝对不是推近。

0.000秒男主坐姿前倾低位持机；0.500—1.500秒抬空闲手朝镜头招呼；2.000—5.000秒身体后移并连续站起，持续前走至10.050秒硬切；约3.000秒由同一持机手把亮屏手机举到画面右侧；5.000秒后全身站立，空闲手做开放式讲解。

手机屏幕显示[Image 3]中的火龙漫剧闪屏页内容：醒目艺术字火龙漫剧、白色卡通龙、粉色到蓝色渐变背景，完整保留原图图形和文字关系，禁止重绘篡改。[Image 3]只能位于物理手机显示区域，被手机圆角边框裁切，随手机姿态同步透视、缩放和轻微玻璃反光，不浮出手机、不溢出屏幕、不污染外壳手指人物和背景。0.000—约3.000秒手机低位斜持；约3.000秒后亮屏朝镜头并保持在画面右侧，手机尺寸朝向和持机手连续不变。

7.483—8.983秒中央x=0.25—0.77W、y=0.19—0.82H保持干净的后期页面覆盖区，不绘制帖子、播放页或悬浮UI；8.983秒后覆盖区清空。

同步生成中文男声：男性，25岁，音色清亮沉稳、低中频干净，语速偏慢、吐字清晰，每句之间自然停顿；兴奋但克制的熟人分享感，开头有招呼感，陈述尾音干脆落下。开头先停顿半秒，然后直接开口说台词，不说任何多余的字。男主说：喂你知道吗，现在看漫剧也能赚零花钱了，就是这个火龙漫剧，直接把福利拉满，用起来确实挺顺手的（2026-09-21 新规已删原句），平时看剧过程中，自动攒火龙币，妥妥的追剧自由啊（2026-09-21 新规已删原句）。

禁止把拉远写成或生成成推近；禁止5秒后继续明显拉远；禁止手机换手、翻面、漂浮、变形；禁止[Image 3]溢出屏幕或污染外壳手指人物背景；禁止把中央页面混进[Image 3]；禁止生成帖子、播放页、字幕、App图标贴纸或其他文字；禁止手机朝向错误、屏幕正反面反转、屏幕内容镜像、物理手机与悬浮页面混层、画中画挡住整张脸、手指覆盖屏幕主体；禁止多余的话、乱语、尾句复读、无意义张嘴。
```

## 从 Seedance 提示词适配的改动清单（通用，0825修正）

| Seedance 原版 | 快乐马 r2v | wan3.0 | 说明 |
|:---|:---|:---|:---|
| @图1/@图2/@图3 | [Image 1]/[Image 2]/[Image 3] | 图1/图2/图3 | 三套语法不能混用 |
| 彩铅三视图还原真人照片级写实 | 删除 | 删除 | DashScope不卡真人 |
| 负面词大段独立 | 合并到正向末尾（禁止...） | 合并到正向末尾（自然描述句） | 两个模型都无negative_prompt |
| 台词逐句时码 `0.500s"喂你知道吗"` | **整段写** `人物说：喂你知道吗，现在看...` | **整段写** 同快乐马 | 快乐马拆时码会乱语(0825实测) |
| 运动+运镜+场景时码 | 全部保留 | 全部保留 | 精确到0.1秒级，不粗化 |
| — | — | prompt_extend: false | wan3.0专属，手写prompt必须关 |
| — | — | audio: true | wan3.0专属，控制音频输出 |
| watermark默认？ | 默认true，必须设false | 默认false | 快乐马有水印，wan3.0没有 |

> ⚠️ **台词写法修正（0825实测血泪）**：原版铁律第1条"保留全部台词逐句时码"只适用于Seedance。快乐马/wan3.0必须整段写在一个"人物说："后面，不拆时码。逐句时码拆分导致快乐马后半段全乱语。

> ⚠️ **口播字数必须跟原片完全一致（0825翻车）**：V20原片镜1是71字9句。自作主张加16字到87字→语速从7.1飙到8.6字/秒。提交前逐字核对。

> ⚠️ **卖点词禁止降级（0825被骂）**：吊打同类/全部免费/现金提走/躺赚白嫖是核心卖点不能改不能删。

> ⚠️ **参考图必须传齐3张含闪屏页（0825翻车）**：V20原版传3张（人物+场景+闪屏页）。只传2张→手机屏空白。

> ⚠️ **wan3.0会自动加镜头切换（0825实测）**：即使prompt写了连续镜头仍会硬切。必须反复强调"一个连续物理镜头，不切画面，不跳镜，不换景别"。
