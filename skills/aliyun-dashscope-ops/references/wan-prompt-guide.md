# 万相视频生成官方提示词指南

> 来源：https://help.aliyun.com/zh/model-studio/text-to-video-prompt
> 抓取方法：广州机 curl + Python 剥 HTML 标签（jina reader 抓不到，help.aliyun.com 全 JS 渲染）
> 抓取时间：2026-08-25

## 适用范围

文生视频 / 图生视频(首帧) / 图生视频(首尾帧) / 参考生视频 的正向提示词写法。
适用于 wan2.7 / wan2.6 / wan2.5 系列。HappyHorse 和 wan3.0 参考图引用语法不同，见下方专门章节和 `references/happyhorse-wan3-prompt-errata.md`。

## 参考图引用语法（0825 官方文档+实测勘误）

**三个模型体系语法完全不同，不能混用：**

| 模型 | 引用语法 | 示例 |
|:---|:---|:---|
| HappyHorse R2V | `[Image 1]` `[Image 2]` | `[Image 1]中身着红色旗袍的女性` |
| Wan3.0 | `图1` `图2` / `视频1`（图和视频分别计数） | `视频1抱着图3，在图4的椅子上` |
| Seedance（火山） | `@图1` `@图2` | `@图1 人物参考` |
| wan2.7 r2v | `character1` `character2`（wan2.6）/ `图1`（wan2.7） | `character1在草地上蹦跳` |

⚠️ `@图1` 是火山 Seedance 专属语法，阿里模型不识别。
⚠️ `{台词}` 大括号是 Seedance 专属语法，阿里模型当普通字符处理。

## 基础公式（新手）

提示词 = 主体 + 场景 + 运动

- **主体**：主要表现对象（人、动物、物品、想象物体）
- **场景**：主体所处的环境（背景、前景，真实或虚构）
- **运动**：主体运动和非主体运动状态（静止、小幅、大幅、局部、整体动势）

## 进阶公式

提示词 = 主体（主体描述）+ 场景（场景描述）+ 运动（运动描述）+ 美学控制 + 风格化

- **主体描述**：外观特征细节，用形容词或短句列举。例："一位身着少数民族服饰的黑发苗族少女"
- **场景描述**：环境特征细节
- **运动描述**：幅度、速率、效果。例："猛烈地摇摆"、"缓慢地移动"
- **美学控制**：光源、光线环境、景别、视角、镜头、运镜
- **风格化**：画面风格。例："赛博朋克"、"勾线插画"、"废土风格"

## 图生视频公式（i2v，重要）

图已经确定了主体、场景与风格，提示词主要描述动态过程及运镜需求。

提示词 = 运动 + 运镜

- **运动描述**：结合图像中的元素描述其动态过程（奔跑、打招呼），用形容词控制程度与速度
- **运镜**：镜头运动要求（"镜头推进"、"镜头左移"、"固定镜头"）

## 声音公式（wan2.7/wan2.6/wan2.5）

提示词 = 主体 + 场景 + 运动 + 声音描述（人声/音效/背景音乐）

- **人声** = 角色说话的内容 + 情绪 + 语调 + 语速 + 音色 + 口音
  - 示例：一个男人在讲脱口秀，他说道："好好学习，天天向上"，语气轻松，语速适中，声音清亮，美式英文。
- **音效** = 音源材质 + 行为 + 环境音
  - 示例：一个玻璃小球从桌面掉在木质地面上，发出"砰"的声音，室内安静环境。
- **背景音乐** = 背景音乐/配乐 + 风格
  - 示例：雨夜，阴森窄小的走廊，尽头有一扇窗户，配有悬疑风格背景音乐。

## 多镜头公式（wan2.7/wan2.6）

提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容

- **总体描述**：概述视频内容、故事主题、叙述风格、核心情感
- **镜头序号**：每个镜头编号，如"镜头1 xxxx，镜头2 xxxx"或"镜头1[0-3秒]xxxx，镜头2[3-6秒]xxx"
- **时间戳**：标明每个镜头在视频中的具体时间范围
- **分镜内容**：每个分镜中角色的具体行为（动作、语言、表情、姿态）

示例：
> 这个故事以第三人称视角，讲述了一个关于放弃与重拾希望的短剧。
> 第1个镜头[0-3秒]一个男孩在操场的角落独自坐着，低头望着手中的信纸，随后轻轻叹气，眼神中透露出迷茫。
> 第2个镜头[4-6秒]硬切转场，固定机位，聚焦于男孩的眼睛，泪光闪烁，带着失落和无助。
> 第3个镜头[7-10秒]硬切转场，场景转至一间简朴的教室。一个女孩眼神温和而坚定，穿着朴素的衣着，面带温和而坚定的笑容，走到男孩的身边安慰他。

**单镜头控制**：想控制一镜到底，中文写"生成单镜头"，英文写"Generate single shot."

## 参考生视频公式（wan2.7/wan2.6 r2v）

wan2.7 提示词 = 参考指代 + 动作 + 场景 + 台词（可选）+ 背景音乐（可选）

### 参考指代（关键）
- 使用"图n"或"视频n"在提示词中指代参考文件，n为该文件在该类型中的序号
- 图和视频分别计数
- 三张图分别为图1、图2、图3，序号与上传顺序一致
- 只有一个参考时可简化为"参考图片"或"参考视频"
- 中文："图1"、"视频1"；英文："Image 1"、"Video 1"（空格，首字母大写）

### 画面内容描述
假设参考图1是一只猫，图2是一个房间：
- 写法①："图1在图2里玩耍"
- 写法②："图1的猫在图2的房间里玩耍"

### 台词
- 在提示词中写 `xx说："xxx"` → 模型保持该台词内容不变
- 不写台词 → 模型自由发挥添加台词
- 写"无台词" → 不生成台词（英文："No dialogue."）

### 背景音乐
- 不写 → 模型自行发挥
- 写"无背景音乐" → 不加BGM（英文："No background music."）

### wan2.6 r2v 差异
- wan2.6 用 `character1`、`character2` 引用参考主角（最多3个主角）
- 提示词 = 主角 + 动作 + 台词 + 场景
- 示例：character1在草地上蹦跳着玩耍，character2在旁边的一颗苹果树下弹奏钢琴，一颗苹果掉到了character2的头上，character1开心地指着character2说："你要变成科学家了！"

## 提示词优化技巧

1. **prompt_extend 参数**：启用后系统自动优化改写简短宽泛的提示词
2. **用 LLM 生成结构化提示词**：把公式作为 system message 给 qwen3.6-plus，让它生成结构清晰的提示词

## 跨模型提示词适配铁律（0825 用户三次纠正）

从 Seedance 提示词改写到快乐马/wan3.0 时：
1. **保留全部台词逐句时码**（0.5秒"喂你知道吗"格式）
2. **保留动作精确时码**（4.35秒躯干前压→4.5秒离座→5.0秒站直，不压缩为"第4.5秒起身"）
3. **保留摄影机运动细节**（后退速度比、侧移换位、不跳切）
4. **保留所有参考图引用**（场景图+闪屏图，不能只传人物图）
5. 只去掉彩铅相关内容和不支持的负面词
6. 快乐马时长上限5秒，台词按原时码截取不超时的部分
7. 需要多张参考图用 r2v（最多9张），不用 i2v（单图）
8. 提示词里必须逐张写明每张参考图的用途（锁人物/锁场景/锁屏内内容）

## 与 Seedance 提示词的关键差异

| 维度 | Seedance | 万相/DashScope |
|:---|:---|:---|
| 参考图引用 | `@图1` `@图2` `@图3` | HappyHorse: `[Image 1]`；Wan3.0: `图1`/`视频1` |
| 负面词 | 大段负面约束 | HappyHorse无negative_prompt参数；效果弱优先写正向末尾 |
| 彩铅绕检 | 必须写"彩铅三视图还原真人照片级写实" | 不需要（DashScope 不卡真人） |
| 台词写法 | 逐句时码+口型同步要求 | `xx说：xxx` 自然语言描述，模型保持台词不变 |
| 多镜头 | 不支持 | wan2.7支持（镜头1[0-3秒]xxx）；HappyHorse不支持 |
| 声音 | 不支持原生音频 | wan2.7支持人声+音效+BGM描述；HappyHorse不支持 |
| SD权重语法 | `(xxx:1.2)` 不适用 | **完全无效**，当普通文本，偶发画面乱字 |
| 英文双引号 | 不适用 | **极易把引号内文字渲染到画面**，避免使用 |
| 大括号台词 | `{台词}` 火山专属 | **普通字符**，不触发语音 |
| 外部音频驱动口型 | 不适用 | **不支持**外部wav驱动口型，只能模型内部生成 |

## 提示词实测坑（文档不写，来自大量调用统计）

1. **SD权重语法完全无效**：`(面部:1.3)` 不加权，当普通文本，偶发画面乱字
2. **英文双引号渲染字幕**：`"台词"` 极易把引号内文字渲染到画面上
3. **负向提示词效果弱**：禁止条件优先写正向提示词末尾
4. **HappyHorse无`{对白}`特殊解析**：大括号是普通字符，台词用自然语言`人物说：xxx`
5. **两个模型都不能上传外部wav驱动口型**：只能模型内部生成语音
