# 快乐马/wan3.0 r2v 提示词实测勘误（2026-08-25 血泪）

> 一次session跑7版S01翻车总结。每条都是实测得出的，文档不写。

## 一、台词必须整段写，禁止按逐句时码拆分

### 翻车过程

把V20原片9句台词按起声时码逐句分开写进prompt：
```
0.500到1.100秒：人物说：哎，跟你说个新发现。
1.100到3.000秒：人物说：现在刷漫剧也能顺手攒点零花钱小惊喜。
3.000到4.200秒：人物说：我说的就是火龙漫剧。
...
```

**快乐马r2v结果**：前3句勉强能听，第4句开始完全乱语：
- "敌人看瘀蛇的人有蜜药"
- "火药看清从洗了药"
- "等让的资金看去"

**wan3.0结果**：丢台词3句+乱语+卖点词被删。

### 修正写法（实测成功）

把全部台词写在一个`人物说：`后面，作为一整段连续文本：
```
人物说：喂你知道吗，现在看漫剧也能赚钱了，就是这个火龙漫剧，直接把福利拉满，用起来确实挺顺手的（2026-09-21 新规已删原句），平时看剧过程中，自动攒火龙币，妥妥的追剧自由啊（2026-09-21 新规已删原句），火龙币也能直接换成现金提走。
```

快乐马r2v用此写法：9句全念对、卖点全保留、不乱语。wan3.0用此写法：74字/10秒=7.4字/秒，语速正常。

### 根因

逐句时码拆分是Seedance专属写法（Seedance能按精确时码控制每句起声）。快乐马/wan3.0不支持这种粒度控制——拆开写让模型处理不了，整段写让模型自己分配节奏。

## 二、语速快的根因是字数不对齐，不是模型能力

| 版本 | 字数 | 时长 | 每秒字数 | 判定 |
|:---|:---|:---|:---|:---|
| V20原片(Seedance) | 71字 | 10.05s | 7.1 | 正常 |
| 快乐马v2(错误版) | 87字 | 10.1s | 8.6 | 太快 |
| wan3.0 v2(对齐版) | 74字 | 10.0s | 7.4 | 正常 |

快乐马v2语速快是因为多塞了16个字（混入了镜2的台词"全部免费看从开头追到大结局"）。口播稿必须与原片逐字对齐，不多塞不少写。

## 三、参考图必须3张全传（人物+场景+闪屏页）

V20原版Seedance传了3张参考图（@图1人物+@图2场景+@图3闪屏页），@图3在生成时直接贴入手机屏幕。

只传2张（人物+场景）会导致手机屏幕空白——闪屏页不是后期ffmpeg贴的，是生成阶段模型贴的。

## 四、wan3.0会自作主张切画面

wan3.0即使prompt写了运镜描述，仍会自己加景别切换（全景→特写→全景硬切）。必须在prompt里反复强调"一个连续物理镜头，不切画面，不跳镜，不换景别"。

## 五、复刻卖点词不能擅自降级

复刻铁律：客户指定卖点词不能改，换话术=换说法不是删卖点。

| 原片卖点词 | 错误降级 | 正确保留 |
|:---|:---|:---|
| 吊打同类 | "用起来确实有点意外" | 保留"用起来确实挺顺手的（2026-09-21 新规已删原句）" |
| 全部免费 | "从开头追到大结局更省心" | 保留"全部免费观看" |
| 现金提走 | "具体按当期规则来" | 保留"换成现金提走" |
| 躺赚白嫖 | "多领一份小福利" | 保留"妥妥的追剧自由啊（2026-09-21 新规已删原句）" |

## 六、提示词必须由GLM/codex出，Hermes不自产

本session所有提示词都是Hermes自己用terminal echo写的，跳过了GLM/codex外包规则，连翻7版全有问题。SOUL.md写"智力活外包"是软规则，没有物理闸拦Hermes自己写prompt——这是已知漏洞，待加guard检测prompt特征。

## 七、痛点版 vs 网赚版画面结构不同，提示词不能串模板（0827实战）

火龙漫剧有两版台词：
- **网赚版**（老版）：人物举手机展示闪屏页，传3张图（人物+场景+闪屏页），prompt写"手中持手机举在胸前，手机屏幕朝向镜头"
- **痛点版**（新版）：纯口播无手机，传2张图（人物+场景），prompt不写手机/闪屏页

翻车：GLM按网赚版模板写痛点版prompt，"手中持一部手机举在胸前，屏幕内显示[Image 3]"串了进来。出片人物举着手机，场景也变了。

**规则：**
1. 纯口播段不传@图3闪屏页，不写手机/举屏/闪屏页描述
2. 只传@图1人物+@图2场景，2张图
3. 动作段写"不持手机不举任何物品"，负面约束加"不要手持手机或任何物品"
4. 派GLM出prompt时任务书里必须写死：当前是痛点版还是网赚版，段几，是否持手机

## 八、声音调参三要素（0827实战）

快乐马r2v声音由prompt文字描述控制，没有独立音频参数。三要素：

| 问题 | v1写法 | v2修正 |
|:---|:---|:---|
| 语速慢 | "语速适中" | "语速明快，节奏紧凑" |
| 情绪弱 | 无情绪描述 | "情绪饱满，吐槽语气夸张，像短视频口播主播有爆发力" |
| 声音小 | 无音量描述 | "音量饱满，声音洪亮" |

v2出片后用户确认声音情绪改善明显。但快乐马音频固定24kHz，音质上限受限，"声音洪亮"只在相对范围内有效。
