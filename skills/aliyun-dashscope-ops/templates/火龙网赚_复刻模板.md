## 四、提示词写法（快乐马r2v — 实测成功版）

### 铁律
1. **台词整段写在一个"人物说："后面**，不按时码拆分。模型自决语速。（0825实测：拆分写法后半段乱语）
2. **不描述人物外观**——靠参考图锁定，只写"[Image 1]中的人物"。（0826用户三次纠正定案）
3. **卖点词不降级不改删**，原片怎么写就怎么写。（0825用户纠正）
4. 动作时码保留（运镜/起身/走位），但台词不嵌时码。
5. 禁止条款写在正向末尾（快乐马无negative_prompt参数）。
6. watermark必须显式设false。
7. 参考图上传后必须逐张MD5校验本地与公网一致。

### 提示词模板

```
[Image 1]中的人物坐在[Image 2]中的场景里，面对镜头，手中持一部亮屏手机。

画面从坐姿近景起幅，人物居中。0.000—6.800秒保持坐姿口播，表情自信从容，目光始终回到镜头。6.800—8.200秒身体重心前移，连续起身并站稳，摄影机只做轻微上摇保持头部构图。8.200—10.050秒左手把手机抬起到脸侧，向镜头走两步，摄影机沿同一轴线后退跟随，人物由中景落到中近景，手机不遮挡脸。手机亮屏但屏幕为纯净低对比占位，真实UI后期贴入。

9:16竖版，720x1280，30fps，50mm感，平视中景，照片级真人写实，天然肌肤质感。人物身份、发型、服装全程不变。

同步生成中文{男/女}声：{男/女}性，{年龄}岁，音色{描述}，语速适中，吐字清晰，每句之间自然停顿；开头先停顿半秒，然后直接开口说台词，不说任何多余的字。人物说：{整段台词原样填入}。

禁止无人空镜开头；禁止人物后置入画；禁止手机遮脸；禁止坐姿与走路跳变、忽然站起；禁止摄影机向前冲、环绕、横移、甩镜、俯拍或仰拍；禁止五官扭曲、人脸漂移、换人、发型服装变化；禁止过度美颜、塑料皮肤、手部畸形、多指、手机变形、肌体穿模；禁止生成内嵌字幕、文字、水印、Logo、二维码；禁止透视服装、夸张扭胯或性暗示动作；禁止多余的话、乱语、尾句复读、无意义张嘴。
```

### API JSON

```json
{
  "model": "happyhorse-1.1-r2v",
  "input": {
    "prompt": "...(上方prompt)...",
    "media": [
      {"type": "reference_image", "url": "http://<GZ_HOST>/人物三视图.png"},
      {"type": "reference_image", "url": "http://<GZ_HOST>/场景图.png"}
    ]
  },
  "parameters": {"resolution": "720P", "ratio": "9:16", "duration": 10, "watermark": false}
}
```

> 快乐马720P 10秒折后0.56元。wan3.0同规格折后5.4元（30fps+有声+语义强）。
> 注意：wan3.0会自行加镜头切换（0825实测），如需严格连续单镜头优先快乐马。

### wan3.0适配差异（仅3处）
- `[Image 1]` → `图1`，`[Image 2]` → `图2`
- 禁止条款改成正向末尾自然句："画面保持...不..."
- 加参数：`prompt_extend: false`、`audio: true`

## 五、参考图要求

### 人物三视图（@图1）
- 16:9横版，2560×1440
- 左1/3面部特写 + 右2/3三全身（正面/侧面/背面）
- 纯白背景，照片级写实，非CG非3D
- codex文生图：prompt显式写性别/排版/风格，出完vision自检

### 场景图（@图2）
- 9:16竖版，1440×2560
- 无人物、无文字、无Logo
- 预留UI贴片区（右侧或中央干净区）

### 闪屏页/UI素材（@图3，必传）
- 真实App闪屏页截图（火龙logo开屏页）
- 所有有人物的镜都传同一张，模型直接把闪屏页内容生成在手机屏里
- 不需要后期贴闪屏页/logo
- 动态切换的UI页（金币页/福利页/剧库页等）仍需后期ffmpeg贴入
- **防止溢出**：prompt必须写"[Image 3]仅作为手机屏幕内的显示内容，严禁出现在画面任何其他位置"（0826实测：不写约束模型会把闪屏页画到背景/墙壁上）

## 八、使用流程

1. **生图**：codex出3张角色三视图 + 3张场景图 → vision自检 → 用户确认
2. **传图**：scp到广州Caddy目录 → MD5校验
3. **生成**：4镜分别提交r2v（快乐马或wan3.0）→ 轮询 → 下载
4. **质检**：逐镜抽帧看人物/场景/语音
5. **合成**：4镜concat + 贴片 + 字幕 + 音频 → ffmpeg编码
6. **交付**：720×1280 MP4，无水印

## 九、踩坑记录

- 台词不能按时码拆分给快乐马，必须整段一个"人物说："（0825实测乱语）
- 卖点词不能擅自降级（0825被纠正：复刻=照抄，换话术≠删卖点）
- 口播字数必须跟原片完全一致（0825多塞16字→语速从7.1飙到8.6字/秒）
- 参考图必须传齐3张含闪屏页（0825只传2张→手机屏空白被骂"logo没放手机里"）
- 参考图MD5必须逐张校验（0825翻车3次：文件名≠内容）
- codex三视图必须显式写性别/排版/风格（0825翻车：出成女性连环画）
- 快乐马watermark默认true，必须显式设false
- wan3.0 prompt_extend必须设false，否则时码被智能改写打乱
- wan3.0会自行加镜头切换，不能用于要求连续单镜头的场景（0825实测）
- 新加坡直连DashScope被墙，必须SSH到广州执行curl
- 闪屏页/logo直接通过@图3生成在手机屏里，不后期贴；动态切换的UI页（金币页/福利页/剧库页等）仍需后期ffmpeg贴入
- r2v提示词禁止描述人物外观，只写"[Image 1]中的人物"+动作（0826用户三次纠正）
- **提示词必须codex出，Hermes禁止自写**（0825严重违纪：跳过codex自写6版提示词连翻6车，浪费时间和API费用）
- **DashScope付费API未入物理闸**（PAID_API_MARKERS缺dashscope.aliyuncs.com，SSH到广州调DashScope不被拦截）
- **发现正确做法后必须立即更新模板**（0826用户纠正：V20原版@图3闪屏页直接生成logo在手机屏里，但模板一直写"纯净占位后期贴入"没改，导致每次复刻都犯同样错误。"你模板是不是一直没改？"——模板不改=同错重复）
